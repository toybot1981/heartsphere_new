### 1. 响应式图片工具 ✅

#### 实现
- **文件**: `frontend/mobile/utils/responsiveImage.ts`
- **功能**:
  - 设备像素比检测
  - 屏幕尺寸检测
  - 设备类型检测（mobile/tablet/desktop）
  - 响应式图片URL生成
  - srcset字符串生成
  - 移动端图片尺寸优化

#### 核心函数

##### `getDevicePixelRatio()`
- 获取设备像素比（DPR）
- 支持1x、2x、3x等不同设备

##### `generateResponsiveImageUrl()`
- 根据设备像素比生成合适尺寸的图片URL
- 自动添加尺寸参数（w=xxx）

##### `generateSrcSet()`
- 生成srcset字符串
- 支持多个设备像素比（1x, 2x, 3x）

##### `generateResponsiveImageConfig()`
- 生成完整的响应式图片配置
- 包括src、srcset、sizes属性

##### `optimizeMobileImageSize()`
- 根据显示尺寸优化移动端图片
- 自动选择最合适的尺寸档位

### 2. MobileLazyImage组件增强 ✅

#### 更新内容
- **文件**: `frontend/mobile/components/MobileLazyImage.tsx`
- **新增功能**:
  - srcset支持
  - sizes属性支持
  - 响应式图片自动配置
  - 移动端图片尺寸优化

#### 新增Props
```typescript
interface MobileLazyImageProps {
  // ... 原有props
  enableResponsive?: boolean; // 是否启用响应式图片（默认true）
  purpose?: 'thumbnail' | 'small' | 'medium' | 'large' | 'xlarge'; // 图片用途
  displayWidth?: number; // 显示宽度（逻辑像素）
  displayHeight?: number; // 显示高度（逻辑像素）
}
```

#### 使用示例

##### 基本使用（自动响应式）
```typescript
<MobileLazyImage
  src="/images/avatar.jpg"
  alt="Avatar"
  purpose="medium" // 自动选择合适尺寸
/>
```

##### 指定显示尺寸
```typescript
<MobileLazyImage
  src="/images/avatar.jpg"
  alt="Avatar"
  displayWidth={200}
  displayHeight={200}
/>
```

##### 禁用响应式（使用原始URL）
```typescript
<MobileLazyImage
  src="/images/avatar.jpg"
  alt="Avatar"
  enableResponsive={false}
/>
```

## 📊 技术实现

### 1. srcset生成

#### 实现原理
```typescript
// 为不同设备像素比生成多个URL
const srcSet = generateSrcSet(originalUrl, 400, [1, 2, 3]);
// 结果: "url?w=400 1x, url?w=800 2x, url?w=1200 3x"
```

#### HTML输出
```html
<img
  src="/images/avatar.jpg?w=400"
  srcset="/images/avatar.jpg?w=400 1x, /images/avatar.jpg?w=800 2x, /images/avatar.jpg?w=1200 3x"
  sizes="100vw"
  alt="Avatar"
/>
```

### 2. sizes属性

#### 移动端
```html
sizes="100vw" <!-- 图片占满容器宽度 -->
```

#### 平板
```html
sizes="(max-width: 768px) 100vw, 50vw" <!-- 小屏100%，大屏50% -->
```

#### 桌面端
```html
sizes="(max-width: 1024px) 50vw, 25vw" <!-- 中屏50%，大屏25% -->
```

### 3. 设备像素比检测

#### 实现
```typescript
const dpr = window.devicePixelRatio || 1;
// iPhone 12: 2
// iPhone 12 Pro Max: 3
// 标准设备: 1
```

### 4. 移动端图片优化

#### 优化策略
1. **根据显示尺寸选择档位**
   - 显示100px → 选择thumbnail (100px)
   - 显示300px → 选择small (200px) 或 medium (400px)
   - 显示800px → 选择large (800px)

2. **根据设备像素比调整**
   - 逻辑像素 × 设备像素比 = 物理像素
   - 例如：200px × 2 = 400px（Retina设备）

3. **自动选择最接近的尺寸**
   - 避免加载过大的图片
   - 避免加载过小的图片（模糊）
