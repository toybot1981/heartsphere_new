### 2. Lighthouse性能测试

#### 使用Chrome DevTools

1. **打开Chrome DevTools**
   - 按 `F12` 或 `Cmd+Option+I` (Mac) / `Ctrl+Shift+I` (Windows)
   - 或右键点击页面 → "检查"

2. **打开Lighthouse标签**
   - 点击 "Lighthouse" 标签
   - 选择 "Mobile" 设备
   - 勾选 "Performance" 和其他需要的类别

3. **运行测试**
   - 点击 "Analyze page load" 按钮
   - 等待测试完成（约30-60秒）

4. **查看结果**
   - 查看性能分数
   - 查看Core Web Vitals指标
   - 查看优化建议

#### 使用命令行（需要安装lighthouse CLI）

```bash
# 安装lighthouse CLI
npm install -g lighthouse

# 运行测试
lighthouse http://localhost:3000/mobile.html --view --preset=mobile

# 生成报告
lighthouse http://localhost:3000/mobile.html --output=html --output-path=./lighthouse-report.html --preset=mobile
```

#### 关键指标说明

- **FCP (First Contentful Paint)**: 首次内容绘制时间
  - 目标: < 1.8秒
  - 优化: 减少关键资源大小、优化CSS加载

- **LCP (Largest Contentful Paint)**: 最大内容绘制时间
  - 目标: < 2.5秒
  - 优化: 优化图片加载、使用CDN、预加载关键资源

- **TTI (Time to Interactive)**: 可交互时间
  - 目标: < 3.8秒
  - 优化: 代码分割、懒加载、减少JavaScript执行时间

- **TBT (Total Blocking Time)**: 总阻塞时间
  - 目标: < 200ms
  - 优化: 减少长任务、代码分割、异步加载

- **CLS (Cumulative Layout Shift)**: 累积布局偏移
  - 目标: < 0.1
  - 优化: 设置图片尺寸、预留空间、避免动态插入内容

### 3. React DevTools Profiler分析

#### 安装React DevTools

1. **Chrome扩展**
   - 在Chrome Web Store搜索 "React Developer Tools"
   - 点击 "添加到Chrome"

2. **Firefox扩展**
   - 在Firefox Add-ons搜索 "React Developer Tools"
   - 点击 "添加到Firefox"

#### 使用Profiler

1. **打开React DevTools**
   - 按 `F12` 打开DevTools
   - 点击 "⚛️ Profiler" 标签

2. **开始录制**
   - 点击 "Record" 按钮（圆形红色按钮）
   - 在应用中执行操作（如导航、滚动、交互）
   - 点击 "Stop" 按钮停止录制

3. **分析结果**
   - 查看组件渲染时间
   - 识别性能瓶颈
   - 查看重渲染次数

#### 性能优化建议

- **识别慢组件**
  - 查找渲染时间 > 16ms的组件（60fps需要 < 16ms）
  - 查找重渲染次数过多的组件

- **优化策略**
  - 使用 `React.memo` 包装纯组件
  - 使用 `useMemo` 缓存计算结果
  - 使用 `useCallback` 缓存回调函数
  - 拆分大组件为小组件

#### 示例分析

```
组件渲染时间分析:
- MobileChatWindowScreen: 45ms (需要优化)
- MobileRealWorldScreen: 12ms ✅
- MobileSceneSelectionScreen: 8ms ✅
- MobileCharacterSelectionScreen: 15ms ✅

重渲染次数:
- MobileChatWindowScreen: 15次 (需要优化)
- MobileRealWorldScreen: 3次 ✅
```

### 4. Chrome DevTools Performance分析

#### 使用方法

1. **打开Performance标签**
   - 按 `F12` 打开DevTools
   - 点击 "Performance" 标签

2. **开始录制**
   - 点击 "Record" 按钮（圆形红色按钮）
   - 在应用中执行操作
   - 点击 "Stop" 按钮停止录制

3. **分析结果**
   - 查看主线程活动
   - 识别长任务（> 50ms）
   - 查看内存使用情况
   - 查看网络请求

#### 关键指标

- **Main Thread**: 主线程活动时间
  - 目标: < 3.8秒（TTI）
  - 优化: 减少JavaScript执行时间、使用Web Workers

- **Long Tasks**: 长任务数量
  - 目标: 尽可能少
  - 优化: 代码分割、异步加载、使用requestIdleCallback

- **Memory**: 内存使用
  - 目标: < 100MB（初始加载）
  - 优化: 清理事件监听器、避免内存泄漏
