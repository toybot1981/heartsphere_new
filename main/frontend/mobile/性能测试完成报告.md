### 2. Lighthouse测试

#### Chrome DevTools
1. 打开 `http://localhost:3000/mobile.html`
2. 按 `F12` 打开DevTools
3. 点击 "Lighthouse" 标签
4. 选择 "Mobile" 设备
5. 点击 "Analyze page load"

#### 命令行
```bash
# 安装lighthouse CLI
npm install -g lighthouse

# 运行测试
lighthouse http://localhost:3000/mobile.html --view --preset=mobile
```

## 📈 性能指标验证

### Core Web Vitals验证

#### FCP (First Contentful Paint)
- **目标**: < 1.8秒
- **验证方法**: Lighthouse测试
- **优化**: 减少关键资源大小、优化CSS加载

#### LCP (Largest Contentful Paint)
- **目标**: < 2.5秒
- **验证方法**: Lighthouse测试
- **优化**: 优化图片加载、使用CDN、预加载关键资源

#### TTI (Time to Interactive)
- **目标**: < 3.8秒
- **验证方法**: Lighthouse测试
- **优化**: 代码分割、懒加载、减少JavaScript执行时间

#### TBT (Total Blocking Time)
- **目标**: < 200ms
- **验证方法**: Lighthouse测试
- **优化**: 减少长任务、代码分割、异步加载

#### CLS (Cumulative Layout Shift)
- **目标**: < 0.1
- **验证方法**: Lighthouse测试
- **优化**: 设置图片尺寸、预留空间、避免动态插入内容

### Bundle大小验证

#### 初始加载大小
- **目标**: < 500KB
- **验证方法**: `npm run analyze:bundle`
- **优化**: 代码分割、懒加载、移除未使用的依赖

#### 最大chunk大小
- **目标**: < 300KB
- **验证方法**: `npm run analyze:bundle`
- **优化**: 拆分大chunk、使用动态导入

#### 总bundle大小
- **目标**: < 2MB
- **验证方法**: `npm run analyze:bundle`
- **优化**: 移除未使用的代码、使用tree-shaking、压缩资源
