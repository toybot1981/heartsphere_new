# 主题系统测试指南

## 测试范围

### 1. 基础功能测试

#### 1.1 主题初始化
- [ ] 应用启动时，默认使用"科技风格"主题
- [ ] 如果localStorage中有保存的主题，应该加载保存的主题
- [ ] `data-theme` 属性正确设置到 `<html>` 元素

#### 1.2 主题切换
- [ ] 在PC端设置界面可以切换主题
- [ ] 在移动端设置界面可以切换主题
- [ ] 主题切换即时生效，无需刷新页面
- [ ] 主题切换有平滑的过渡动画（200-300ms）

#### 1.3 主题持久化
- [ ] 选择的主题保存到localStorage
- [ ] 刷新页面后主题保持不变
- [ ] 关闭浏览器后重新打开，主题仍然保持

### 2. 视觉测试

#### 2.1 科技风格主题
- [ ] 背景色为深色（黑色、slate-950）
- [ ] 文字颜色为高对比度（白色、浅灰色）
- [ ] 主色调为indigo-600和purple-600
- [ ] 渐变效果正确显示
- [ ] 阴影效果符合科技感风格

#### 2.2 海天宁静主题
- [ ] 背景色为淡蓝色（#E8F4F8, #BFD9E8, #9FC9E0）
- [ ] 文字颜色为深灰蓝色（#2C3E50, #5A6C7D）
- [ ] 主色调为宁静蓝色（#7FB8D1, #9FC9E0）
- [ ] 渐变效果正确显示
- [ ] 阴影效果柔和

#### 2.3 移动端特殊效果（海天宁静主题）
- [ ] 场景选择页：云纹背景正确显示
- [ ] 心域连接页：星空背景正确显示（如果图片资源可用）
- [ ] 柔光星辰效果：动画流畅
- [ ] 大圆角白色浮动卡片：样式正确
- [ ] 半透明白色底部导航：样式正确

### 3. 组件测试

#### 3.1 已迁移组件
- [ ] Button组件：在不同主题下显示正确
- [ ] CharacterCard组件：背景、文字、按钮样式正确
- [ ] SceneCard组件：背景、文字、按钮样式正确

#### 3.2 渐变效果
- [ ] `.gradient-button` 类在不同主题下显示正确
- [ ] `.gradient-primary` 类在不同主题下显示正确
- [ ] `.gradient-bg` 类在不同主题下显示正确

### 4. 兼容性测试

#### 4.1 向后兼容
- [ ] 现有的 `[data-theme="dark"]` 映射到 `tech` 主题
- [ ] 现有组件在没有主题系统时仍然正常工作
- [ ] 温度感系统变量在不同主题下正常工作

#### 4.2 错误处理
- [ ] localStorage不可用时，使用默认主题
- [ ] 无效的主题ID时，使用默认主题
- [ ] CSS变量缺失时，有合理的fallback值

### 5. 性能测试

#### 5.1 主题切换性能
- [ ] 主题切换在100ms内完成
- [ ] 主题切换时没有明显的UI卡顿
- [ ] 大量组件更新时性能良好

#### 5.2 动画性能
- [ ] 过渡动画流畅（60fps）
- [ ] 柔光星辰动画不影响性能
- [ ] 主题切换动画不卡顿

### 6. 无障碍性测试

#### 6.1 颜色对比度
- [ ] 文字与背景对比度符合WCAG AA标准（至少4.5:1）
- [ ] 链接文字与背景对比度符合标准
- [ ] 按钮文字与背景对比度符合标准

#### 6.2 可访问性
- [ ] 主题选择器支持键盘导航
- [ ] 主题选择器有适当的ARIA标签
- [ ] 屏幕阅读器可以正确识别主题选择器

### 7. 跨平台测试

#### 7.1 PC端
- [ ] Chrome浏览器：主题切换正常
- [ ] Firefox浏览器：主题切换正常
- [ ] Safari浏览器：主题切换正常
- [ ] Edge浏览器：主题切换正常

#### 7.2 移动端
- [ ] iOS Safari：主题切换正常
- [ ] Android Chrome：主题切换正常
- [ ] 移动端特殊效果正确显示

## 测试步骤

### 步骤1：基础功能测试
1. 打开应用，检查默认主题
2. 打开设置界面，切换到"海天宁静"主题
3. 检查界面是否立即更新
4. 刷新页面，检查主题是否保持
5. 关闭浏览器，重新打开，检查主题是否保持

### 步骤2：视觉测试
1. 切换到"科技风格"主题，检查所有页面
2. 切换到"海天宁静"主题，检查所有页面
3. 检查移动端特殊效果（如果适用）

### 步骤3：组件测试
1. 检查已迁移的组件在不同主题下的表现
2. 检查渐变效果在不同主题下的表现
3. 检查按钮、卡片等组件的交互效果

### 步骤4：兼容性测试
1. 检查向后兼容性
2. 测试错误处理场景
3. 检查温度感系统兼容性

### 步骤5：性能测试
1. 使用浏览器开发者工具检查主题切换性能
2. 检查动画性能
3. 检查大量组件更新时的性能

### 步骤6：无障碍性测试
1. 使用颜色对比度检查工具
2. 使用键盘导航测试
3. 使用屏幕阅读器测试
