# Figma 到项目 UX 规范自检清单

从 Figma 导出或还原界面时，请对照本清单与 **openspec/project.md** 中的 **UX Design Guidelines**、**多风格支持** 做自检，确保实现与项目规范一致。

## 色彩与主题

- [ ] 颜色使用 **CSS 变量**（`var(--color-name)`），无硬编码色值
- [ ] 渐变、阴影、圆角等设计属性通过 CSS 变量或主题 Token 定义
- [ ] 组件支持主题切换，主题切换时样式正确更新

## 间距与布局

- [ ] 间距遵循 **8px 基准**，使用统一间距等级
- [ ] 布局与设计稿层级、对齐一致

## 字体

- [ ] 字体族、字号、字重、行高符合项目 **字体系统** 规范
- [ ] 文本颜色使用主题变量

## 组件与交互

- [ ] 按钮、表单、卡片、导航等符合 **组件设计** 规范
- [ ] 动画、反馈、状态符合 **交互设计** 规范
- [ ] PC/Mobile 分别遵循 **PC端规范** / **Mobile端规范**（布局、导航、触摸、安全区域等）

## 无障碍

- [ ] 关键交互支持键盘导航
- [ ] 语义与可访问性符合 WCAG AA 要求（如适用）

**完整规范**：见 `openspec/project.md` 中「UX Design Guidelines」「多风格支持」及 `docs/12-开发指南/开发规范/心域开发指南.md` 第 3.5 节。
