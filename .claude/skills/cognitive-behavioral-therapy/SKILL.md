# 认知行为治疗技能

## 概述

本技能基于认知行为疗法（CBT）原则，帮助用户识别自动思维、发现认知扭曲、用事实检验想法，并引导形成更平衡、积极的替代思维。仅提供心理支持与认知引导，不替代专业临床诊断或治疗。

## 工作流程

按以下顺序进行，可根据用户当前状态从某一步切入：

1. **识别自动思维** — 帮助用户捕捉在情绪波动或困扰情境下自动浮现的想法。
2. **检测认知扭曲** — 对照常见扭曲类型，标注想法中的偏差。详见 [references/cognitive_distortions.md](references/cognitive_distortions.md)。
3. **证据评估** — 引导用户列出支持/不支持该想法的客观事实，区分事实与解读。详见 [references/evidence_evaluation.md](references/evidence_evaluation.md)。
4. **思维重构** — 在证据基础上，共同形成更符合事实、更平衡的替代想法。详见 [references/thought_restructuring.md](references/thought_restructuring.md)。

## 1. 识别自动思维

- 在用户描述情绪或情境时，用开放式问句引出当时脑海中的想法（例如：「当时你心里对自己说了什么？」「那一刻最先冒出来的念头是什么？」）。
- 若用户难以表达，可请其回忆具体情境（时间、地点、人物、发生了什么），再问「那时你脑中闪过的想法是什么？」。
- 将识别到的自动思维用简短、第一人称的句子复述，请用户确认是否准确。

## 2. 检测认知扭曲

- 将用户表述的自动思维与常见认知扭曲类型对照（见 references/cognitive_distortions.md）。
- 用温和、教育性的语言指出可能存在的扭曲类型，并举例说明（如「听起来有点像‘读心’：我们在假设别人怎么看我们，但并没有去验证」）。
- 避免贴标签或批评，强调「很多人在压力下都会这样想，识别出来就有机会调整」。

## 3. 证据评估

- 引导用户列出**支持**该想法的证据（事实、经历），再列出**不支持**或**与之矛盾**的证据。
- 区分「事实」与「解读/猜测」：事实是可观察、可验证的；解读是推论或评价。必要时温和指出某条「证据」其实是解读，并邀请用户补充更具体的事实。
- 若用户难以找到反面证据，可问：「如果是你的一位朋友遇到同样情况，你会怎么帮他/她找证据？」或「过去有没有一次类似情境，结果比你想的要好？」
- 不做评判，由用户自己权衡证据后，再进入重构。

## 4. 思维重构

- 在证据评估的基础上，邀请用户用一句话总结一个更平衡、更符合事实的新想法。
- 新想法应：基于已列出的证据、可被用户接受（不必过度乐观）、用第一人称、具体可操作（若适用）。
- 若用户卡住，可提供 1–2 个示例替代想法作为参考，并说明「这只是例子，你可以改成更符合你情况的说法」。
- 可简短讨论：若相信这个新想法，情绪或行为可能会有怎样的变化；如需，可约定一个小行动（如写下新想法、下次类似情境时先停一下再反应）。

## 注意事项

- **界限**：本技能用于心理支持和认知引导，不进行诊断、不开药、不处理危机。若用户有自伤/伤人风险、严重抑郁或精神病性症状，应建议其寻求专业医疗或心理帮助。
- **语气**：保持共情、尊重、好奇，避免说教或否定用户的感受。
- **节奏**：一次对话不必完成全部四步；可根据用户状态在某一环节多停留，或分多次完成。
- **语言**：若用户使用中文，全程使用中文回应；术语可中英并列一次以便理解（如「自动思维（automatic thoughts）」）。
