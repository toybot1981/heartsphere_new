# 思维重构

用于在「思维重构」步骤中，在证据评估的基础上引导用户形成更平衡、更符合事实的替代想法。

## 原则

- **基于证据**：新想法应能由前面列出的证据（尤其是反面证据）支撑，而不是空洞的「往好处想」。
- **可接受**：用户能真心认同，不必强求过度乐观；「比之前平衡一点」即可。
- **第一人称、具体**：用「我」开头，尽量具体（如「我这次没做好，但不代表我每次都做不好」比「事情会变好」更易操作）。
- **可操作（若适用）**：若与行为有关，可顺带一句「下次我可以……」以增强掌控感。

## 引导话术示例

- 「根据我们刚才列出的证据，你会怎么用一句话重新描述这件事？」
- 「如果让你在‘原来的想法’和‘完全相反的想法’之间取一个更平衡的说法，你会怎么说？」
- 「假如你相信‘（总结一个更平衡的想法）’，你的情绪或接下来想做的事会有什么不同？」
- 「你愿意把这句话记下来，下次类似情况时提醒自己吗？」

## 替代想法示例（仅供示范，需根据用户情境改写）

| 原自动思维 | 替代想法示例 |
|------------|-----------------------------|
| 我搞砸了，我就是个失败者。 | 我这次没做好，不代表我这个人失败；我可以从这次里学到东西，下次改进。 |
| 他们肯定觉得我很烦。 | 我不知道他们心里怎么想，我也没有去问过；我可以选择相信他们的反馈，或者找机会确认一下。 |
| 我永远找不到工作。 | 目前还没找到，但‘永远’是预测不是事实；我可以继续投递并改进简历和面试。 |
| 我不应该犯这种错。 | 我犯了错，会尽量弥补和改正；人都会犯错，重要的是接下来怎么做。 |
| 没有人会喜欢我。 | 我有时会这么觉得，但‘没有人’是过度概括；已经有人表达过关心/认可，我可以多看看这些。 |

## 若用户难以自己说出替代想法

- 可根据证据评估的结果，给出 1–2 个**示例**替代想法，并明确说明：「这只是举例，你可以改成更符合你情况的说法，或者换一种你更顺口的表达。」
- 问：「上面哪一句比较接近你现在的感受？你想怎么改一改？」
- 避免代用户「定稿」；最终那句平衡想法最好由用户自己说出或认可。

## 与行为或后续步骤的衔接

- 可简短讨论：若相信这个新想法，情绪或行为可能会有怎样的变化。
- 若用户愿意，可约定一个小行动，例如：把新想法写下来、下次类似情境时先停一下再反应、或和信任的人分享一次练习结果。
- 不强制「作业」；强调「你愿意试就试，我们下次可以再聊」。
