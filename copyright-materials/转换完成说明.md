## 📝 下一步操作

### 1. 在Word中打开文档

1. 打开Microsoft Word
2. 打开转换后的Word文档（如`main-client/软件说明书.docx`）

### 2. 设置页眉页脚

参考 `Word模板设置说明.md` 进行设置：

**页眉设置：**
- 双击页眉区域
- 输入软件名称（如"数字生命主客户端系统"）
- 字体：黑体，小五号，左对齐

**页脚设置：**
- 双击页脚区域
- 输入："第 " + 页码 + " 页，共 " + 总页数 + " 页"
- 字体：宋体，小五号，居中

### 3. 调整格式

1. 设置页边距：上下2.54cm，左右3.17cm
2. 设置字体：正文宋体小四，标题黑体
3. 设置行距：1.5倍行距
4. 设置段落：首行缩进2字符

### 4. 扩展内容

参考 `内容扩展模板.md` 扩展内容至60页（前30页+后30页）：

- 添加详细的章节描述
- 添加架构图和流程图说明
- 添加功能截图说明
- 添加使用案例
- 添加技术细节说明

### 5. 提取源代码文档

使用提取脚本：

```bash
cd copyright-materials

# 提取源代码
./extract-source-code.sh main-client
./extract-source-code.sh admin-platform
./extract-source-code.sh mentis
./extract-source-code.sh education-edition

# 转换为Word格式
pandoc main-client/源代码提取.md -o main-client/源代码文档.docx --wrap=none
```
