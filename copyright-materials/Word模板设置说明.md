# Word模板设置说明

本文档说明如何创建和设置Word模板文件，用于软件说明书的格式转换。

## 创建Word模板

### 步骤1：创建新Word文档

1. 打开Microsoft Word
2. 创建新文档
3. 保存为 `template.docx`

### 步骤2：设置页面格式

#### 页边距设置

1. 点击"布局"选项卡
2. 点击"页边距"按钮
3. 选择"自定义边距"
4. 设置：
   - 上：2.54cm
   - 下：2.54cm
   - 左：3.17cm
   - 右：3.17cm
   - 装订线：0cm
   - 装订线位置：左

#### 纸张设置

1. 点击"布局"选项卡
2. 点击"纸张大小"按钮
3. 选择"A4"（21cm × 29.7cm）

### 步骤3：设置字体格式

#### 正文格式

1. 选中正文内容
2. 设置字体：
   - 中文字体：宋体
   - 西文字体：Times New Roman
   - 字号：小四号（12pt）
   - 行距：1.5倍行距
   - 段前：0.5行
   - 段后：0.5行
   - 首行缩进：2字符

#### 标题格式

**标题1（一级标题）**：
- 字体：黑体
- 字号：二号（22pt）
- 加粗：是
- 对齐：居中
- 段前：12pt
- 段后：6pt

**标题2（二级标题）**：
- 字体：黑体
- 字号：三号（16pt）
- 加粗：是
- 对齐：左对齐
- 段前：6pt
- 段后：3pt

**标题3（三级标题）**：
- 字体：黑体
- 字号：四号（14pt）
- 加粗：是
- 对齐：左对齐
- 段前：3pt
- 段后：3pt

### 步骤4：设置页眉

#### 插入页眉

1. 点击"插入"选项卡
2. 点击"页眉"按钮
3. 选择"空白"样式

#### 设置页眉内容

1. 在页眉左侧输入软件名称（如"数字生命主客户端系统"）
2. 设置字体：
   - 字体：黑体
   - 字号：小五号（9pt）
   - 对齐：左对齐

#### 页眉格式示例

```
数字生命主客户端系统                    [可选：章节名称]
```

### 步骤5：设置页脚

#### 插入页脚

1. 点击"插入"选项卡
2. 点击"页脚"按钮
3. 选择"空白"样式

#### 设置页码

1. 在页脚中输入："第 "
2. 点击"插入" > "页码" > "当前位置" > "普通数字"
3. 输入：" 页，共 "
4. 点击"插入" > "文档部件" > "域"
5. 选择"NumPages"域
6. 输入：" 页"

#### 页码格式示例

```
第 1 页，共 60 页
```

#### 设置页脚字体

1. 选中页脚内容
2. 设置字体：
   - 字体：宋体
   - 字号：小五号（9pt）
   - 对齐：居中

### 步骤6：设置样式

#### 创建样式

1. 点击"开始"选项卡
2. 点击"样式"窗格
3. 点击"新建样式"按钮
4. 创建以下样式：
   - 正文样式
   - 标题1样式
   - 标题2样式
   - 标题3样式
   - 代码样式（Courier New，小四号）

#### 样式设置

**正文样式**：
- 名称：正文
- 字体：宋体，小四号
- 段落：首行缩进2字符，1.5倍行距

**代码样式**：
- 名称：代码
- 字体：Courier New，小四号
- 段落：无缩进，单倍行距
- 背景：浅灰色（可选）

### 步骤7：保存模板

1. 点击"文件" > "另存为"
2. 选择文件类型："Word模板 (*.dotx)"
3. 文件名：`template.dotx`
4. 保存位置：`copyright-materials/` 目录

或者保存为普通Word文档：
1. 点击"文件" > "另存为"
2. 选择文件类型："Word文档 (*.docx)"
3. 文件名：`template.docx`
4. 保存位置：`copyright-materials/` 目录

## 使用模板转换文档

### 使用Pandoc转换

```bash
cd copyright-materials
pandoc main-client/软件说明书.md -o main-client/软件说明书.docx \
  --reference-doc=template.docx \
  --toc \
  --toc-depth=2
```

### 使用转换脚本

```bash
cd copyright-materials
chmod +x convert-all.sh
./convert-all.sh
```

## 转换后检查清单

转换完成后，请检查以下项目：

### 格式检查

- [ ] 页边距符合要求（上下2.54cm，左右3.17cm）
- [ ] 字体格式符合要求（正文宋体小四，标题黑体）
- [ ] 行距符合要求（1.5倍行距）
- [ ] 段落格式符合要求（首行缩进2字符）

### 页眉页脚检查

- [ ] 页眉包含软件名称
- [ ] 页眉字体为黑体小五号
- [ ] 页脚包含页码（第 X 页，共 Y 页）
- [ ] 页脚字体为宋体小五号
- [ ] 页码格式正确
- [ ] 页码从第1页开始

### 内容检查

- [ ] 目录自动生成（如有）
- [ ] 标题格式正确
- [ ] 图表清晰可见
- [ ] 内容完整无遗漏

### 页数检查

- [ ] 文档页数达到60页（前30页+后30页）
- [ ] 前30页内容完整
- [ ] 后30页内容完整

## 手动调整

如果转换后的格式不完全符合要求，可以手动调整：

### 调整页眉

1. 双击页眉区域
2. 修改软件名称
3. 调整字体和格式
4. 点击"关闭页眉和页脚"

### 调整页脚

1. 双击页脚区域
2. 检查页码格式
3. 调整字体和格式
4. 点击"关闭页眉和页脚"

### 调整样式

1. 选中需要调整的内容
2. 在"开始"选项卡中选择样式
3. 或手动设置字体和段落格式

## 常见问题

### 问题1：页码格式不正确

**解决方案**：
1. 双击页脚区域
2. 删除现有页码
3. 按照步骤5重新插入页码

### 问题2：页眉不显示

**解决方案**：
1. 检查是否启用了页眉
2. 在"插入"选项卡中重新插入页眉
3. 检查页眉设置

### 问题3：字体格式不正确

**解决方案**：
1. 选中需要调整的内容
2. 在"开始"选项卡中设置字体
3. 或使用样式功能统一设置

### 问题4：页数不足60页

**解决方案**：
1. 参考"内容扩展模板.md"扩展内容
2. 添加详细的章节描述
3. 添加图表和示例
4. 添加技术细节说明
