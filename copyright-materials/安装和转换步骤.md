# 安装和转换步骤

本文档提供详细的安装和转换步骤，帮助您完成软件说明书的格式转换工作。

## 第一步：安装Pandoc工具

### macOS安装

```bash
# 使用Homebrew安装（推荐）
brew install pandoc

# 验证安装
pandoc --version
```

### Windows安装

1. 访问Pandoc官网：https://pandoc.org/installing.html
2. 下载Windows安装包
3. 运行安装程序
4. 验证安装：打开命令提示符，运行 `pandoc --version`

### Linux安装

```bash
# Ubuntu/Debian
sudo apt-get install pandoc

# CentOS/RHEL
sudo yum install pandoc

# 或使用conda
conda install -c conda-forge pandoc
```

### 备选方案：使用Typora

如果不想安装Pandoc，可以使用Typora（图形界面工具）：

1. 下载Typora：https://typora.io/
2. 安装Typora
3. 打开Markdown文件
4. 点击"文件" > "导出" > "Word (.docx)"

## 第二步：创建Word模板文件

由于无法自动创建Word模板，您需要手动创建：

### 方法1：使用提供的模板设置说明

1. 打开Microsoft Word
2. 创建新文档
3. 按照 `Word模板设置说明.md` 中的步骤设置：
   - 页边距：上下2.54cm，左右3.17cm
   - 字体：正文宋体小四，标题黑体
   - 行距：1.5倍行距
   - 页眉：软件名称（黑体小五，左对齐）
   - 页脚：页码"第 X 页，共 Y 页"（宋体小五，居中）
4. 保存为 `template.docx` 在 `copyright-materials/` 目录

### 方法2：使用默认转换（无模板）

如果没有模板，Pandoc会使用默认格式转换。转换后可以在Word中手动调整格式。

## 第三步：转换软件说明书

### 使用脚本批量转换

```bash
cd /Users/admin/Workspace/heartsphere_new/copyright-materials

# 如果有模板
./convert-all.sh

# 如果没有模板，脚本会使用默认格式转换
```

### 手动转换单个文件

```bash
cd copyright-materials

# 转换主客户端
pandoc main-client/软件说明书.md -o main-client/软件说明书.docx --toc --toc-depth=2

# 转换管理平台
pandoc admin-platform/软件说明书.md -o admin-platform/软件说明书.docx --toc --toc-depth=2

# 转换Mentis
pandoc mentis/软件说明书.md -o mentis/软件说明书.docx --toc --toc-depth=2

# 转换教育版
pandoc education-edition/软件说明书.md -o education-edition/软件说明书.docx --toc --toc-depth=2
```

### 使用Typora转换

1. 打开Typora
2. 打开 `main-client/软件说明书.md`
3. 点击"文件" > "导出" > "Word (.docx)"
4. 保存为 `main-client/软件说明书.docx`
5. 重复以上步骤转换其他产品

## 第四步：提取源代码文档

### 使用脚本提取

```bash
cd copyright-materials

# 提取主客户端源代码
./extract-source-code.sh main-client

# 提取管理平台源代码
./extract-source-code.sh admin-platform

# 提取Mentis源代码
./extract-source-code.sh mentis

# 提取教育版源代码
./extract-source-code.sh education-edition
```

**注意**：脚本会生成Markdown格式的源代码文档，需要进一步：
1. 检查提取的源代码
2. 去除敏感信息
3. 转换为Word格式
4. 调整格式，确保每页不少于50行代码

### 手动提取源代码

1. 参考各产品的 `源代码文档说明.md`
2. 从代码库中选择代表性源代码文件
3. 按照前30页+后30页的要求组织
4. 复制到Word文档中
5. 设置为等宽字体（Courier New）
6. 添加文件路径和功能说明

## 第五步：在Word中调整格式

转换完成后，需要在Word中调整格式：

### 1. 打开转换后的Word文档

### 2. 设置页眉

1. 双击页眉区域
2. 输入软件名称（如"数字生命主客户端系统"）
3. 设置字体：黑体，小五号
4. 设置对齐：左对齐
5. 点击"关闭页眉和页脚"

### 3. 设置页脚

1. 双击页脚区域
2. 点击"插入" > "页码" > "当前位置" > "普通数字"
3. 在页码前后输入："第 " 和 " 页，共 "
4. 点击"插入" > "文档部件" > "域" > "NumPages"
5. 输入：" 页"
6. 设置字体：宋体，小五号
7. 设置对齐：居中
8. 点击"关闭页眉和页脚"

### 4. 检查格式

- 页边距：上下2.54cm，左右3.17cm
- 字体：正文宋体小四，标题黑体
- 行距：1.5倍行距
- 段落：首行缩进2字符

### 5. 检查页数

- 文档总页数：60页（前30页+后30页）
- 如果不足，需要扩展内容

## 第六步：扩展内容

## 常见问题

### Q1: Pandoc安装失败怎么办？

**A**: 可以使用Typora或其他Markdown转Word工具，或者使用在线转换工具。

### Q2: 没有Word模板文件怎么办？

**A**: 可以先用默认格式转换，然后在Word中手动调整格式。

### Q3: 转换后的格式不正确怎么办？

**A**: 在Word中手动调整格式，参考 `Word模板设置说明.md`。

### Q4: 内容页数不足60页怎么办？

**A**: 参考 `内容扩展模板.md` 扩展内容，添加详细的描述、图表和示例。

### Q5: 源代码文档如何提取？

**A**: 使用 `extract-source-code.sh` 脚本或手动从代码库中选择代表性源代码文件。
