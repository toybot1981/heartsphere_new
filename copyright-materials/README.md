# 软件著作权申请材料

本目录包含HeartSphere项目四个核心产品的软件著作权申请材料。

**快速开始**：请先阅读 `开始转换工作.md` 了解如何开始转换工作。

## 材料要求

根据国家版权局软件著作权登记要求，每个产品需要准备：

1. **软件说明书**（60页，前30页+后30页）
   - 使用Markdown模板编写内容
   - 完成后转换为Word文档格式（.docx）
   - 标准页眉页脚，页码规范

2. **源代码文档**（60页，前30页+后30页，每页不少于50行）
   - 选择代表性源代码
   - 包含前端核心组件和后端核心服务
   - 添加必要的代码注释和说明
   - 格式化为Word文档

3. **软件基本信息**
   - 软件名称、版本号
   - 开发语言、框架
   - 运行环境要求
   - 开发完成日期

## 使用说明

1. 参考各产品的`软件基本信息.txt`填写基本信息
2. 使用`软件说明书.md`模板编写软件说明书内容
3. 根据`源代码文档说明.md`选择代表性源代码
4. 将所有Markdown文档转换为Word格式（.docx）
5. 确保格式符合官方要求（页眉页脚、页码等）

## 注意事项

- 所有材料需围绕"数字生命"主题
- 技术描述需准确、完整
- 源代码需具有代表性，体现核心功能
- 格式需符合官方申请要求
- 确保各产品材料的一致性
