# 软件说明书格式转换指南

本文档说明如何将Markdown格式的软件说明书转换为符合软件著作权申请要求的Word文档格式。

## 转换步骤

### 步骤1：安装转换工具

推荐使用以下工具之一：

1. **Pandoc**（推荐）
   ```bash
   # macOS
   brew install pandoc
   
   # 或使用conda
   conda install -c conda-forge pandoc
   ```

2. **Typora**（图形界面）
   - 下载安装：https://typora.io/
   - 支持直接导出为Word格式

3. **在线转换工具**
   - CloudConvert: https://cloudconvert.com/md-to-docx
   - Convertio: https://convertio.co/md-docx/

### 步骤2：使用Pandoc转换

```bash
# 基本转换命令
pandoc input.md -o output.docx

# 带格式的转换（推荐）
pandoc input.md -o output.docx \
  --reference-doc=template.docx \
  --toc \
  --toc-depth=2

# 批量转换所有产品
cd copyright-materials
for dir in main-client admin-platform mentis education-edition; do
  pandoc "$dir/软件说明书.md" -o "$dir/软件说明书.docx" \
    --reference-doc=template.docx \
    --toc \
    --toc-depth=2
done
```

### 步骤3：创建Word模板

创建一个Word模板文件（template.docx），包含：
- 标准页眉：软件名称（如"数字生命主客户端系统"）
- 标准页脚：页码（格式：第 X 页，共 Y 页）
- 标准字体：正文使用宋体，标题使用黑体
- 标准行距：1.5倍行距
- 标准页边距：上下2.54cm，左右3.17cm

## 内容扩展要求

### 1. 扩展至60页

当前Markdown文档约10-15页（A4纸，标准格式），需要扩展至60页（前30页+后30页）。

**扩展方法：**
1. 添加详细的章节内容
2. 添加架构图和流程图说明
3. 添加功能截图说明
4. 添加代码示例
5. 添加使用案例
6. 添加技术细节说明

### 2. 前30页内容建议

- 引言部分（3-5页）
  - 开发背景（详细描述）
  - 开发目的（详细描述）
  - 开发意义（详细描述）
  - 市场需求分析
  - 技术发展趋势

- 功能描述部分（15-20页）
  - 每个功能的详细描述
  - 功能的技术实现
  - 功能的使用场景
  - 功能的优势特点
  - 功能截图说明（占位符）

- 系统架构部分（5-7页）
  - 整体架构图说明
  - 前端架构详细说明
  - 后端架构详细说明
  - 数据流设计详细说明
  - 安全设计详细说明

### 3. 后30页内容建议

- 运行环境部分（5-7页）
  - 硬件要求详细说明
  - 软件环境详细说明
  - 网络环境详细说明
  - 安装部署说明
  - 配置说明

- 技术特点部分（10-15页）
  - 技术创新点详细说明
  - 技术优势详细说明
  - 技术难点和解决方案
  - 技术选型理由
  - 性能优化策略

- 使用示例部分（5-8页）
  - 详细的使用场景
  - 操作步骤说明
  - 常见问题解答
  - 最佳实践建议

## 页眉页脚设置

### 页眉设置

**格式**：
- 左侧：软件名称（如"数字生命主客户端系统"）
- 右侧：章节名称（可选）

**设置方法**：
1. 在Word中插入页眉
2. 输入软件名称
3. 设置字体：黑体，小五号
4. 设置对齐：左对齐

### 页脚设置

**格式**：
- 居中：第 X 页，共 Y 页

**设置方法**：
1. 在Word中插入页脚
2. 插入页码字段
3. 设置格式：第 {PAGE} 页，共 {NUMPAGES} 页
4. 设置字体：宋体，小五号
5. 设置对齐：居中

## 格式要求

### 字体要求

- **标题1**：黑体，二号，加粗，居中
- **标题2**：黑体，三号，加粗，左对齐
- **标题3**：黑体，四号，加粗，左对齐
- **正文**：宋体，小四号，左对齐
- **代码**：Courier New，小四号

### 段落要求

- **行距**：1.5倍行距
- **段前**：0.5行
- **段后**：0.5行
- **首行缩进**：2字符（正文）

### 页边距要求

- **上**：2.54cm
- **下**：2.54cm
- **左**：3.17cm
- **右**：3.17cm

### 页码要求

- **位置**：页脚居中
- **格式**：第 X 页，共 Y 页
- **字体**：宋体，小五号
- **起始页**：从第1页开始

## 自动化脚本

### 批量转换脚本（bash）

```bash
#!/bin/bash
# convert-all.sh - 批量转换所有软件说明书

# 设置Pandoc模板路径
TEMPLATE="template.docx"

# 转换函数
convert_doc() {
    local input="$1"
    local output="$2"
    
    if [ -f "$input" ]; then
        echo "转换: $input -> $output"
        pandoc "$input" -o "$output" \
            --reference-doc="$TEMPLATE" \
            --toc \
            --toc-depth=2 \
            --standalone
    else
        echo "错误: 文件不存在 $input"
    fi
}

# 转换所有产品
cd copyright-materials

convert_doc "main-client/软件说明书.md" "main-client/软件说明书.docx"
convert_doc "admin-platform/软件说明书.md" "admin-platform/软件说明书.docx"
convert_doc "mentis/软件说明书.md" "mentis/软件说明书.docx"
convert_doc "education-edition/软件说明书.md" "education-edition/软件说明书.docx"

echo "转换完成！"
```

### 使用说明

1. 创建Word模板文件 `template.docx`
2. 安装Pandoc工具
3. 运行转换脚本：
   ```bash
   chmod +x convert-all.sh
   ./convert-all.sh
   ```

## 注意事项

1. **内容真实性**：确保所有技术描述准确，基于实际代码和功能
2. **格式规范**：严格按照要求格式化文档
3. **图表清晰**：确保图表清晰可见，标注完整
4. **页码正确**：确保页码格式正确，从第1页开始
5. **版本一致**：确保所有文档中的版本号和时间信息一致
