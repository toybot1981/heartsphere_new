# 数字生命Mentis智能体系统使用示例

本文档提供Mentis智能体系统的使用示例，帮助理解系统功能和使用方式。

## 1. 系统登录

### 1.1 登录系统

用户可以通过以下方式登录Mentis系统：

1. 打开Mentis登录页面
2. 输入用户名和密码
3. 点击"登录"按钮
4. 系统验证用户信息，成功后跳转到主界面

## 2. 智能对话

### 2.1 开始对话

用户可以通过对话与智能体交互：

1. 登录系统后，进入主界面
2. 在对话输入框中输入任务描述或问题
3. 点击"发送"按钮或按Enter键发送消息
4. 系统分析任务意图，生成任务执行计划
5. 用户可以查看任务执行计划，确认或修改

### 2.2 查看任务计划

系统会为任务生成执行计划：

1. 用户输入任务后，系统生成任务执行计划
2. 任务计划以流程图形式展示
3. 用户可以查看每个步骤的详细信息
4. 用户可以修改任务计划（添加、删除、修改步骤）
5. 用户确认任务计划后，系统开始执行

## 3. 任务执行

### 3.1 创建任务

用户可以创建新任务：

1. 在任务列表页面点击"创建任务"按钮
2. 填写任务信息：
   - 任务名称
   - 任务描述（自然语言）
   - 任务类型（API调用、文件操作、GUI自动化等）
3. 点击"保存"按钮创建任务
4. 系统自动生成任务执行计划

### 3.2 执行任务

用户可以执行任务：

1. 在任务列表中选择要执行的任务
2. 点击"执行"按钮开始执行任务
3. 系统按照任务计划执行任务步骤
4. 用户可以实时查看任务执行进度
5. 任务执行完成后，显示执行结果

### 3.3 查看任务结果

用户可以查看任务执行结果：

1. 在任务列表中选择已执行的任务
2. 点击"查看结果"按钮查看执行结果
3. 可以查看任务执行的详细日志
4. 可以查看任务执行的输出结果
5. 可以导出任务执行结果

## 4. VM管理

### 4.1 创建VM

用户可以创建虚拟机：

1. 在VM管理页面点击"创建VM"按钮
2. 填写VM信息：
   - VM名称
   - 镜像类型（Ubuntu、Windows等）
   - VM规格（CPU、内存、磁盘）
3. 点击"创建"按钮创建VM
4. 系统调用Docker API创建容器
5. VM创建成功后，可以在VM列表中查看

### 4.2 查看VM屏幕

用户可以查看VM屏幕：

1. 在VM列表中选择要查看的VM
2. 点击"查看屏幕"按钮
3. 系统打开VM屏幕查看窗口
4. 用户可以实时查看VM桌面
5. 用户可以在VM屏幕中执行操作（通过操作执行功能）

### 4.3 在VM中执行操作

用户可以在VM中执行操作：

1. 在VM列表中选择要操作的VM
2. 点击"执行操作"按钮
3. 输入要执行的命令或操作
4. 点击"执行"按钮执行操作
5. 系统在VM中执行操作，返回执行结果

### 4.4 删除VM

用户可以删除VM：

1. 在VM列表中选择要删除的VM
2. 点击"删除"按钮
3. 确认删除操作
4. 系统调用Docker API删除容器
5. VM删除后，资源被释放

## 5. GUI自动化

### 5.1 录制操作

用户可以录制GUI操作：

1. 在GUI自动化页面点击"录制"按钮
2. 系统开始录制操作
3. 用户在目标应用中执行操作（点击、输入等）
4. 系统记录操作序列
5. 点击"停止录制"按钮停止录制
6. 系统生成操作脚本

### 5.2 回放操作

用户可以回放录制的操作：

1. 在GUI自动化页面选择要回放的操作脚本
2. 点击"回放"按钮开始回放
3. 系统自动执行录制的操作序列
4. 用户可以实时查看回放过程
5. 回放完成后，显示执行结果

### 5.3 编辑操作脚本

用户可以编辑操作脚本：

1. 在GUI自动化页面选择要编辑的操作脚本
2. 点击"编辑"按钮打开编辑器
3. 可以添加、删除、修改操作步骤
4. 可以设置操作参数（等待时间、重试次数等）
5. 点击"保存"按钮保存修改

## 6. 会话管理

### 6.1 创建会话

用户可以创建新会话：

1. 在主界面点击"新建会话"按钮
2. 填写会话信息：
   - 会话名称
   - 会话描述
3. 点击"创建"按钮创建会话
4. 会话创建后，可以在会话中执行任务

### 6.2 切换会话

用户可以在不同会话之间切换：

1. 在会话列表中选择要切换的会话
2. 点击"进入会话"按钮
3. 系统加载会话数据和历史记录
4. 用户可以在会话中继续执行任务

### 6.3 查看会话历史

用户可以查看会话历史：

1. 在会话列表中选择要查看的会话
2. 点击"查看历史"按钮
3. 系统显示会话中的所有对话和任务
4. 可以搜索和筛选历史记录
5. 可以导出会话历史

## 7. 执行日志

### 7.1 查看执行日志

用户可以查看任务执行日志：

1. 在执行日志页面查看日志列表
2. 可以查看任务执行的详细日志
3. 可以搜索和筛选日志
4. 可以查看日志详情（错误信息、堆栈跟踪等）
5. 支持导出日志为文本文件

### 7.2 日志分析

用户可以分析执行日志：

1. 在执行日志页面选择要分析的日志
2. 点击"分析"按钮开始分析
3. 系统分析日志，识别错误和问题
4. 生成分析报告，提供改进建议
5. 可以帮助用户优化任务执行计划

## 8. 常见问题

### 8.1 任务执行失败怎么办？

1. 查看任务执行日志，了解失败原因
2. 检查任务执行计划是否正确
3. 检查外部工具和API是否可用
4. 修改任务计划后重新执行
5. 如果问题持续，联系技术支持

### 8.2 VM创建失败怎么办？

1. 检查Docker服务是否正常运行
2. 检查系统资源是否充足（内存、磁盘等）
3. 检查VM镜像是否存在
4. 查看VM创建日志，了解失败原因
5. 如果问题持续，联系技术支持

### 8.3 GUI自动化操作不准确怎么办？

1. 检查目标应用的界面是否变化
2. 尝试使用不同的元素识别策略
3. 添加等待时间，确保元素加载完成
4. 使用元素缓存，提高识别速度
5. 如果问题持续，联系技术支持

**说明**：本文档为使用示例，实际使用中可能因版本更新而有所变化。详细使用说明请参考系统帮助文档。
