软件名称：数字生命Mentis智能体系统
软件简称：Mentis智能体
版本号：V1.0
开发完成日期：2025年1月

开发语言：
- 前端：TypeScript、JavaScript
- 后端：Java 17

开发框架：
- 前端：React 18+、Vite、Material-UI (MUI)
- 后端：Spring Boot 3.2.0、Spring Data JPA
- Docker Java API（用于VM管理）

运行环境：
- 操作系统：Windows 7/10/11、macOS 10.14+、Linux（Ubuntu 18.04+）
- Web浏览器：Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
- 数据库：MySQL 8.0+
- Java运行环境：JDK 17或更高版本
- Node.js：18.0或更高版本
- Docker（用于VM管理）

硬件要求：
- CPU：四核2.4GHz或更高
- 内存：8GB RAM或更高（推荐16GB）
- 硬盘：10GB可用空间
- 网络：宽带互联网连接

软件功能概述：
数字生命Mentis智能体系统是一个超级智能体平台，提供智能对话、任务执行、会话管理、VM（虚拟机）管理、GUI自动化执行等功能。系统支持复杂的任务执行流程，可以调用外部工具和API，执行GUI自动化操作，为用户提供强大的智能助手功能。

主要技术特点：
1. 智能对话系统，支持复杂的任务理解和执行
2. 任务执行引擎，支持多步骤任务流程
3. VM（虚拟机）管理，支持Docker容器管理
4. GUI自动化执行，支持图形界面操作自动化
5. 会话管理，支持多会话并行处理
6. 执行日志记录和查看
7. 任务流程图可视化
8. 与主客户端AI服务集成
