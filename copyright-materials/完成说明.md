## 使用指南

### 步骤1：扩展软件说明书

1. 打开各产品的`软件说明书.md`文件
2. 参考项目文档补充详细内容
3. 添加架构图和流程图
4. 添加功能截图和示例
5. 确保内容达到60页（前30页+后30页）

### 步骤2：准备源代码文档

1. 参考`源代码文档说明.md`中的文件建议
2. 从代码库中选择代表性源代码文件
3. 按照前30页+后30页的要求组织代码
4. 添加必要的代码注释和说明
5. 确保每页不少于50行代码

### 步骤3：格式转换

1. 将Markdown文档转换为Word文档
2. 添加标准页眉页脚（软件名称、页码）
3. 调整格式（字体、行距、页边距等）
4. 检查文档完整性

### 步骤4：质量检查

1. 检查所有文档格式是否符合要求
2. 检查页码、页眉页脚是否规范
3. 检查源代码文档行数是否符合要求（≥50行/页）
4. 检查技术描述的准确性和完整性
5. 统一术语和命名规范
6. 交叉检查各产品材料的一致性

## 注意事项

1. **内容真实性**：确保所有技术描述准确、完整，基于实际代码和功能
2. **格式规范**：严格按照官方申请要求格式化文档
3. **代码完整性**：确保源代码片段完整，能够体现功能逻辑
4. **敏感信息**：去除敏感信息（API密钥、密码等）
5. **版本一致性**：确保所有文档中的版本号和时间信息一致
