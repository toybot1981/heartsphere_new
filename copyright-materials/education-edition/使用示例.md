# 数字生命教育版系统使用示例

本文档提供教育版系统的使用示例，帮助理解系统功能和使用方式。

## 1. 学生端使用

### 1.1 学生登录

学生可以通过以下方式登录系统：

1. 打开教育版登录页面
2. 选择"学生登录"选项
3. 输入学号和密码
4. 点击"登录"按钮
5. 系统验证学生信息，成功后跳转到学生端主页

### 1.2 AI对话学习

学生可以通过AI对话学习新知识：

1. 在学生端主页点击"AI对话"菜单
2. 选择要对话的数字生命体角色
3. 在对话输入框中输入问题或学习内容
4. 点击"发送"按钮发送消息
5. 数字生命体通过AI生成回复，帮助学生学习
6. 对话历史会保存，学生可以查看历史对话

### 1.3 场景创建学习

学生可以创建学习场景进行学习：

1. 在学生端主页点击"场景学习"菜单
2. 点击"创建场景"按钮
3. 填写场景信息（场景名称、描述等）
4. 在场景中创建数字生命体角色
5. 与角色对话，学习相关知识
6. 场景学习数据会记录，用于生成学习报告

### 1.4 作业管理

学生可以查看和提交作业：

1. 在学生端主页点击"作业"菜单
2. 系统显示作业列表，包含待完成和已完成作业
3. 点击作业查看作业详情（作业要求、截止时间等）
4. 完成作业后，点击"提交"按钮提交作业
5. 教师批改后，学生可以查看批改结果和评语

### 1.5 课程学习

学生可以学习课程内容：

1. 在学生端主页点击"课程"菜单
2. 系统显示课程列表，包含已报名和可选课程
3. 点击课程进入课程学习页面
4. 可以查看课程内容、完成学习任务
5. 学习进度会记录，教师可以查看

### 1.6 心理咨询

学生可以进行心理咨询：

1. 在学生端主页点击"心理咨询"菜单
2. 可以查看心理咨询师列表
3. 点击"预约咨询"按钮预约咨询时间
4. 到预约时间后，可以进行在线心理咨询
5. 咨询记录会保存，家长和教师可以查看（如需要）

## 2. 教师端使用

### 2.1 教师登录

教师可以通过以下方式登录系统：

1. 打开教育版登录页面
2. 选择"教师登录"选项
3. 输入教师账号和密码
4. 点击"登录"按钮
5. 系统验证教师信息，成功后跳转到教师端主页

### 2.2 学生管理

教师可以管理班级学生：

1. 在教师端主页点击"学生管理"菜单
2. 系统显示学生列表，包含学生基本信息
3. 可以查看学生的详细信息（学习情况、作业完成情况等）
4. 可以编辑学生信息（修改个人信息、重置密码等）
5. 可以查看学生的学习报告和数据分析

### 2.3 课程管理

教师可以创建和管理课程：

1. 在教师端主页点击"课程管理"菜单
2. 点击"创建课程"按钮
3. 填写课程信息（课程名称、描述、内容等）
4. 可以编辑课程内容，添加学习任务
5. 课程创建后，可以发布给学生
6. 可以查看课程的学习情况（报名人数、完成情况等）

### 2.4 作业管理

教师可以创建和批改作业：

1. 在教师端主页点击"作业管理"菜单
2. 点击"创建作业"按钮
3. 填写作业信息（作业名称、要求、截止时间等）
4. 作业创建后，可以发布给学生
5. 学生提交作业后，教师可以批改作业
6. 可以查看作业的提交情况、完成情况等统计数据

### 2.5 进度监控

教师可以监控学生学习进度：

1. 在教师端主页点击"进度监控"菜单
2. 可以查看班级学生的学习进度
3. 可以查看学生的学习数据（学习时长、完成情况等）
4. 可以分析学习数据，生成学习报告
5. 可以导出学习数据为Excel文件

## 3. 家长端使用

### 3.1 家长登录

家长可以通过以下方式登录系统：

1. 打开教育版登录页面
2. 选择"家长登录"选项
3. 输入家长账号和密码
4. 点击"登录"按钮
5. 系统验证家长信息，成功后跳转到家长端主页

### 3.2 学习报告

家长可以查看孩子的学习报告：

1. 在家长端主页点击"学习报告"菜单
2. 系统显示孩子的学习报告（学习时长、完成情况、成绩等）
3. 可以查看不同时间段的学习数据
4. 可以查看详细的学习统计（每日学习时长、完成作业数等）
5. 可以导出学习报告为PDF文件

### 3.3 作业状态

家长可以查看孩子的作业完成情况：

1. 在家长端主页点击"作业状态"菜单
2. 系统显示孩子的作业列表
3. 可以查看作业的完成情况、提交时间、批改结果等
4. 可以查看作业的详细内容和评语
5. 可以督促孩子完成未完成的作业

### 3.4 时间控制

家长可以设置孩子的使用时间限制：

1. 在家长端主页点击"时间控制"菜单
2. 可以设置每日使用时间限制（如2小时）
3. 可以设置使用时间段（如晚上8点后禁止使用）
4. 可以查看孩子的实际使用时间
5. 使用时间达到限制后，系统会自动限制使用

### 3.5 内容控制

家长可以设置内容访问权限：

1. 在家长端主页点击"内容控制"菜单
2. 可以设置孩子可以访问的内容类型
3. 可以设置禁止访问的内容（关键词、分类等）
4. 可以查看孩子的访问记录
5. 违规内容访问会被阻止并通知家长

### 3.6 情感总结

家长可以查看孩子的情感状态总结：

1. 在家长端主页点击"情感总结"菜单
2. 系统显示孩子的情感状态分析
3. 可以查看孩子的情感趋势（积极、消极等）
4. 可以查看心理咨询记录（如有）
5. 可以关注孩子的心理健康状况

## 4. 常见问题

### 4.1 学生忘记密码怎么办？

1. 在登录页面点击"忘记密码"链接
2. 输入学号和注册时使用的邮箱
3. 系统发送密码重置邮件
4. 点击邮件中的链接重置密码
5. 或者联系教师重置密码

### 4.2 家长如何查看孩子的作业？

1. 家长登录家长端
2. 点击"作业状态"菜单
3. 系统显示孩子的所有作业
4. 点击作业查看作业详情和批改结果

### 4.3 教师如何批量批改作业？

1. 在作业管理页面选择要批改的作业
2. 点击"批量批改"按钮
3. 系统显示作业列表，可以批量评分和添加评语
4. 批改完成后，点击"保存"按钮保存批改结果

### 4.4 如何导出学习报告？

1. 在学习报告页面点击"导出"按钮
2. 选择导出格式（PDF、Excel等）
3. 系统生成报告文件，可以下载到本地
4. 报告包含完整的学习数据和图表
