# 源代码文档说明

## 要求

根据软件著作权申请要求，源代码文档需要：
- 共60页（前30页+后30页）
- 每页不少于50行代码
- 包含代表性源代码，体现软件核心功能
- 添加必要的代码注释和说明

## 源代码选择原则

### 前30页源代码（主要功能模块）

建议选择以下核心模块的源代码：

1. **前端核心组件**（约10页）
   - 学生端页面（`frontend-edu/src/pages/student/`）
   - 教师端页面（`frontend-edu/src/pages/teacher/`）
   - 家长端页面（`frontend-edu/src/pages/parent/`）
   - AI对话组件
   - 作业管理组件
   - 课程管理组件

2. **前端服务层**（约5页）
   - API服务（`frontend-edu/src/services/`）
   - 学生API服务
   - 教师API服务
   - 课程API服务

3. **后端核心服务**（约10页）
   - Controller层（`edu/backend/src/main/java/com/heartsphere/edu/.../controller/`）
     - 学生Controller
     - 教师Controller
     - 课程Controller
     - 作业Controller
   - Service层（`edu/backend/src/main/java/com/heartsphere/edu/.../service/`）
     - 学生Service
     - 教师Service
     - 课程Service
     - 作业Service

4. **后端数据层**（约5页）
   - Repository层
   - Entity层

### 后30页源代码（辅助功能）

建议选择以下辅助功能模块的源代码：

1. **工具类和工具函数**（约10页）
   - 前端工具函数（`frontend-edu/src/utils/`）
   - 后端工具类
   - 公共组件（`frontend-edu/src/components/common/`）

2. **配置和初始化**（约5页）
   - 前端配置文件（`frontend-edu/vite.config.ts`等）
   - 后端配置类
   - 应用配置文件

3. **权限和安全**（约10页）
   - 权限管理相关代码
   - 安全配置类
   - JWT认证相关代码
   - 多角色权限控制代码

4. **数据处理和DTO**（约5页）
   - DTO类
   - 类型定义

## 注意事项

1. **代码格式**：保持代码格式规范，包含必要的注释
2. **敏感信息**：去除敏感信息（API密钥、密码等）
3. **完整性**：确保代码片段完整，能够体现功能逻辑
4. **注释说明**：添加必要的注释，说明代码功能
5. **文件名**：在文档中标注源代码文件名和路径

## 文档格式

源代码文档需要：
1. 使用等宽字体（如Courier New）
2. 保持代码缩进格式
3. 添加代码块说明（功能、文件路径等）
4. 每页不少于50行代码
5. 转换为Word文档格式后，确保格式正确

## 生成步骤

1. 从代码库中选择代表性源代码文件
2. 按照前30页+后30页的要求组织代码
3. 添加必要的代码注释和说明
4. 格式化为Word文档（.docx）
5. 检查每页代码行数（≥50行）
6. 添加页眉页脚和页码
