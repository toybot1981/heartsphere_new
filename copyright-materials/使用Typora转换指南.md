# 使用Typora转换指南

由于Pandoc安装遇到Homebrew配置问题，推荐使用Typora进行格式转换。Typora是图形界面工具，操作简单，转换质量好。

## 第一步：下载安装Typora

1. 访问Typora官网：https://typora.io/
2. 点击"Download"按钮
3. 选择macOS版本下载
4. 打开下载的.dmg文件
5. 将Typora拖拽到Applications文件夹
6. 打开Typora（首次打开可能需要允许）

## 第二步：转换软件说明书

### 转换主客户端

1. 打开Typora
2. 点击"文件" > "打开"
3. 选择文件：`copyright-materials/main-client/软件说明书.md`
4. 等待文件加载完成
5. 点击"文件" > "导出" > "Word (.docx)"
6. 保存为：`copyright-materials/main-client/软件说明书.docx`
7. 点击"保存"

### 转换其他产品

重复以上步骤转换其他产品：

- `admin-platform/软件说明书.md` → `admin-platform/软件说明书.docx`
- `mentis/软件说明书.md` → `mentis/软件说明书.docx`
- `education-edition/软件说明书.md` → `education-edition/软件说明书.docx`

## 第三步：在Word中调整格式

转换完成后，需要在Word中调整格式：

### 1. 打开Word文档

1. 打开Microsoft Word
2. 打开转换后的Word文档（如`main-client/软件说明书.docx`）

### 2. 设置页眉

1. 双击页眉区域（页面顶部）
2. 输入软件名称："数字生命主客户端系统"
3. 选中文字，设置字体：
   - 字体：黑体
   - 字号：小五号（9pt）
   - 对齐：左对齐
4. 点击"关闭页眉和页脚"（或双击正文区域）

### 3. 设置页脚

1. 双击页脚区域（页面底部）
2. 输入："第 "
3. 点击"插入" > "页码" > "当前位置" > "普通数字"
4. 输入：" 页，共 "
5. 点击"插入" > "文档部件" > "域"
6. 选择"NumPages"域，点击"确定"
7. 输入：" 页"
8. 选中页脚文字，设置字体：
   - 字体：宋体
   - 字号：小五号（9pt）
   - 对齐：居中
9. 点击"关闭页眉和页脚"

### 4. 调整页面格式

1. 点击"布局"选项卡
2. 点击"页边距" > "自定义边距"
3. 设置：
   - 上：2.54cm
   - 下：2.54cm
   - 左：3.17cm
   - 右：3.17cm
4. 点击"确定"

### 5. 调整字体格式

**正文格式：**
1. 按Ctrl+A全选（或Cmd+A）
2. 设置字体：
   - 中文字体：宋体
   - 西文字体：Times New Roman
   - 字号：小四号（12pt）
3. 设置段落：
   - 行距：1.5倍行距
   - 段前：0.5行
   - 段后：0.5行
   - 首行缩进：2字符

**标题格式：**
- 标题1：黑体，二号（22pt），居中
- 标题2：黑体，三号（16pt），左对齐
- 标题3：黑体，四号（14pt），左对齐

### 6. 检查页数

1. 查看文档底部状态栏的页数
2. 如果不足60页，需要扩展内容
3. 参考 `内容扩展模板.md` 扩展内容

## 第四步：提取源代码文档

### 使用脚本提取

```bash
cd /Users/admin/Workspace/heartsphere_new/copyright-materials

# 提取主客户端源代码
./extract-source-code.sh main-client

# 提取其他产品
./extract-source-code.sh admin-platform
./extract-source-code.sh mentis
./extract-source-code.sh education-edition
```

### 转换为Word格式

1. 打开Typora
2. 打开提取的源代码文档（如`main-client/源代码提取.md`）
3. 点击"文件" > "导出" > "Word (.docx)"
4. 保存为：`main-client/源代码文档.docx`
5. 在Word中打开，设置为等宽字体（Courier New）
6. 调整格式，确保每页不少于50行代码

## Typora的优势

1. **图形界面**：操作简单，无需命令行
2. **实时预览**：可以实时查看Markdown效果
3. **转换质量好**：转换后的Word文档格式良好
4. **支持多种格式**：支持导出为Word、PDF、HTML等
5. **无需配置**：安装后即可使用

## 常见问题

### Q1: Typora是免费的吗？

**A**: Typora是付费软件，但有试用期。如果需要免费方案，可以使用在线转换工具。

### Q2: 转换后的格式不正确怎么办？

**A**: 在Word中手动调整格式，参考 `Word模板设置说明.md`。

### Q3: 如何批量转换？

**A**: Typora不支持批量转换，需要逐个文件转换。或者使用Pandoc脚本批量转换。

### Q4: 转换后页数不足怎么办？

**A**: 参考 `内容扩展模板.md` 扩展内容，添加详细的描述、图表和示例。
