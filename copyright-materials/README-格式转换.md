# 格式转换快速开始

本文档提供格式转换的快速开始指南。

## 快速开始

### 1. 安装转换工具

**推荐使用Pandoc：**

```bash
# macOS
brew install pandoc

# 验证安装
pandoc --version
```

**或使用Typora（图形界面）：**
- 下载：https://typora.io/
- 支持直接导出Word格式

### 2. 创建Word模板

1. 打开Microsoft Word
2. 参考 `Word模板设置说明.md` 创建模板
3. 保存为 `template.docx`（放在 `copyright-materials/` 目录）

### 3. 转换软件说明书

**使用脚本批量转换：**
```bash
cd copyright-materials
./convert-all.sh
```

**或手动转换单个文件：**
```bash
pandoc main-client/软件说明书.md -o main-client/软件说明书.docx \
  --reference-doc=template.docx \
  --toc \
  --toc-depth=2
```

### 4. 提取源代码文档

**使用脚本提取：**
```bash
cd copyright-materials
./extract-source-code.sh main-client
```

**或手动提取：**
1. 参考 `源代码文档提取指南.md`
2. 选择代表性源代码文件
3. 组织为前30页+后30页
4. 转换为Word格式

### 5. 调整格式

1. 在Word中打开转换后的文档
2. 按照 `Word模板设置说明.md` 调整格式
3. 添加页眉页脚
4. 检查每页行数

### 6. 内容扩展

1. 参考 `内容扩展模板.md` 扩展内容
2. 添加架构图、流程图、功能截图
3. 确保达到60页（前30页+后30页）

### 7. 质量检查

1. 使用 `格式转换完成检查清单.md` 进行检查
2. 确保所有格式符合要求
3. 确保内容完整准确
