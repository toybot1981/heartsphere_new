# 源代码文档提取指南

本文档说明如何从代码库中提取代表性源代码，生成符合软件著作权申请要求的源代码文档（60页，前30页+后30页，每页不少于50行）。

## 提取要求

### 基本要求

- **页数要求**：共60页（前30页+后30页）
- **行数要求**：每页不少于50行代码
- **格式要求**：Word文档格式（.docx）
- **字体要求**：等宽字体（如Courier New）
- **注释要求**：包含必要的代码注释和说明

### 内容要求

- **前30页**：主要功能模块的源代码
- **后30页**：辅助功能、工具类等的源代码
- **代表性**：选择的源代码应具有代表性，体现软件核心功能
- **完整性**：代码片段应完整，能够体现功能逻辑

## 提取步骤

### 步骤1：选择源代码文件

参考各产品的`源代码文档说明.md`文件，选择代表性源代码文件。

**选择原则：**
1. 核心功能模块代码
2. 关键技术实现代码
3. 具有独创性的算法或逻辑
4. 前后端关键组件

### 步骤2：组织源代码

按照前30页+后30页的要求组织源代码：

**前30页内容建议：**
- 前端核心组件（约10页）
- 前端服务层（约5页）
- 后端核心服务（约10页）
- 后端数据层（约5页）

**后30页内容建议：**
- 工具类和工具函数（约10页）
- 配置和初始化（约5页）
- 数据处理和DTO（约10页）
- 异常处理和安全（约5页）

### 步骤3：格式化源代码

#### 代码格式要求

1. **字体**：等宽字体（Courier New）
2. **字号**：小四号（12pt）
3. **行距**：单倍行距
4. **缩进**：保持代码原有缩进
5. **注释**：保留代码注释，必要时添加说明

#### 代码块说明

每个代码块前应添加说明：

```
// 文件路径：frontend/src/pages/ChatPage.tsx
// 功能说明：AI对话页面组件，实现用户与数字生命体的对话交互
// 关键功能：
//   1. 对话消息显示
//   2. 对话输入和发送
//   3. 对话历史管理
//   4. 上下文管理

[源代码内容]
```

### 步骤4：生成Word文档

#### 方法1：手动复制粘贴

1. 在Word中创建新文档
2. 设置字体为Courier New，字号为小四号
3. 设置行距为单倍行距
4. 复制源代码到Word文档
5. 添加代码块说明
6. 检查每页代码行数（≥50行）

#### 方法2：使用脚本提取

创建脚本自动提取源代码：

```bash
#!/bin/bash
# extract-code.sh - 提取源代码并生成文档

# 设置输出文件
OUTPUT="source-code.md"

# 提取函数
extract_file() {
    local file="$1"
    local description="$2"
    
    if [ -f "$file" ]; then
        echo "// 文件路径：$file" >> "$OUTPUT"
        echo "// 功能说明：$description" >> "$OUTPUT"
        echo "" >> "$OUTPUT"
        cat "$file" >> "$OUTPUT"
        echo "" >> "$OUTPUT"
        echo "---" >> "$OUTPUT"
        echo "" >> "$OUTPUT"
    fi
}

# 提取源代码
# 前30页
extract_file "frontend/src/pages/ChatPage.tsx" "AI对话页面组件"
extract_file "frontend/src/services/api/chat.ts" "对话API服务"
# ... 更多文件

# 转换为Word格式
pandoc "$OUTPUT" -o "源代码文档.docx" \
  --wrap=none \
  --highlight-style=tango
```

### 步骤5：添加页眉页脚

在Word文档中添加页眉页脚：

**页眉：**
- 内容：软件名称（如"数字生命主客户端系统源代码"）
- 字体：黑体，小五号
- 对齐：左对齐

**页脚：**
- 内容：页码（第 X 页，共 Y 页）
- 字体：宋体，小五号
- 对齐：居中

### 步骤6：检查行数

确保每页不少于50行代码：

1. 在Word中查看页面
2. 统计每页代码行数
3. 如果不足50行，添加更多代码或调整格式
4. 如果超过50行，可以适当分割

## 代码处理注意事项

### 敏感信息处理

**必须去除的内容：**
- API密钥和密码
- 数据库连接字符串（密码部分）
- 个人隐私信息
- 内网IP地址

**处理方式：**
- 使用占位符（如`${API_KEY}`）替代敏感信息
- 添加注释说明："实际部署时需配置API密钥"

### 代码注释

**添加说明注释：**
- 文件功能说明
- 关键函数说明
- 复杂逻辑说明
- 参数说明

**示例：**
```java
/**
 * AI对话服务实现类
 * 
 * 功能：
 *   1. 处理用户对话请求
 *   2. 构建对话上下文
 *   3. 调用AI服务接口
 *   4. 保存对话历史
 * 
 * @author HeartSphere Team
 * @version 1.0
 */
public class ChatServiceImpl implements ChatService {
    // 实现代码
}
```

### 代码格式

**保持原格式：**
- 保持代码原有缩进
- 保持代码原有注释
- 保持代码结构完整

**统一格式：**
- 使用统一的代码风格
- 使用统一的注释风格
- 使用统一的命名规范

## 自动化脚本

### 提取脚本示例

```bash
#!/bin/bash
# extract-source-code.sh - 提取源代码

PRODUCT="$1"  # main-client, admin-platform, mentis, education-edition
OUTPUT_DIR="copyright-materials/$PRODUCT"
OUTPUT_FILE="$OUTPUT_DIR/源代码提取.md"

# 创建输出文件
echo "# 源代码文档" > "$OUTPUT_FILE"
echo "" >> "$OUTPUT_FILE"

# 提取函数
extract_with_header() {
    local file="$1"
    local desc="$2"
    
    if [ -f "$file" ]; then
        echo "## 文件：$file" >> "$OUTPUT_FILE"
        echo "" >> "$OUTPUT_FILE"
        echo "**功能说明**：$desc" >> "$OUTPUT_FILE"
        echo "" >> "$OUTPUT_FILE"
        echo "\`\`\`" >> "$OUTPUT_FILE"
        cat "$file" >> "$OUTPUT_FILE"
        echo "\`\`\`" >> "$OUTPUT_FILE"
        echo "" >> "$OUTPUT_FILE"
    fi
}

# 根据产品提取文件
case "$PRODUCT" in
    main-client)
        extract_with_header "frontend/src/pages/ChatPage.tsx" "AI对话页面"
        # ... 更多文件
        ;;
    admin-platform)
        extract_with_header "admin/frontend/src/pages/edu/StudentManagePage.tsx" "学生管理页面"
        # ... 更多文件
        ;;
    *)
        echo "未知产品：$PRODUCT"
        exit 1
        ;;
esac

echo "提取完成：$OUTPUT_FILE"
```

### 使用方法

```bash
chmod +x extract-source-code.sh
./extract-source-code.sh main-client
```
