# 源代码文档说明

## 要求

根据软件著作权申请要求，源代码文档需要：
- 共60页（前30页+后30页）
- 每页不少于50行代码
- 包含代表性源代码，体现软件核心功能
- 添加必要的代码注释和说明

## 源代码选择原则

### 前30页源代码（主要功能模块）

建议选择以下核心模块的源代码：

1. **前端核心组件**（约10页）
   - 主页面组件（`frontend/src/pages/`）
   - AI对话组件（对话界面相关组件）
   - 场景管理组件（场景列表、场景编辑等）
   - 角色管理组件（角色列表、角色创建等）

2. **前端服务层**（约5页）
   - API服务（`frontend/src/services/api/`）
   - AI对话服务
   - 场景管理服务
   - 角色管理服务

3. **后端核心服务**（约10页）
   - Controller层（`backend/src/main/java/com/heartsphere/.../controller/`）
     - AI对话Controller
     - 场景管理Controller
     - 角色管理Controller
   - Service层（`backend/src/main/java/com/heartsphere/.../service/`）
     - AI对话Service
     - 场景管理Service
     - 角色管理Service

4. **后端数据层**（约5页）
   - Repository层（`backend/src/main/java/com/heartsphere/.../repository/`）
   - Entity层（`backend/src/main/java/com/heartsphere/.../entity/`）

### 后30页源代码（辅助功能）

建议选择以下辅助功能模块的源代码：

1. **工具类和工具函数**（约10页）
   - 前端工具函数（`frontend/src/utils/`）
   - 后端工具类（`backend/src/main/java/com/heartsphere/.../util/`）
   - 公共组件（`shared/frontend/src/components/`）

2. **配置和初始化**（约5页）
   - 前端配置文件（`frontend/vite.config.ts`、`frontend/tsconfig.json`等）
   - 后端配置类（`backend/src/main/java/com/heartsphere/.../config/`）
   - 应用配置文件（`backend/src/main/resources/application.yml`）

3. **数据处理和DTO**（约10页）
   - DTO类（`backend/src/main/java/com/heartsphere/.../dto/`）
   - 类型定义（`frontend/src/types/`）

4. **异常处理和安全**（约5页）
   - 异常处理类（`backend/src/main/java/com/heartsphere/.../exception/`）
   - 安全配置（`backend/src/main/java/com/heartsphere/.../config/WebSecurityConfig.java`）

## 注意事项

1. **代码格式**：保持代码格式规范，包含必要的注释
2. **敏感信息**：去除敏感信息（API密钥、密码等）
3. **完整性**：确保代码片段完整，能够体现功能逻辑
4. **注释说明**：添加必要的注释，说明代码功能
5. **文件名**：在文档中标注源代码文件名和路径

## 文档格式

源代码文档需要：
1. 使用等宽字体（如Courier New）
2. 保持代码缩进格式
3. 添加代码块说明（功能、文件路径等）
4. 每页不少于50行代码
5. 转换为Word文档格式后，确保格式正确

## 生成步骤

1. 从代码库中选择代表性源代码文件
2. 按照前30页+后30页的要求组织代码
3. 添加必要的代码注释和说明
4. 格式化为Word文档（.docx）
5. 检查每页代码行数（≥50行）
6. 添加页眉页脚和页码
