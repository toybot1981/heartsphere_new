# 数字生命主客户端系统使用示例

本文档提供系统的使用示例，帮助理解系统功能和使用方式。

## 1. 用户注册和登录

### 1.1 用户注册

用户首次使用系统需要注册账号：

1. 打开系统首页，点击"注册"按钮
2. 填写注册信息：
   - 用户名（必填，3-20个字符）
   - 邮箱（必填，用于验证和找回密码）
   - 密码（必填，至少8个字符，包含字母和数字）
3. 点击"注册"按钮提交
4. 系统发送验证邮件到用户邮箱
5. 用户点击邮件中的验证链接完成注册

### 1.2 用户登录

已注册用户可以通过以下方式登录：

1. 打开系统首页，点击"登录"按钮
2. 输入用户名和密码
3. 点击"登录"按钮
4. 系统验证用户信息，成功后跳转到主界面

## 2. 场景管理

### 2.1 创建场景

用户可以创建自己的数字世界场景：

1. 登录系统后，进入"场景管理"页面
2. 点击"创建场景"按钮
3. 填写场景信息：
   - 场景名称（如"我的大学"）
   - 场景描述（描述场景的背景和设定）
   - 选择场景封面图
   - 设置场景类型和标签
4. 点击"保存"按钮创建场景
5. 场景创建成功后，可以进入场景进行编辑

### 2.2 编辑场景

用户可以编辑已创建的场景：

1. 在场景列表中选择要编辑的场景
2. 点击"编辑"按钮进入场景编辑页面
3. 可以修改场景基本信息
4. 可以添加或删除场景中的角色
5. 可以配置场景的规则和设定
6. 点击"保存"按钮保存修改

### 2.3 场景切换

用户可以在不同场景之间切换：

1. 在场景列表中选择要进入的场景
2. 点击"进入场景"按钮
3. 系统加载场景数据，显示场景界面
4. 用户可以在场景中与角色对话、查看剧本等

## 3. 角色管理

### 3.1 创建角色

用户可以在场景中创建数字生命体角色：

1. 进入场景后，点击"角色管理"菜单
2. 点击"创建角色"按钮
3. 填写角色信息：
   - 角色名称（如"小明"）
   - 角色头像（上传图片）
   - 角色描述（描述角色的性格、背景等）
   - 角色技能（配置角色可以执行的功能）
4. 点击"保存"按钮创建角色
5. 角色创建成功后，可以在场景中与角色对话

### 3.2 与角色对话

用户可以与场景中的角色进行AI对话：

1. 在场景中选择要对话的角色
2. 点击"对话"按钮打开对话界面
3. 在输入框中输入对话内容
4. 点击"发送"按钮发送消息
5. 角色通过AI生成回复内容
6. 用户可以继续对话，系统会保持上下文理解

## 4. AI对话功能

### 4.1 开始对话

用户可以通过以下方式开始AI对话：

1. 在场景中选择角色，点击"对话"按钮
2. 系统打开对话界面，显示对话历史（如果有）
3. 用户在输入框中输入对话内容
4. 点击"发送"按钮或按Enter键发送消息
5. 系统显示"正在输入..."提示
6. AI生成回复后显示在对话界面

### 4.2 对话历史

系统会保存对话历史：

1. 用户可以查看历史对话记录
2. 对话历史按时间顺序显示
3. 用户可以搜索历史对话内容
4. 用户可以导出对话历史为文本文件

## 5. 剧本系统

### 5.1 创建剧本

用户可以创建剧本，定义剧情事件：

1. 在场景中点击"剧本管理"菜单
2. 点击"创建剧本"按钮
3. 填写剧本信息：
   - 剧本名称
   - 剧本描述
   - 触发条件（何时触发剧本）
   - 剧本内容（剧情事件）
4. 点击"保存"按钮创建剧本
5. 剧本创建后，当满足触发条件时会自动执行

### 5.2 剧本执行

剧本会在满足触发条件时自动执行：

1. 系统监控场景中的触发条件
2. 当条件满足时，系统执行对应的剧本
3. 剧本执行时，会显示剧情内容
4. 用户可以查看剧本执行历史

## 6. 心域连接

### 6.1 共享心域

用户可以共享自己的心域给其他用户：

1. 在场景管理页面，选择要共享的场景
2. 点击"共享设置"按钮
3. 选择共享模式：
   - 公开：所有用户都可以访问
   - 需审批：其他用户需要申请，获得批准后才能访问
   - 仅邀请：只有被邀请的用户可以访问
4. 点击"保存"按钮保存设置
5. 系统生成心域连接码，可以分享给其他用户

### 6.2 访问他人心域

用户可以访问他人共享的心域：

1. 在首页点击"心域连接"菜单
2. 输入心域连接码或搜索公开心域
3. 点击"连接"按钮连接心域
4. 如果是需审批的心域，需要等待批准
5. 连接成功后，可以进入心域体验（体验模式）

## 7. 跨时空信箱

### 7.1 发送消息

用户可以在不同场景之间发送消息：

1. 在场景中点击"跨时空信箱"菜单
2. 点击"发送消息"按钮
3. 选择目标场景
4. 输入消息内容
5. 点击"发送"按钮发送消息
6. 消息发送成功后，目标场景会收到通知

### 7.2 接收消息

用户可以接收来自其他场景的消息：

1. 在场景中点击"跨时空信箱"菜单
2. 查看收到的消息列表
3. 点击消息查看详细内容
4. 可以回复消息或删除消息

## 8. 插件系统

### 8.1 安装插件

用户可以安装插件扩展功能：

1. 在系统设置中点击"插件管理"菜单
2. 浏览可用插件列表
3. 选择要安装的插件
4. 点击"安装"按钮安装插件
5. 插件安装成功后，可以在场景中使用

### 8.2 使用插件

用户可以在场景中使用已安装的插件：

1. 在场景中点击"插件"菜单
2. 选择要使用的插件
3. 插件功能会在场景中激活
4. 用户可以使用插件提供的功能

## 9. 移动端使用

系统支持移动端（iOS和Android）：

1. 用户可以在应用商店下载移动端应用
2. 使用与Web端相同的账号登录
3. 移动端提供与Web端相同的功能
4. 界面针对移动端进行了优化，支持触摸操作
5. 支持离线缓存，可以在无网络时查看已加载的内容

## 10. 常见问题

### 10.1 如何找回密码？

1. 在登录页面点击"忘记密码"链接
2. 输入注册时使用的邮箱
3. 系统发送密码重置邮件
4. 点击邮件中的链接重置密码

### 10.2 如何删除场景？

1. 在场景列表中选择要删除的场景
2. 点击"删除"按钮
3. 确认删除操作
4. 场景删除后，场景中的所有数据也会被删除（软删除，可恢复）

### 10.3 如何导出数据？

1. 在设置页面点击"数据导出"菜单
2. 选择要导出的数据类型（场景、对话历史等）
3. 点击"导出"按钮
4. 系统生成导出文件，可以下载到本地
