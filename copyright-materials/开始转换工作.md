## 🚀 快速开始

### 方法1：使用Pandoc（推荐）

**第一步：安装Pandoc**

```bash
# macOS
brew install pandoc

# 验证安装
pandoc --version
```

**第二步：转换文档**

```bash
cd /Users/admin/Workspace/heartsphere_new/copyright-materials

# 批量转换（如果有模板）
./convert-all.sh

# 或手动转换单个文件
pandoc main-client/软件说明书.md -o main-client/软件说明书.docx --toc --toc-depth=2
```

**第三步：在Word中调整格式**

参考 `Word模板设置说明.md` 和 `安装和转换步骤.md`

### 方法2：使用Typora（图形界面）

1. 下载安装Typora：https://typora.io/
2. 打开Markdown文件
3. 点击"文件" > "导出" > "Word (.docx)"
4. 在Word中调整格式

### 方法3：在线转换

1. 访问在线转换工具（如CloudConvert）
2. 上传Markdown文件
3. 下载Word文件
4. 在Word中调整格式

## 📝 工作流程

1. **准备阶段**（10-15分钟）
   - 安装Pandoc或Typora
   - 创建Word模板（可选）
   - 准备Word软件

2. **转换阶段**（5-10分钟）
   - 运行转换脚本
   - 检查转换结果

3. **调整阶段**（20-30分钟）
   - 在Word中设置页眉页脚
   - 调整字体和格式
   - 检查页边距

4. **提取阶段**（30-60分钟）
   - 运行源代码提取脚本
   - 检查提取的源代码
   - 去除敏感信息
   - 转换为Word格式

5. **扩展阶段**（2-4小时）
   - 参考内容扩展模板
   - 添加详细的描述
   - 添加图表和截图说明
   - 确保达到60页

6. **检查阶段**（30-60分钟）
   - 使用检查清单
   - 检查格式和内容
   - 确保质量符合要求
