# 传送门系统快速开始指南

## 前置准备

### 1. 安装依赖

传送门系统需要Three.js库支持3D渲染：

```bash
cd frontend
npm install three @types/three
```

### 2. 启用功能开关

在 `backend/src/main/resources/application.yml` 中启用传送门功能：

```yaml
heartconnect:
  portal:
    enabled: true  # 启用传送门功能
    features:
      stargate: true   # 启用星门类型
      wormhole: true   # 启用虫洞类型
      quantum: true    # 启用量子类型
```

或通过环境变量：

```bash
export PORTAL_ENABLED=true
```

### 3. 数据库迁移

数据库迁移脚本会在应用启动时自动执行（Flyway）：
- `V20260107__create_portal_tables.sql`

如果使用手动迁移，请执行该SQL脚本。

## 基础使用

### 在场景中渲染传送门

```tsx
import React, { useState, useEffect } from 'react';
import { 
  PortalLayer, 
  TeleportationManager, 
  usePortal 
} from '@/components/portal';
import { isPortalEnabledSync } from '@/services/api/portal/config';

const SceneComponent: React.FC<{ sceneId: number }> = ({ sceneId }) => {
  const { portals, loadPortals } = usePortal(sceneId);
  const isEnabled = isPortalEnabledSync();

  useEffect(() => {
    if (isEnabled && sceneId) {
      loadPortals(sceneId);
    }
  }, [sceneId, isEnabled, loadPortals]);

  const handlePortalClick = (portalId: number) => {
    // 传送门点击事件会通过TeleportationManager处理
    window.dispatchEvent(new CustomEvent('portal-click', {
      detail: { portalId }
    }));
  };

  const handleTeleportationComplete = (targetHeartsphereId: number, targetShareCode?: string) => {
    // 处理传送完成后的场景切换
    if (targetShareCode) {
      window.location.href = `/share/${targetShareCode}`;
    } else {
      // 切换到目标心域
      console.log('传送到心域:', targetHeartsphereId);
    }
  };

  return (
    <div className="scene-container relative w-full h-full">
      {/* 传送管理器包装场景内容 */}
      <TeleportationManager
        sceneId={sceneId}
        onTeleportationComplete={handleTeleportationComplete}
      >
        {/* 场景内容 */}
        <div className="scene-content">
          {/* 你的场景内容 */}
        </div>

        {/* 传送门渲染层 */}
        {isEnabled && (
          <PortalLayer
            portals={portals}
            sceneId={sceneId}
            onPortalClick={handlePortalClick}
          />
        )}
      </TeleportationManager>
    </div>
  );
};
```

### 打开管理界面

```tsx
import React, { useState } from 'react';
import { PortalManagement } from '@/components/portal';

const SceneEditorComponent: React.FC<{ sceneId: number }> = ({ sceneId }) => {
  const [showPortalManagement, setShowPortalManagement] = useState(false);

  return (
    <div>
      <button onClick={() => setShowPortalManagement(true)}>
        管理传送门
      </button>

      {showPortalManagement && (
        <PortalManagement
          sceneId={sceneId}
          onClose={() => setShowPortalManagement(false)}
          onPortalCreated={(portal) => {
            console.log('传送门已创建:', portal);
          }}
          onPortalUpdated={(portal) => {
            console.log('传送门已更新:', portal);
          }}
          onPortalDeleted={(portalId) => {
            console.log('传送门已删除:', portalId);
          }}
        />
      )}
    </div>
  );
};
```

## API调用示例

### 创建传送门

```typescript
import { portalApi } from '@/services/api/portal';

const createPortal = async () => {
  try {
    const portal = await portalApi.createPortal({
      sceneId: 1,
      portalName: '星门入口',
      portalType: 'stargate',
      targetShareCode: 'SC-ABC123',  // 或使用 targetHeartsphereId
      positionX: 0,
      positionY: 0,
      positionZ: 0,
      size: 3.0,
      permissionType: 'approval',
      description: '通往另一个心域的星门',
    });
    console.log('传送门创建成功:', portal);
  } catch (error) {
    console.error('创建失败:', error);
  }
};
```

### 获取场景传送门列表

```typescript
import { portalApi } from '@/services/api/portal';

const loadPortals = async (sceneId: number) => {
  try {
    const portals = await portalApi.getPortalsByScene(sceneId, true); // true = 只获取激活的
    console.log('传送门列表:', portals);
  } catch (error) {
    console.error('加载失败:', error);
  }
};
```

### 执行传送

```typescript
import { portalApi } from '@/services/api/portal';

const teleport = async (portalId: number) => {
  try {
    const result = await portalApi.executeTeleportation(portalId, {
      skipAnimation: false,  // 是否跳过动画
    });
    
    if (result.success) {
      console.log('传送成功:', result);
      // 处理场景切换
    } else {
      console.error('传送失败:', result.errorMessage);
    }
  } catch (error) {
    console.error('传送失败:', error);
  }
};
```

## 使用Hook

### usePortal Hook

```typescript
import { usePortal } from '@/hooks/usePortal';

const MyComponent: React.FC<{ sceneId: number }> = ({ sceneId }) => {
  const {
    portals,           // 传送门列表
    loading,           // 加载状态
    error,             // 错误信息
    loadPortals,       // 加载传送门
    createPortal,      // 创建传送门
    updatePortal,      // 更新传送门
    deletePortal,      // 删除传送门
    teleport,          // 执行传送
    getPreview,        // 获取预览
  } = usePortal(sceneId);

  // 自动加载传送门列表
  // usePortal会在sceneId变化时自动加载

  return (
    <div>
      {portals.map(portal => (
        <div key={portal.id}>
          <h3>{portal.portalName}</h3>
          <button onClick={() => teleport(portal.id)}>传送</button>
        </div>
      ))}
    </div>
  );
};
```

## 常见问题

### 1. Three.js未安装

**错误**: `Three.js未安装，请运行: npm install three @types/three`

**解决**: 
```bash
npm install three @types/three
```

### 2. 传送门不显示

**检查清单**:
- 功能开关是否启用：`heartconnect.portal.enabled=true`
- 传送门是否激活：`isActive=true`
- PortalLayer是否正确渲染
- 场景ID是否正确

### 3. 传送失败

**可能原因**:
- 没有访问权限（permissionType限制）
- 目标心域不存在或不可用
- 网络请求失败

**调试**:
```typescript
try {
  const result = await portalApi.executeTeleportation(portalId);
  console.log('传送结果:', result);
} catch (error) {
  console.error('传送错误:', error);
}
```

### 4. 动画不播放

- 检查Three.js是否正确加载
- 检查浏览器WebGL支持
- 尝试降低质量设置：`quality: 'low'`
