# 传送门系统调试指南

## 问题：前端看不到传送门效果

### 检查清单

#### 1. 后端配置检查

确保 `backend/src/main/resources/application.yml` 中已启用：

```yaml
heartconnect:
  portal:
    enabled: true
```

#### 2. 前端功能开关检查

打开浏览器控制台，检查日志：

```javascript
// 检查当前功能状态
import { getPortalConfigDebugInfo } from '@/services/api/portal/config';
console.log(getPortalConfigDebugInfo());
```

#### 3. 手动启用功能（临时调试）

如果后端已启用但前端仍显示未启用，可以手动设置：

```javascript
// 在浏览器控制台中执行
import { setPortalEnabledManually } from '@/services/api/portal/config';
setPortalEnabledManually(true);
// 然后刷新页面
```

#### 4. 检查日志输出

打开浏览器开发者工具，查看控制台日志，应该能看到：

```
[PortalConfig] checkPortalEnabled 被调用
[PortalConfig] 从后端获取配置
[PortalLayer] 组件渲染
[PortalLayer] 初始化效果执行
[usePortal] 开始自动加载传送门列表
```

### 常见问题

#### 问题1: 功能未启用

**日志表现**:
```
[PortalLayer] 功能未启用，不渲染组件
```

**解决方案**:
1. 检查后端配置 `heartconnect.portal.enabled=true`
2. 清除localStorage缓存：`localStorage.removeItem('portal_enabled')`
3. 刷新页面让前端重新获取配置

#### 问题2: Three.js未安装

**日志表现**:
```
[PortalLayer] 初始化失败: Three.js未安装，请运行: npm install three @types/three
```

**解决方案**:
```bash
cd frontend
npm install three @types/three
```

#### 问题3: 没有传送门数据

**日志表现**:
```
[usePortal] 加载传送门列表成功: sceneId=1, count=0
[PortalLayer] 准备创建传送门: totalPortals=0, activePortals=0
```

**解决方案**:
1. 使用管理界面创建传送门
2. 或通过API创建传送门
3. 确保传送门的 `isActive=true`

#### 问题4: 传送门不显示

**可能原因**:
- 传送门位置在视野外
- 传送门尺寸太小
- 3D渲染器初始化失败

**调试步骤**:
1. 检查日志中是否有错误信息
2. 检查传送门的位置和尺寸配置
3. 检查浏览器是否支持WebGL

### 调试工具函数

在浏览器控制台中使用：

```javascript
// 1. 检查配置状态
import { getPortalConfigDebugInfo } from '@/services/api/portal/config';
console.log(getPortalConfigDebugInfo());

// 2. 手动启用功能
import { setPortalEnabledManually } from '@/services/api/portal/config';
setPortalEnabledManually(true);

// 3. 重置配置
import { resetPortalConfig } from '@/services/api/portal/config';
resetPortalConfig();

// 4. 检查传送门列表
// 使用React DevTools检查组件状态
// 或直接在代码中添加 console.log
```

### 日志级别

所有关键操作都会输出日志，日志前缀：
- `[PortalConfig]` - 配置相关
- `[PortalLayer]` - 渲染层相关
- `[usePortal]` - Hook相关
- `[PortalRenderer]` - 渲染器相关

### 网络请求检查

检查浏览器Network标签页，应该能看到：
- `GET /api/portal/scene/{sceneId}` - 获取传送门列表
- `GET /api/portal/{id}` - 获取传送门详情

如果这些请求返回404或500，说明后端可能有问题。

### 快速诊断命令

在浏览器控制台执行：

```javascript
// 完整诊断
(async () => {
  const { getPortalConfigDebugInfo, checkPortalEnabled } = await import('/src/services/api/portal/config.ts');
  
  console.log('=== 传送门系统诊断 ===');
  console.log('1. 配置状态:', getPortalConfigDebugInfo());
  console.log('2. 功能启用:', await checkPortalEnabled());
  console.log('3. localStorage:', localStorage.getItem('portal_enabled'));
})();
```
