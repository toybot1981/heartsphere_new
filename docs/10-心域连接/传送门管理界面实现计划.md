# 传送门管理界面实现计划

## 当前状态

已完成基础框架（PortalManagement.tsx），包含：
- ✅ 组件基本结构
- ✅ 状态管理（UI状态、表单数据）
- ✅ 基础UI布局（头部、列表、模态框占位）
- ✅ usePortal Hook集成

## 待实现内容

### 步骤1：创建功能实现
需要实现的方法和组件：

1. **handleCreatePortal**
   - 重置表单数据
   - 打开创建模态框

2. **handleCreateSubmit**
   - 表单验证
   - 调用createPortal API
   - 处理成功/失败
   - 关闭模态框并刷新列表

3. **handleCreateCancel**
   - 重置表单
   - 关闭模态框

4. **renderCreateModal**
   - 完整的创建表单模态框UI

5. **renderCreateForm**
   - 传送门名称输入
   - 传送门类型选择（stargate/wormhole/quantum）
   - 目标心域选择（heartsphereId 或 shareCode）
   - 位置设置（X, Y, Z坐标）
   - 尺寸设置
   - 权限类型选择（public/approval/invite）
   - 描述文本域
   - 表单验证提示

### 步骤2：编辑和删除功能实现
需要实现的方法和组件：

1. **handleEditPortal**
   - 加载选中传送门数据到表单
   - 打开编辑模态框

2. **handleEditSubmit**
   - 表单验证
   - 调用updatePortal API
   - 处理成功/失败
   - 关闭模态框并刷新列表

3. **handleEditCancel**
   - 重置表单
   - 关闭模态框

4. **handleDeletePortal**
   - 设置删除确认ID
   - 打开删除确认对话框

5. **handleDeleteConfirm**
   - 调用deletePortal API
   - 处理成功/失败
   - 关闭确认对话框并刷新列表

6. **handleDeleteCancel**
   - 关闭删除确认对话框

7. **renderEditModal**
   - 完整的编辑表单模态框UI
   - 复用renderCreateForm的逻辑（可提取为通用组件）

8. **renderEditForm**
   - 与创建表单类似，但预填充数据
   - 包含激活/禁用开关

9. **renderDeleteConfirm**
   - 删除确认对话框
   - 显示传送门信息
   - 警告提示

10. **renderPortalList**
    - 增强列表显示
    - 显示更多详细信息
    - 状态指示器
    - 快捷操作按钮

## 实现顺序

1. **第一步**：实现创建功能（步骤1的所有内容）
2. **第二步**：实现编辑和删除功能（步骤2的所有内容）

## 注意事项

- 表单验证要完善（必填字段、数值范围等）
- 错误处理要友好（显示明确的错误提示）
- 加载状态要清晰（提交时禁用按钮、显示加载指示器）
- 目标心域选择可以支持两种方式：heartsphereId（直接ID）或shareCode（共享码）
- 位置坐标可以使用滑块或数字输入
- 考虑添加预览功能（显示传送门在场景中的大概位置）
