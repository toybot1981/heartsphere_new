## 二、详细设计方案

### 2.1 心域社区与广场

#### 2.1.1 功能描述

创建一个心域社区广场，让用户可以：
- 浏览和发现心域
- 参与社区讨论
- 关注心域创作者
- 分享心域故事

#### 2.1.2 设计方案

**A. 心域广场首页**

**功能模块**：
1. **精选推荐区**：编辑推荐的高质量心域
2. **热门心域区**：实时热门心域排行
3. **最新发布区**：最新共享的心域
4. **分类浏览区**：按标签分类浏览
5. **搜索发现区**：智能搜索和推荐

### 2.2 互动评价系统

#### 2.2.1 功能描述

建立完善的评价和反馈系统，包括：
- 心域评分
- 评价留言
- 标签标记
- 举报机制

#### 2.2.2 设计方案

**A. 评分系统**

**评分维度**：
1. **整体评分**：1-5星综合评分
2. **多维度评分**：
   - 内容质量（1-5星）
   - 角色设计（1-5星）
   - 交互体验（1-5星）
   - 创意度（1-5星）

**后端设计**：
```java
@Entity
public class HeartSphereRating {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    private Long shareConfigId;
    private Long raterId;          // 评分者ID
    
    private Integer overallRating; // 整体评分 1-5
    private Integer contentRating; // 内容质量
    private Integer designRating;  // 角色设计
    private Integer experienceRating; // 交互体验
    private Integer creativityRating; // 创意度
    
    private String comment;        // 评价文字
    private LocalDateTime ratedAt;
}

// 评分统计
@Entity
public class HeartSphereRatingStatistics {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @OneToOne
    private HeartSphereShareConfig shareConfig;

    private Double averageContentRating;    // 平均内容评分

}
```

### 2.3 心域合作与共创

#### 2.3.1 功能描述

支持多个用户共同创作和管理心域，包括：
- 协作邀请
- 角色权限管理
- 协作编辑
- 版本管理

#### 2.3.2 设计方案

**A. 协作邀请系统**

**功能特性**：
- 心域主人可以邀请其他用户成为协作者
- 设置协作者权限（编辑、查看、管理等）
- 协作者可以共同管理心域

**后端设计**：
```java
@Entity
public class HeartSphereCollaboration {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    private Long shareConfigId;
    private Long ownerId;          // 主人ID
    private Long collaboratorId;  // 协作者ID
    
    private String role;           // 'editor', 'viewer', 'admin'
    private List<String> permissions; // 权限列表
    
    private String status;        // 'invited', 'accepted', 'rejected'
    private LocalDateTime invitedAt;
    private LocalDateTime respondedAt;
}

// 协作权限枚举
public enum CollaborationPermission {
    VIEW_WORLDS,          // 查看世界
    EDIT_WORLDS,          // 编辑世界
    VIEW_ERAS,            // 查看场景
    EDIT_ERAS,            // 编辑场景
    VIEW_CHARACTERS,      // 查看角色
    EDIT_CHARACTERS,      // 编辑角色
    MANAGE_SHARE_CONFIG,  // 管理共享配置
    MANAGE_COLLABORATORS  // 管理协作者
}
```

**B. 协作编辑功能**

**功能特性**：
- 多人同时编辑（需要冲突解决机制）
- 编辑历史记录
- 实时协作提示

**技术实现**：
- 使用 WebSocket 实现实时协作
- 使用操作转换（OT）算法解决冲突
- 或使用锁机制避免冲突

**C. 版本管理**

**功能描述**：
- 保存心域的历史版本
- 版本对比功能
- 版本回滚功能

**后端设计**：
