## 二、详细设计方案

### 2.1 共享心域发现与筛选系统

#### 2.1.1 功能描述

当前用户只能看到所有公开的共享心域，缺乏有效的筛选和发现机制。需要增加：

- 热门推荐
- 个性化推荐

**B. 热门推荐算法**

**推荐维度**：
1. **访问量统计**：记录每个共享心域的访问次数
2. **收藏数量**：统计被收藏的次数
3. **留言互动**：统计暖心留言数量
4. **连接成功率**：已批准连接数 / 总请求数
5. **最近活跃度**：最近7天的访问量

**后端实现**：
```java
// 新增统计表
@Entity
public class ShareConfigStatistics {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @OneToOne
    private HeartSphereShareConfig shareConfig;
    
    private Long visitCount;        // 访问次数
    private Long favoriteCount;    // 收藏次数
    private Long messageCount;      // 留言数量
    private Long connectionCount;   // 连接数量
    private LocalDateTime lastVisitTime; // 最后访问时间
    private Double popularityScore; // 热度分数（计算值）
}

// 热度计算服务
@Service
public class ShareConfigStatisticsService {
    public Double calculatePopularityScore(ShareConfigStatistics stats) {
        // 综合计算热度分数
        double score = 
            stats.getVisitCount() * 0.3 +
            stats.getFavoriteCount() * 0.25 +
            stats.getMessageCount() * 0.2 +
            stats.getConnectionCount() * 0.15 +
            (isRecentActive(stats) ? 0.1 : 0);
        return score;
    }
}
```

**前端展示**：
- 热门心域专区：展示热度排名前10的心域
- 热度指标可视化：显示访问量、收藏数等数据
- 排序选项：按热度、最新、收藏数等排序
