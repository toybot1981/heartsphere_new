# 心域连接功能完善 - 分步实施计划

## 概述

本文档提供了心域连接功能的分步完善计划，分为3个主要阶段，每个阶段包含具体的功能点和技术实现方案。

---

## 第一阶段：增强发现和推荐机制（优先级：高）

### 目标
让用户更容易发现和找到感兴趣的心域，提升连接空间的可用性和吸引力。

### 功能点

#### 1.1 心域标签系统
**需求**：为心域添加标签，便于分类和搜索

**实现方案**：
- **数据库扩展**
  ```sql
  CREATE TABLE heart_sphere_tag (
    id BIGINT PRIMARY KEY,
    share_config_id BIGINT,
    tag_name VARCHAR(50),
    created_at TIMESTAMP
  );
  ```

- **后端API**
  ```java
  // 添加标签
  POST /api/heartconnect/config/{id}/tags
  Body: { "tags": ["科幻", "冒险", "情感"] }
  
  // 获取标签列表
  GET /api/heartconnect/tags/popular
  ```

- **前端实现**
  - 在 ShareConfigModal 中添加标签选择器
  - 在 ConnectionSpace 中显示标签
  - 支持点击标签筛选

**预计工作量**：3-5天

      // 2. 分析用户偏好标签
      // 3. 计算匹配度
      // 4. 返回推荐列表
  }
  ```

- **前端实现**
  - 在 ConnectionSpace 中添加"为你推荐"区域
  - 显示推荐理由（如："因为你喜欢科幻类心域"）

**预计工作量**：5-7天

#### 1.3 筛选和排序功能
**需求**：提供多种筛选和排序选项

**实现方案**：
- **筛选选项**
  - 按标签筛选
  - 按访问权限筛选（公开/需审批/邀请制）

- **排序选项**

  - 最多访问
  - 最高评分
  - 最多收藏

- **UI设计**
  ```

  │ 标签: [科幻] [情感] [冒险] [+更多] │
  │ 权限: [全部] [公开] [需审批]       │
  │ 排序: [最新] [热门] [评分] [收藏]  │

**预计工作量**：3-4天

**第一阶段总工作量**：11-16天

## 第二阶段：增强互动和社交功能（优先级：中）

### 目标
提升用户参与度，建立用户之间的互动和连接。

### 功能点

#### 2.1 评分和评论系统
**需求**：用户可以评价和评论心域

**实现方案**：
- **数据模型**
  ```java
  @Entity
  public class HeartSphereRating {
      @Id
      @GeneratedValue
      private Long id;
      
      @Column(nullable = false)
      private Long shareConfigId;
      
      @Column(nullable = false)
      private Long userId;
      
      @Column(nullable = false)
      @Min(1) @Max(5)
      private Integer rating; // 1-5星
      
      @Column(length = 500)
      private String comment; // 评论内容
      
      private LocalDateTime createdAt;
      
      // 唯一约束：同一用户对同一心域只能评分一次
      @Table(uniqueConstraints = @UniqueConstraint(
          columnNames = {"shareConfigId", "userId"}
      ))
  }
  ```

- **后端API**
  ```java
  // 提交评分
  POST /api/heartconnect/shared/{shareConfigId}/rating
  Body: { "rating": 5, "comment": "非常有趣的心域！" }
  
  // 获取评分列表
  GET /api/heartconnect/shared/{shareConfigId}/ratings
  Response: {
    "averageRating": 4.5,
    "totalRatings": 120,
    "ratings": [...]
  }
  ```

- **前端实现**
  - 在心域详情页显示评分
  - 评分和评论表单
  - 评论列表展示

**预计工作量**：4-6天

#### 2.2 收藏功能

**实现方案**：

## 第三阶段：增强安全性和用户体验（优先级：中低）

### 目标
提升系统安全性，优化用户体验，为长期运营打下基础。

### 功能点

#### 3.1 精细化权限控制
**需求**：提供更灵活的访问控制选项

**实现方案**：
- **访问规则配置**
  ```java
  @Entity
  public class HeartSphereAccessRule {
      @Id
      @GeneratedValue
      private Long id;
      
      private Long shareConfigId;
      
      @Enumerated(EnumType.STRING)
      private AccessRuleType ruleType;
      
      @Column(columnDefinition = "TEXT")
      private String ruleConfig; // JSON配置
      
      private Boolean enabled;
  }
  
  public enum AccessRuleType {
      TIME_LIMIT,      // 时间限制：如每天9:00-22:00开放
      COUNT_LIMIT,     // 次数限制：如每个用户最多访问3次
      CONTENT_FILTER,  // 内容过滤：部分场景/角色不可见
      BLACKLIST        // 黑名单：禁止特定用户访问
  }
  ```

- **实现功能**
  - 访问时间窗口设置
  - 访问次数限制
  - 内容分级显示（逐步解锁）
  - 黑名单管理

**预计工作量**：6-8天

#### 3.2 心域预览功能
**需求**：用户无需进入即可预览心域内容

**实现方案**：
- **预览内容**
  - 心域封面和简介
  - 角色列表（头像、名称、简介）
  - 场景列表（名称、描述）
  - 评分和评论摘要

- **前端实现**
  - 在 ConnectionSpace 中，点击心域卡片弹出预览模态框
  - 预览模态框包含多个标签页
  - 支持从预览直接进入或发送连接请求

**预计工作量**：4-5天

#### 3.3 搜索功能增强
**需求**：提供强大的搜索能力

**实现方案**：
- **搜索范围**
  - 心域名称
  - 心域描述
  - 标签
  - 角色名称
  - 主人昵称

- **搜索功能**
  - 全文搜索
  - 智能提示
  - 搜索历史
  - 高级搜索（多条件组合）

- **技术实现**
  - 使用 Elasticsearch 或数据库全文索引
  - 前端实现搜索建议和自动完成

**预计工作量**：5-7天

#### 3.4 异常访问检测和防护
**需求**：检测和防止恶意访问

**实现方案**：
- **检测机制**
  - 访问频率检测
  - 异常访问模式识别
  - IP地址分析

- **防护措施**
  - 自动限流
  - 临时封禁
  - 验证码机制（可选）

**预计工作量**：4-6天

**第三阶段总工作量**：19-26天

## 技术栈建议

### 前端
- **UI组件**：继续使用 Tailwind CSS
- **图表库**：Chart.js 或 ECharts（用于统计数据可视化）
- **搜索组件**：自定义实现或使用 react-select

### 后端
- **缓存**：Redis（缓存热门心域、推荐结果）
- **搜索**：Elasticsearch（全文搜索）或数据库全文索引
- **消息队列**：RabbitMQ 或 Kafka（异步处理统计任务）

### 数据库
- **索引优化**：为常用查询字段添加索引
- **分表策略**：访问日志表按时间分表
- **读写分离**：考虑主从复制

## 风险与应对

### 技术风险
- **推荐算法效果不佳**
  - 应对：先实现简单规则，逐步优化
  - 收集用户反馈，持续调整

- **性能问题**
  - 应对：使用缓存、异步处理、数据库优化
  - 进行压力测试

### 业务风险
- **用户参与度不高**
  - 应对：增加激励机制、优化UI/UX
  - 收集用户反馈
