## API接口文档

### 配额相关API

#### GET /api/membership/quota
获取当前用户的配额信息

**响应示例**:
```json
{
  "userId": 1,
  "membershipId": 1,
  "planType": "basic",
  "textTokenQuota": 100000,
  "textTokenUsed": 50000,
  "textTokenAvailable": 50000,
  "imageQuota": 50,
  "imageUsed": 20,
  "imageAvailable": 30,
  ...
}
```

#### GET /api/membership/quota/usage
获取当前周期使用统计

#### GET /api/membership/quota/usage/history
获取历史使用统计（每日）

**参数**:
- `startDate` (required): 开始日期（ISO格式：YYYY-MM-DD）
- `endDate` (required): 结束日期（ISO格式：YYYY-MM-DD）

### 权限相关API

#### GET /api/membership/permissions
获取用户权限信息

### 升级/降级API

#### GET /api/membership/upgrade/price
获取升级价格

**参数**:
- `targetPlanId` (required): 目标计划ID

#### POST /api/membership/upgrade
升级会员

**请求体**:
```json
{
  "targetPlanId": 3
}
```

#### POST /api/membership/downgrade
降级会员
