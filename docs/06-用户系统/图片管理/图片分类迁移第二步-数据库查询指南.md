# 图片分类迁移第二步 - 数据库查询指南

## 目标
查询数据库中哪些记录使用了 `general` 分类的图片，确定需要迁移的数据。

## 方法一：使用脚本自动执行（推荐）

### 执行命令
```bash
cd backend/scripts
chmod +x execute_migration_step2.sh
bash execute_migration_step2.sh
```

### 或者设置环境变量后执行
```bash
export DB_NAME=heartsphere
export DB_USER=root
export DB_PASSWORD=your_password
export DB_HOST=localhost
export DB_PORT=3306

bash backend/scripts/execute_migration_step2.sh
```

### 输出
脚本会生成两个报告文件：
1. **统计报告**: `backend/migration_reports/count_report_YYYYMMDD_HHMMSS.txt`
   - 显示每个表中使用 general 的记录数量
2. **详细报告**: `backend/migration_reports/general_images_report_YYYYMMDD_HHMMSS.txt`
   - 显示每个记录的详细信息

## 方法二：手动执行 SQL 查询

### 步骤 1: 快速统计
在数据库管理工具中执行：
```sql
-- 文件: backend/scripts/query_general_images_count.sql
```
这会返回每个表中使用 general 的记录数量。

### 步骤 2: 详细查询
在数据库管理工具中执行：
```sql
-- 文件: backend/scripts/generate_general_images_report.sql
```
这会返回所有使用 general 的记录的详细信息。

### 使用 MySQL 命令行
```bash
# 统计查询
mysql -u root -p heartsphere < backend/scripts/query_general_images_count.sql

# 详细报告
mysql -u root -p heartsphere < backend/scripts/generate_general_images_report.sql > report.txt
```

## 查询结果说明

### 统计报告字段
- `table_name`: 表名
- `condition`: 查询条件说明
- `count`: 记录数量

### 详细报告字段
- `table_name`: 表名
- `id`: 记录ID
- `name/title`: 记录名称/标题
- `user_id`: 用户ID（如果是用户资源）
- `url/avatar_url/background_url/image_url`: 图片URL
- `issue_type`: 问题类型
- `created_at`: 创建时间

## 迁移规则

根据查询结果，确定每个记录应该迁移到哪个分类：

| 表名 | 字段 | 迁移规则 |
|------|------|----------|
| `journal_entries` | `image_url` | `general` → `journal` |
| `characters` | `avatar_url`, `background_url` | `general` → `character` |
| `eras` | `image_url` | `general` → `era` |
| `system_characters` | `avatar_url`, `background_url` | `general` → `character` |
| `system_eras` | `image_url` | `general` → `era` |
| `system_main_stories` | `avatar_url`, `background_url` | `general` → `character` |
| `system_resources` | `url` | 根据 `category` 字段确定 |

## 注意事项

1. **备份**: 执行查询前建议备份数据库
2. **验证**: 查看详细报告，确认迁移规则是否正确
3. **测试**: 如果有测试环境，先在测试环境执行

## 下一步

查询完成后，根据结果：
1. 确认需要迁移的记录数量
2. 验证迁移规则是否正确
3. 准备执行迁移脚本（第三步）
