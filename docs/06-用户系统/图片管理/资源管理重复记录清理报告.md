## 清理操作

### 1. 数据备份
- 创建备份表：`system_resources_backup_before_cleanup`
- 备份所有记录，以防需要恢复

### 2. 清理完全重复的记录
- **清理策略**：保留最早的记录（ID最小的），删除其他完全重复的记录
- **匹配条件**：category（类别）、name（名称）、description（描述）都相同
- **执行结果**：删除所有完全重复的记录

### 3. 清理名称重复的记录
- **清理策略**：对于名称相同但描述不同的记录，保留ID最小的，删除其他的
- **匹配条件**：category（类别）、name（名称）相同
- **执行结果**：确保每个类别下的名称唯一

### 4. 添加唯一性约束
- **约束名称**：`uk_category_name`
- **约束列**：`category`, `name`
- **约束类型**：UNIQUE
- **作用**：防止未来再次出现同一类别下的重复名称

## 恢复方法

如果需要恢复被删除的记录，可以从备份表中恢复：

```sql
-- 从备份表恢复记录
INSERT INTO system_resources 
SELECT * FROM system_resources_backup_before_cleanup
WHERE id NOT IN (SELECT id FROM system_resources);
```
