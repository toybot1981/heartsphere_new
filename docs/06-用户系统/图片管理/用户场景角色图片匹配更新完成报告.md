# 用户场景和角色图片匹配更新完成报告

## 执行时间
2024年修复执行

## 问题描述
用户的场景和角色图片展示不出来，需要根据名称与预置资源进行匹配，匹配成功后更新用户相应表的数据。

## 修复方案

### 匹配规则
1. **场景 (eras) 匹配优先级**：
   - 优先：通过 `system_era_id` 匹配 `system_eras` 表
   - 其次：通过名称匹配 `system_eras` 表
   - 最后：通过名称匹配 `system_resources` 表（category='era'）

2. **角色 (characters) 匹配优先级**：
   - 优先：通过名称匹配 `system_characters` 表
   - 其次：通过名称匹配 `system_resources` 表（category='avatar' 或 'character'）
   - 头像优先使用 category='avatar'，其次使用 category='character'
   - 背景使用 category='character'

### 更新条件
- 只更新图片链接为空、NULL 或占位符（placeholder://）的记录
- 只使用有效的图片链接（非空、非占位符）
