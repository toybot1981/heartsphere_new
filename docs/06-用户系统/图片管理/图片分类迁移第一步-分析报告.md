## 下一步操作

### 1. 数据库查询
需要运行以下 SQL 查询脚本来检查数据库中的记录：
- `backend/scripts/analyze_general_images.sql` - 详细分析脚本
- `backend/scripts/generate_general_images_report.sql` - 生成完整报告

### 2. 查询要点
需要检查以下表中使用 general 分类的记录：
- `system_resources` - 系统资源表
- `characters` - 用户角色表
- `eras` - 用户时代表
- `journal_entries` - 日记表
- `system_characters` - 系统角色表
- `system_eras` - 系统时代表
- `system_main_stories` - 系统主线故事表

### 3. 迁移规则
根据表的不同，迁移规则如下：
- `journal_entries.image_url`: `general` → `journal`
- `characters.avatar_url/background_url`: `general` → `character`
- `eras.image_url`: `general` → `era`
- `system_characters.avatar_url/background_url`: `general` → `character`
- `system_eras.image_url`: `general` → `era`
- `system_main_stories.avatar_url/background_url`: `general` → `character`
- `system_resources`: 根据 `category` 字段确定（如果 `category='general'` 但实际应该是其他分类）
