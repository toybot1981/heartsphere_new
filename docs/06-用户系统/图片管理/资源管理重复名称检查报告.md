### 问题分析

#### 可能的原因
1. **数据导入重复**：可能是数据导入或同步时出现了重复
2. **时间差异**：从created_at字段看，有些记录创建时间不同（如2025-12-28和2026-01-06）
3. **描述相同但URL不同**：部分重复记录的描述完全相同，但URL不同（有些是placeholder，有些是实际图片）

#### 重复记录特征
- **完全重复**：名称、类别、描述都相同的记录
- **部分重复**：名称和类别相同，但描述或URL不同的记录

### 建议处理方案

#### 1. 清理完全重复的记录
- 保留最早创建的记录（created_at最早的）
- 删除其他完全重复的记录

#### 2. 合并部分重复的记录
- 对于名称相同但URL不同的记录，可能需要人工审核
- 保留URL指向实际图片的记录，删除placeholder的记录

#### 3. 添加唯一性约束
- 在数据库中添加 `UNIQUE(category, name)` 约束
- 防止未来再次出现重复

### 清理脚本建议

```sql
-- 删除完全重复的记录（保留ID最小的）
DELETE sr1 FROM system_resources sr1
INNER JOIN system_resources sr2
WHERE sr1.category = sr2.category
  AND sr1.name = sr2.name
  AND sr1.description = sr2.description
  AND sr1.id > sr2.id;
```

## 结论

资源管理中存在大量重复名称的记录，主要集中在**item类别**中。建议：
1. 先分析重复记录的原因
2. 制定清理策略
3. 执行清理操作
4. 添加唯一性约束防止再次出现
