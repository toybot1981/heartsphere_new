# 测试指南：增强主项目用户体验功能

## 概述

本文档提供了 `enhance-main-project-ux` 提案的完整测试指南，包括所有功能的测试步骤和验证点。

## 测试环境准备

### 前置条件
1. 确保后端服务正在运行（端口 8081）
2. 确保前端服务正在运行（端口 5173 或配置的端口）
3. 准备测试账号（至少 2 个用户账号，用于测试共享心域功能）
4. 准备测试数据（至少 1 个场景、1 个角色、1 个插件）

### 测试工具
- Chrome DevTools（用于检查网络请求和性能）
- React DevTools（用于检查组件状态）
- 移动设备或浏览器移动端模拟器

## Phase 1: 插件隐藏功能测试

### 1.1 测试隐藏按钮显示
**测试步骤：**
1. 进入现实世界页面（RealWorldScreen）
2. 添加至少 1 个插件到场景
3. 检查插件容器右上角是否显示隐藏按钮（眼睛图标或类似图标）

**验证点：**
- [ ] 隐藏按钮可见
- [ ] 隐藏按钮样式正确（不遮挡插件内容）
- [ ] 鼠标悬停时按钮有视觉反馈

### 1.2 测试插件隐藏功能
**测试步骤：**
1. 点击插件的隐藏按钮
2. 观察插件动画效果
3. 检查插件是否移动到右侧边栏（较窄区域）

**验证点：**
- [ ] 插件有平滑的隐藏动画
- [ ] 插件移动到屏幕右侧
- [ ] 隐藏后的插件显示为较窄的条状（约 12px 宽）
- [ ] 隐藏状态保存到 localStorage（检查 `plugin_hidden_{pluginInstanceId}`）

### 1.3 测试插件恢复功能
**测试步骤：**
1. 点击隐藏的插件条
2. 观察插件恢复动画
3. 检查插件是否恢复到原来的位置

**验证点：**
- [ ] 插件有平滑的恢复动画
- [ ] 插件恢复到原来的位置和大小
- [ ] 恢复后插件功能正常

### 1.4 测试多插件场景
**测试步骤：**
1. 添加 3-5 个插件到场景
2. 隐藏其中几个插件
3. 检查隐藏插件的排列

**验证点：**
- [ ] 多个插件可以独立隐藏/恢复
- [ ] 隐藏的插件在右侧边栏正确排列
- [ ] 隐藏状态互不影响

### 1.5 测试移动端适配
**测试步骤：**
1. 在移动设备或移动端模拟器中打开页面
2. 检查插件隐藏功能

**验证点：**
- [ ] 移动端插件隐藏按钮可见且可点击
- [ ] 隐藏动画在移动端流畅
- [ ] 隐藏后的插件条在移动端可点击恢复

- [ ] 背景图片清晰

### 2.3 测试列表展示质量
**测试步骤：**
1. 打开场景列表或角色列表
2. 检查列表中的图片
3. 使用 Chrome DevTools 检查网络请求

**验证点：**
- [ ] 列表图片使用中等质量（800×600）
- [ ] 图片加载速度快
- [ ] 图片清晰度适合列表展示

### 2.4 测试回退策略
**测试步骤：**
1. 模拟网络慢速（Chrome DevTools > Network > Throttling）
2. 检查图片加载行为
3. 检查是否有回退到低质量版本

**验证点：**
- [ ] 网络慢时自动回退到低质量版本
- [ ] 回退过程平滑
- [ ] 最终显示合适的质量版本

### 2.5 测试移动端图片质量
**测试步骤：**
1. 在移动设备上打开应用
2. 检查各种图片的加载
3. 使用移动端网络工具检查请求大小

**验证点：**
- [ ] 移动端自动选择合适质量的图片
- [ ] 移动端图片加载速度快
- [ ] 移动端图片清晰度适合屏幕尺寸

## Phase 4: 场景风格系统重构测试

### 4.1 测试场景创建时的风格选择
**测试步骤：**
1. 打开场景创建/编辑模态框（EraConstructorModal）
2. 检查风格选择器是否显示
3. 选择不同的风格
4. 保存场景

**验证点：**
- [ ] 风格选择器可见（下拉菜单）
- [ ] 可以选择不同的风格（写实、动漫、赛博朋克等）
- [ ] 默认风格为"写实"（realistic）
- [ ] 保存后风格正确保存到数据库

### 4.2 测试风格对场景图片生成的影响
**测试步骤：**
1. 创建一个新场景，选择"动漫"风格
2. 使用 AI 生成场景封面图片
3. 检查生成的图片风格

**验证点：**
- [ ] 生成的图片符合选择的风格
- [ ] 不同风格生成的图片有明显区别
- [ ] 图片质量良好

### 4.3 测试风格对角色图片生成的影响
**测试步骤：**
1. 在"动漫"风格的场景中创建角色
2. 使用 AI 生成角色头像
3. 检查生成的图片风格

**验证点：**
- [ ] 角色图片符合场景风格
- [ ] 不同场景风格下的角色图片有区别

### 4.4 测试移动端场景风格选择
**测试步骤：**
1. 在移动设备上打开场景创建/编辑页面
2. 测试风格选择器
3. 测试风格保存

**验证点：**
- [ ] 移动端风格选择器可见且可用
- [ ] 移动端风格选择流程正常
- [ ] 移动端风格保存成功

### 4.5 测试数据迁移
**测试步骤：**
1. 检查数据库中现有场景的 `style` 字段
2. 验证所有场景都有 `style` 值
3. 验证默认值为 'realistic'

**验证点：**
- [ ] 所有现有场景都有 `style` 字段
- [ ] 默认值为 'realistic'
- [ ] 新创建的场景正确保存风格

## Phase 7: 性能测试

### 7.1 测试图片加载性能
**测试工具：** Chrome DevTools > Network > Performance

**测试步骤：**
1. 打开包含多个图片的页面
2. 记录页面加载时间
3. 检查图片加载顺序和速度

**验证点：**
- [ ] 页面加载时间 < 3 秒（首次加载）
- [ ] 图片按优先级加载（缩略图优先）
- [ ] 图片总大小合理（< 5MB）

### 7.2 测试插件隐藏性能
**测试步骤：**
1. 添加 10+ 个插件到场景
2. 测试隐藏/恢复操作
3. 检查动画流畅度

**验证点：**
- [ ] 隐藏/恢复动画流畅（60fps）
- [ ] 多个插件同时隐藏不影响性能
- [ ] 页面不卡顿

### 7.3 测试整体性能影响
**测试工具：** Chrome DevTools > Performance > Lighthouse

**测试步骤：**
1. 运行 Lighthouse 性能测试
2. 检查各项性能指标

**验证点：**
- [ ] Performance Score > 80
- [ ] First Contentful Paint < 1.5s
- [ ] Time to Interactive < 3s
- [ ] Total Blocking Time < 300ms

## 注意事项

1. **测试数据准备**：确保有足够的测试数据（场景、角色、插件）
2. **网络环境**：在不同网络环境下测试（WiFi、4G、慢速网络）
3. **浏览器兼容性**：在主流浏览器中测试（Chrome、Safari、Firefox、Edge）
4. **移动端测试**：在真实移动设备上测试，不仅仅是模拟器
5. **性能监控**：使用性能监控工具记录性能指标
6. **错误处理**：测试各种错误场景（网络错误、API 错误等）
