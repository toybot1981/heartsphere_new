## 一、项目概述

### 1.1 项目简介

心域（HeartSphere）是一个数字生命体交互系统，提供AI对话、场景管理、角色扮演、剧本系统等核心功能。系统采用前后端分离架构，支持Web、移动端（Capacitor）等多平台。

### 1.2 技术栈

#### 后端技术栈
- **框架**: Spring Boot 3.2.0
- **语言**: Java 17
- **ORM**: Spring Data JPA
- **数据库**: MySQL 8.0+
- **安全**: Spring Security + JWT
- **数据库迁移**: Flyway
- **构建工具**: Maven 3.9+
- **API文档**: SpringDoc OpenAPI (Swagger)

#### 前端技术栈
- **框架**: React 18+ + TypeScript
- **构建工具**: Vite
- **UI库**: Tailwind CSS
- **状态管理**: React Hooks / Context API
- **路由**: React Router
- **HTTP客户端**: Fetch API / Axios
- **移动端**: Capacitor 8.0+

#### AI服务
- **大模型**: Gemini、OpenAI、Qwen、豆包等
- **AI服务**: 自研AI服务 + AipexBase集成
- **代码生成**: AI代码生成服务

## 三、设计规范

### 3.1 架构设计原则

1. **前后端分离**: 标准RESTful API，前后端独立开发部署
2. **模块化设计**: 功能模块化，低耦合高内聚
3. **可扩展性**: 支持功能扩展和性能扩展
4. **安全性**: 数据安全、接口安全、权限控制
5. **可维护性**: 代码清晰、文档完善、易于理解

### 3.2 数据库设计规范

#### 3.2.1 命名规范
- **表名**: 小写字母+下划线，复数形式（如：`user_profiles`）
- **字段名**: 小写字母+下划线（如：`created_at`）
- **主键**: 统一使用 `id`，类型为 `BIGINT`
- **外键**: `{表名}_id`（如：`user_id`）

#### 3.2.2 字段规范
- **时间字段**: 
  - `created_at`: 创建时间（TIMESTAMP，NOT NULL，DEFAULT CURRENT_TIMESTAMP）
  - `updated_at`: 更新时间（TIMESTAMP，NOT NULL，DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP）
- **软删除**: 使用 `deleted_at` 字段（TIMESTAMP，NULL）
- **状态字段**: 使用枚举类型或TINYINT
- **文本字段**: 根据实际需求选择VARCHAR长度，避免过长

#### 3.2.3 索引规范
- **主键索引**: 自动创建
- **外键索引**: 所有外键字段必须创建索引
- **查询字段索引**: 频繁查询的字段创建索引
- **组合索引**: 多字段查询创建组合索引

#### 3.2.4 数据库迁移
- **使用Flyway**: 所有数据库变更通过Flyway迁移脚本
- **命名规范**: `V{版本号}__{描述}.sql`（如：`V1__Create_User_Table.sql`）
- **版本号**: 递增整数，不跳跃
- **回滚脚本**: 重要变更提供回滚脚本

### 3.3 API设计规范

#### 3.3.1 RESTful API规范
- **URL命名**: 小写字母+连字符（如：`/api/user-profiles`）
- **HTTP方法**: 
  - GET: 查询
  - POST: 创建
  - PUT: 完整更新
  - PATCH: 部分更新
  - DELETE: 删除
- **版本控制**: URL中包含版本号（如：`/api/v1/user-profiles`）

#### 3.3.2 请求规范
- **Content-Type**: `application/json`
- **认证**: 使用Bearer Token（`Authorization: Bearer {token}`）
- **请求体**: JSON格式，字段命名使用camelCase

#### 3.3.3 响应规范
- **统一响应格式**:
```json
{
  "code": 200,
  "message": "成功",
  "data": { /* 数据 */ },
  "timestamp": "2025-01-04T10:00:00"
}
```

- **状态码规范**:
  - `200 OK`: 成功
  - `201 Created`: 创建成功
  - `400 Bad Request`: 请求错误
  - `401 Unauthorized`: 未授权
  - `403 Forbidden`: 禁止访问
  - `404 Not Found`: 资源不存在
  - `500 Internal Server Error`: 服务器错误

#### 3.3.4 分页规范
- **请求参数**: `page`（页码，从1开始）、`size`（每页数量，默认10）
- **响应格式**:
```json
{
  "code": 200,
  "data": {
    "content": [ /* 数据列表 */ ],
    "totalElements": 100,
    "totalPages": 10,
    "page": 1,
    "size": 10
  }
}
```

### 3.4 前端设计规范

#### 3.4.1 组件设计
- **组件拆分**: 单一职责，组件粒度适中
- **组件命名**: PascalCase（如：`UserProfile.tsx`）
- **Props接口**: 使用TypeScript接口定义
- **状态管理**: 优先使用本地状态，复杂状态使用Context

#### 3.4.2 样式规范
- **使用Tailwind CSS**: 优先使用Tailwind工具类
- **自定义样式**: 放在组件内或独立的CSS模块
- **响应式设计**: 使用Tailwind响应式类（sm、md、lg、xl）
- **主题色**: 使用统一的颜色变量

#### 3.4.3 路由规范
- **路由命名**: kebab-case（如：`/user-profile`）
- **路由守卫**: 需要认证的路由使用路由守卫
- **懒加载**: 使用React.lazy进行代码分割

@ControllerAdvice
public class GlobalExceptionHandler {
    
    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<ApiResponse<Void>> handleResourceNotFound(
            ResourceNotFoundException e) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND)
                .body(ApiResponse.error(404, e.getMessage()));
    }
    
    @ExceptionHandler(ValidationException.class)
    public ResponseEntity<ApiResponse<Void>> handleValidation(
            ValidationException e) {
        return ResponseEntity.status(HttpStatus.BAD_REQUEST)
                .body(ApiResponse.error(400, e.getMessage()));
    }
    
    @ExceptionHandler(Exception.class)
    public ResponseEntity<ApiResponse<Void>> handleGeneric(Exception e) {
        logger.error("Unexpected error", e);

                .body(ApiResponse.error(500, "服务器内部错误"));
    }

  onUpdate?: (profile: UserProfile) => void;

export const UserProfileComponent: React.FC<UserProfileProps> = ({
  userId,
  onUpdate,
}) => {

  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

      setLoading(false);
    }

  if (error) return <div>错误: {error}</div>;

## 九、常见问题与解决方案

### 9.1 开发环境问题

#### 问题1: Maven构建慢
**解决方案**:
- 配置Maven镜像（使用阿里云镜像）
- 使用多线程构建（`-T 4`）
- 优化pom.xml依赖

#### 问题2: 前端依赖安装失败
**解决方案**:
- 使用npm镜像（`npm config set registry`）
- 清除缓存重新安装（`npm cache clean --force`）
- 使用yarn替代npm

### 9.2 数据库问题

#### 问题1: 数据库连接失败
**解决方案**:
- 检查数据库服务是否启动
- 检查连接配置是否正确
- 检查防火墙设置

#### 问题2: 迁移脚本执行失败
**解决方案**:
- 检查SQL语法是否正确
- 检查版本号是否冲突
- 查看Flyway日志

### 9.3 部署问题

#### 问题1: 服务启动失败
**解决方案**:
- 检查日志文件
- 检查环境变量配置
- 检查端口是否被占用

#### 问题2: 前端页面空白
**解决方案**:
- 检查构建是否成功
- 检查Nginx配置
- 检查浏览器控制台错误
