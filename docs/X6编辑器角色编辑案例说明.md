# X6 编辑器角色编辑案例说明

## 概述

我已经创建了一个完整的角色编辑示例 Graph，名为 **"角色编辑示例 - 创建新角色"**，展示了角色创建和编辑的完整流程。

## 如何查看示例

1. **启动后端服务**（如果尚未启动）
2. **运行数据库迁移**：示例数据会在 Flyway 迁移时自动插入
3. **打开 Admin 管理端**
4. **进入 Graph 编辑器**：左侧菜单 → 内容管理 → Graph流程编辑器
5. **勾选 "使用 X6 编辑器（POC）"**
6. **找到 "角色编辑示例 - 创建新角色"** 并点击"编辑流程"

## 示例包含的节点类型

### ✅ 1. Start 节点（开始）
- **节点ID**: `start_char_1`
- **位置**: (100, 50)
- **功能**: 角色创建流程的起始点

### ✅ 2. Dialogue 节点（对话）
- **节点数量**: 10 个
- **功能**: 显示系统提示和角色信息
- **关键对话**:
  - `dialogue_char_1`: 欢迎信息
  - `dialogue_char_2`: 提示输入角色名称
  - `dialogue_char_4`: 提示选择职业
  - `dialogue_char_5`: 提示配置技能
  - `dialogue_char_6`: 提示定制外观
  - `dialogue_char_7`: 确认保存提示
  - `dialogue_char_8`: 创建成功提示
  - `dialogue_char_9`: 角色预览信息
  - `dialogue_char_10`: 取消保存提示

### ✅ 3. Wait 节点（等待）
- **节点ID**: `wait_char_1`
- **位置**: (100, 500)
- **功能**: 等待用户输入角色名称
- **配置**:
  - 等待类型: `USER_INPUT`
  - 等待条件: `characterName`
  - 超时时间: 60000ms (60秒)

### ✅ 4. Condition 节点（条件判断）
- **节点数量**: 2 个
- **功能**: 验证输入和判断用户选择
- **判断逻辑**:
  - `condition_char_1`: 验证角色名称是否有效（2-20个字符）
  - `condition_char_2`: 判断用户是否确认保存

### ✅ 5. Choice 节点（选择）
- **节点数量**: 3 个
- **功能**: 让用户做出选择
- **选择内容**:
  - `choice_char_1`: 职业选择（战士、法师、盗贼、牧师）
  - `choice_char_2`: 外观风格选择（经典、现代、奇幻、随机）
  - `choice_char_3`: 确认保存选择（确认、取消、预览）

### ✅ 6. Skill Check 节点（技能检查）
- **节点ID**: `skill_check_char_1`
- **位置**: (100, 1400)
- **功能**: 技能点分配检查
- **配置**:
  - 可用技能点: 20
  - 技能类型: strength, intelligence, agility, vitality
  - 成功效果: 技能点已分配

### ✅ 7. State Change 节点（状态变更）
- **节点数量**: 4 个
- **功能**: 修改角色状态和数据
- **变更内容**:
  - `state_change_char_1`: 应用职业属性
  - `state_change_char_2`: 保存技能点分配
  - `state_change_char_3`: 应用外观设置
  - `state_change_char_4`: 保存角色到数据库

### ✅ 8. End 节点（结束）
- **节点数量**: 2 个
- **功能**: 流程结束点
- **结局类型**:
  - `end_char_1`: 角色创建成功
  - `end_char_2`: 角色创建已取消

## 流程路径

### 主路径（成功创建角色）:
```
Start → Dialogue 1 → Dialogue 2 → Wait 1 → Condition 1 (有效) 
→ Dialogue 4 → Choice 1 (选择职业) → State Change 1 
→ Dialogue 5 → Skill Check 1 → State Change 2 
→ Dialogue 6 → Choice 2 (选择外观) → State Change 3 
→ Dialogue 7 → Choice 3 (确认保存) → Condition 2 (确认) 
→ State Change 4 → Dialogue 8 → End 1
```

### 名称验证失败路径:
```
Wait 1 → Condition 1 (无效) → Dialogue 3 → Wait 1 (重新输入)
```

### 预览路径:
```
Choice 3 → Dialogue 9 → Choice 3 (返回)
```

### 取消路径:
```
Choice 3 → Dialogue 10 → End 2
```

## 编辑建议

1. **查看完整流程**: 从 Start 节点开始，按照连线查看整个创建流程
2. **测试条件分支**: 查看 Condition 节点的不同分支路径
3. **修改节点配置**: 双击节点查看和编辑属性，例如修改职业属性值
4. **添加新节点**: 可以添加更多节点类型，例如添加"角色背景故事"输入节点
5. **测试选择节点**: 查看 Choice 节点的多个选项和对应的效果

## 注意事项

- 示例数据通过 Flyway 迁移脚本自动插入
- 如果数据库中已存在同名 Graph，迁移可能会失败
- 可以在 Admin 端直接编辑和保存这个示例
- 建议在编辑前先复制一份作为备份
- 节点配置中的模板变量（如 `{{characterName}}`）需要在执行时替换为实际值
