# AI流程编辑工具设计文档

## 概述

参考Dify的设计理念，设计一个内置的AI流程编辑工具，支持场景、角色、事件、物品等多种实体的融合。

## 设计目标

1. **实体融合**：支持场景、角色、事件、物品等多种实体的无缝融合
2. **可视化编辑**：提供直观的可视化流程编辑界面
3. **智能关联**：自动识别和关联实体之间的关系
4. **动态执行**：支持实体的动态创建、修改和删除
5. **上下文感知**：基于当前上下文智能推荐相关实体

## 核心实体类型

### 1. 场景节点 (Scene Node)
- **功能**：定义游戏场景、环境、背景
- **属性**：
  - 场景ID、名称、描述
  - 场景类型（室内/室外、现代/古代等）
  - 场景状态（天气、时间、氛围等）
  - 关联的角色、物品、事件
- **执行逻辑**：
  - 设置当前场景
  - 触发场景相关事件
  - 更新场景状态

### 2. 角色节点 (Character Node)
- **功能**：定义和管理角色
- **属性**：
  - 角色ID、名称、描述
  - 角色属性（性格、技能、关系等）
  - 角色状态（位置、情绪、健康等）
  - 角色关系网络
- **执行逻辑**：
  - 创建/更新角色
  - 修改角色属性
  - 触发角色相关事件
  - 更新角色关系

### 3. 事件节点 (Event Node)
- **功能**：定义游戏事件
- **属性**：
  - 事件ID、名称、描述
  - 事件类型（对话、战斗、探索等）
  - 触发条件
  - 事件结果
- **执行逻辑**：
  - 检查触发条件
  - 执行事件逻辑
  - 更新相关实体状态
  - 触发后续事件

### 4. 物品节点 (Item Node)
- **功能**：定义和管理物品
- **属性**：
  - 物品ID、名称、描述
  - 物品类型（武器、道具、消耗品等）
  - 物品属性（效果、价值、稀有度等）
  - 物品状态（数量、位置等）
- **执行逻辑**：
  - 创建/更新物品
  - 物品获取/使用
  - 物品效果应用
  - 更新物品状态

### 5. 实体关联节点 (Entity Relation Node)
- **功能**：定义实体之间的关系
- **属性**：
  - 源实体ID、目标实体ID
  - 关系类型（拥有、属于、触发等）
  - 关系强度
  - 关系条件
- **执行逻辑**：
  - 建立/更新实体关系
  - 检查关系条件
  - 触发关系相关事件

## 流程编辑器功能

### 1. 节点类型
- **基础节点**：开始、结束、对话、选择、条件判断
- **实体节点**：场景、角色、事件、物品、实体关联
- **逻辑节点**：循环、分支、合并、延迟
- **AI节点**：LLM调用、向量检索、知识库查询

### 2. 实体面板
- **场景管理**：场景列表、场景编辑、场景预览
- **角色管理**：角色列表、角色编辑、角色关系图
- **事件管理**：事件列表、事件编辑、事件触发条件
- **物品管理**：物品列表、物品编辑、物品效果

### 3. 智能推荐
- **实体推荐**：基于当前上下文推荐相关实体
- **关系推荐**：自动识别实体之间的潜在关系
- **流程优化**：智能优化流程结构

### 4. 执行监控
- **实时状态**：显示当前执行的节点和实体状态
- **执行日志**：详细的执行日志记录
- **实体追踪**：追踪实体的创建、修改和删除

## 技术实现

### 1. 前端架构
- **编辑器组件**：基于X6的流程编辑器
- **实体面板**：实体管理界面
- **执行监控**：实时执行状态展示
- **数据可视化**：实体关系图、执行流程图

### 2. 后端架构
- **实体服务**：场景、角色、事件、物品的CRUD服务
- **关系服务**：实体关系的管理和查询
- **执行引擎**：扩展GraphEngine支持实体节点
- **推荐引擎**：基于上下文的实体推荐

### 3. 数据模型
- **实体表**：scenes, characters, events, items
- **关系表**：entity_relations
- **执行表**：graph_executions, execution_logs
- **状态表**：entity_states
