### 2.2 API接口

#### 2.2.1 插件列表查询

**接口：** `GET /api/admin/plugins`

**功能：**
- 支持关键词搜索
- 支持分类筛选
- 支持状态筛选
- 支持分页
- 支持排序

**请求参数：**
```typescript
{
  keyword?: string;      // 搜索关键词
  category?: string;     // 分类筛选
  status?: 'ACTIVE' | 'INACTIVE' | 'ALL';  // 状态筛选
  type?: 'SYSTEM' | 'USER' | 'ALL';  // 类型筛选
  page?: number;         // 页码（默认0）
  size?: number;         // 每页数量（默认20）
  sort?: string;         // 排序字段
}
```

**响应数据：**
```typescript
{
  plugins: Plugin[];     // 插件列表
  total: number;         // 总数
  page: number;          // 当前页
  size: number;          // 每页数量
}
```

#### 2.2.2 插件详情查询

**接口：** `GET /api/admin/plugins/{pluginId}`

**功能：**
- 获取插件完整信息
- 包含权限列表
- 包含依赖列表
- 包含使用统计

#### 2.2.3 启用插件

**接口：** `POST /api/admin/plugins/{pluginId}/enable`

**功能：**
- 将插件状态设置为ACTIVE
- 更新数据库记录

#### 2.2.4 禁用插件

**接口：** `POST /api/admin/plugins/{pluginId}/disable?force=false`

**功能：**
- 将插件状态设置为INACTIVE
- 检查是否有用户在使用
- 支持强制禁用（force=true）

#### 2.2.5 更新插件配置

**接口：** `PUT /api/admin/plugins/{pluginId}/config`

**功能：**
- 更新插件的默认配置
- 配置以JSON格式存储

**请求体：**
```json
{
  "config": {
    "maxAlbums": 200,
    "maxPhotosPerAlbum": 2000
  }
}
```

### 2.3 数据库表结构

#### 2.3.1 plugins 表

存储系统级插件元数据：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| plugin_id | VARCHAR(100) | 插件唯一标识 |
| name | VARCHAR(255) | 插件名称 |
| version | VARCHAR(50) | 版本号 |
| description | TEXT | 描述 |
| status | VARCHAR(20) | 状态（ACTIVE/INACTIVE/DISABLED） |
| category | VARCHAR(100) | 分类 |
| permissions | JSON | 权限列表 |
| default_config | JSON | 默认配置 |
| usage_count | INT | 使用次数 |
| rating | DECIMAL(3,2) | 评分 |

#### 2.3.2 user_plugins 表

存储用户安装的插件实例：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| user_id | BIGINT | 用户ID |
| plugin_id | VARCHAR(100) | 插件ID |
| status | VARCHAR(20) | 状态 |
| config | JSON | 用户配置 |

#### 2.3.3 scene_plugins 表

存储场景中添加的插件：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| scene_id | VARCHAR(100) | 场景ID |
| plugin_id | VARCHAR(100) | 插件ID |
| position_x | INT | X坐标 |
| position_y | INT | Y坐标 |
| width | INT | 宽度 |
| height | INT | 高度 |
| is_visible | BOOLEAN | 是否可见 |

#### 2.3.4 plugin_data 表

存储插件数据（通用存储）：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| plugin_id | VARCHAR(100) | 插件ID |
| user_id | BIGINT | 用户ID |
| data_key | VARCHAR(255) | 数据键 |
| data_value | JSON | 数据值 |

### 3.2 界面功能

#### 3.2.1 插件列表页面

**布局：**
- 顶部：搜索框 + 筛选器 + 刷新按钮
- 中间：插件卡片网格（响应式布局）
- 底部：分页控件

**插件卡片显示：**
- 插件图标
- 插件名称和版本
- 状态标签（已启用/已禁用）
- 描述（最多2行）
- 统计信息（使用次数、用户数、评分）
- 操作按钮（详情、启用/禁用）

#### 3.2.2 搜索和筛选

**搜索功能：**
- 实时搜索（输入关键词即时过滤）
- 支持按名称和描述搜索

**筛选功能：**
- 分类筛选：生活方式、教育、娱乐、社交
- 状态筛选：全部、已启用、已禁用

#### 3.2.3 详情弹窗

**显示内容：**
- 插件ID
- 版本号
- 完整描述
- 作者信息
- 分类
- 状态
- 所需权限列表
- 操作按钮（启用/禁用）

#### 3.2.4 启用/禁用功能

**启用流程：**
1. 点击"启用"按钮
2. 调用API启用插件
3. 更新列表显示

**禁用流程：**
1. 点击"禁用"按钮
2. 显示确认对话框
3. 如果插件正在被使用，提示是否强制禁用
4. 调用API禁用插件
5. 更新列表显示
