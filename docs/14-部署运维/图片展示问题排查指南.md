# 图片展示问题排查指南

## 常见问题

### 1. 图片URL格式问题

**症状**：图片无法加载，浏览器控制台显示404错误

**可能原因**：
- URL包含 `localhost`
- URL使用旧格式 `/api/images/files/`
- URL路径格式不正确

**排查方法**：
```bash
# 检查特定图片URL
./scripts/diagnose-image-issues.sh '图片URL'

# 检查所有问题URL
./scripts/check-system-tables-image-urls.sh
./scripts/check-user-tables-image-urls.sh
```

**解决方法**：
- 执行迁移脚本修复URL格式
- 确保URL使用相对路径格式

### 2. 文件不存在

**症状**：图片无法加载，浏览器控制台显示404错误

**可能原因**：
- 文件系统路径不正确
- 文件未上传或已删除
- 文件路径与数据库记录不匹配

**排查方法**：
```bash
# 检查文件是否存在
ls -la backend/uploads/images/路径/文件

# 检查数据库记录
mysql -uroot -p123456 heartsphere -e "SELECT * FROM 表名 WHERE id=记录ID;"
```

**解决方法**：
- 确认文件路径正确
- 重新上传图片
- 检查文件权限

### 3. 路径缺少userId前缀

**症状**：用户资源图片无法加载

**可能原因**：
- 用户资源路径格式为 `category/year/month/filename`（缺少userId）
- 应该是 `userId/category/year/month/filename`

**排查方法**：
```bash
# 检查缺少userId的记录
./scripts/check-user-tables-image-urls.sh
```

**解决方法**：
```bash
# 执行迁移脚本添加userId前缀
mysql -uroot -p123456 heartsphere < backend/src/main/resources/db/migration/V20250103006__add_userid_prefix_to_user_image_urls.sql
```

### 4. Nginx配置问题

**症状**：生产环境图片无法访问

**可能原因**：
- Nginx未配置 `/images/` 路径
- Nginx配置路径错误
- 文件权限问题

**排查方法**：
```bash
# 检查Nginx配置
cat /etc/nginx/conf.d/heartsphere.conf | grep images

# 测试图片访问
curl -I http://your-domain.com/images/category/year/month/filename.png
```

**解决方法**：
- 参考 `docs/14-部署运维/nginx-images配置说明.md`
- 使用配置脚本：`./scripts/update-nginx-images-config.sh`

### 5. 后端服务未启动

**症状**：所有图片都无法访问

**可能原因**：
- 后端服务未启动
- 端口配置错误

**排查方法**：
```bash
# 检查后端服务状态
ps aux | grep java
netstat -tlnp | grep 8081

# 检查后端日志
tail -f backend/backend.log
```

**解决方法**：
- 启动后端服务
- 检查端口配置

### 6. 跨域问题

**症状**：浏览器控制台显示CORS错误

**可能原因**：
- 前端和后端域名不同
- Nginx未配置CORS头

**解决方法**：
- 在Nginx配置中添加CORS头
- 或使用代理方式访问图片

## 诊断步骤

### 步骤1：检查图片URL

1. 打开浏览器开发者工具（F12）
2. 查看Network标签页
3. 找到图片请求，查看：
   - 请求URL
   - 响应状态码
   - 响应内容

### 步骤2：检查数据库记录

```bash
# 根据图片URL查找数据库记录
mysql -uroot -p123456 heartsphere -e "
SELECT 'system_resources' as table_name, id, url 
FROM system_resources 
WHERE url LIKE '%图片路径%'
UNION ALL
SELECT 'characters', id, avatar_url 
FROM characters 
WHERE avatar_url LIKE '%图片路径%';
"
```

### 步骤3：检查文件系统

```bash
# 检查文件是否存在
ls -la backend/uploads/images/图片路径

# 检查文件权限
stat backend/uploads/images/图片路径
```

### 步骤4：检查后端配置

```bash
# 检查WebMvcConfig
grep -A 5 "addResourceHandler" backend/src/main/java/com/heartsphere/config/WebMvcConfig.java

# 检查ImageUrlUtils
grep -A 10 "toFullUrl" backend/src/main/java/com/heartsphere/util/ImageUrlUtils.java
```

### 步骤5：检查Nginx配置（生产环境）

```bash
# 检查Nginx配置
nginx -t
cat /etc/nginx/conf.d/heartsphere.conf | grep -A 10 "location.*images"

# 测试图片访问
curl -I http://your-domain.com/images/图片路径
```
