# 前端重新部署指南

## 问题描述

生产环境可能出现以下错误：
- `Uncaught TypeError: Cannot read properties of undefined (reading 'ForwardRef')`
- React 相关错误
- 构建产物问题
- 依赖版本冲突

## 快速修复

使用重新部署脚本：

```bash
cd deploy
sudo ./redeploy-frontend.sh
```

## 脚本功能

`deploy/redeploy-frontend.sh` 脚本会执行以下操作：

1. **完全清理**
   - 删除旧的构建产物（dist）
   - 删除 node_modules
   - 清理 Vite 缓存
   - 清理 npm 缓存

2. **重新安装依赖**
   - 使用 `--legacy-peer-deps` 避免 peer dependencies 冲突
   - 验证关键依赖（React, React-DOM）

3. **创建生产配置**
   - 创建 `.env.production` 文件
   - 配置 `VITE_API_BASE_URL` 为空字符串（使用相对路径）

4. **重新构建**
   - 清理所有构建缓存
   - 验证 React 版本
   - 执行构建并保存日志

5. **部署到生产目录**
   - 复制构建产物到 `/opt/heartsphere/frontend`
   - 设置正确的权限

6. **验证部署**
   - 检查关键文件
   - 检查是否有 localhost 硬编码
   - 验证 Nginx 配置

## 手动修复步骤

如果脚本无法使用，可以手动执行：

### 1. 清理旧文件

```bash
cd /opt/heartsphere/frontend
rm -rf dist node_modules .vite .env.production package-lock.json
```

### 2. 进入源码目录

```bash
cd /path/to/heartsphere_new/frontend
rm -rf node_modules dist .vite .env.production package-lock.json
```

### 3. 清理 npm 缓存

```bash
npm cache clean --force
```

### 4. 重新安装依赖

```bash
npm install --legacy-peer-deps --no-audit --no-fund --force
```

### 5. 创建生产环境配置

```bash
cat > .env.production <<EOF
VITE_API_BASE_URL=
NODE_ENV=production
EOF
```

### 6. 重新构建

```bash
npm run build
```

### 7. 部署

```bash
cp -r dist/* /opt/heartsphere/frontend/
chown -R heartsphere:heartsphere /opt/heartsphere/frontend
```

### 8. 重新加载 Nginx

```bash
sudo nginx -t
sudo systemctl reload nginx
```

## 常见问题排查

### Q1: 构建失败，提示 React 版本不兼容

**解决方案**：
```bash
cd frontend
rm -rf node_modules package-lock.json
npm install --legacy-peer-deps --force
```

### Q2: ForwardRef 错误仍然存在

**解决方案**：
1. 检查 React 版本是否一致：
   ```bash
   npm list react react-dom
   ```
2. 确保只有一个 React 实例：
   ```bash
   # 检查是否有多个 React 版本
   find node_modules -name "react" -type d
   ```

### Q3: 构建成功但页面空白

**检查**：
1. 浏览器控制台错误
2. 网络请求是否正常
3. Nginx 配置是否正确

### Q4: 仍然有 localhost 硬编码

**解决方案**：
```bash
# 检查构建产物
grep -r "localhost:8081" /opt/heartsphere/frontend/

# 如果发现，确保 .env.production 中 VITE_API_BASE_URL 为空
echo "VITE_API_BASE_URL=" > frontend/.env.production
npm run build
```

## 验证部署

### 1. 检查构建产物

```bash
ls -la /opt/heartsphere/frontend/
# 应该看到 index.html 和 assets 目录
```

### 2. 检查文件大小

```bash
du -sh /opt/heartsphere/frontend/
# 应该有几MB到几十MB
```

### 3. 检查浏览器

1. 打开网站
2. 打开浏览器开发者工具（F12）
3. 检查 Console 标签是否有错误
4. 检查 Network 标签，API 请求是否正常

### 4. 检查 Nginx 日志

```bash
tail -f /var/log/nginx/heartsphere-error.log
```

## 预防措施

1. **定期更新依赖**：
   ```bash
   npm update --legacy-peer-deps
   ```

2. **使用固定版本**：
   在 `package.json` 中使用固定版本号，避免自动更新导致的问题

3. **构建前清理**：
   每次构建前清理缓存：
   ```bash
   rm -rf node_modules/.vite dist
   ```

4. **使用 CI/CD**：
   自动化构建和部署流程
