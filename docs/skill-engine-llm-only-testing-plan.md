# 技能引擎纯 LLM 驱动测试计划

## 测试目标

验证技能引擎重构为纯 LLM 驱动后的功能正确性、性能和稳定性。

## 测试范围

### 1. 单元测试

#### 1.1 LLM 驱动的技能发现（Level 1）
- **测试目标**：验证 LLM 能够从所有可用技能中发现可能相关的技能
- **测试用例**：
  - 测试用户消息与技能元数据的匹配
  - 测试相关性评分的准确性
  - 测试候选技能数量的限制
- **预期结果**：LLM 返回的相关技能列表准确，评分合理

#### 1.2 LLM 驱动的技能评估（Level 2）
- **测试目标**：验证 LLM 能够深度评估候选技能的适用性
- **测试用例**：
  - 测试技能指令的解析和评估
  - 测试置信度评分的准确性
  - 测试参数提取的正确性
- **预期结果**：LLM 返回的评估结果准确，置信度合理

#### 1.3 LLM 驱动的技能选择（Level 3）
- **测试目标**：验证 LLM 能够选择最合适的技能组合
- **测试用例**：
  - 测试技能组合的选择逻辑
  - 测试执行顺序的合理性
  - 测试技能协同的考虑
- **预期结果**：LLM 选择的技能组合合理，执行顺序正确

### 2. 集成测试

#### 2.1 完整的技能发现和调用流程
- **测试目标**：验证从用户消息到技能执行的完整流程
- **测试步骤**：
  1. 发送用户消息
  2. 系统进行 Level 1 发现
  3. 系统进行 Level 2 评估
  4. 系统进行 Level 3 选择
  5. 系统执行选定的技能
  6. 验证执行结果
- **预期结果**：整个流程顺畅，技能选择和执行正确

#### 2.2 错误处理
- **测试目标**：验证 LLM 调用失败时的错误处理
- **测试用例**：
  - LLM 服务不可用
  - LLM 返回无效响应
  - 网络超时
- **预期结果**：系统返回空结果，记录错误日志，不崩溃

### 3. 端到端测试

#### 3.1 技能管理功能
- **测试目标**：验证管理端和主工程的技能管理功能
- **测试用例**：
  - 创建新技能（符合新规范）
  - 编辑技能
  - 删除技能
  - 查看技能列表
  - 装备技能到角色
- **预期结果**：所有功能正常工作，只支持新格式技能

#### 3.2 技能使用功能
- **测试目标**：验证角色使用技能的功能
- **测试用例**：
  - 角色自动使用技能
  - 用户手动触发技能
  - 技能执行结果展示
- **预期结果**：技能使用正常，结果正确

### 4. 性能测试

#### 4.1 LLM 调用性能
- **测试目标**：测量 LLM 驱动的技能选择性能
- **测试指标**：
  - Level 1 发现耗时
  - Level 2 评估耗时
  - Level 3 选择耗时
  - 总耗时
- **预期结果**：
  - Level 1: < 2秒
  - Level 2: < 3秒
  - Level 3: < 2秒
  - 总耗时: < 7秒

#### 4.2 缓存效果
- **测试目标**：验证缓存对性能的提升
- **测试用例**：
  - 首次调用（无缓存）
  - 缓存命中
  - 缓存失效
- **预期结果**：缓存命中时响应时间显著减少（< 100ms）

#### 4.3 并发性能
- **测试目标**：验证系统在高并发下的性能
- **测试场景**：
  - 10个并发请求
  - 50个并发请求
  - 100个并发请求
- **预期结果**：系统稳定，响应时间在可接受范围内

### 5. 准确性测试

#### 5.1 技能选择准确性
- **测试目标**：验证 LLM 选择的技能是否准确
- **测试方法**：
  - 准备测试用例（用户消息 + 预期技能）
  - 执行技能选择
  - 对比实际选择和预期选择
- **预期结果**：准确率 > 80%

#### 5.2 与规则驱动的对比
- **测试目标**：对比 LLM 驱动和规则驱动的准确性
- **测试方法**：
  - 使用相同的测试用例
  - 分别使用 LLM 驱动和规则驱动（如果可能）
  - 对比结果
- **预期结果**：LLM 驱动的准确率高于规则驱动

## 测试环境

### 前置条件
1. 数据库已清理旧格式技能
2. 系统配置为纯 LLM 驱动模式
3. LLM 服务可用
4. 测试数据准备完成

### 测试数据
- 至少 10 个符合新规范的技能
- 至少 5 个测试角色
- 至少 20 个测试用例（用户消息）

## 测试执行

### 阶段1：单元测试
- 执行时间：1-2小时
- 执行人员：开发人员
- 工具：JUnit 5

### 阶段2：集成测试
- 执行时间：2-3小时
- 执行人员：测试人员
- 工具：Postman / curl

### 阶段3：端到端测试
- 执行时间：3-4小时
- 执行人员：测试人员
- 工具：浏览器 + 手动测试

### 阶段4：性能测试
- 执行时间：2-3小时
- 执行人员：性能测试人员
- 工具：JMeter / 自定义脚本

## 测试报告

测试完成后需要生成测试报告，包括：
1. 测试执行摘要
2. 测试结果统计
3. 发现的问题
4. 性能指标
5. 改进建议

## 验收标准

- ✅ 所有单元测试通过
- ✅ 所有集成测试通过
- ✅ 所有端到端测试通过
- ✅ 性能指标达到预期
- ✅ 准确率 > 80%
- ✅ 无严重缺陷

## 注意事项

1. **LLM 成本**：测试会产生 LLM 调用成本，注意控制测试规模
2. **缓存影响**：测试时注意清除缓存，确保测试结果的准确性
3. **环境隔离**：使用独立的测试环境，避免影响生产环境
4. **数据备份**：测试前备份数据，测试后可以恢复
