## 问题处理

### 常见问题

1. **LLM 调用失败**
   - 检查 LLM 服务状态
   - 检查网络连接
   - 检查配置是否正确

2. **技能选择不准确**
   - 检查技能数据格式
   - 检查 LLM 提示词
   - 调整候选数量限制

3. **响应时间过长**
   - 检查缓存配置
   - 检查 LLM 服务性能
   - 优化提示词长度

4. **旧格式技能残留**
   - 检查清理脚本执行结果
   - 手动清理残留数据
   - 验证清理完成
