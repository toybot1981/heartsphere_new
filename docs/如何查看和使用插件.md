# 如何查看和使用插件

## 插件入口位置

在"现实世界"页面中，插件功能入口位于**标签筛选区域**的右侧。

### 1. 添加插件按钮

在现实世界页面的顶部，标签筛选区域（显示各种标签的地方）的**最右侧**，你会看到：

- **"添加插件"** 按钮（紫色渐变按钮，带 + 号图标）
- 如果已经有插件，还会显示 **"编辑插件"** 按钮

### 2. 如何添加插件

1. 点击 **"添加插件"** 按钮
2. 在弹出的插件选择窗口中，浏览可用的插件
3. 点击插件卡片上的 **"添加到场景"** 按钮
4. 插件会出现在现实世界页面中

### 3. 如何使用插件

1. **退出编辑模式**（如果当前在编辑模式）
2. 在插件容器中，你会看到：
   - 插件名称和图标
   - **"执行插件功能"** 按钮（紫色渐变大按钮）
3. 点击 **"执行插件功能"** 按钮即可使用插件

### 4. 编辑插件位置

1. 点击 **"编辑插件"** 按钮进入编辑模式
2. 在编辑模式下：
   - 可以拖拽插件移动位置
   - 可以拖拽右下角调整大小
   - 可以点击插件顶部的删除按钮删除插件
   - 可以点击配置按钮配置插件

### 5. 如果看不到插件入口

请检查：

1. **是否在访客模式？** 访客模式下不显示插件功能
2. **浏览器是否已刷新？** 按 `Ctrl+Shift+R` (Windows) 或 `Cmd+Shift+R` (Mac) 硬刷新
3. **后端服务是否运行？** 检查浏览器控制台是否有错误
4. **是否登录？** 确保已登录账户

### 6. 插件入口的多个位置

插件入口在现实世界页面中有多个位置：

1. **标签筛选区域右侧**（主要入口）
   - "添加插件" 按钮
   - "编辑插件" 按钮（有插件时显示）

2. **日志编辑器工具栏**（底部工具栏）
   - 插件图标按钮

3. **日志卡片操作区**（每个日志卡片上）
   - 插件图标按钮

## 常见问题

### Q: 点击"添加插件"没有反应？
A: 检查浏览器控制台是否有错误，可能是后端API未启动或返回错误。

### Q: 添加插件后看不到插件容器？
A: 
1. 确保退出编辑模式
2. 检查插件是否被隐藏（`visible: false`）
3. 刷新页面

### Q: 插件执行按钮是灰色的？
A: 确保不在编辑模式下，编辑模式下按钮会被禁用。

## 技术说明

- 插件数据存储在 `scene_plugins` 表中
- 场景ID为 `real-world`
- 插件API路径：`/api/scenes/real-world/plugins`
- 插件执行API路径：`/api/plugins/{pluginId}/execute`
