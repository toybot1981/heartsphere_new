- ✅ **表字符集**: 所有系统表都使用 `utf8mb4_unicode_ci` (正确)

### 2. 应用配置

**MySQL 命令行客户端默认使用 `latin1` 字符集**，导致：
- 查询结果显示乱码（如 `????`）
- 数据本身是正确的，只是显示问题

## 解决方案

### 1. 使用 MySQL 客户端时
**必须指定 UTF-8 字符集**，否则会显示乱码：

```bash
# 方式1：使用 --default-character-set 参数
mysql -h localhost -u root -p123456 heartsphere --default-character-set=utf8mb4

# 方式2：连接后设置字符集
mysql -h localhost -u root -p123456 heartsphere
SET NAMES utf8mb4;

# 方式3：使用便捷脚本
bash backend/scripts/query_with_utf8.sh "SELECT * FROM system_resources LIMIT 10;"
```

### 2. 执行 SQL 脚本时
```bash
# 使用 --default-character-set 参数
mysql -h localhost -u root -p123456 heartsphere --default-character-set=utf8mb4 < script.sql

# 或使用便捷脚本
bash backend/scripts/query_with_utf8.sh script.sql
```

### 3. 应用代码
应用代码已经正确配置，无需修改：
- `application.yml` 中已设置 `characterEncoding=UTF-8`
- `connectionCollation=utf8mb4_unicode_ci` 确保连接使用正确的排序规则
