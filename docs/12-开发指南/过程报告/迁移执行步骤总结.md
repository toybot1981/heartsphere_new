## 第二步执行方法

### 推荐方式：使用数据库管理工具

1. 打开数据库管理工具（MySQL Workbench、Navicat、DBeaver 等）
2. 连接到 `heartsphere` 数据库
3. 执行以下 SQL 文件：
   - `backend/scripts/query_general_images_count.sql` - 快速统计
   - `backend/scripts/generate_general_images_report.sql` - 详细报告

### 或者使用 MySQL 命令行

```bash
# 统计查询
mysql -u root -p heartsphere < backend/scripts/query_general_images_count.sql

# 详细报告（保存到文件）
mysql -u root -p heartsphere < backend/scripts/generate_general_images_report.sql > migration_report.txt
```

## 查询结果说明

查询会返回以下信息：
- 每个表中使用 general 的记录数量
- 每个记录的详细信息（ID、名称、URL、问题类型）

## 迁移规则

根据表的不同，迁移规则如下：

| 表名 | 字段 | 迁移规则 |
|------|------|----------|
| `journal_entries` | `image_url` | `general` → `journal` |
| `characters` | `avatar_url`, `background_url` | `general` → `character` |
| `eras` | `image_url` | `general` → `era` |
| `system_characters` | `avatar_url`, `background_url` | `general` → `character` |
| `system_eras` | `image_url` | `general` → `era` |
| `system_main_stories` | `avatar_url`, `background_url` | `general` → `character` |
| `system_resources` | `url` | 根据 `category` 字段确定 |
