# 视频转动画工具使用指南

## 概述

视频转动画工具允许用户将上传的视频文件转换为动画格式（GIF、Lottie、PAG），支持自定义转换参数，如帧率、尺寸、质量等。

## 功能特性

### ✅ 已实现功能

- **视频上传**：支持 MP4、MOV、AVI、WebM 格式，最大 100MB
- **GIF转换**：完整实现，使用 FFmpeg 进行转换
- **视频元数据提取**：自动提取视频时长、尺寸、帧率等信息
- **格式验证**：自动验证上传文件的格式和大小
- **自定义参数**：支持自定义帧率、尺寸、质量、时长等参数

### ⚠️ 待实现功能

- **Lottie转换**：当前为占位符实现，需要额外的转换工具
- **PAG转换**：当前为占位符实现，需要腾讯 PAG SDK

## 使用方式

### 1. 通过管理后台使用

1. 登录管理后台
2. 进入"系统配置" → "视频管理"
3. 点击"上传视频"按钮
4. 选择视频文件并选择分类文件夹
5. 上传成功后，选择视频并点击"转换为动画"
6. 配置转换参数：
   - **输出格式**：选择 GIF、Lottie 或 PAG（当前仅 GIF 可用）
   - **帧率 (FPS)**：1-30，默认 10
   - **宽度/高度**：自定义尺寸，支持保持宽高比
   - **质量**：低/中/高
   - **开始时间**：从视频的哪个时间点开始转换（秒）
   - **时长**：转换多长的视频片段（秒，0 表示全部）
7. 点击"开始转换"
8. 转换完成后，动画文件会保存在与原视频相同的文件夹下

### 2. 通过 API 使用

#### 上传视频

```bash
POST /api/videos/upload
Content-Type: multipart/form-data

参数：
- file: 视频文件
- category: 分类名称（可选，默认 "general"）
- isSystemResource: 是否为系统资源（可选，默认 false）
```

**响应示例：**
```json
{
  "success": true,
  "url": "http://localhost:8081/videos/general/2026/01/xxx.mp4",
  "relativePath": "general/2026/01/xxx.mp4",
  "message": "视频上传成功"
}
```

#### 转换视频为动画

```bash
POST /api/videos/to-animation
Content-Type: application/json

{
  "url": "http://localhost:8081/videos/general/2026/01/xxx.mp4",
  "format": "gif",
  "fps": 10,
  "width": 640,
  "height": 480,
  "keepAspectRatio": true,
  "quality": "medium",
  "startTime": 0,
  "duration": 10
}
```

**响应示例：**
```json
{
  "success": true,
  "url": "http://localhost:8081/videos/general/2026/01/xxx_animation_640x480_10fps.gif",
  "relativePath": "general/2026/01/xxx_animation_640x480_10fps.gif",
  "format": "gif",
  "originalSize": 10485760,
  "message": "视频转换成功"
}
```

#### 获取视频信息

```bash
GET /api/videos/info?url=http://localhost:8081/videos/general/2026/01/xxx.mp4
```

**响应示例：**
```json
{
  "success": true,
  "width": 1920,
  "height": 1080,
  "duration": 30.5,
  "frameRate": 30.0,
  "fileSize": 10485760,
  "format": "mp4",
  "codec": "h264"
}
```

## 配置说明

### 后端配置（application.yml）

```yaml
app:
  video:
    storage:
      type: local
      local:
        path: ./uploads/videos
      base-url: # 可选，如果未配置则自动使用当前请求的域名
      max-size: 104857600 # 100MB
      supported-formats: mp4,mov,avi,webm
    processing:
      animation:
        default-fps: 10
        max-fps: 30
        default-width: 640
        default-height: 480
        max-duration: 30 # 秒
        default-quality: medium
        supported-formats: gif,lottie,pag
```

### 环境变量

可以通过环境变量覆盖配置：

- `VIDEO_STORAGE_PATH`: 视频存储路径
- `VIDEO_BASE_URL`: 视频服务基础URL
- `VIDEO_MAX_SIZE`: 最大文件大小（字节）
- `VIDEO_SUPPORTED_FORMATS`: 支持的输入格式
- `VIDEO_ANIMATION_DEFAULT_FPS`: 默认帧率
- `VIDEO_ANIMATION_MAX_FPS`: 最大帧率
- `VIDEO_ANIMATION_DEFAULT_WIDTH`: 默认宽度
- `VIDEO_ANIMATION_DEFAULT_HEIGHT`: 默认高度
- `VIDEO_ANIMATION_MAX_DURATION`: 最大时长（秒）
- `VIDEO_ANIMATION_DEFAULT_QUALITY`: 默认质量（low/medium/high）
- `VIDEO_ANIMATION_SUPPORTED_OUTPUT_FORMATS`: 支持的输出格式

## 转换参数说明

### 通用参数

- **format** (string): 输出格式，可选值：`gif`、`lottie`、`pag`
- **fps** (integer): 帧率，范围 1-30，默认 10
- **width** (integer): 输出宽度（像素），默认 640
- **height** (integer): 输出高度（像素），默认 480
- **keepAspectRatio** (boolean): 是否保持宽高比，默认 true
- **quality** (string): 质量等级，可选值：`low`、`medium`、`high`，默认 `medium`
- **startTime** (number): 开始时间（秒），默认 0
- **duration** (number): 转换时长（秒），0 表示转换全部，默认 0

### GIF 格式特定参数

GIF 格式使用通用参数即可，质量参数会影响文件大小和视觉效果。

### Lottie 格式特定参数（待实现）

- **lottiePrecision** (integer): 精度，范围 1-10，默认 3
- **lottieOptimize** (boolean): 是否优化输出文件，默认 true

### PAG 格式特定参数（待实现）

- **pagCompressionLevel** (integer): 压缩级别，范围 0-9，默认 6

## 文件命名规则

转换后的动画文件命名规则：
```
原文件名_animation_宽度x高度_帧率fps.扩展名
```

例如：
- 原文件：`video.mp4`
- 转换后：`video_animation_640x480_10fps.gif`

## 最佳实践

### GIF 转换建议

1. **帧率选择**：
   - 低帧率（5-10 fps）：适合静态场景，文件小
   - 中帧率（10-15 fps）：平衡质量和文件大小
   - 高帧率（20-30 fps）：适合快速动作，文件大

2. **尺寸选择**：
   - 缩略图：200x200 或更小
   - 中等尺寸：640x480
   - 高质量：1280x720 或更大（注意文件大小）

3. **质量选择**：
   - 低质量：适合预览或缩略图
   - 中等质量：适合大多数场景
   - 高质量：适合最终展示

4. **时长控制**：
   - 建议转换时长不超过 30 秒
   - 较短的片段（5-10 秒）转换更快，文件更小

### 性能优化

1. **文件大小**：较大的视频文件转换时间更长，建议先压缩视频
2. **并发处理**：当前为同步处理，大量转换请求可能影响性能
3. **存储空间**：转换后的 GIF 文件可能比原视频更大，注意磁盘空间

## 错误处理

### 常见错误

1. **不支持的视频格式**
   - 错误信息：`不支持的视频格式: xxx`
   - 解决方法：确保视频格式为 MP4、MOV、AVI 或 WebM

2. **文件过大**
   - 错误信息：`文件大小不能超过 100MB`
   - 解决方法：压缩视频或使用更小的文件

3. **不支持的动画格式**
   - 错误信息：`不支持的动画格式: xxx`
   - 解决方法：当前仅支持 GIF，Lottie 和 PAG 待实现

4. **FFmpeg 不可用**
   - 错误信息：`GIF转换失败: ...`
   - 解决方法：确保系统安装了 FFmpeg，或检查 JAVE 依赖是否正确配置

5. **Lottie/PAG 转换未实现**
   - 错误信息：`Lottie转换功能需要额外的转换工具支持`
   - 解决方法：当前版本仅支持 GIF，请使用 GIF 格式

## 技术架构

### 后端

- **框架**：Spring Boot
- **视频处理**：JAVE (Java Audio Video Encoder) - FFmpeg Java wrapper
- **存储**：本地文件系统（可扩展为云存储）

### 前端

- **框架**：React + TypeScript
- **UI组件**：自定义管理后台组件
- **API调用**：基于项目的统一 API 服务

## 依赖要求

### 后端依赖

- `ws.schild:jave-all:3.5.2` - FFmpeg Java wrapper
- Spring Boot Web
- Spring Boot Security（用于认证）

### 系统要求

- Java 17+
- FFmpeg（由 JAVE 自动管理，但需要确保系统可以执行 FFmpeg 命令）
