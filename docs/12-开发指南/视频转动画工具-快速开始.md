# 视频转动画工具 - 快速开始

## 概述

视频转动画工具允许您将视频文件转换为动画格式（当前支持 GIF）。该工具已集成到管理后台，可以通过图形界面或 API 使用。

## 快速开始

### 1. 通过管理后台使用（推荐）

1. **登录管理后台**
   - 访问管理后台并登录

2. **进入视频管理**
   - 点击左侧菜单：`系统配置` → `视频管理`

3. **上传视频**
   - 点击 `📤 上传视频` 按钮
   - 选择视频文件（支持 MP4, MOV, AVI, WebM）
   - 选择分类文件夹（或创建自定义文件夹）
   - 点击上传

4. **转换为动画**
   - 在视频列表中选择要转换的视频
   - 点击右侧面板的 `🎬 转换为动画` 按钮
   - 配置转换参数：
     - **格式**：选择 GIF（当前仅支持 GIF）
     - **帧率**：建议 10-15 fps
     - **尺寸**：建议 640x480 或更小
     - **质量**：选择 medium（平衡质量和文件大小）
   - 点击 `开始转换`

5. **获取结果**
   - 转换完成后，动画文件会保存在与原视频相同的文件夹
   - 文件名格式：`原文件名_animation_宽度x高度_帧率fps.gif`

### 2. 通过 API 使用

#### 上传视频

```bash
curl -X POST http://localhost:8081/api/videos/upload \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@video.mp4" \
  -F "category=general" \
  -F "isSystemResource=true"
```

#### 转换为 GIF

```bash
curl -X POST http://localhost:8081/api/videos/to-animation \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "http://localhost:8081/videos/general/2026/01/xxx.mp4",
    "format": "gif",
    "fps": 10,
    "width": 640,
    "height": 480,
    "quality": "medium"
  }'
```

## 推荐参数

### 缩略图 GIF
- 帧率：5-10 fps
- 尺寸：200x200 或更小
- 质量：low
- 时长：3-5 秒

### 中等质量 GIF
- 帧率：10-15 fps
- 尺寸：640x480
- 质量：medium
- 时长：5-10 秒

### 高质量 GIF
- 帧率：20-30 fps
- 尺寸：1280x720
- 质量：high
- 时长：10-30 秒

## 注意事项

1. **文件大小**：较大的视频文件转换时间更长，建议先压缩视频
2. **时长限制**：建议转换时长不超过 30 秒
3. **格式支持**：当前仅支持 GIF，Lottie 和 PAG 待实现
4. **FFmpeg 要求**：需要系统支持 FFmpeg（由 JAVE 库自动管理）

## 常见问题

**Q: 转换失败怎么办？**
A: 检查视频格式是否支持，文件大小是否超过 100MB，以及系统是否安装了 FFmpeg。

**Q: 转换后的 GIF 文件很大怎么办？**
A: 降低帧率、尺寸或质量，或缩短转换时长。

**Q: 支持哪些视频格式？**
A: 当前支持 MP4, MOV, AVI, WebM。

**Q: 什么时候会支持 Lottie 和 PAG？**
A: 这些功能正在开发中，当前版本仅支持 GIF。
