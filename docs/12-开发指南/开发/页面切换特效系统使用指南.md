# 页面切换特效系统使用指南

## 📋 概述

页面切换特效系统是一个独立的、可复用的组件系统，提供多种页面切换动画效果，特别支持穿越感特效，用于进入/离开共享心域等场景。

---

## 🎯 核心功能

### 1. 多种特效类型

- **fade**: 淡入淡出
- **slide**: 滑动（支持上下左右方向）
- **scale**: 缩放
- **portal**: 穿越（进入）- 特别用于进入共享心域
- **portal-out**: 穿越（离开）- 特别用于离开共享心域
- **blur**: 模糊
- **rotate**: 旋转
- **flip**: 翻转
- **zoom**: 缩放
- **slide-fade**: 滑动+淡入淡出
- **starfield**: 星空穿越

### 2. 便捷的 Hook 和工具

- `usePageTransition`: 本地页面切换控制
- `useGlobalPageTransition`: 全局页面切换管理
- `SharedHeartSphereTransition`: 专门用于共享心域的切换组件
- `SharedHeartSphereWrapper`: 自动检测共享模式并应用特效

## 🚀 快速开始

### 基础使用

```typescript
import { PageTransition } from '../components/transitions';

function MyComponent() {
  return (
    <PageTransition
      type="fade"
      duration={600}
      isVisible={true}
    >
      <div>页面内容</div>
    </PageTransition>
  );
}
```

### 使用 Hook 控制切换

```typescript
import { usePageTransition } from '../hooks/usePageTransition';

function MyComponent() {
  const { state, transition, enterSharedHeartSphere, leaveSharedHeartSphere } = usePageTransition();

  return (
    <PageTransition
      transitionKey={state.transitionKey}
      type={state.isVisible ? 'portal' : 'portal-out'}
      duration={800}
      isVisible={state.isVisible}
    >
      <div>
        <button onClick={enterSharedHeartSphere}>进入共享心域</button>
        <button onClick={leaveSharedHeartSphere}>离开共享心域</button>
      </div>
    </PageTransition>
  );
}
```

### 共享心域专用组件

## 📖 详细用法

### 1. PageTransition 组件

#### 基本属性

```typescript
interface PageTransitionProps {
  children: ReactNode;
  type?: TransitionType;           // 特效类型
  duration?: number;                 // 动画时长（毫秒）
  delay?: number;                   // 延迟时间（毫秒）
  direction?: 'left' | 'right' | 'up' | 'down';  // 方向（用于 slide）
  showLoading?: boolean;             // 是否显示加载状态
  className?: string;               // 自定义类名
  isVisible?: boolean;             // 是否显示
  transitionKey?: string | number;  // 切换键（当 key 变化时触发切换）
  onEnterComplete?: () => void;     // 进入动画完成回调
  onExitComplete?: () => void;     // 离开动画完成回调
}
```

#### 示例

```typescript
// 淡入淡出
<PageTransition type="fade" duration={300}>
  <div>内容</div>
</PageTransition>

// 滑动
<PageTransition 
  type="slide" 
  direction="right" 
  duration={500}
>
  <div>内容</div>
</PageTransition>

// 穿越特效
<PageTransition 
  type="portal" 
  duration={800}
  onEnterComplete={() => console.log('进入完成')}
>
  <div>内容</div>
</PageTransition>
```

### 2. usePageTransition Hook

#### 返回值

```typescript
{
  state: {
    isTransitioning: boolean;    // 是否正在切换
    isVisible: boolean;          // 当前页面是否可见
    transitionKey: string | number; // 切换键
  };
  config: PageTransitionConfig;  // 当前配置
  transition: (type?, duration?) => void;  // 触发切换
  enterSharedHeartSphere: () => void;     // 进入共享心域
  leaveSharedHeartSphere: () => void;     // 离开共享心域
  starfieldTransition: () => void;          // 星空穿越
  reset: () => void;                       // 重置状态
  setConfig: (config) => void;            // 更新配置
}
```

#### 示例

```typescript
const { 
  state, 
  enterSharedHeartSphere, 
  leaveSharedHeartSphere 
} = usePageTransition({
  type: 'portal',
  duration: 800,
});

// 进入共享心域
const handleEnter = () => {
  enterSharedHeartSphere();
  // 执行其他逻辑...
};

// 离开共享心域
const handleLeave = () => {
  leaveSharedHeartSphere();
  // 执行其他逻辑...
};
```

## 🎨 特效说明

### 穿越特效（Portal）

**进入（portal）**:
- 从中心点缩放并旋转进入
- 带有模糊和亮度变化
- 营造穿越时空的感觉

**离开（portal-out）**:
- 向中心点缩放并旋转离开
- 带有模糊和亮度变化
- 营造返回原点的感觉

### 星空穿越（Starfield）

- 3D 透视效果
- 从远处快速拉近
- 带有星空光效
- 营造穿越星空的感觉

### 其他特效

- **fade**: 简单的淡入淡出
- **slide**: 滑动切换（支持方向）
- **scale**: 缩放切换
- **blur**: 模糊切换
- **rotate**: 旋转切换
- **flip**: 翻转切换
- **zoom**: 放大切换
- **slide-fade**: 滑动+淡入淡出组合

```typescript
import { usePageTransition } from '../hooks/usePageTransition';

function ConnectionSpace() {
  const { enterSharedHeartSphere } = usePageTransition();

  const handleConnect = async () => {
    // 触发穿越特效
    enterSharedHeartSphere();
    
    // 执行进入逻辑
    await enterSharedMode(shareConfig, visitorId);
```

### 3. 在离开时触发特效

```typescript
import { usePageTransition } from '../hooks/usePageTransition';
import { useSharedMode } from '../hooks/useSharedMode';

function SharedModeBanner() {
  const { leaveSharedMode } = useSharedMode();
  const { leaveSharedHeartSphere } = usePageTransition();

  const handleLeave = () => {
    // 触发离开特效
    leaveSharedHeartSphere();
    
    // 延迟执行离开逻辑，等待动画完成
    setTimeout(() => {
      leaveSharedMode();
      dispatch({ type: 'SET_CURRENT_SCREEN', payload: 'entryPoint' });
    }, 800);
  };

  return <button onClick={handleLeave}>离开</button>;
}
```

## 📝 最佳实践

### 1. 特效选择

- **进入共享心域**: 使用 `portal` 或 `starfield`
- **离开共享心域**: 使用 `portal-out`
- **普通页面切换**: 使用 `fade` 或 `slide`
- **重要操作**: 使用 `scale` 或 `flip`

### 2. 时长设置

- **快速切换**: 300-400ms
- **标准切换**: 600ms
- **穿越特效**: 800-1000ms
- **星空穿越**: 1000ms

### 3. 性能优化

- 避免在低性能设备上使用复杂特效
- 使用 `showLoading` 在切换时显示加载状态
- 合理使用 `delay` 避免动画冲突

### 4. 用户体验

- 在切换时提供视觉反馈
- 使用回调函数执行后续逻辑
- 确保动画流畅自然

## 🎯 使用场景

### 1. 进入共享心域

```typescript
const handleEnterShared = async () => {
  const { enterSharedHeartSphere } = usePageTransition();
  
  enterSharedHeartSphere();
  await enterSharedMode(shareConfig, visitorId);
  dispatch({ type: 'SET_CURRENT_SCREEN', payload: 'sharedHeartSphere' });
};
```

### 2. 离开共享心域

```typescript
const handleLeaveShared = () => {
  const { leaveSharedHeartSphere } = usePageTransition();
  const { leaveSharedMode } = useSharedMode();
  
  leaveSharedHeartSphere();
  setTimeout(() => {
    leaveSharedMode();
    dispatch({ type: 'SET_CURRENT_SCREEN', payload: 'entryPoint' });
  }, 800);
};
```

### 3. 普通页面切换

```typescript
const { transition } = usePageTransition();

const handleNavigate = (screen: string) => {
  transition('slide', 500);
  setTimeout(() => {
    dispatch({ type: 'SET_CURRENT_SCREEN', payload: screen });
  }, 500);
};
```

## 📚 API 参考

### PageTransition

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| type | TransitionType | 'fade' | 特效类型 |
| duration | number | 600 | 动画时长（毫秒） |
| delay | number | 0 | 延迟时间（毫秒） |
| direction | 'left'\|'right'\|'up'\|'down' | 'right' | 方向（用于 slide） |
| showLoading | boolean | false | 是否显示加载状态 |
| isVisible | boolean | true | 是否显示 |
| transitionKey | string \| number | - | 切换键 |
| onEnterComplete | () => void | - | 进入完成回调 |
| onExitComplete | () => void | - | 离开完成回调 |

### usePageTransition

| 返回值 | 类型 | 说明 |
|--------|------|------|
| state | TransitionState | 切换状态 |
| config | PageTransitionConfig | 当前配置 |
| transition | (type?, duration?) => void | 触发切换 |
| enterSharedHeartSphere | () => void | 进入共享心域 |
| leaveSharedHeartSphere | () => void | 离开共享心域 |
| starfieldTransition | () => void | 星空穿越 |
| reset | () => void | 重置状态 |
| setConfig | (config) => void | 更新配置 |
