║         🎯 Android Studio 配置和运行 - 快速参考            ║
╚═══════════════════════════════════════════════════════════════╝

┌─ STEP 1: Android Studio 首次配置 ─────────────────────────┐
│                                                                │
│  1. 欢迎界面 → 点击 "Next"                                    │
│  2. 安装类型 → 选择 "Standard" → 点击 "Next"                  │
│  3. 验证设置 → 点击 "Finish"                                  │
│  4. 等待下载 SDK 和工具（10-30 分钟）⏳                      │
│  5. 完成后点击 "Finish"                                      │
│                                                                │
└────────────────────────────────────────────────────────────────┘

┌─ STEP 2: 打开心域项目 ─────────────────────────────────────┐
│                                                                │
│  在终端运行：                                                  │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ cd /Users/admin/Workspace/heartsphere_new             │ │
│  │ export NVM_DIR="$HOME/.nvm"                           │ │
│  │ [ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"     │ │
│  │ nvm use 22                                            │ │
│  │ npx cap open android                                   │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                                │
└────────────────────────────────────────────────────────────────┘

┌─ STEP 3: 等待 Gradle 同步 ─────────────────────────────────┐
│                                                                │
│  看到: "Gradle Build Running..."                           │
│  做:   耐心等待 5-10 分钟 ⏳                                 │
│  完成: 看到 "BUILD SUCCESSFUL"                             │
│                                                                │
│  ⚠️  不要点击 Stop！不要关闭 Android Studio！                │
│                                                                │
└────────────────────────────────────────────────────────────────┘

┌─ STEP 4: 创建虚拟设备 ─────────────────────────────────────┐
│                                                                │
│  1. Tools → Device Manager                                   │
│  2. 点击 "Create Device"                                     │
│  3. 选择: Pixel 6 → Next                                     │
│  4. 选择: Android 13.0 (API 33) → Next                       │
│     （如果需要，点击下载）                                    │
│  5. 配置:                                                   │
│     - AVD Name: Pixel_6_API_33                              │
│     - RAM: 2048 MB                                          │
│  6. 点击 "Finish"                                            │
│                                                                │
└────────────────────────────────────────────────────────────────┘

┌─ STEP 5: 运行应用 ─────────────────────────────────────────┐
│                                                                │
│  1. 在顶部工具栏选择设备（Pixel_6_API_33）                   │
│  2. 点击绿色运行按钮 ▶️                                       │
│  3. 等待模拟器启动和应用安装（2-5 分钟）⏳                   │
│  4. 看到"心域"应用界面！✅                                   │
│                                                                │
└────────────────────────────────────────────────────────────────┘
