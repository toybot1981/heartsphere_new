# 图片分辨率展示规则使用指南

**最后更新**: 2025-01-13

---

## 📋 概述

本文档介绍如何在项目中使用统一的图片分辨率展示规则。所有项目（admin、main、edu等）必须遵循相同的规则，确保图片展示的一致性和性能优化。

## 🎯 核心概念

### 展示场景类型

系统定义了以下标准展示场景类型：

- `thumbnail`: 缩略图（列表、卡片等小尺寸展示）
- `list`: 列表项（列表中的图片项）
- `detail`: 详情页/对话框（中等尺寸展示）
- `background`: 移动端背景（移动端全屏背景）
- `chatBackground`: ChatWindow背景（PC端聊天窗口背景）
- `original`: 原图（特殊需求，不推荐）

### 分辨率映射规则

| 场景类型 | PC端分辨率 | 移动端分辨率 | 回退策略 |
|---------|-----------|-------------|---------|
| `thumbnail` / `list` | 200×200 小缩略图 | 200×200 小缩略图 | 原图 |
| `detail` | 800×600 中等质量图 | 800×600 中等质量图 | 小缩略图 → 原图 |
| `background` | 800×600 中等质量图 | 800×600 中等质量图 | 小缩略图 → 原图 |
| `chatBackground` | 1920×1080 高质量图 | 800×600 中等质量图 | 中等质量图 → 小缩略图 → 原图 |
| `original` | 原图 | 原图 | 无 |

## 🚀 快速开始

### 1. 使用 LazyImage 组件（推荐）

`LazyImage` 组件已集成统一规则，自动根据场景选择合适的分辨率。

```tsx
import { LazyImage } from '../components/LazyImage';
import type { ImageVariants } from '../utils/imageResolution';

// 示例：列表中的缩略图
<LazyImage
  src={imageUrl}
  alt="图片描述"
  variants={imageVariants}  // 可选：多分辨率版本URL
  purpose="thumbnail"       // 指定展示场景
  className="w-full h-full object-cover"
/>

// 示例：详情页图片
<LazyImage
  src={imageUrl}
  alt="图片描述"
  variants={imageVariants}
  purpose="detail"
  className="w-full h-full object-cover"
/>

// 示例：PC端ChatWindow背景
<LazyImage
  src={backgroundUrl}
  alt="背景"
  variants={backgroundVariants}
  purpose="chatBackground"
  isMobile={false}  // 可选：手动指定设备类型，默认自动检测
  className="absolute inset-0"
/>
```

### 2. 使用工具函数（高级用法）

如果需要更精细的控制，可以直接使用 `selectImageResolution` 函数：

```tsx
import { selectImageResolution, isMobileDevice } from '../utils/imageResolution';
import type { ImageVariants, ImageDisplayPurpose } from '../utils/imageResolution';

// 获取合适的分辨率URL
const variants: ImageVariants = {
  original: 'https://example.com/image.jpg',
  thumbnail: 'https://example.com/image_200*200.jpg',
  medium: 'https://example.com/image_800*600.jpg',
  highQuality: 'https://example.com/image_1920*1080.jpg'
};

const isMobile = isMobileDevice();
const selectedUrl = selectImageResolution(
  variants.original!,
  variants,
  'chatBackground',
  isMobile
);

// 使用选中的URL
<img src={selectedUrl} alt="图片" />
```

## 🔧 API 参考

### LazyImage 组件属性

| 属性 | 类型 | 必需 | 默认值 | 说明 |
|-----|------|------|--------|------|
| `src` | `string` | ✅ | - | 原图URL |
| `alt` | `string` | ✅ | - | 图片描述 |
| `variants` | `ImageVariants` | ❌ | - | 多分辨率版本URL对象 |
| `purpose` | `ImageDisplayPurpose` | ❌ | `'detail'` | 展示场景类型 |
| `isMobile` | `boolean` | ❌ | 自动检测 | 是否为移动端 |
| `className` | `string` | ❌ | `''` | CSS类名 |
| `placeholder` | `string` | ❌ | `'/placeholder.png'` | 占位符图片 |
| `onLoad` | `() => void` | ❌ | - | 加载完成回调 |
| `onError` | `() => void` | ❌ | - | 加载失败回调 |

### selectImageResolution 函数

```typescript
function selectImageResolution(
  imageUrl: string,
  variants?: ImageVariants,
  purpose: ImageDisplayPurpose = 'detail',
  isMobile: boolean = false
): string
```

**参数说明**：
- `imageUrl`: 原图URL（必需）
- `variants`: 多分辨率版本URL对象（可选）
- `purpose`: 展示场景类型（可选，默认 `'detail'`）
- `isMobile`: 是否为移动端（可选，默认 `false`）

**返回值**：选择的分辨率版本URL

### ImageVariants 接口

```typescript
interface ImageVariants {
  original?: string;      // 原图URL
  thumbnail?: string;     // 缩略图URL (200x200)
  medium?: string;        // 中等质量图URL (800x600)
  highQuality?: string;   // 高质量背景图URL (1920x1080)
}
```

### ImageDisplayPurpose 类型

```typescript
type ImageDisplayPurpose = 
  | 'thumbnail'      // 缩略图
  | 'list'           // 列表项
  | 'detail'         // 详情页/对话框
  | 'background'     // 移动端背景
  | 'chatBackground' // PC ChatWindow背景
  | 'original';      // 原图（不推荐）
```

## ⚠️ 注意事项

1. **始终使用标准场景类型**：不要自定义场景名称，必须使用预定义的类型。

2. **提供 variants 参数**：如果后端返回了多分辨率版本URL，应该传递给组件，以获得最佳性能。

3. **设备类型检测**：`LazyImage` 组件会自动检测设备类型，也可以手动指定 `isMobile` 参数。

4. **回退策略**：如果目标分辨率不存在，系统会自动按优先级回退，无需手动处理。

5. **向后兼容**：如果没有提供 `variants` 参数，组件会使用原图，保持向后兼容。

## 🔄 迁移指南

### 从旧代码迁移

#### 旧代码（直接使用 img 标签）

```tsx
// ❌ 旧代码

```

#### 新代码（使用 LazyImage）

```tsx
// ✅ 新代码
<LazyImage
  src={imageUrl}
  alt="图片"
  purpose="detail"  // 根据实际场景选择
  className="w-full h-full object-cover"
/>
```

### 从自定义分辨率选择逻辑迁移

#### 旧代码（自定义逻辑）

```tsx
// ❌ 旧代码
const getImageUrl = () => {
  if (variants?.thumbnail && purpose === 'thumbnail') {
    return variants.thumbnail;
  }
  if (variants?.medium && purpose === 'detail') {
    return variants.medium;
  }
  return imageUrl;
};

<img src={getImageUrl()} alt="图片" />
```

#### 新代码（使用统一规则）

```tsx
// ✅ 新代码
<LazyImage
  src={imageUrl}
  alt="图片"
  variants={variants}
  purpose={purpose}
/>
```

## 🐛 常见问题

### Q: 如何知道应该使用哪个场景类型？

A: 根据图片的展示位置和尺寸选择：
- 列表、卡片、小图标 → `thumbnail` 或 `list`
- 详情页、对话框、中等尺寸展示 → `detail`
- 移动端全屏背景 → `background`
- PC端ChatWindow背景 → `chatBackground`
- 特殊需求（如下载、打印） → `original`

### Q: 如果没有提供 variants 参数会怎样？

A: 组件会使用原图，保持向后兼容。但建议提供 variants 以获得更好的性能。

### Q: 如何手动指定设备类型？

A: 传递 `isMobile` 参数：
```tsx
<LazyImage
  src={imageUrl}
  alt="图片"
  purpose="chatBackground"
  isMobile={true}  // 手动指定为移动端
/>
```

### Q: 回退策略是如何工作的？

A: 系统会按优先级自动回退：
- 小缩略图场景：目标分辨率 → 原图
- 中等质量场景：目标分辨率 → 小缩略图 → 原图
- 高质量场景：目标分辨率 → 中等质量图 → 小缩略图 → 原图
