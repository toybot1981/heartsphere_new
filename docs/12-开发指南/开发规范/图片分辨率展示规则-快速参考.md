# 图片分辨率展示规则 - 快速参考卡片

**最后更新**: 2025-01-13

---

## 🚀 5秒速查

### ✅ 正确写法

```tsx
import { LazyImage } from '../components/LazyImage';

<LazyImage
  src={imageUrl}
  alt="图片描述"
  purpose="thumbnail"  // 必须指定
  className="w-full h-full object-cover"
/>
```

### ❌ 错误写法

```tsx
// ❌ 禁止：直接使用 img 标签
<img src={imageUrl} alt="图片描述" />
```

---

## 📋 场景类型速查表

| 展示位置 | purpose 值 | 示例 |
|---------|-----------|------|
| 列表、卡片、小图标（< 100px） | `thumbnail` | 角色列表头像 |
| 列表项 | `list` | 资源列表项 |
| 详情页、对话框 | `detail` | 角色详情页 |
| 移动端背景 | `background` | 移动端全屏背景 |
| PC端ChatWindow背景 | `chatBackground` | PC聊天窗口背景 |
| 特殊需求 | `original` | 下载、打印（不推荐） |

---

## 🔍 代码审查检查

### 必须检查项

- [ ] 使用 `LazyImage` 组件（不是 `<img>`）
- [ ] 指定了 `purpose` 参数
- [ ] `purpose` 值符合标准类型
- [ ] 如果后端支持，提供了 `variants` 参数

### 常见错误

- ❌ 直接使用 `<img>` 标签
- ❌ 未指定 `purpose` 参数
- ❌ 使用自定义场景类型
- ❌ 场景类型选择错误
