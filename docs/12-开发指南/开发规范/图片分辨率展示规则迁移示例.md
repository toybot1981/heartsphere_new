# 图片分辨率展示规则迁移示例

**最后更新**: 2025-01-13

---

## 📋 概述

本文档提供实际代码迁移示例，展示如何将现有代码迁移到统一的图片分辨率展示规则。

---

## 🎯 需要迁移的文件清单

根据代码扫描，以下文件需要迁移：

### main/frontend/components

1. **EraConstructorModal.tsx** - 时代构造器模态框
2. **EntryPoint.tsx** - 入口点组件（头像显示）
3. **RealWorldScreen.tsx** - 真实世界屏幕
4. **UserProfile.tsx** - 用户资料（多个头像）
5. **MessageList.tsx** - 消息列表
6. **InitializationWizard.tsx** - 初始化向导
7. **CharacterConstructorModal.tsx** - 角色构造器
8. **MailboxModal.tsx** - 信箱模态框

### admin/frontend/src/components

1. **CharactersManagement.tsx** - 角色管理（头像和背景）
2. **ErasManagement.tsx** - 时代管理
3. **PluginManagement.tsx** - 插件管理

## 📝 迁移示例

### 示例1：EraConstructorModal.tsx - 封面图片

**文件位置**: `main/frontend/components/EraConstructorModal.tsx`  
**行号**: 481

#### 迁移前

```tsx
{imageUrl ? (
    <img src={imageUrl} alt="Cover" className="w-full h-full object-cover" />
) : (
    <div className="text-center p-2">
        <div className="flex flex-col items-center text-gray-400">
            <span>点击上传封面</span>
        </div>
    </div>
)}
```

#### 迁移后

```tsx
import { LazyImage } from './LazyImage';

{imageUrl ? (
    <LazyImage
        src={imageUrl}
        alt="Cover"
        purpose="detail"  // 详情页场景
        className="w-full h-full object-cover"
    />
) : (
    <div className="text-center p-2">
        <div className="flex flex-col items-center text-gray-400">
            <span>点击上传封面</span>
        </div>
    </div>
)}
```

**说明**: 封面图片在详情页显示，使用 `detail` 场景。

### 示例4：UserProfile.tsx - 多个头像

**文件位置**: `main/frontend/components/UserProfile.tsx`  
**行号**: 多个位置

#### 迁移前

```tsx
{/* 用户头像 */}
<img src={userProfile.avatarUrl} alt="Avatar" className="w-full h-full object-cover" />

{/* 场景缩略图 */}
<img src={scene.imageUrl} alt={scene.name} className="w-10 h-10 rounded-lg object-cover" />

{/* 角色头像 */}
<img src={character.avatarUrl} alt={character.name} className="w-10 h-10 rounded-full object-cover" />
```

#### 迁移后

```tsx
import { LazyImage } from './LazyImage';

{/* 用户头像 - 大尺寸，使用详情场景 */}
<LazyImage
    src={userProfile.avatarUrl}
    alt="Avatar"
    purpose="detail"
    className="w-full h-full object-cover"
/>

{/* 场景缩略图 - 小尺寸，使用缩略图场景 */}
<LazyImage
    src={scene.imageUrl}
    alt={scene.name}
    purpose="thumbnail"
    className="w-10 h-10 rounded-lg object-cover"
/>

{/* 角色头像 - 小尺寸，使用缩略图场景 */}
<LazyImage
    src={character.avatarUrl}
    alt={character.name}
    purpose="thumbnail"
    className="w-10 h-10 rounded-full object-cover"
/>
```

**说明**: 
- 大尺寸头像使用 `detail`
- 小尺寸头像（10×10）使用 `thumbnail`

## 🔄 批量迁移脚本

### 查找需要迁移的文件

```bash
#!/bin/bash
# find-images-to-migrate.sh

echo "=== 查找需要迁移的文件 ==="
echo ""
echo "main/frontend/components:"
grep -r "<img" --include="*.tsx" main/frontend/components | grep -v "LazyImage" | cut -d: -f1 | sort -u

echo ""
echo "admin/frontend/src/components:"
grep -r "<img" --include="*.tsx" admin/frontend/src/components | grep -v "LazyImage" | cut -d: -f1 | sort -u
```

### 迁移进度统计

```bash
#!/bin/bash
# migration-progress.sh

echo "=== 迁移进度统计 ==="
echo ""

TOTAL_IMG=$(grep -r "<img" --include="*.tsx" main/frontend/components admin/frontend/src/components 2>/dev/null | wc -l | tr -d ' ')
LAZY_IMAGE=$(grep -r "LazyImage" --include="*.tsx" main/frontend/components admin/frontend/src/components 2>/dev/null | wc -l | tr -d ' ')

echo "总 img 标签数: $TOTAL_IMG"
echo "LazyImage 使用数: $LAZY_IMAGE"

if [ "$TOTAL_IMG" -gt 0 ]; then
    PROGRESS=$(( LAZY_IMAGE * 100 / TOTAL_IMG ))
    echo "迁移进度: $PROGRESS%"
else
    echo "迁移进度: 100%"
fi
```
