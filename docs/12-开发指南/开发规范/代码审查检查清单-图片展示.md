# 代码审查检查清单 - 图片展示规范

**最后更新**: 2025-01-13  
**适用范围**: 所有前端代码审查

---

## 📋 强制检查项

### ✅ 必须使用 LazyImage 组件

- [ ] **禁止直接使用 `<img>` 标签**
  - ❌ 错误: `<img src={url} alt="..." />`
  - ✅ 正确: `<LazyImage src={url} alt="..." purpose="..." />`

- [ ] **已导入 LazyImage 组件**
  ```tsx
  import { LazyImage } from '../components/LazyImage';
  // 或
  import { LazyImage } from './LazyImage';
  ```

### ✅ 必须指定场景类型

- [ ] **已指定 `purpose` 参数**
  - 必须使用标准场景类型：`thumbnail`, `list`, `detail`, `background`, `chatBackground`, `original`
  - 禁止自定义场景类型

- [ ] **场景类型选择正确**
  - 列表、卡片、小图标（< 100px）→ `thumbnail`
  - 列表项 → `list`
  - 详情页、对话框 → `detail`
  - 移动端背景 → `background`
  - PC端ChatWindow背景 → `chatBackground`
  - 特殊需求 → `original`（需说明原因）

### ✅ 提供 variants 参数（如果可用）

- [ ] **如果后端返回了多分辨率版本URL，已传递给组件**
  ```tsx
  <LazyImage
    src={imageUrl}
    variants={imageVariants}  // 如果后端提供了
    purpose="detail"
  />
  ```

## 🚫 常见错误

### 错误1：直接使用 img 标签

```tsx
// ❌ 错误
<img src={imageUrl} alt="图片" />

// ✅ 正确
<LazyImage src={imageUrl} alt="图片" purpose="detail" />
```

### 错误2：未指定 purpose 参数

```tsx
// ❌ 错误（虽然不会报错，但不推荐）
<LazyImage src={imageUrl} alt="图片" />

// ✅ 正确
<LazyImage src={imageUrl} alt="图片" purpose="detail" />
```

### 错误3：使用自定义场景类型

```tsx
// ❌ 错误
<LazyImage src={imageUrl} purpose="custom" />

// ✅ 正确
<LazyImage src={imageUrl} purpose="thumbnail" />
```

### 错误4：场景类型选择错误

```tsx
// ❌ 错误：列表中的小图片使用 detail
<LazyImage src={imageUrl} purpose="detail" />

// ✅ 正确：列表中的小图片使用 thumbnail
<LazyImage src={imageUrl} purpose="thumbnail" />
```
