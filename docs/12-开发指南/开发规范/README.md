## 📝 文档维护

### 更新原则

1. **及时更新**: 规范变更后及时更新文档
2. **版本管理**: 重要变更更新版本号
3. **变更记录**: 在版本历史中记录变更内容
4. **通知团队**: 重要规范变更通知团队

### 新增规范文档

新增规范文档时：

1. 将文档放入 `docs/12-开发指南/开发规范/` 目录
2. 按照命名规范命名文档：`{功能名}开发规范.md`
3. 在本文档中添加文档索引
4. 更新相关引用
