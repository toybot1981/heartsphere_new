## ✅ 迁移步骤

### 步骤1：导入 LazyImage 组件

```tsx
// 在文件顶部添加
import { LazyImage } from '../components/LazyImage';
// 或
import { LazyImage } from './LazyImage';
```

### 步骤2：替换 img 标签

**旧代码**:
```tsx
<img 
  src={imageUrl} 
  alt="图片" 
  className="w-full h-full object-cover"
/>
```

**新代码**:
```tsx
<LazyImage
  src={imageUrl}
  alt="图片"
  purpose="detail"  // 根据实际场景选择
  className="w-full h-full object-cover"
/>
```

### 步骤3：确定场景类型

根据图片的展示位置选择 `purpose` 值：

| 展示位置 | purpose 值 |
|---------|-----------|
| 列表、卡片、小图标 | `thumbnail` |
| 详情页、对话框 | `detail` |
| 移动端全屏背景 | `background` |
| PC端ChatWindow背景 | `chatBackground` |

### 步骤4：添加 variants 参数（如果可用）

如果后端返回了多分辨率版本URL，添加 `variants` 参数：

```tsx
<LazyImage
  src={imageUrl}
  alt="图片"
  variants={imageVariants}  // 如果后端提供了
  purpose="detail"
  className="w-full h-full object-cover"
/>
```

### 步骤5：测试验证

- [ ] 图片正常显示
- [ ] 不同场景使用正确的分辨率
- [ ] 回退策略正常工作
- [ ] 无控制台错误

## 🎯 按优先级迁移

### 高优先级（立即迁移）

1. **列表和卡片组件**
   - 使用频率高
   - 性能影响大
   - 迁移简单

2. **详情页组件**
   - 用户体验影响大
   - 迁移简单

### 中优先级（逐步迁移）

1. **背景组件**
   - 使用频率中等
   - 需要设备类型检测

2. **特殊场景组件**
   - 使用频率低
   - 可能需要特殊处理

### 低优先级（可选迁移）

1. **一次性组件**
   - 使用频率极低
   - 可以保持原样

## 🔧 迁移工具脚本

### 查找需要迁移的文件

```bash
#!/bin/bash
# find-images-to-migrate.sh

echo "查找直接使用 img 标签的文件..."
echo "=== main/frontend/components ==="
grep -r "<img" --include="*.tsx" --include="*.ts" main/frontend/components | grep -v "LazyImage" | cut -d: -f1 | sort -u

echo ""
echo "=== admin/frontend/src/components ==="
grep -r "<img" --include="*.tsx" --include="*.ts" admin/frontend/src/components | grep -v "LazyImage" | cut -d: -f1 | sort -u
```

### 统计迁移进度

```bash
#!/bin/bash
# migration-progress.sh

TOTAL_IMG=$(grep -r "<img" --include="*.tsx" --include="*.ts" main/frontend/components admin/frontend/src/components | wc -l)
LAZY_IMAGE=$(grep -r "LazyImage" --include="*.tsx" --include="*.ts" main/frontend/components admin/frontend/src/components | wc -l)

echo "总 img 标签数: $TOTAL_IMG"
echo "LazyImage 使用数: $LAZY_IMAGE"
echo "迁移进度: $(( LAZY_IMAGE * 100 / TOTAL_IMG ))%"
```
