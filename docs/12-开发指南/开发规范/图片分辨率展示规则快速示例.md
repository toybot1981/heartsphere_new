# 图片分辨率展示规则快速示例

**最后更新**: 2025-01-13

---

## 🚀 5分钟快速上手

### 场景1：列表中的缩略图

```tsx
import { LazyImage } from '../components/LazyImage';

// 在角色列表中使用
<div className="grid grid-cols-4 gap-4">
  {characters.map((character) => (
    <div key={character.id} className="w-20 h-20 rounded-full overflow-hidden">
      <LazyImage
        src={character.avatarUrl}
        alt={character.name}
        variants={character.avatarVariants}  // 可选：如果后端提供了多分辨率版本
        purpose="thumbnail"                   // 使用缩略图场景
        className="w-full h-full object-cover"
      />
    </div>
  ))}
</div>
```

**效果**：自动使用 200×200 小缩略图，如果不存在则回退到原图。

### 场景3：ChatWindow背景（PC端）

```tsx
import { LazyImage } from '../components/LazyImage';
import { isMobileDevice } from '../utils/imageResolution';

// 在ChatWindow组件中
const isMobile = isMobileDevice();

<div className="absolute inset-0 z-0">
  <LazyImage
    src={backgroundImage}
    alt="背景"
    variants={backgroundVariants}  // 可选
    purpose="chatBackground"       // 使用ChatWindow背景场景
    isMobile={isMobile}            // 自动检测或手动指定
    className="w-full h-full object-cover"
  />
</div>
```

**效果**：
- PC端：自动使用 1920×1080 高质量图
- 移动端：自动使用 800×600 中等质量图
- 如果目标分辨率不存在，自动按优先级回退

### 场景5：直接使用工具函数（高级）

```tsx
import { selectImageResolution, isMobileDevice } from '../utils/imageResolution';
import type { ImageVariants } from '../utils/imageResolution';

// 获取合适的分辨率URL
const variants: ImageVariants = {
  original: 'https://example.com/image.jpg',
  thumbnail: 'https://example.com/image_200*200.jpg',
  medium: 'https://example.com/image_800*600.jpg',
  highQuality: 'https://example.com/image_1920*1080.jpg'
};

const isMobile = isMobileDevice();
const selectedUrl = selectImageResolution(
  variants.original!,
  variants,
  'chatBackground',  // 场景类型
  isMobile           // 设备类型
);

// 使用选中的URL（例如在CSS背景中）
<div 
  className="absolute inset-0 bg-cover bg-center"
  style={{ backgroundImage: `url(${selectedUrl})` }}
/>
```

## 📋 场景类型速查表

| 场景 | 场景类型 | 适用位置 | 分辨率 |
|-----|---------|---------|--------|
| 列表缩略图 | `thumbnail` | 角色列表、资源列表、卡片 | 200×200 |
| 列表项 | `list` | 列表中的图片项 | 200×200 |
| 详情页 | `detail` | 详情页、对话框、中等尺寸展示 | 800×600 |
| 移动端背景 | `background` | 移动端全屏背景 | 800×600 |
| PC背景 | `chatBackground` | PC端ChatWindow背景 | 1920×1080 (PC) / 800×600 (移动) |
| 原图 | `original` | 特殊需求（不推荐） | 原图 |

## 💡 最佳实践

### ✅ 推荐做法

```tsx
// 1. 始终指定 purpose 参数
<LazyImage
  src={imageUrl}
  alt="图片"
  purpose="thumbnail"  // ✅ 明确指定场景
/>

// 2. 提供 variants 参数（如果后端支持）
<LazyImage
  src={imageUrl}
  alt="图片"
  variants={imageVariants}  // ✅ 提供多分辨率版本
  purpose="detail"
/>

// 3. 让组件自动检测设备类型
<LazyImage
  src={imageUrl}
  alt="图片"
  purpose="chatBackground"
  // ✅ 不指定 isMobile，让组件自动检测
/>
```

### ❌ 避免做法

```tsx
// 1. 不要直接使用 img 标签（除非特殊需求）
<img src={imageUrl} alt="图片" />  // ❌ 不使用统一规则

// 2. 不要自定义场景类型
<LazyImage
  src={imageUrl}
  purpose="custom"  // ❌ 使用标准场景类型
/>

// 3. 不要手动实现分辨率选择逻辑
const url = variants?.customSize || imageUrl;  // ❌ 使用统一工具函数
```

## 🔍 常见场景映射

### 从旧代码迁移

```tsx
// 旧代码：根据 size 选择
const url = size === 'small' 
  ? variants?.small || imageUrl
  : variants?.large || imageUrl;

// 新代码：使用 purpose
<LazyImage
  src={imageUrl}
  variants={variants}
  purpose={size === 'small' ? 'thumbnail' : 'detail'}
/>
```

```tsx
// 旧代码：根据设备类型选择
const url = isMobile 
  ? variants?.mobile || imageUrl
  : variants?.desktop || imageUrl;

// 新代码：使用 chatBackground 场景
<LazyImage
  src={imageUrl}
  variants={variants}
  purpose="chatBackground"
  isMobile={isMobile}
/>
```
