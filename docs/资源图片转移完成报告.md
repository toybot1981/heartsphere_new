# 资源图片转移完成报告

## 转移时间
2025-01-05

## 转移内容
根据资源类别（`item` 和 `event`），将资源图片从其他目录转移到对应的 `item` 和 `event` 文件夹下。

## 转移步骤

### 1. 数据库 URL 更新
执行 `backend/scripts/update_resources_urls_to_item_event_folders.sql` 更新数据库中的图片 URL：

- **Item 类别**：将 URL 从 `general/...`、`character/...`、`scenario/...` 等更新为 `item/2025/12/...`
- **Event 类别**：将 URL 从 `era/...`、`general/...` 等更新为 `event/2025/12/...`

### 2. 物理文件转移
执行 `backend/scripts/move_resources_files_to_item_event_folders.sh` 移动物理文件：

- **Item 图片**：从 `general/`、`character/`、`scenario/` 等目录移动到 `item/2025/12/`
- **Event 图片**：从 `era/`、`general/` 等目录移动到 `event/2025/12/`

## 验证

执行以下命令可以验证转移结果：

```bash

find backend/uploads/images/item -type f | wc -l

# 检查 event 目录文件数
find backend/uploads/images/event -type f | wc -l

# 检查数据库 URL
mysql -h localhost -u root -p123456 heartsphere --default-character-set=utf8mb4 -e "
SELECT category, 
       COUNT(*) as total,
       SUM(CASE WHEN url LIKE 'item/%' THEN 1 ELSE 0 END) as item_url,
       SUM(CASE WHEN url LIKE 'event/%' THEN 1 ELSE 0 END) as event_url
FROM system_resources
WHERE category IN ('item', 'event')
GROUP BY category;
"
```
