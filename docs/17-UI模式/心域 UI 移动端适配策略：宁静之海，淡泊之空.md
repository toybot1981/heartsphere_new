# 心域 UI 移动端适配策略：宁静之海，淡泊之空

本移动端适配策略旨在确保“宁静之海，淡泊之空”的视觉风格在移动设备上得到完美延续，同时优化用户体验，强调**放松、易用和沉浸感**。

## 一、 适配核心原则

1.  **保持宁静感：** 延续浅蓝背景和充足留白，避免信息密度过高带来的压迫感。
2.  **触控优化：** 确保所有交互元素（按钮、卡片）的点击区域（Tap Target）符合移动端规范，易于单手操作。
3.  **内容流优先：** 将桌面端的并列布局（如个人资料页的两栏）转换为移动端的垂直堆叠布局。

## 二、 关键页面适配策略

| 页面 | 桌面端布局 | 移动端适配策略 | 视觉效果优化 |
| :--- | :--- | :--- | :--- |
| **登录/入口页** | 居中卡片 | **全屏居中**，卡片宽度适应屏幕，高度自适应。 | 柔和的背景渐变和卡片的“浮动”效果更加突出，增强沉浸感。 |
| **心域主页（场景选择）** | 网格/并列卡片 | **垂直堆叠**，卡片宽度 100% 适应屏幕，或采用**水平滑动**（Carousel）展示。 | 增加卡片高度，确保卡片内的自然插画清晰可见，保持视觉上的“呼吸感”。 |
| **个人资料页** | 两栏布局 | **垂直堆叠**。顶部为头像和核心数据，下方为设置列表。 | 设置列表采用**全宽列表项**，点击区域更大，图标和文字清晰。 |
| **剧本编辑页** | 复杂多区域 | **分步或分层**。将角色选择、剧本描述、节点流程等复杂区域拆分为独立的步骤或可折叠面板。 | 节点流程图可能需要优化为**可缩放/拖动**的视图，或简化为列表式编辑。 |

## 三、 视觉元素适配

| 元素 | 适配调整 | 目的 |
| :--- | :--- | :--- |
| **字体** | 适当增大基础字号（如正文 14px 调整为 16px），并确保行高充足。 | 提升在小屏幕上的可读性和舒适度。 |
| **圆角** | 保持与桌面端一致的中等到大圆角（8px-16px）。 | 延续柔和、放松的视觉风格。 |
| **阴影** | 保持柔和的浅蓝色阴影，但**略微减弱**，以确保在移动端快速滚动时性能流畅。 | 维持“浮动”感，同时优化性能。 |
| **导航** | 采用**底部 Tab Bar** 作为主要导航，将桌面端的顶部/侧边导航项整合。 | 方便单手操作，提升核心功能的可达性。 |

通过上述策略，这套设计方案在移动设备上不仅能保持其宁静、放松的视觉风格，还能提供流畅、舒适的触控交互体验。
