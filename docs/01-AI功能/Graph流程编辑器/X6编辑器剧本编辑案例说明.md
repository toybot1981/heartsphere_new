# X6 编辑器剧本编辑案例说明

## 概述

我已经创建了一个完整的剧本编辑示例 Graph，名为 **"剧本编辑示例 - 三幕剧"**，展示了剧本创建、场景管理、对话配置、剧情分支等完整流程。

## 如何查看示例

1. **启动后端服务**（如果尚未启动）
2. **运行数据库迁移**：示例数据会在 Flyway 迁移时自动插入
3. **打开 Admin 管理端**
4. **进入 Graph 编辑器**：左侧菜单 → 内容管理 → Graph流程编辑器
5. **勾选 "使用 X6 编辑器（POC）"**
6. **找到 "剧本编辑示例 - 三幕剧"** 并点击"编辑流程"

## 示例包含的节点类型

### ✅ 1. Start 节点（开始）
- **节点ID**: `start_script_1`
- **位置**: (100, 50)
- **功能**: 剧本编辑流程的起始点

### ✅ 2. Dialogue 节点（对话）
- **节点数量**: 21 个
- **功能**: 显示系统提示、旁白、角色对话
- **关键对话**:
  - `dialogue_script_1`: 欢迎信息
  - `dialogue_script_4`: 第一幕场景介绍
  - `dialogue_script_6`: 老人对话
  - `dialogue_script_11`: 第二幕场景介绍
  - `dialogue_script_15`: 第三幕场景介绍
  - `dialogue_script_16`: 真相揭示
  - `dialogue_script_17-19`: 三种不同的结局

### ✅ 3. Wait 节点（等待）
- **节点ID**: `wait_script_1`
- **位置**: (100, 500)
- **功能**: 等待用户输入剧本基本信息
- **配置**:
  - 等待类型: `USER_INPUT`
  - 等待条件: `scriptBasicInfo`
  - 超时时间: 60000ms (60秒)

### ✅ 4. Condition 节点（条件判断）
- **节点数量**: 4 个
- **功能**: 判断选择、探索结果、结局类型、保存操作
- **判断逻辑**:
  - `condition_script_1`: 判断是否选择了感谢
  - `condition_script_2`: 判断探索是否成功
  - `condition_script_3`: 判断是否接受职责
  - `condition_script_4`: 判断是否保存

### ✅ 5. Choice 节点（选择）
- **节点数量**: 3 个
- **功能**: 让玩家做出选择
- **选择内容**:
  - `choice_script_1`: 玩家回应选择（我是谁/发生了什么/谢谢你）
  - `choice_script_2`: 最终选择（接受职责/拒绝/寻求真相）
  - `choice_script_3`: 保存或继续编辑（保存/保存并发布/继续编辑）

### ✅ 6. Skill Check 节点（技能检查）
- **节点ID**: `skill_check_script_1`
- **位置**: (100, 2750)
- **功能**: 探索技能检查
- **配置**:
  - 技能: `exploration`
  - 难度: 12
  - 成功效果: 找到线索，进度+20
  - 失败效果: 进度+10

### ✅ 7. State Change 节点（状态变更）
- **节点数量**: 8 个
- **功能**: 保存剧本信息和更新剧情状态
- **变更内容**:
  - `state_change_script_1`: 保存剧本基本信息
  - `state_change_script_2-4,6`: 创建场景（第一幕、第二幕、第三幕）
  - `state_change_script_3`: 更新角色关系
  - `state_change_script_5`: 更新剧情进度
  - `state_change_script_7`: 保存结局
  - `state_change_script_8`: 保存剧本到数据库

### ✅ 8. End 节点（结束）
- **节点数量**: 2 个
- **功能**: 流程结束点
- **结局类型**:
  - `end_script_1`: 剧本保存完成
  - `end_script_2`: 继续编辑

## 三幕剧结构

### 第一幕：失忆（Act 1）
- **场景**: 主角在小镇上醒来，失去记忆
- **关键对话**: 老人（张伯）介绍情况
- **玩家选择**: 如何回应老人（影响信任度和好感度）
- **结果**: 建立角色关系，第一幕结束

### 第二幕：探索（Act 2）
- **场景**: 主角在小镇中探索
- **技能检查**: 探索技能检查（难度12）
- **成功**: 发现旧照片线索
- **失败**: 没有发现特别的东西
- **结果**: 更新剧情进度，第二幕结束

### 第三幕：真相（Act 3）
- **场景**: 真相揭示，面临选择
- **关键对话**: 张伯揭示主角是守护者
- **最终选择**: 
  - 接受职责 → 英雄结局
  - 拒绝 → 和平结局
  - 寻求真相 → 神秘结局
- **结果**: 剧本完成，保存或继续编辑

## 流程路径

### 主路径（完整三幕剧）:
```
Start → Dialogue 1 → Dialogue 2 → Wait 1 → State Change 1 
→ Dialogue 3 → Dialogue 4 → State Change 2 (第一幕)
→ Dialogue 5 → Dialogue 6 → Choice 1 → Dialogue 7 
→ Condition 1 → [Dialogue 8/Dialogue 9] → State Change 3 
→ Dialogue 10 → Dialogue 11 → State Change 4 (第二幕)
→ Skill Check 1 → Condition 2 → [Dialogue 12/Dialogue 13] 
→ State Change 5 → Dialogue 14 → Dialogue 15 
→ State Change 6 (第三幕) → Dialogue 16 → Choice 2 
→ Condition 3 → [Dialogue 17/Dialogue 18/Dialogue 19] 
→ State Change 7 → Dialogue 20 → Choice 3 
→ Condition 4 → State Change 8 → Dialogue 21 → End 1
```

### 分支路径:
1. **第一幕选择分支**: 根据玩家回应影响后续对话
2. **探索结果分支**: 技能检查成功/失败影响发现的内容
3. **结局分支**: 三种不同的结局选择
4. **保存分支**: 保存、发布或继续编辑

## 剧本要素

### 基本信息
- 剧本名称
- 剧本类型
- 剧本简介
- 剧本类型（Genre）

### 场景管理
- **第一幕**: 失忆场景
- **第二幕**: 探索场景
- **第三幕**: 真相场景

### 角色对话
- **系统/旁白**: 场景描述和提示
- **老人-张伯**: 关键NPC对话
- **玩家**: 通过选择节点参与

### 剧情分支
- 第一幕选择影响角色关系
- 第二幕探索影响发现的线索
- 第三幕选择决定结局类型

### 三种结局
1. **英雄结局**: 接受守护者职责，成为英雄
2. **和平结局**: 拒绝职责，回归普通生活
3. **神秘结局**: 寻求更多真相，继续探索

## 编辑建议

1. **查看三幕结构**: 从 Start 开始，按照场景切换查看完整流程
2. **测试分支路径**: 查看不同选择导致的不同路径和结局
3. **修改对话内容**: 双击 Dialogue 节点编辑对话文本
4. **添加新场景**: 可以在三幕之间添加更多场景
5. **扩展结局**: 可以添加更多结局选择
6. **修改技能检查**: 调整难度和成功/失败效果

## 注意事项

- 示例数据通过 Flyway 迁移脚本自动插入
- 如果数据库中已存在同名 Graph，迁移可能会失败
- 可以在 Admin 端直接编辑和保存这个示例
- 建议在编辑前先复制一份作为备份
- 节点配置中的模板变量（如 `{{scriptName}}`）需要在执行时替换为实际值

## 剧本示例故事概要

**遗忘小镇** - 一个三幕互动剧本

主角在一个神秘的小镇上醒来，发现自己失去了记忆。在老人张伯的帮助下，主角开始探索这个小镇，寻找关于自己身份的线索。通过一系列的选择和探索，主角最终发现了自己的真实身份：小镇的守护者。面对这个真相，主角需要做出选择：接受职责、拒绝回归普通生活，或是寻求更多真相...

这是一个典型的三幕剧结构，适合作为剧本编辑系统的参考模板。
