# X6 Graph 流程编辑器访问指南

**更新日期**: 2025-01-03

---

## 一、访问路径

### 1. 登录管理后台

首先需要登录到管理后台系统。

---

### 2. 进入 Graph 流程编辑器页面

**步骤**：

1. 在左侧侧边栏，找到 **"内容管理"** 分组（图标：📚）
2. 点击 **"Graph流程编辑器"**（图标：🔄）

**菜单路径**：
```
左侧侧边栏 → 内容管理（📚）→ Graph流程编辑器（🔄）
```

---

### 3. 使用 X6 编辑器

在 Graph 列表页面顶部，有一个复选框：

- ✅ **勾选 "使用 X6 编辑器（POC）"** - 使用 X6 编辑器
- ❌ **不勾选** - 使用 React Flow 编辑器（旧版）

---

## 二、功能操作

### 1. 创建新的 Graph

**方法一：使用流程编辑器创建**
1. 在 Graph 列表页面顶部，**勾选 "使用 X6 编辑器（POC）"**（如果要使用 X6）
2. 点击 **"+ 新增Graph（流程编辑器）"** 按钮
3. 进入流程编辑器界面
4. 在画布上编辑节点和连线
5. 点击 **"保存"** 按钮保存 Graph

**方法二：快速创建**
1. 点击 **"+ 新增Graph（快速创建）"** 按钮
2. 填写基本信息（名称、描述、类型等）
3. 点击 **"保存"** 按钮保存 Graph

---

### 2. 编辑现有 Graph

在 Graph 列表页面：

1. 找到要编辑的 Graph
2. 点击 **"编辑流程"** 按钮（打开流程编辑器）
3. 或者点击 **"编辑"** 按钮（快速编辑基本信息）

**注意**：
- 如果要使用 X6 编辑器，需要先勾选 "使用 X6 编辑器（POC）" checkbox
- 然后在点击 "编辑流程" 时，会使用 X6 编辑器打开

---

### 3. 使用 X6 编辑器功能

**基础操作**：
- **平移画布**：按住鼠标左键拖拽
- **缩放画布**：按住 Ctrl + 鼠标滚轮（或触摸板手势）

**节点操作**：
- **添加节点**：从左侧侧边栏拖拽节点类型到画布
- **移动节点**：拖拽节点到新位置
- **选中节点**：点击节点
- **编辑节点属性**：双击节点，右侧属性面板会显示
- **删除节点**：选中节点后，按 Delete 键，或点击右上角 "删除节点" 按钮

**连线操作**：
- **创建连线**：从一个节点的底部连接点拖拽到另一个节点的顶部连接点
- **删除连线**：选中连线后，按 Delete 键

**保存操作**：
- 点击顶部工具栏的 **"保存"** 按钮
- 填写 Graph 名称（必填）
- 可以选择填写描述和类型
- 保存成功后会显示成功提示

---

## 三、支持的节点类型

X6 编辑器支持以下 8 种节点类型：

1. **start**（开始） - 流程的起始节点
2. **dialogue**（对话） - 对话节点
3. **choice**（选择） - 选择分支节点
4. **condition**（条件） - 条件判断节点
5. **skill_check**（技能检查） - 技能检查节点
6. **state_change**（状态变更） - 状态变更节点
7. **wait**（等待） - 等待节点
8. **end**（结束） - 流程的结束节点

---

## 四、快速开始示例

### 创建一个简单的对话流程

1. **进入 Graph 流程编辑器页面**
   - 左侧侧边栏 → 内容管理 → Graph流程编辑器

2. **勾选使用 X6 编辑器**
   - 在列表页面顶部，勾选 "使用 X6 编辑器（POC）"

3. **创建新 Graph**
   - 点击 "+ 新增Graph（流程编辑器）" 按钮

4. **添加开始节点**
   - 从左侧侧边栏拖拽 "start" 节点到画布中央

5. **添加对话节点**
   - 从左侧侧边栏拖拽 "dialogue" 节点到画布上
   - 双击对话节点，在右侧属性面板中输入对话内容

6. **创建连线**
   - 从 start 节点的底部连接点拖拽到 dialogue 节点的顶部连接点

7. **添加结束节点**
   - 从左侧侧边栏拖拽 "end" 节点到画布上
   - 从 dialogue 节点的底部连接点拖拽到 end 节点的顶部连接点

8. **保存 Graph**
   - 在顶部工具栏输入 Graph 名称（必填）
   - 点击 "保存" 按钮

---

## 五、注意事项

1. **X6 编辑器切换**
   - 需要在 Graph 列表页面勾选 "使用 X6 编辑器（POC）" checkbox
   - 勾选后，点击 "编辑流程" 或创建新 Graph 时会使用 X6 编辑器

2. **Graph 名称**
   - 保存时 Graph 名称是必填项
   - 如果名称为空，会显示错误提示

3. **数据保存**
   - 编辑完成后需要点击 "保存" 按钮
   - 保存成功后数据会保存到后端数据库

4. **POC 标识**
   - 当前 X6 编辑器处于 POC（概念验证）阶段
   - 标题中有 "(X6 POC)" 标识
   - 有 POC 提示信息面板（可以忽略）

## 六、故障排查

### 问题：看不到 Graph 流程编辑器菜单项

**解决方案**：
- 确认已登录管理后台
- 确认有访问权限
- 刷新页面重试

---

### 问题：X6 编辑器无法加载

**解决方案**：
- 确认已安装 X6 依赖：`npm install @antv/x6 @antv/x6-react-shape`
- 检查浏览器控制台是否有错误信息
- 刷新页面重试

---

### 问题：无法保存 Graph

**解决方案**：
- 确认已填写 Graph 名称（必填）
- 确认已登录并有管理员权限
- 检查浏览器控制台是否有错误信息
- 确认后端服务正常运行

---

### 问题：节点或连线无法正常显示

**解决方案**：
- 刷新页面重试
- 检查浏览器控制台是否有错误信息
- 确认 X6 依赖已正确安装

---
