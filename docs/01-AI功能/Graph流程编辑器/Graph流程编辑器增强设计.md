# Graph流程编辑器增强设计（参考Dify）

## 设计目标

参考Dify的流程编辑工具，创建一个支持多种实体类型融合的AI流程编辑工具，支持场景、角色、事件、物品等多种实体的关联和配置。

## 系统实体类型

1. **Era (场景)** - 游戏场景/时代
2. **Character (角色)** - 游戏角色
3. **ScenarioEvent (事件)** - 场景事件
4. **ScenarioItem (物品)** - 场景物品
5. **World (世界)** - 游戏世界
6. **Script (剧本)** - 剧本内容

## 功能设计

### 1. 实体选择器组件

- **统一实体选择器**：支持选择不同类型的实体
- **实体预览**：显示实体基本信息（名称、描述、ID等）
- **实体搜索**：支持按名称、ID搜索实体
- **实体分类**：按类型分组显示

### 2. 节点配置增强

#### Dialogue节点
- 关联角色（Character）
- 关联场景（Era）
- 对话内容支持变量引用

#### Choice节点
- 选项可以关联事件（ScenarioEvent）
- 选项可以关联物品（ScenarioItem）
- 选项效果可以修改角色好感度、技能等

#### Condition节点
- 条件可以检查角色属性
- 条件可以检查物品拥有情况
- 条件可以检查事件触发状态

#### StateChange节点
- 可以修改角色属性
- 可以触发事件
- 可以添加/移除物品
- 可以设置场景变量

### 3. 可视化增强

- **实体连接线**：显示节点与实体的关联关系
- **实体面板**：在编辑器中显示可用的实体列表
- **实体预览**：悬停显示实体详细信息
- **实体搜索**：快速查找和关联实体

### 4. 执行增强

- **实体上下文**：执行时自动加载关联的实体信息
- **实体状态**：实时显示实体状态变化
- **实体日志**：记录实体相关的操作日志

## 实现计划

### Phase 1: 基础实体选择器
1. 创建EntitySelector组件
2. 实现实体列表API
3. 集成到节点配置面板

### Phase 2: 节点配置增强
1. Dialogue节点支持角色/场景关联
2. Choice节点支持事件/物品关联
3. Condition节点支持实体条件检查
4. StateChange节点支持实体操作

### Phase 3: 可视化增强
1. 实体面板组件
2. 实体连接线显示
3. 实体预览功能

### Phase 4: 执行增强
1. 实体上下文加载
2. 实体状态显示
3. 实体操作日志

## 技术实现

### 前端组件
- `EntitySelector.tsx` - 实体选择器组件
- `EntityPanel.tsx` - 实体面板组件
- `EntityPreview.tsx` - 实体预览组件
- 增强 `NodePropertyPanel.tsx` - 支持实体关联

### 后端API
- `/api/admin/entities/eras` - 获取场景列表
- `/api/admin/entities/characters` - 获取角色列表
- `/api/admin/entities/events` - 获取事件列表
- `/api/admin/entities/items` - 获取物品列表
- `/api/admin/entities/worlds` - 获取世界列表

### 数据模型
- 节点配置中增加实体关联字段
- 执行时加载关联实体信息
- 记录实体操作日志
