# X6 编辑器节点显示问题排查

**问题**: 可以切换到 X6 编辑器，但是节点没有正常显示

---

## 可能的原因

1. **useEffect 重复执行导致节点重复添加**
   - useEffect 依赖数组包含 `graphData?.nodes` 和 `graphData?.edges`
   - 每次这些数据变化时，useEffect 会重新执行
   - 如果没有先清除旧节点，可能会导致节点重复或显示异常

2. **节点位置问题**
   - 节点位置可能都在 (0, 0)，重叠在一起
   - 或者位置超出了可见区域

3. **X6 Graph 实例未正确初始化**
   - Graph 实例可能还没有完全初始化就尝试添加节点

---

## 解决方案

### 方案 1：先清除旧节点（已实施）

在加载新节点之前，先清除所有已有的节点和连线：

```typescript
// Graph 初始化完成后加载节点
// 先清除已有节点（如果有）
graph.getNodes().forEach(node => graph.removeNode(node));
graph.getEdges().forEach(edge => graph.removeEdge(edge));

if (graphData?.nodes && graphData.nodes.length > 0) {
  // 加载节点...
}
```

---

### 方案 2：检查浏览器控制台

打开浏览器开发者工具（F12），查看：
1. **Console 标签**：是否有 JavaScript 错误
2. **Network 标签**：X6 相关的资源是否正常加载

---

### 方案 3：调试节点数据

在浏览器控制台中执行：

```javascript
// 查看 graphData 数据
console.log('graphData:', graphData);

// 查看节点数量
console.log('nodes count:', graphData?.nodes?.length);

// 查看节点位置
graphData?.nodes?.forEach(node => {
  console.log('node:', node.nodeId, 'position:', node.positionX, node.positionY);
});
```

---

## 调试步骤

1. **打开浏览器开发者工具**（F12）
2. **查看 Console**，检查是否有错误信息
3. **检查 Network 标签**，确认 @antv/x6 相关资源已加载
4. **检查节点数据**：
   - graphData 是否存在
   - nodes 数组是否有数据
   - 节点位置是否合理
5. **检查画布**：
   - 尝试平移画布（拖拽）
   - 尝试缩放画布（Ctrl + 鼠标滚轮）

---

## 常见问题

### 问题 1：节点都在 (0, 0) 位置

**原因**：节点数据中 positionX 和 positionY 可能都是 0 或 undefined

**解决**：检查节点数据，确保有正确的位置信息

---

### 问题 2：节点被清除后没有重新添加

**原因**：可能是 useEffect 依赖数组的问题

**解决**：确保 useEffect 正确触发，检查依赖数组

---

### 问题 3：X6 Graph 未正确初始化

**原因**：containerRef.current 可能为 null

**解决**：确保容器元素已经挂载

---

## 已实施的修复

我已经添加了节点清除逻辑，在加载新节点之前先清除所有已有的节点和连线。这应该可以解决节点重复或显示异常的问题。

如果问题仍然存在，请：
1. 刷新页面重试
2. 检查浏览器控制台的错误信息
3. 查看节点数据是否正确
