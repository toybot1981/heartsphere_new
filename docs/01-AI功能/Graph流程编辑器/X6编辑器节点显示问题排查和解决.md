# X6 编辑器节点显示问题排查和解决

**问题**: 可以切换到 X6 编辑器，但是节点没有正常显示

---

## 已实施的修复

我已经添加了节点清除逻辑，在加载新节点之前先清除所有已有的节点和连线：

```typescript
// Graph 初始化完成后加载节点
// 先清除已有节点（如果有）
graph.getNodes().forEach(node => graph.removeNode(node));
graph.getEdges().forEach(edge => graph.removeEdge(edge));
```

---

## 排查步骤

### 1. 检查浏览器控制台

打开浏览器开发者工具（F12），查看 Console 标签，检查是否有错误信息。

**常见错误**：
- `Graph is not defined` - X6 库未正确加载
- `Cannot read property 'nodes' of undefined` - graphData 为空
- 其他 JavaScript 错误

---

### 2. 检查节点数据

在浏览器控制台中执行以下代码来检查数据：

```javascript
// 查看 graphData
console.log('graphData:', window.graphData); // 可能需要通过其他方式访问

// 或者直接在组件中添加 console.log
// 在 X6GraphFlowEditor.tsx 的 useEffect 中添加：
console.log('Loading nodes:', graphData?.nodes);
console.log('Node count:', graphData?.nodes?.length);
```

---

### 3. 检查节点位置

如果节点数据存在但不可见，可能是位置问题：

- **所有节点都在 (0, 0)**：节点重叠在一起
- **节点位置超出可见区域**：需要平移画布查看

**解决方法**：
1. 尝试拖拽画布（平移）
2. 尝试缩放画布（Ctrl + 鼠标滚轮）
3. 查看节点数据中的 positionX 和 positionY

---

### 4. 检查 Graph 实例

确认 Graph 实例是否正确创建：

在浏览器控制台中，如果可以通过某种方式访问 graph 实例：

```javascript
// 查看 graph 实例
console.log('Graph instance:', graphRef.current);

// 查看节点数量
console.log('Nodes in graph:', graphRef.current?.getNodes().length);

// 查看所有节点
graphRef.current?.getNodes().forEach(node => {
  console.log('Node:', node.id, 'Position:', node.position());
});
```

---

### 5. 尝试添加新节点

尝试从侧边栏拖拽一个新节点到画布：
1. 如果新节点可以显示，说明 Graph 实例正常，问题在数据加载
2. 如果新节点也不能显示，说明 Graph 实例或渲染有问题

---

## 可能的解决方案

### 方案 1：检查数据格式

确保 graphData 的格式正确：
- `graphData.nodes` 应该是数组
- 每个节点应该有 `nodeId`, `nodeType`, `positionX`, `positionY` 等字段

---

### 方案 2：添加调试日志

在 `X6GraphFlowEditor.tsx` 的 useEffect 中添加日志：

```typescript
console.log('X6GraphFlowEditor - graphData:', graphData);
console.log('X6GraphFlowEditor - nodes:', graphData?.nodes);
console.log('X6GraphFlowEditor - nodes count:', graphData?.nodes?.length);

if (graphData?.nodes && graphData.nodes.length > 0) {
  console.log('Loading nodes...');
  graphData.nodes.forEach((node: GraphNode) => {
    console.log('Adding node:', node.nodeId, 'at', node.positionX, node.positionY);
    // ... 节点创建代码
  });
} else {
  console.log('No nodes to load');
}
```

---

### 方案 3：检查是否是新建 Graph

如果是新建的 Graph（graphData 为空或 nodes 为空），节点不会显示是正常的。

**解决方法**：
1. 从侧边栏拖拽节点到画布
2. 或者编辑一个已存在的 Graph
