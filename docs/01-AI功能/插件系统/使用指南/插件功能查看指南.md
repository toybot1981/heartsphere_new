# 插件功能查看指南

## 🔍 问题：在现实世界中看不到插件功能

如果您在现实世界中看不到插件功能，请按以下步骤检查：

### 1. 检查前端服务是否运行

**检查方式：**
```bash
# 检查端口 3000 是否被占用
lsof -ti:3000
```

**如果没有运行，启动前端服务：**
```bash
cd frontend
npm run dev
```

### 2. 清除浏览器缓存并刷新

**方法1：硬刷新（推荐）**
- **Mac**: `Cmd + Shift + R`
- **Windows/Linux**: `Ctrl + Shift + R` 或 `Ctrl + F5`

**方法2：清除浏览器缓存**
1. 打开浏览器开发者工具（F12）
2. 右键点击刷新按钮
3. 选择"清空缓存并硬性重新加载"

### 3. 检查代码是否已更新

**检查插件管理按钮位置：**
- 在标签筛选区域的右侧
- 应该能看到 **"添加插件"** 和 **"编辑插件"** 按钮（如果有已安装的插件）

**检查位置：**
1. 打开现实世界页面
2. 向下滚动到标签筛选区域
3. 在标签右侧应该能看到插件管理按钮

### 4. 确认已登录（不是访客模式）

插件功能只在**非访客模式**下显示。确保：
- 已经登录账户
- 不是以访客身份访问

### 5. 检查浏览器控制台

打开浏览器开发者工具（F12），查看控制台是否有错误：

**常见错误：**
- `Cannot find module './plugin'` - 说明代码没有正确编译
- `ScenePluginContainer is not defined` - 说明组件没有正确导入
- 网络错误 - 检查后端 API 是否正常运行

### 6. 重启前端服务

如果以上方法都不行，尝试重启前端服务：

```bash
# 方法1：使用重启脚本
cd /Users/admin/Workspace/heartsphere_new
bash restart-frontend-dev.sh

# 方法2：手动重启
cd frontend
# 停止现有服务（Ctrl+C 或 kill 进程）
# 然后重新启动
npm run dev
```

### 7. 检查代码是否已保存

确认以下文件已正确保存：
- `frontend/components/RealWorldScreen.tsx`
- `frontend/components/plugin/ScenePluginContainer.tsx`
- `frontend/components/plugin/PluginToolbar.tsx`
- `frontend/components/plugin/PluginSelectorModal.tsx`

## 🎯 功能应该出现的位置

### 插件管理按钮
- **位置**：标签筛选区域右侧
- **条件**：已登录且非访客模式
- **按钮**：
  - "添加插件" - 总是显示（如果有已安装插件）
  - "编辑插件" - 仅在有已安装插件时显示

### 插件容器
- **位置**：现实世界页面主区域（绝对定位）
- **显示条件**：已有插件添加到场景中
- **外观**：半透明背景的卡片，带有插件名称和功能按钮

### 编辑器中的插件入口
- **位置1**：日志编辑器工具栏（模板按钮区域）
  - 在星星、方块、闪电等模板按钮旁边
  - 显示为插件图标 🎨
- **位置2**：日志编辑器工具栏底部
  - 在"咨询本我镜像"和"添加图片"按钮下方
  - 显示已安装的插件快捷入口

### 日志卡片中的插件按钮
- **位置**：日志卡片操作按钮区域
- **显示条件**：悬停卡片时显示
- **外观**：紫色渐变圆形按钮，带有插件图标

## ✅ 验证步骤

1. ✅ 打开现实世界页面
2. ✅ 确认已登录（不是访客）
3. ✅ 向下滚动到标签筛选区域
4. ✅ 查看右侧是否有"添加插件"按钮
5. ✅ 点击"添加插件"，应该弹出插件选择器
6. ✅ 如果已有插件，应该能看到插件卡片
7. ✅ 点击"编辑插件"按钮进入编辑模式

## 🐛 故障排查

### 如果仍然看不到功能：

1. **检查网络请求**
   - 打开开发者工具（F12）→ Network 标签
   - 刷新页面
   - 查看是否有 `/api/scenes/real-world/plugins` 的请求
   - 如果返回 404，说明后端 API 还未实现

2. **检查组件是否正确导入**
   - 查看浏览器控制台是否有导入错误
   - 确认 `frontend/components/plugin/index.ts` 文件存在

3. **清除 Vite 缓存**
   ```bash
   cd frontend
   rm -rf node_modules/.vite
   npm run dev
   ```

4. **检查浏览器兼容性**
   - 确保使用现代浏览器（Chrome 90+, Firefox 88+, Safari 14+）
   - 检查浏览器控制台是否有兼容性错误

## 📞 如果问题仍然存在

如果按照以上步骤仍然看不到功能，请提供以下信息：

1. 浏览器控制台的错误信息
2. Network 标签中的 API 请求状态
3. 前端服务是否正常运行
4. 使用的是开发环境还是生产环境
