## 一、项目概述

### 1.1 产品定位

**心域（HeartSphere）** 是一个基于人工智能技术的**数字生命体交互系统**，构建了一个与现实世界平行的精神与数据空间。系统通过先进的大语言模型技术，实现了用户与数字生命体（E-SOUL）的深度情感交互，为用户提供沉浸式的虚拟角色互动体验。

### 1.2 核心价值主张

- **情感陪伴**：提供24/7的AI情感陪伴，满足现代人的情感需求
- **个性化交互**：每个数字生命体拥有独特的人格、记忆和成长轨迹
- **多场景体验**：支持不同时代切片（大学时代、赛博都市、心域诊所等）的沉浸式体验
- **创作与分享**：用户可以创建自己的数字世界，并与他人分享

### 1.3 目标用户

- **情感陪伴需求者**：寻求情感支持和陪伴的用户
- **角色扮演爱好者**：喜欢虚拟角色互动的用户
- **内容创作者**：利用AI角色进行创意内容创作
- **教育市场**：K12学生AI素养教育（教育版）

## 二、核心功能模块

### 2.1 AI对话系统

**功能特点**：
- 基于Google Gemini、OpenAI、通义千问等多模型支持
- 支持多轮对话、上下文理解
- 个性化响应，根据角色设定生成回复
- 流式响应，实时交互体验

**技术亮点**：
- 统一的大模型接入层，支持多模型切换
- 智能成本控制，自动选择最优模型
- 上下文记忆管理，支持长期对话

### 2.2 数字生命体（E-SOUL）管理

**功能特点**：
- 创建具有完整人格设定的数字生命体
- 支持MBTI人格类型、性格、背景故事等丰富属性
- 多时代切片支持，同一角色在不同时代呈现不同状态
- 角色技能系统，支持自定义功能扩展

**创新点**：
- **记忆系统**：每个角色拥有独立的记忆体系
  - 短期记忆（Redis）：对话上下文、工作记忆
  - 长期记忆（MongoDB）：用户事实、偏好、交互历史
  - 语义搜索：基于向量嵌入的智能记忆检索
- **温度感系统**：通过情感计算增强交互的温度感

### 2.3 场景管理系统

**功能特点**：
- 创建和管理多个虚拟世界
- 支持不同主题的时代切片（如"我的大学"、"赛博都市"、"心域诊所"等）
- 场景构建工具，提供丰富的场景模板
- 资源管理，支持图片、音频等多媒体资源

**应用场景**：
- 情感陪伴场景
- 角色扮演游戏
- 心理疏导场景
- 创意写作辅助

### 2.4 心域连接功能

**功能特点**：
- **快速连接**：将连接E-SOUL的步骤从3-4步减少到1-2步
- **智能推荐**：基于用户行为智能推荐E-SOUL
- **心域共享**：用户可以共享自己的心域给他人
- **体验模式**：访问他人心域，体验不同场景

**核心价值**：
- 效率提升50%以上
- 增强用户与E-SOUL的情感连接
- 促进社区互动和内容分享

### 2.5 跨时空信箱

**功能特点**：
- 跨场景消息传递
- 时间胶囊功能，支持定时发送
- 情感表达，增强用户与角色的情感连接

### 2.6 插件系统

**功能特点**：
- 可独立运行的功能模块
- 动态加载和卸载
- 可嵌入到"现实世界"场景中
- 支持功能扩展和定制

### 2.7 AI Agent工作流引擎

**功能特点**：
- **Graph流程编辑器**：可视化AI工作流编辑
- **多智能体系统**：Planner、Executor、Monitor Agent
- **虚拟电脑系统**（规划中）：为AI角色提供完整的虚拟计算机环境
  - 支持Web浏览、文件操作、代码执行
  - 持久化会话，任务可跨数小时甚至数天完成
  - 安全隔离的沙箱环境

## 三、技术优势

### 3.1 技术架构

**后端技术栈**：
- Spring Boot 3.2.0 + Java 17
- Spring Data JPA + MySQL 8.0+
- Spring Security + JWT认证
- Flyway数据库迁移
- Redis（短期记忆、缓存）
- MongoDB（长期记忆）

**前端技术栈**：
- React 18+ + TypeScript
- Vite构建工具
- Tailwind CSS
- Capacitor 8.0+（移动端支持）

**AI服务**：
- 统一的大模型接入层
- 支持Gemini、OpenAI、Qwen、豆包等多模型
- 智能成本控制和模型切换

### 3.2 核心技术亮点

1. **双层记忆架构**
   - 短期记忆（Redis）：快速访问，支持实时对话
   - 长期记忆（MongoDB）：持久化存储，支持跨会话记忆
   - 记忆巩固机制：智能的短期到长期记忆转换

2. **多模型适配**
   - 统一接口支持多种大语言模型
   - 智能成本控制，自动选择最优模型
   - 模型降级策略，保证服务可用性

3. **温度感系统**
   - 情感计算增强交互的温度感
   - 个性化响应生成
   - 情感状态管理

4. **可扩展架构**
   - 插件系统支持功能扩展
   - 前后端分离，支持多端适配
   - 模块化设计，易于维护和扩展

### 3.3 安全与性能

- **安全机制**：JWT认证、RBAC权限控制、数据隔离
- **性能优化**：数据库索引优化、缓存策略、代码分割
- **可扩展性**：支持水平扩展，支持多用户并发
