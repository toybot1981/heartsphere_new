# 心域（HeartSphere）项目执行摘要

## 一句话介绍

**心域（HeartSphere）** 是一个基于AI技术的数字生命体交互系统，通过独特的记忆系统和温度感系统，为用户提供24/7的情感陪伴和个性化交互体验。

---

## 核心价值主张

### 1. 产品定位
- **数字生命体交互平台**：构建与现实世界平行的精神与数据空间
- **情感陪伴**：24/7的AI情感陪伴，满足现代人的情感需求
- **个性化交互**：每个数字生命体拥有独特的人格、记忆和成长轨迹

### 2. 核心功能
- **AI对话系统**：多模型支持，智能上下文理解
- **数字生命体（E-SOUL）**：完整人格设定，独立记忆体系
- **场景管理**：多时代切片，沉浸式体验
- **心域连接**：快速连接，智能推荐，心域共享
- **记忆系统**：双层记忆架构（短期+长期），语义搜索
- **温度感系统**：情感计算，增强交互温度感

---

## 技术优势

### 1. 核心技术
- **双层记忆架构**：Redis（短期）+ MongoDB（长期）
- **多模型适配**：统一接口支持Gemini、OpenAI、Qwen等
- **温度感系统**：情感计算，个性化响应
- **可扩展架构**：插件系统，模块化设计

### 2. 技术栈
- **后端**：Spring Boot 3.2.0 + Java 17 + MySQL + Redis + MongoDB
- **前端**：React 18+ + TypeScript + Vite
- **AI服务**：统一大模型接入层，智能成本控制
