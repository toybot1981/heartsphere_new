# AgentScope Computer-Use 演示快速访问指南

## 🚀 快速访问

### 管理端演示监控界面

**访问步骤**:
1. 启动项目（后端 + 前端）
2. 访问管理后台：`http://localhost:5173/admin.html`（开发环境）
3. 使用管理员账户登录
4. 在左侧导航菜单中，找到 **"AI 智能体"** 分组
5. 点击 **"AgentScope 演示管理"** 菜单项

**访问路径**:
```
管理后台 (/admin.html) 
  → 登录 
  → 左侧菜单 "AI 智能体" 
  → "AgentScope 演示管理"
```

## 📍 详细访问地址

### 开发环境

- **前端入口**: `http://localhost:5173/admin.html`
- **后端 API**: `http://localhost:8081/api/`
- **管理后台**: `http://localhost:5173/admin.html#agentscope-demo`

### 生产环境

- **前端入口**: `https://yourdomain.com/admin.html`
- **后端 API**: `https://yourdomain.com/api/`
- **管理后台**: `https://yourdomain.com/admin.html#agentscope-demo`

## 🔐 权限要求

- ✅ 需要管理员权限
- ✅ 需要有效的管理员 Token（登录后自动获取）

## 📱 界面功能

### 管理端演示监控界面

访问后可以看到 4 个标签页：

1. **工具调用监控**
   - 查看所有会话的工具调用记录
   - 筛选和搜索工具调用
   - 查看详细统计信息

2. **虚拟机管理**
   - 查看所有活动的虚拟机
   - 管理虚拟机状态
   - 执行虚拟机操作

3. **会话管理**
   - 查看所有活跃会话
   - 管理会话状态
   - 创建演示会话

4. **性能监控**
   - 查看性能指标
   - 查看统计信息
   - 监控系统性能

## 🛠️ 故障排除

### 无法看到菜单项

1. 检查是否以管理员身份登录
2. 检查浏览器控制台是否有错误
3. 刷新页面重新加载

### 无法访问界面

1. 检查后端服务是否正常运行（端口 8081）
2. 检查前端服务是否正常运行（端口 5173）
3. 检查数据库连接是否正常
