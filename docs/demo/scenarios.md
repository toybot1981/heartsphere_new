# AgentScope Computer-Use 演示场景

## 概述

本文档描述了 AgentScope Computer-Use 演示原型中所有可用的演示场景。每个场景都展示了 AgentScope Java 在 Computer-Use 场景中的不同能力。

## 场景分类

### 1. 命令执行场景

#### 场景 1.1: 简单命令执行

**场景ID**: `command-simple`

**描述**: 执行基本的系统命令，如 ls、pwd 等

**示例对话**:
```
用户: 请帮我执行 ls 命令查看当前目录的文件列表
```

**预期结果**: 
- Agent 应该调用 `computer_use` 工具的 `execute_command` 操作
- 应该能看到当前目录的文件列表
- 工具调用监控面板应该显示工具调用记录

**演示要点**:
- 展示 Agent 如何理解用户意图并调用工具
- 展示工具调用的参数传递和结果返回
- 展示实时工具调用监控

#### 场景 1.2: 复杂命令执行

**场景ID**: `command-complex`

**描述**: 执行带管道、重定向的复杂命令

**示例对话**:
```
用户: 请帮我执行命令：cat /etc/passwd | grep root | wc -l
```

**预期结果**:
- Agent 应该能够执行复杂的命令
- 应该返回包含 root 的行数
- 展示 Agent 对复杂命令的理解能力

#### 场景 1.3: 命令执行失败处理

**场景ID**: `command-error`

**描述**: 演示命令执行失败时的错误处理

**示例对话**:
```
用户: 请执行一个不存在的命令：nonexistent_command_xyz
```

**预期结果**:
- Agent 应该能够处理命令执行失败的情况
- 应该显示清晰的错误信息
- 展示错误处理机制

### 2. 脚本执行场景

#### 场景 2.1: Python 脚本执行

**场景ID**: `script-python`

**描述**: 执行一个简单的 Python 脚本

**示例对话**:
```
用户: 请帮我执行一个 Python 脚本：
```python
print("Hello from Python!")
for i in range(5):
    print(f"Count: {i}")
```
```

**预期结果**:
- Agent 应该能够识别 Python 代码并执行
- 应该输出 Hello from Python! 和 0-4 的计数
- 展示脚本执行能力

#### 场景 2.2: JavaScript 脚本执行

**场景ID**: `script-javascript`

**描述**: 执行一个简单的 JavaScript 脚本

**示例对话**:
```
用户: 请帮我执行一个 JavaScript 脚本：
```javascript
console.log("Hello from JavaScript!");
const sum = [1, 2, 3, 4, 5].reduce((a, b) => a + b, 0);
console.log("Sum:", sum);
```
```

**预期结果**:
- Agent 应该能够识别 JavaScript 代码并执行
- 应该输出 Hello from JavaScript! 和 Sum: 15
- 展示多语言脚本支持

#### 场景 2.3: 长时间运行脚本

**场景ID**: `script-long-running`

**描述**: 演示长时间运行脚本的处理

**示例对话**:
```
用户: 请帮我执行一个需要运行几秒钟的 Python 脚本：
```python
import time
for i in range(5):
    print(f"Step {i+1}/5")
    time.sleep(1)
print("Done!")
```
```

**预期结果**:
- 应该能看到逐步输出的进度信息
- 展示长时间运行操作的处理能力
- 展示超时控制机制

### 4. 虚拟机生命周期场景

#### 场景 4.1: 虚拟机生命周期

**场景ID**: `vm-lifecycle`

**描述**: 完整的虚拟机生命周期：创建 → 执行操作 → 删除

**示例对话**:
```
用户: 请帮我创建一个 Ubuntu 虚拟机，然后执行 ls 命令，最后删除虚拟机
```

**预期结果**:
- Agent 应该能够：
  1. 调用 `vm_manager` 工具创建虚拟机
  2. 调用 `computer_use` 工具执行命令
  3. 调用 `vm_manager` 工具删除虚拟机
- 展示 Agent 的任务分解和执行能力
- 展示多个工具调用的链式执行

#### 场景 4.2: 虚拟机状态查询

**场景ID**: `vm-status`

**描述**: 查询虚拟机的当前状态

**示例对话**:
```
用户: 请帮我查询当前虚拟机的状态
```

**预期结果**:
- 应该能显示虚拟机的状态信息（ID、状态、创建时间等）
- 展示虚拟机状态管理能力

#### 场景 4.3: 虚拟机快照操作

**场景ID**: `vm-snapshot`

**描述**: 创建和恢复虚拟机快照（如果支持）

**示例对话**:
```
用户: 请帮我创建一个名为 "backup" 的虚拟机快照
```

**预期结果**:
- 应该能创建快照（如果功能已实现）
- 展示快照管理能力

## 使用说明

### 在客户端演示界面中使用

1. 打开客户端演示界面
2. 在左侧面板的"演示场景"中选择一个场景
3. 点击场景卡片，示例对话会自动填充到输入框
4. 点击"发送"按钮开始演示
5. 在工具调用监控面板中观察工具调用过程
6. 在虚拟机状态面板中查看虚拟机状态

### 在管理端监控

1. 打开管理端演示界面
2. 在"工具调用监控"面板中查看所有会话的工具调用
3. 在"虚拟机管理"面板中查看所有虚拟机
4. 在"会话管理"面板中查看所有会话
5. 在"性能监控"面板中查看性能指标

## 场景扩展

要添加新的演示场景，可以：

1. 在 `frontend/demo/scenarios.ts` 中添加场景定义
2. 或者在后端 API `/api/demo/scenarios` 中返回场景数据
3. 场景会自动出现在场景选择器中
