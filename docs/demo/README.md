# AgentScope Computer-Use 演示原型使用说明

## 概述

AgentScope Computer-Use 演示原型是一个可视化的演示系统，用于展示 AgentScope Java 框架在 Computer-Use 场景中的能力。演示原型包括客户端演示界面和管理端监控界面。

## 功能特性

### 客户端演示界面

- **聊天交互**: 与 AgentScope Agent 进行对话
- **工具调用监控**: 实时显示工具调用过程和结果
- **虚拟机状态**: 显示当前会话的虚拟机状态
- **演示场景**: 预设的演示场景，一键开始演示

### 管理端监控界面

- **工具调用监控**: 监控所有会话的工具调用
- **虚拟机管理**: 管理所有活动的虚拟机
- **会话管理**: 管理所有活跃会话
- **性能监控**: 查看系统性能指标

## 快速开始

### 前置条件

1. 后端服务已启动
2. 管理员账户已登录
3. AgentScope Java 依赖已添加（已在 test scope）

### 访问管理端监控界面

1. 打开管理后台：访问 `/admin.html` 或管理后台入口页面
2. 使用管理员账户登录
3. 在左侧导航菜单中找到 **"AI 智能体"** 分组
4. 点击 **"AgentScope 演示管理"** 菜单项
5. 使用标签切换不同的监控面板

### 访问客户端演示界面

**当前状态**: 客户端演示界面（`AgentScopeDemo.tsx`）已创建，但尚未集成到主应用路由。

- 选项 2：创建独立的访问页面

详细的访问说明请参考 [ACCESS_GUIDE.md](./ACCESS_GUIDE.md)

## 使用指南

### 客户端演示界面

#### 1. 创建会话

- 打开客户端演示界面后，系统会自动创建会话
- 会话ID会显示在界面中

#### 2. 选择演示场景

- 在左侧面板的"演示场景"中选择一个场景
- 点击场景卡片，示例对话会自动填充到输入框
- 点击"发送"按钮开始演示

#### 3. 观察工具调用

- 在"监控"标签页中查看工具调用列表
- 点击工具调用项查看详情（参数、结果、错误信息）
- 工具调用会实时更新（通过 SSE）

#### 4. 查看虚拟机状态

- 在左侧面板的"虚拟机状态"区域查看当前会话的虚拟机状态
- 可以刷新状态或执行虚拟机操作

### 管理端监控界面

#### 1. 工具调用监控

- 查看所有会话的工具调用记录
- 使用筛选器按会话ID、工具名称、时间范围筛选
- 查看统计信息（总数、成功数、失败数、平均执行时间）
- 点击工具调用项查看详情

#### 2. 虚拟机管理

- 查看所有活动的虚拟机列表
- 使用筛选器按状态筛选
- 使用搜索框搜索虚拟机
- 执行虚拟机操作（查看详情、删除）

#### 3. 会话管理

- 查看所有活跃会话
- 查看会话的虚拟机绑定关系
- 创建演示会话
- 删除会话

#### 4. 性能监控

- 查看工具调用性能指标
- 查看虚拟机操作性能指标
- 查看按工具分组的统计信息
- 查看性能趋势（图表待实现）

## API 接口

### 客户端 API

- `GET /api/demo/tool-calls?sessionId={sessionId}` - 查询工具调用日志
- `GET /api/demo/vm-status/{sessionId}` - 查询虚拟机状态
- `GET /api/demo/tool-call-statistics/{sessionId}` - 查询统计信息
- `GET /api/demo/scenarios` - 获取演示场景列表
- `GET /api/demo/events/session/{sessionId}` - 订阅会话事件（SSE）

### 管理端 API

- `GET /api/demo/tool-calls` - 查询所有工具调用（支持筛选）
- `GET /api/demo/events/global` - 订阅全局事件（SSE）

## 故障排除

### 常见问题

1. **无法创建会话**
   - 检查管理员 token 是否有效
   - 检查后端服务是否正常运行
   - 查看浏览器控制台的错误信息

2. **工具调用不显示**
   - 检查 SSE 连接是否正常
   - 检查工具调用日志是否已记录
   - 查看浏览器网络面板的 SSE 连接状态

3. **虚拟机状态不更新**
   - 检查虚拟机是否已创建
   - 检查 sessionId 是否正确
   - 手动刷新虚拟机状态

## 开发说明

### 添加新场景

1. 在 `frontend/demo/scenarios.ts` 中添加场景定义
2. 或者在后端 API 中返回场景数据
3. 场景会自动出现在场景选择器中

### 扩展功能

- 性能图表：集成 Chart.js 或 Recharts
- 虚拟机列表 API：实现获取所有虚拟机的 API
- 会话列表 API：实现获取所有会话的 API
