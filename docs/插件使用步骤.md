# 插件使用步骤

## 第一步：添加插件

1. 在"现实世界"页面顶部，找到标签筛选区域
2. 在标签区域的最右侧，点击 **"添加插件"** 按钮（紫色渐变按钮）
3. 在弹出的插件选择窗口中：
   - 浏览可用的插件列表
   - 点击插件卡片上的 **"添加到场景"** 按钮
4. 插件会立即出现在现实世界页面中

## 第二步：使用插件

### 重要：退出编辑模式

**插件只有在非编辑模式下才能使用！**

1. 检查页面顶部是否有 **"编辑插件"** 按钮
2. 如果按钮显示为 **"退出编辑"**（蓝色高亮），说明当前在编辑模式
3. 点击 **"退出编辑"** 按钮，退出编辑模式

### 找到插件容器

1. 在现实世界页面中，找到插件容器（通常显示为半透明的卡片）
2. 插件容器会显示：
   - 插件名称和图标
   - 插件状态（运行中/已禁用）
   - **"执行插件功能"** 按钮（紫色渐变大按钮）

### 执行插件功能

1. 在插件容器中，找到 **"执行插件功能"** 按钮
   - 这是一个紫色渐变的大按钮
   - 按钮上有播放图标和"执行插件功能"文字
   - 按钮上方有提示："✨ 插件已就绪"
2. 点击 **"执行插件功能"** 按钮
3. 按钮会显示"执行中..."（带旋转动画）
4. 执行完成后会显示成功或错误提示

## 常见问题

### Q: 看不到"执行插件功能"按钮？

**可能原因：**

1. **在编辑模式下**
   - 解决：点击"退出编辑"按钮退出编辑模式
   - 编辑模式下会显示"编辑模式"提示，而不是执行按钮

2. **插件被隐藏**
   - 检查插件容器的 `visible` 属性
   - 如果插件被隐藏，容器会显示但透明度降低

3. **浏览器缓存**
   - 按 `Ctrl+Shift+R` (Windows) 或 `Cmd+Shift+R` (Mac) 硬刷新

### Q: 点击按钮没有反应？

**检查：**

1. **后端服务是否运行？**
   - 打开浏览器控制台（F12）
   - 查看 Network 标签，检查 API 请求是否成功
   - 如果看到 404 错误，说明后端服务未启动或 Controller 未加载

2. **是否登录？**
   - 确保已登录账户
   - 检查 localStorage 中是否有 token

3. **浏览器控制台错误**
   - 按 F12 打开开发者工具
   - 查看 Console 标签中的错误信息

### Q: 按钮是灰色的（禁用状态）？

**可能原因：**

1. 在编辑模式下（按钮会被禁用）
2. 插件正在执行中（防止重复点击）
3. 插件被设置为不可见（`visible: false`）

### Q: 执行插件后没有效果？

**检查：**

1. **查看执行结果提示**
   - 执行成功会显示绿色提示
   - 执行失败会显示红色错误提示

2. **查看浏览器控制台**
   - 按 F12 打开开发者工具
   - 查看 Console 标签中的日志信息

3. **检查插件类型**
   - 不同类型的插件执行后可能有不同的行为
   - 相册插件：会打开相册界面
   - 日记插件：会打开日记界面
   - 其他插件：显示执行成功提示

## 插件功能说明

### 插件容器显示内容

- **插件头部**：显示插件图标、名称、ID
- **状态指示**：绿色圆点表示"插件运行中"
- **功能区域**：
  - 非编辑模式：显示"执行插件功能"按钮
  - 编辑模式：显示"编辑模式"提示
- **配置信息**：显示插件的当前配置（如果有）

### 编辑模式 vs 使用模式

**编辑模式：**
- 可以拖拽插件移动位置
- 可以调整插件大小
- 可以删除插件
- 可以配置插件
- **不能执行插件功能**

**使用模式（非编辑模式）：**
- 可以执行插件功能
- 可以查看插件信息
- 可以配置插件（点击右上角⚙️图标）
- **不能移动或调整大小**

## 快速检查清单

使用插件前，请确认：

- [ ] 已添加插件到场景
- [ ] 不在编辑模式下（如果看到"退出编辑"按钮，请点击退出）
- [ ] 能看到插件容器（半透明卡片）
- [ ] 能看到"执行插件功能"按钮（紫色渐变大按钮）
- [ ] 按钮不是灰色（未禁用）
- [ ] 后端服务正在运行（检查控制台无404错误）

## 技术细节

- **插件执行API**：`POST /api/plugins/{pluginId}/execute`
- **场景ID**：`real-world`
- **执行参数**：包含场景ID、动作类型和插件配置
- **响应处理**：根据插件类型显示不同的提示或执行不同的操作
