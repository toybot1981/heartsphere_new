### 1.5 功能增强 ✅ **显著**

**AgentScope 提供的增强功能**:

1. **结构化输出**:
   - Mentis: 需要手动解析 JSON
   - AgentScope: 支持 `Class<?>` 或 `JsonNode` 定义输出结构
   - **优势**: 类型安全，减少解析错误

2. **任务计划可视化**:
   - Mentis: 无可视化
   - AgentScope: `PlanNotebook` 支持可视化
   - **优势**: 便于调试和监控

3. **工具调用流式响应**:
   - Mentis: 不支持
   - AgentScope: 支持工具调用的流式响应
   - **优势**: 更好的用户体验

4. **长期记忆**:
   - Mentis: 无
   - AgentScope: `LongTermMemory` 支持语义搜索
   - **优势**: 增强上下文理解

5. **RAG 支持**:
   - Mentis: 无
   - AgentScope: `Knowledge` 和 `RAGMode` 支持 RAG
   - **优势**: 集成企业知识库

### 2.3 保留的组件

**保留 Mentis 现有实现**:

1. **MentisSessionService** - 会话管理
   - **理由**: 已有完善的数据库集成和业务逻辑
   - **策略**: 不与 AgentScope Session 集成

2. **MentisMessageService** - 消息存储
   - **理由**: AgentScope 不提供消息存储功能
   - **策略**: 继续使用现有实现

3. **执行器实现** - ComputerUseExecutor、CommandExecutor、ScriptExecutor
   - **理由**: 业务逻辑完整，只需包装为工具
   - **策略**: 包装为 AgentScope `AgentTool`

### 2.4 替换的组件

**使用 AgentScope 替换**:

1. **IntentRecognizer** → ReActAgent 内部推理
2. **TaskPlanner** → ReActAgent + PlanNotebook
3. **ExecutionEngine** → Toolkit + AgentTool
4. **ResponseGenerator** → ReActAgent 内部生成

**替换策略**: 通过配置开关并行运行，逐步切换

### 2.5 新增的组件

**需要新增的组件**:

1. **MentisAgentScopeService** - 新的服务实现
   - 包装 ReActAgent
   - 处理流式响应
   - 管理工具调用

2. **AgentTool 实现** - 工具包装类
   - `CommandTool` - 包装命令执行器
   - `ComputerUseTool` - 包装 GUI 操作执行器
   - `ScriptTool` - 包装脚本执行器

3. **配置类** - AgentScope 配置管理
   - 模型配置
   - 工具注册
   - 系统提示词管理
