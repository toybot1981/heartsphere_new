# 多智能体协作示例场景

## 场景 1: 提高工作效率和健康生活

**用户请求**: "我想提高工作效率，同时保持健康的生活方式"

**参与的智能体**:
- 时小光（时间管理）
- 康小健（健康生活）

**协作流程**:
1. 系统分析请求，识别需要时间管理和健康管理两个领域
2. 路由到时小光和康小健
3. 并行执行：
   - 时小光：制定时间管理计划，提高工作效率
   - 康小健：制定健康生活计划，包括饮食和运动
4. 整合结果：将两个计划整合，确保时间管理和健康生活不冲突

**预期结果**:
- 时小光提供时间管理建议（如番茄工作法、任务优先级）
- 康小健提供健康建议（如饮食计划、运动安排）
- 整合后的方案确保工作高效且生活健康

## 最佳实践

1. **明确需求**: 用户请求越明确，路由越准确
2. **合理分解**: 复杂需求会自动分解为多个子任务
3. **耐心等待**: 多智能体协作需要时间，请耐心等待
4. **查看详情**: 可以展开查看每个智能体的详细输出

## 注意事项

1. 协作是异步的，需要轮询状态或使用 WebSocket
2. 结果可能包含多个智能体的输出，需要整合展示
3. 如果某个智能体失败，其他智能体的结果仍会返回
4. 可以取消正在执行的协作任务
