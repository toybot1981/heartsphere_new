# 测试指南：角色记忆标签页功能

## 概述

本文档提供了 `add-character-memory-tab` 提案的完整测试指南，包括所有功能的测试步骤和验证点。

## 测试环境准备

### 前置条件
1. 确保后端服务正在运行（端口 8081）
2. 确保前端服务正在运行（端口 5173 或配置的端口）
3. 准备测试账号（至少 1 个用户账号）
4. 准备测试数据：
   - 至少 1 个角色
   - 至少 3-5 条与该角色相关的记忆（不同重要性、不同类型）

### 测试工具
- Chrome DevTools（用于检查网络请求和性能）
- React DevTools（用于检查组件状态）
- 移动设备或浏览器移动端模拟器

---

## Phase 1: 记忆标签页组件测试

### 1.1 测试组件基本显示
**测试步骤：**
1. 打开角色编辑/查看模态框（CharacterConstructorModal）
2. 切换到"记忆"标签页
3. 检查标签页是否显示

**验证点：**
- [ ] "记忆"标签页可见
- [ ] 标签页可以正常切换
- [ ] 标签页内容区域正确显示

### 1.2 测试记忆数据加载
**测试步骤：**
1. 打开记忆标签页
2. 观察加载状态
3. 等待数据加载完成

**验证点：**
- [ ] 显示加载动画（如果有记忆数据）
- [ ] 数据加载完成后显示记忆列表
- [ ] 如果没有记忆，显示空状态提示

### 1.3 测试记忆列表展示
**测试步骤：**
1. 确保有至少 3 条记忆数据
2. 检查记忆列表显示

**验证点：**
- [ ] 记忆列表正确显示
- [ ] 记忆按时间排序（最新的在前）
- [ ] 记忆按重要性分组（核心、重要、普通、临时）
- [ ] 每个记忆项显示基本信息（内容、类型、重要性、时间）

### 1.4 测试记忆项详细信息
**测试步骤：**
1. 点击一个记忆项
2. 检查详细信息是否展开
3. 再次点击检查是否收起

**验证点：**
- [ ] 点击后记忆项展开显示详细信息
- [ ] 详细信息包括：完整内容、类型、重要性、时间戳、来源
- [ ] 再次点击后记忆项收起
- [ ] 展开/收起动画流畅

### 1.5 测试空状态显示
**测试步骤：**
1. 选择一个没有记忆的角色
2. 打开记忆标签页

**验证点：**
- [ ] 显示友好的空状态提示
- [ ] 空状态提示信息清晰
- [ ] 空状态样式美观

## Phase 2: 集成测试

### 2.1 测试标签页切换
**测试步骤：**
1. 打开角色编辑模态框
2. 依次切换到"基本信息"、"技能"、"记忆"标签页
3. 检查切换是否流畅

**验证点：**
- [ ] 标签页切换流畅
- [ ] 切换后内容正确显示
- [ ] 切换时没有闪烁或延迟

### 2.2 测试记忆数据加载流程
**测试步骤：**
1. 打开角色编辑模态框
2. 切换到记忆标签页
3. 使用 Chrome DevTools 检查网络请求

**验证点：**
- [ ] 正确调用记忆 API（`memoryApi.searchMemories`）
- [ ] API 请求参数正确（userId, characterId）
- [ ] API 响应正确解析
- [ ] 记忆数据正确过滤（只显示当前角色的记忆）

### 2.3 测试错误处理
**测试步骤：**
1. 模拟 API 错误（断开网络或修改 API 端点）
2. 打开记忆标签页
3. 检查错误处理

**验证点：**
- [ ] 显示友好的错误提示
- [ ] 错误提示信息清晰
- [ ] 可以重试加载

## Phase 3: 优化和增强测试

### 3.1 测试性能优化
**测试步骤：**
1. 打开记忆标签页
2. 等待数据加载
3. 快速切换标签页多次
4. 检查是否有重复请求

**验证点：**
- [ ] 使用缓存机制（5 分钟内不重复请求）
- [ ] 切换标签页时使用缓存数据
- [ ] 缓存过期后重新请求

### 3.2 测试用户体验
**测试步骤：**
1. 打开记忆标签页
2. 测试各种交互

**验证点：**
- [ ] 加载动画流畅
- [ ] 错误提示友好
- [ ] 空状态提示清晰
- [ ] 记忆分组显示清晰
- [ ] 展开/收起交互流畅

### 3.3 测试移动端适配
**测试步骤：**
1. 在移动设备上打开角色编辑模态框
2. 测试记忆标签页

**验证点：**
- [ ] 移动端标签页显示正确
- [ ] 移动端记忆列表布局合理
- [ ] 移动端展开/收起功能正常
- [ ] 移动端响应式高度正确

## Phase 4: 性能测试

### 4.1 测试大量记忆数据加载
**测试步骤：**
1. 准备一个角色，有 50+ 条记忆
2. 打开记忆标签页
3. 记录加载时间

**验证点：**
- [ ] 加载时间 < 2 秒
- [ ] 页面不卡顿
- [ ] 记忆列表渲染流畅

### 4.2 测试内存使用
**测试工具：** Chrome DevTools > Memory

**测试步骤：**
1. 打开记忆标签页
2. 记录内存使用
3. 切换标签页多次
4. 检查内存是否泄漏

**验证点：**
- [ ] 内存使用合理（< 50MB）
- [ ] 没有内存泄漏
- [ ] 切换标签页后内存释放

### 4.3 测试缓存机制
**测试步骤：**
1. 打开记忆标签页（第一次）
2. 等待数据加载完成
3. 切换到其他标签页
4. 立即切换回记忆标签页（5 分钟内）
5. 检查是否使用缓存

**验证点：**
- [ ] 5 分钟内使用缓存数据
- [ ] 缓存数据正确
- [ ] 5 分钟后重新请求数据

## 注意事项

1. **测试数据准备**：确保有足够的测试记忆数据（不同重要性、不同类型）
2. **网络环境**：在不同网络环境下测试（WiFi、4G、慢速网络）
3. **浏览器兼容性**：在主流浏览器中测试（Chrome、Safari、Firefox、Edge）
4. **移动端测试**：在真实移动设备上测试，不仅仅是模拟器
5. **性能监控**：使用性能监控工具记录性能指标
6. **错误处理**：测试各种错误场景（网络错误、API 错误、空数据等）
