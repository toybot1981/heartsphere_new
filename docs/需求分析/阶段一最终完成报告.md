## 📝 使用示例

### 1. 装备技能

```bash
POST /api/characters/123/skills/crisis-intervention/equip
{
  "isEnabled": true,
  "autoTrigger": true,
  "priority": 10
}
```

### 2. 获取角色可用技能（用于 Function Calling）

```bash
GET /api/skills/character/123/available
```

### 3. 执行技能

```bash
POST /api/skills/execute
{
  "skillId": "crisis-intervention",
  "characterId": 123,
  "parameters": {
    "action": "assess",
    "patientId": "456"
  }
}
```
