## 四、技术实现

### 4.1 文件组织

所有SQL迁移文件位于：
```
backend/src/main/resources/db/migration/
```

文件命名规则：
- `V20250106_XX__create_[character]_skills_part[N].sql` - 技能定义文件
- 每个文件包含2个技能的定义和绑定
- 使用Flyway版本号管理

### 4.2 数据编码

- **字符集**: UTF8MB4
- **排序规则**: utf8mb4_unicode_ci
- **编码验证**: 所有中文字符正确存储，无乱码

### 4.3 技能结构

每个技能包含：
1. **技能定义** (skill_definitions)
   - skill_id, name, description
   - category, skill_type, execution_type
   - function_schema (JSON格式)
   - execution_config (JSON格式)
   - auto_trigger_keywords

2. **技能指令** (skill_instructions)
   - instruction_level: 2
   - instruction_text: 详细使用说明
   - 包含功能描述、参数说明、使用场景、执行流程等

3. **技能绑定** (character_skill_bindings)
   - character_id, skill_id
   - is_enabled, auto_trigger
   - priority, usage_count
