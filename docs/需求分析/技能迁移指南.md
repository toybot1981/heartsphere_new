# 技能迁移指南

## 📋 概述

本指南说明如何将 `.claude/skills` 目录中的技能迁移到数据库，使其可以在数字人 Skill 系统中使用。

---

## 🎯 迁移目标

将现有的 Claude Skill（JavaScript 格式）转换为：
1. **技能定义**（skill_definitions 表）
2. **技能指令**（skill_instructions 表）
3. **技能资源**（skill_resources 表）

---

## 📝 迁移步骤

### 方法一：使用 SQL 迁移脚本（推荐）

#### 1. 创建迁移脚本

在 `backend/src/main/resources/db/migration/` 目录下创建迁移脚本，例如：
- `V20250104__migrate_crisis_intervention_skill.sql`

#### 2. 脚本内容结构

```sql
-- 1. 插入技能定义
INSERT INTO skill_definitions (
    skill_id, name, description, category,
    skill_type, execution_type, function_schema,
    execution_config, auto_trigger_keywords,
    required_permissions, version, author,
    is_system_skill, is_active
) VALUES (
    'crisis-intervention',
    '危机干预',
    '危机干预工具 - 评估风险、制定干预方案、提供应急指导',
    'PSYCHIATRY',
    'ACTIVE',
    'SCRIPT',
    '{"type":"object","properties":{...}}',
    '{"script":"crisis-intervention.js","language":"javascript"}',
    '危机,紧急,自杀,自伤',
    'PSYCHIATRY_ACCESS',
    '1.0.0',
    'HeartSphere Psychiatry Team',
    true,
    true
) ON DUPLICATE KEY UPDATE ...;

-- 2. 插入技能指令
INSERT INTO skill_instructions (
    skill_id, instruction_level, instruction_text, priority
) VALUES ...;

-- 3. 插入技能资源
INSERT INTO skill_resources (
    skill_id, resource_type, resource_name, resource_path
) VALUES ...;
```

#### 3. 执行迁移

迁移脚本会在应用启动时自动执行（Flyway）。

### 方法二：使用 Java 工具类

#### 1. 使用 SkillMigrationTool

```java
@Autowired
private SkillMigrationTool migrationTool;

// 准备迁移数据

data.setName("危机干预");
data.setDescription("危机干预工具");
// ... 设置其他字段

// 执行迁移
migrationTool.migrateSkill(data);
```

## 🔧 关键字段说明

### Function Schema（JSON Schema）

将技能的 `args` 转换为 JSON Schema 格式：

**原始格式**（Claude Skill）：
```javascript
args: {
    action: {
        type: "string",
        required: true,
        enum: ["assess", "plan", "guide", "resources"]
    },
    patientId: {
        type: "string",
        description: "患者ID"
    }
}
```

**转换后**（Function Schema）：
```json
{
    "type": "object",
    "properties": {
        "action": {
            "type": "string",
            "enum": ["assess", "plan", "guide", "resources"],
            "description": "操作类型"
        },
        "patientId": {
            "type": "string",
            "description": "患者ID"
        }
    },
    "required": ["action"]
}
```

### Execution Config

```json
{
    "script": "crisis-intervention.js",
    "language": "javascript",
    "entryPoint": "run",
    "timeout": 30000
}
```

### Auto Trigger Keywords

自动触发关键词（逗号分隔）：
```
危机,紧急,自杀,自伤,危险,风险,干预,应急
```

## 📝 迁移模板

### SQL 迁移脚本模板

```sql
-- 迁移 [技能名称] 技能
-- 创建时间：YYYY-MM-DD

-- 1. 插入技能定义
INSERT INTO skill_definitions (
    skill_id, name, description, category,
    skill_type, execution_type, function_schema,
    execution_config, auto_trigger_keywords,
    required_permissions, max_usage_per_day,
    version, author, is_system_skill, is_active,
    created_at, updated_at
) VALUES (
    '[skill-id]',
    '[技能名称]',
    '[技能描述]',
    '[分类]',
    'ACTIVE',
    'SCRIPT',
    '[Function Schema JSON]',
    '[Execution Config JSON]',
    '[自动触发关键词]',
    '[所需权限]',
    -1,
    '[版本号]',
    '[作者]',
    true,
    true,
    NOW(),
    NOW()
) ON DUPLICATE KEY UPDATE
    name = VALUES(name),
    description = VALUES(description),
    function_schema = VALUES(function_schema),
    execution_config = VALUES(execution_config),
    version = VALUES(version),
    updated_at = NOW();

-- 2. 插入技能指令
INSERT INTO skill_instructions (
    skill_id, instruction_level, instruction_text, priority, created_at
) VALUES
    ('[skill-id]', 2, '[指令1]', 1, NOW()),
    ('[skill-id]', 2, '[指令2]', 2, NOW())
ON DUPLICATE KEY UPDATE
    instruction_text = VALUES(instruction_text),
    priority = VALUES(priority);

-- 3. 插入技能资源
INSERT INTO skill_resources (
    skill_id, resource_type, resource_name, resource_path, created_at
) VALUES
    ('[skill-id]', 'SCRIPT', '[脚本文件名]', '/skills/[路径]/[文件名]', NOW())
ON DUPLICATE KEY UPDATE
    resource_path = VALUES(resource_path),
    updated_at = NOW();
```

---

## ⚠️ 注意事项

1. **技能 ID 唯一性**：确保 `skill_id` 在系统中唯一
2. **Function Schema 格式**：必须符合 JSON Schema 规范
3. **执行类型**：根据技能实现选择合适的执行类型
4. **权限控制**：设置适当的 `required_permissions`
5. **版本管理**：使用语义化版本号（如 1.0.0）
6. **系统技能**：系统技能设置为 `is_system_skill = true`，不可删除

## 🔄 更新已迁移的技能

如果需要更新已迁移的技能：

1. **修改迁移脚本**：更新 SQL 语句中的值
2. **或使用 UPDATE**：直接更新数据库记录
3. **刷新缓存**：调用 `SkillRegistry.refreshSkillCache()`
