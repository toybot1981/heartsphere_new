# 测试技能使用说明

## 📋 概述

`test-skill` 是一个简单的测试技能，用于验证技能系统的基本功能。

---

## 🎯 技能信息

- **技能ID**: `test-skill`
- **技能名称**: 测试技能
- **技能类型**: ACTIVE（主动技能）
- **执行类型**: RULE_BASED（基于规则）
- **分类**: UTILITY（工具类）

---

## 📝 功能说明

这个技能可以接收用户输入，并根据指定的动作进行处理：

### 支持的动作

| 动作 | 说明 | 示例 |
|------|------|------|
| `echo` | 原样返回输入内容 | "Hello" → "Hello" |
| `uppercase` | 将输入转换为大写 | "Hello" → "HELLO" |
| `lowercase` | 将输入转换为小写 | "HELLO" → "hello" |
| `reverse` | 反转输入字符串 | "Hello" → "olleH" |

---

## 🔧 Function Schema

```json
{
  "type": "object",
  "properties": {
    "input": {
      "type": "string",
      "description": "用户输入的内容"
    },
    "action": {
      "type": "string",
      "enum": ["echo", "uppercase", "lowercase", "reverse"],
      "description": "处理动作"
    }
  },
  "required": ["input"]
}
```

## 💡 使用示例

### 示例 1：原样返回

**AI 调用**：
```json
{
  "name": "test-skill",
  "arguments": {
    "input": "Hello World",
    "action": "echo"
  }
}
```

```json
{
```

## 🧪 测试步骤

### 1. 验证技能已创建

```bash
# 查询技能
GET /api/skills/test-skill
```

### 2. 装备技能到角色

1. 进入角色管理
2. 编辑某个角色
3. 切换到"技能管理"标签页
4. 找到"测试技能"
5. 点击"装备"

### 3. 测试技能执行

**通过 API**：
```bash
POST /api/skills/execute
{
  "skillId": "test-skill",
  "characterId": 1,
  "parameters": {
    "input": "Hello World",
    "action": "uppercase"
  }
}
```

**通过对话**：
```
用户：请帮我测试一下技能，把 "hello" 转成大写
AI：→ 应该自动调用 test-skill 技能
    → 返回结果："HELLO"
```

## 🔍 故障排查

### 问题 1：技能未出现在列表中

**可能原因**：
- 迁移脚本未执行
- 技能未激活（`is_active = false`）

**解决方法**：
1. 检查数据库：`SELECT * FROM skill_definitions WHERE skill_id = 'test-skill';`
2. 确认 `is_active = true`
3. 重启后端服务

### 问题 2：技能执行失败

**可能原因**：
- 参数格式错误
- 缺少必填参数

**解决方法**：
1. 检查参数是否符合 Function Schema
2. 确保 `input` 参数存在
3. 检查后端日志

### 问题 3：AI 不调用技能

**可能原因**：
- 技能未装备到角色
- Function Schema 格式错误

**解决方法**：
1. 确认技能已装备到角色
2. 检查 `function_schema` 字段格式
3. 查看 AI 服务日志
