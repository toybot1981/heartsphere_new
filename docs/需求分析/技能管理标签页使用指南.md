# 技能管理标签页使用指南

## 📍 如何找到技能管理标签页

### 步骤 1：进入角色管理页面

1. 登录管理后台
2. 导航到 **角色管理** 页面
3. 应该能看到角色列表

### 步骤 2：进入编辑模式

1. 在角色列表中找到要编辑的角色
2. 点击该角色行的 **"编辑"** 按钮
3. 页面会切换到编辑模式

### 步骤 3：查看标签页导航

在编辑模式下，**标题下方**应该能看到两个标签页按钮：

```
[ 基本信息 ] [ 技能管理 ]
```

**位置**：
- 在 "编辑角色" 标题下方
- 在角色编辑表单上方
- 有下划线分隔

### 步骤 4：切换到技能管理

1. 点击 **"技能管理"** 标签页按钮
2. 页面会切换到技能管理界面
3. 应该能看到：
   - 技能统计（已装备/可用）
   - 搜索框
   - 技能列表

---

## 🔍 如果看不到标签页

### 检查清单

- [ ] **是否进入了编辑模式？**
  - 确认点击了"编辑"按钮
  - 确认页面显示了编辑表单（不是列表）

- [ ] **是否在正确的页面？**
  - 确认在角色管理页面
  - 不是角色列表页面

- [ ] **浏览器控制台是否有错误？**
  - 按 F12 打开开发者工具
  - 查看 Console 标签页
  - 查看是否有红色错误信息

- [ ] **标签页是否被隐藏？**
  - 检查 CSS 样式
  - 尝试缩小浏览器窗口
  - 检查是否有滚动条

├─────────────────────────────────────┤

### 标签页导航样式

- **激活的标签页**：蓝色文字，底部有蓝色下划线
- **未激活的标签页**：灰色文字，鼠标悬停变白色
- **位置**：标题下方，表单上方

## 🐛 常见问题

### 问题 1：看不到标签页导航

**可能原因**：
- 没有进入编辑模式
- `editingId` 为空
- `viewMode` 不是 'edit'

**解决方法**：
1. 确认点击了"编辑"按钮
2. 刷新页面
3. 检查浏览器控制台

### 问题 2：点击标签页无反应

**可能原因**：
- 状态更新问题
- 事件处理问题

**解决方法**：
1. 刷新页面
2. 检查浏览器控制台
3. 尝试多次点击

### 问题 3：技能管理界面空白

**可能原因**：
- API 调用失败
- 组件渲染错误
- 数据加载失败

**解决方法**：
1. 检查浏览器控制台
2. 检查 Network 标签页
3. 查看 API 请求是否成功

## 🔧 调试方法

### 方法 1：浏览器控制台

打开浏览器开发者工具（F12），在 Console 中输入：

```javascript
// 检查组件状态（如果组件暴露了状态）
// 或者查看 React DevTools
```

### 方法 2：React DevTools

1. 安装 React DevTools 浏览器扩展
2. 打开 React DevTools
3. 检查 CharactersManagement 组件
4. 查看 `viewMode`、`editingId`、`activeTab` 的值

### 方法 3：网络请求检查

1. 打开 Network 标签页
2. 切换到技能管理标签页
3. 查看是否有以下请求：
   - `GET /api/skills/available`
   - `GET /api/characters/{id}/skills`
