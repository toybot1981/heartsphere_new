## 四、API 集成测试

### 4.1 管理员接口测试

#### 4.1.1 创建会话

**请求**：
```http
POST /api/admin/mentis/sessions
Authorization: Bearer <admin_token>
Content-Type: application/json

{
  "title": "测试会话"
}
```

**预期响应**：
- 状态码：200
- 包含 `sessionId`
- `userId` 为负数（管理员ID的负值）

#### 4.1.2 发送消息（同步）

**请求**：
```http
POST /api/admin/mentis/chat/send
Authorization: Bearer <admin_token>
Content-Type: application/json

{
  "sessionId": "<session_id>",
  "message": "你好",
  "enableComputerUse": true
}
```

**预期响应**：
- 状态码：200
- 包含 `response` 字段
- 包含 `messageId`

#### 4.1.3 发送消息（流式）

**请求**：
```http
POST /api/admin/mentis/chat/stream
Authorization: Bearer <admin_token>
Content-Type: application/json

{
  "sessionId": "<session_id>",
  "message": "帮我执行 ls -la",
  "enableComputerUse": true
}
```

**预期响应**：
- 状态码：200
- Content-Type: `text/event-stream`
- SSE 格式：`data: {...}\n\n`

## 六、性能测试

### 6.1 并发测试

- **目标**：验证系统在并发请求下的稳定性
- **方法**：使用 JMeter 或 Apache Bench
- **指标**：
  - 响应时间 < 2s（同步）
  - 吞吐量 > 100 req/s
  - 错误率 < 1%

### 6.2 流式响应测试

- **目标**：验证SSE连接的稳定性
- **测试场景**：
  - 长时间连接（5分钟）
  - 大量并发流式连接（10+）
  - 网络中断恢复
