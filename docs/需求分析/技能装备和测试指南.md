# 技能装备和测试指南

## 📋 概述

本指南说明如何为角色装备技能，并测试技能是否正常工作。

---

## 🎯 技能装备步骤

### 方法一：通过前端界面（推荐）

#### 步骤 1：进入角色管理

1. 登录管理后台
2. 导航到"角色管理"
3. 找到要装备技能的角色
4. 点击"编辑"按钮

#### 步骤 2：切换到技能管理标签页

1. 在编辑页面顶部，点击"技能管理"标签页
2. 应该能看到：
   - 技能统计：`已装备: X 可用: Y`
   - 搜索框
   - 技能列表

#### 步骤 3：装备技能

1. 在"可用技能"列表中找到"测试技能"
2. 点击"装备"按钮
3. 在装备对话框中配置：
   - **启用技能**：✓（勾选）
   - **自动触发**：可选（勾选后 AI 会自动判断是否使用）
   - **优先级**：0（数字越大优先级越高）
4. 点击"确认装备"

#### 步骤 4：验证装备成功

1. 技能应该出现在"已装备"列表中
2. 技能统计应该更新：`已装备: 1 可用: Y`
3. 可以点击"卸载"按钮移除技能

### 方法二：通过 API（开发测试）

#### 1. 装备技能

```bash
# 替换 YOUR_TOKEN 和 CHARACTER_ID
TOKEN="YOUR_TOKEN"
CHARACTER_ID=1

curl -X POST http://localhost:8080/api/characters/${CHARACTER_ID}/skills/test-skill/equip \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "isEnabled": true,
    "autoTrigger": false,
    "priority": 0
  }'
```

#### 2. 查询已装备技能

```bash
curl -X GET http://localhost:8080/api/characters/${CHARACTER_ID}/skills \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN"
```

## 🧪 测试技能执行

### 测试方法一：通过 API 直接执行

#### 1. 执行测试技能

```bash
curl -X POST http://localhost:8080/api/skills/execute \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "skillId": "test-skill",
    "characterId": 1,
    "parameters": {
      "input": "Hello World",
      "action": "uppercase"
    }
  }'
```

**预期响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "skillId": "test-skill",
    "success": true,
    "result": {
      "skillId": "test-skill",
      "skillName": "测试技能",
      "message": "技能执行成功（基于规则）",
      "parameters": {
        "input": "Hello World",
        "action": "uppercase"
      }
    },
    "executionTimeMs": 50
  }
}
```

## 🔍 故障排查

### 问题 1：装备技能失败

**可能原因**：
- 角色不存在
- 技能不存在
- 权限问题
- 技能已装备

**解决方法**：
1. 检查角色ID是否正确
2. 检查技能ID是否存在
3. 检查后端日志
4. 验证是否已装备（查询已装备技能列表）

### 问题 2：技能执行失败

**可能原因**：
- 参数格式错误
- 缺少必填参数
- 技能未装备
- 技能未启用

**解决方法**：
1. 检查参数是否符合 Function Schema
2. 确保 `input` 参数存在
3. 确认技能已装备且启用
4. 查看后端日志错误信息

### 问题 3：AI 不调用技能

**可能原因**：
- 技能未装备
- 技能未启用
- Function Schema 格式错误
- AI 判断不需要使用技能

**解决方法**：
1. 确认技能已装备且启用
2. 检查 `function_schema` 字段格式
3. 尝试更明确的用户输入
4. 检查 AI 服务日志
