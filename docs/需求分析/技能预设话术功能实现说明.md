# 技能预设话术功能实现说明

**文档版本**: V1.0  
**创建日期**: 2025-01-07  
**功能**: 在 ChatWindow 中为生活助手角色添加预设话术按钮，方便用户测试技能

---

## 一、功能概述

为六个生活助手角色（时小光、康小健、学小知、心小暖、心小安、暖小阳）在 ChatWindow 中增加了预设话术按钮功能。用户可以通过点击这些按钮快速发送测试消息，触发对应的技能，从而方便地测试技能的能力。

---

## 二、实现内容

### 1. 预设话术配置文件

**文件**: `frontend/constants/skillPrompts.ts`

**内容**:
- 定义了 `SkillPrompt` 接口，包含话术ID、文本、技能名称和分类
- 定义了 `CharacterSkillPrompts` 接口，包含角色名称和话术列表
- 定义了 `DAILY_LIFE_ASSISTANT_PROMPTS` 常量，包含六个角色的48个预设话术（每个角色8个）
- 实现了 `isDailyLifeAssistant()` 函数，用于检查角色是否是生活助手
- 实现了 `getCharacterPrompts()` 函数，用于获取指定角色的预设话术

**每个角色的8个话术**:
- **时小光（时间管理导师）**: 时间审计、任务分解、优先级矩阵、时间块规划、截止日期管理、拖延克服教练、番茄工作法助手、习惯养成追踪
- **康小健（健康生活顾问）**: 健康数据追踪、个性化饮食建议、运动计划制定、睡眠优化指导、压力缓解技巧、水分摄入提醒、健康习惯养成、健康状态评估
- **学小知（学习成长导师）**: 学习计划制定、记忆技巧训练、笔记方法指导、专注力训练、考试复习规划、学习风格分析、知识图谱构建、学习动力激励
- **心小暖（情绪陪伴师）**: 情绪日记、情感支持、情绪变化追踪、应对策略建议、感恩练习、危机支持、陪伴与鼓励、情绪确认与倾听
- **心小安（心理健康顾问）**: 压力源分析、CBT认知重构、正念冥想指导、睡眠健康分析、人际关系指导、心理健康评估、焦虑管理技巧、自我关爱计划
- **暖小阳（情感陪伴师）**: 日常聊天、鼓励与支持、兴趣话题引导、温暖消息生成、活动建议、成就庆祝、安慰性对话、积极回忆引导

### 2. 预设话术按钮组件

**文件**: `frontend/components/chat/SkillPromptButtons.tsx`

**功能**:
- 显示角色的预设话术按钮
- 支持按技能分类筛选（显示分类下拉菜单）
- 支持展开/收起（默认显示4个，可展开显示全部）
- 鼠标悬停显示技能名称提示
- 点击按钮直接发送消息

**UI特性**:
- 标题栏显示"💡 技能测试话术"和当前显示数量
- 分类下拉菜单：显示所有技能分类，可选择筛选
- 展开/收起按钮：当话术数量超过4个时显示
- 话术按钮：显示话术文本，悬停显示技能名称
- 提示信息：显示还有多少话术未展开

**样式**:
- 使用半透明黑色背景和白色文字
- 按钮有悬停效果和边框高亮
- 响应式设计，支持移动端

---

### 3. ChatWindow 集成

**文件**: `frontend/components/ChatWindow.tsx`

**修改内容**:
1. 导入 `SkillPromptButtons` 组件和 `isDailyLifeAssistant` 函数
2. 创建 `handleSendWithText()` 函数，支持使用指定文本发送消息
3. 重构 `handleSend()` 函数，使其调用 `handleSendWithText()`
4. 在输入框上方添加 `SkillPromptButtons` 组件（仅在非场景模式、非影院模式、非语音模式下显示，且角色必须是生活助手）

**显示条件**:
- 角色必须是六个生活助手之一（通过 `isDailyLifeAssistant()` 检查）
- 不在场景模式（`!isScenarioMode`）
- 不在影院模式（`!uiState.isCinematic`）
- 不在语音模式（`!voiceInput.isVoiceMode`）

**点击行为**:
- 点击预设话术按钮后，直接调用 `handleSendWithText(text)` 发送消息
- 不填充到输入框，直接发送，提高用户体验

## 三、使用说明

### 1. 如何访问预设话术

1. 选择六个生活助手角色之一（时小光、康小健、学小知、心小暖、心小安、暖小阳）
2. 进入聊天窗口
3. 在输入框上方会显示"💡 技能测试话术"区域

### 2. 如何使用预设话术

1. **点击话术按钮**: 直接点击任意话术按钮，会自动发送消息并触发对应技能
2. **筛选分类**: 使用分类下拉菜单选择特定类型的技能（如"时间管理"、"健康管理"等）
3. **展开查看**: 默认显示4个话术，点击"展开 ↓"按钮可以查看全部话术
4. **查看技能名称**: 鼠标悬停在话术按钮上，会显示对应的技能名称

### 3. 话术示例

**时小光（时间管理导师）**:
- "帮我分析一下今天的时间使用情况" → 触发"时间审计"技能
- "把这个任务分解成小步骤" → 触发"任务分解"技能
- "用番茄工作法来安排学习时间" → 触发"番茄工作法助手"技能

**康小健（健康生活顾问）**:
- "我想记录一下今天的体重和运动情况" → 触发"健康数据追踪"技能
- "给我一些饮食建议" → 触发"个性化饮食建议"技能
- "帮我制定一个运动计划" → 触发"运动计划制定"技能

**学小知（学习成长导师）**:
- "我想制定一个学习计划" → 触发"学习计划制定"技能
- "有什么好的记忆方法吗？" → 触发"记忆技巧训练"技能
- "教我如何做笔记" → 触发"笔记方法指导"技能

## 四、技术实现细节

### 1. 角色识别

使用 `isDailyLifeAssistant(characterName)` 函数检查角色是否是生活助手：

```typescript
export function isDailyLifeAssistant(characterName: string): boolean {
  return DAILY_LIFE_ASSISTANT_PROMPTS.some(
    config => config.characterName === characterName
  );
}
```

### 2. 话术获取

使用 `getCharacterPrompts(characterName)` 函数获取角色的预设话术：

```typescript
export function getCharacterPrompts(characterName: string): SkillPrompt[] {
  const config = DAILY_LIFE_ASSISTANT_PROMPTS.find(
    config => config.characterName === characterName
  );
  return config?.prompts || [];
}
```

### 3. 消息发送

使用 `handleSendWithText(text)` 函数发送指定文本的消息：

```typescript
const handleSendWithText = async (text?: string) => {
  const textToSend = text || input.trim();
  // ... 发送消息逻辑
};
```

### 4. 分类筛选

使用 `useMemo` Hook 实现分类筛选功能：

```typescript
const filteredPrompts = useMemo(() => {
  if (!selectedCategory) {
    return prompts;
  }
  return prompts.filter(prompt => prompt.category === selectedCategory);
}, [prompts, selectedCategory]);
```
