# 技能信息显示功能实现说明

**文档版本**: V1.0  
**创建日期**: 2025-01-07  
**功能**: 在角色对话中显示触发的技能信息

---

## 一、功能概述

当拥有技能的角色在对话中触发技能时，在角色的回复消息底部以括号小字的形式显示技能名称，格式为：`（使用技能：技能名称）`

---

## 二、前端实现（已完成）

### 2.1 Message接口扩展

在 `frontend/types.ts` 中，已为 `Message` 接口添加了技能信息字段：

```typescript
export interface Message {
  id: string;
  role: 'user' | 'model';
  text: string;
  image?: string;
  timestamp: number;
  // 技能信息（当角色触发技能时显示）
  skillId?: string;      // 技能ID
  skillName?: string;    // 技能名称
}
```

### 2.2 MessageBubble组件修改

在 `frontend/components/chat/MessageBubble.tsx` 中，已添加技能信息显示逻辑：

- 仅在角色消息（`role === 'model'`）且非电影模式时显示
- 显示位置：消息文本下方，音频按钮上方
- 样式：小字、斜体、半透明白色（`text-xs text-white/50 italic`）
- 格式：`（使用技能：技能名称）`

### 3.2 技能执行结果获取

在对话处理服务中，当技能被执行时，需要获取技能信息并添加到响应中。

#### 示例代码结构：

```java
@Service
public class ConversationService {
    
    private final SkillExecutor skillExecutor;
    private final SkillDefinitionRepository skillDefinitionRepository;
    
    public ChatResponseDTO processMessage(Long userId, ChatRequestDTO request) {
        // ... 处理消息逻辑 ...
        
        // 如果触发了技能
        if (skillWasTriggered) {
            SkillExecutor.SkillExecutionResult skillResult = skillExecutor.execute(
                skillId, parameters, context
            );
            
            // 获取技能定义
            SkillDefinition skill = skillDefinitionRepository
                .findBySkillId(skillId)
                .orElse(null);
            
            // 创建响应
            ChatResponseDTO response = new ChatResponseDTO();
            response.setResponse(aiResponseText);
            
            // 设置技能信息
            if (skill != null) {
                response.setSkillId(skill.getSkillId());
                response.setSkillName(skill.getName());
            }
            
            return response;
        }
        
        // ... 正常响应 ...
    }
}
```

## 四、技能触发检测

### 4.1 技能触发时机

技能可能在以下时机被触发：

1. **自动触发**：根据 `auto_trigger` 配置和 `auto_trigger_keywords` 自动触发
2. **手动触发**：用户明确请求使用某个技能
3. **AI判断触发**：AI根据对话内容判断需要调用技能

### 4.2 技能执行流程

```
用户消息
  ↓
意图识别/技能匹配
  ↓
技能执行（SkillExecutor.execute）
  ↓
获取技能定义（SkillDefinition）
  ↓
生成AI回复（包含技能执行结果）
  ↓
构建响应DTO（包含技能信息）
  ↓
返回给前端
```

## 六、测试建议

### 6.1 功能测试

1. **基本显示测试**：
   - 触发一个技能，验证技能名称是否正确显示
   - 验证显示位置和样式是否符合要求

2. **边界情况测试**：
   - 未触发技能时，不应显示技能信息
   - 用户消息不应显示技能信息
   - 电影模式下不应显示技能信息

3. **多技能测试**：
   - 连续触发多个技能，验证每个消息都正确显示对应的技能信息

### 6.2 集成测试

1. 测试技能执行后，技能信息是否正确传递到前端
2. 测试前端是否正确解析和显示技能信息
3. 测试在不同对话场景下的表现

---

## 七、注意事项

1. **性能考虑**：技能信息显示不应影响消息渲染性能
2. **样式一致性**：技能信息显示样式应与整体UI风格一致
3. **国际化**：如果支持多语言，技能名称可能需要翻译
4. **权限控制**：确保只有拥有技能的角色才能触发和显示技能信息
