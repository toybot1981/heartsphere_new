# 如何让角色触发技能指南

**文档版本**: V1.0  
**创建日期**: 2025-01-07  
**功能**: 说明如何让角色在对话中触发技能

---

## 一、技能触发机制概述

角色触发技能有两种方式：

1. **Function Calling触发（主动触发）**：AI 分析用户输入，决定是否需要调用技能
2. **自动触发（Auto Trigger）**：当用户输入包含特定关键词时，自动触发技能

---

## 二、前置条件

### 1. 技能必须已装备

技能必须已经装备到角色上，并且处于启用状态。

**检查方法**：
- 查看数据库 `character_skill_bindings` 表
- 确保 `character_id` 对应角色ID
- 确保 `skill_id` 对应技能ID
- 确保 `is_enabled = 1`（技能已启用）

**SQL查询示例**：
```sql
-- 查看角色的已装备技能
SELECT 
    sc.name AS '角色',
    sd.name AS '技能名称',
    sd.skill_id AS '技能ID',
    csb.is_enabled AS '是否启用',
    csb.auto_trigger AS '是否自动触发',
    sd.auto_trigger_keywords AS '自动触发关键词'
FROM character_skill_bindings csb
JOIN system_characters sc ON csb.character_id = sc.id
JOIN skill_definitions sd ON csb.skill_id = sd.skill_id
WHERE sc.name = '时小光';  -- 替换为你要检查的角色名
```

## 三、Function Calling触发（主动触发）

### 工作原理

1. 用户发送消息
2. 前端获取角色的可用技能，转换为 Function Definitions
3. AI 分析用户输入和对话上下文
4. AI 判断是否需要调用技能
5. 如果需要，AI 生成 function_call 请求
6. 前端执行技能，返回结果给 AI
7. AI 基于技能结果继续生成回复

### 如何触发

#### 方法1：明确请求使用技能

在对话中明确提到技能相关的关键词或功能：

**示例**（时小光 - 时间管理导师）：

```
用户："帮我分析一下今天的时间使用情况"
AI：→ 调用"时间审计"技能 (time_audit)

用户："把这个任务分解一下"
AI：→ 调用"任务分解"技能 (task_breakdown)

用户："用番茄工作法来安排学习时间"
AI：→ 调用"番茄工作法助手"技能 (pomodoro_assistant)
```

#### 方法2：描述需要使用技能的场景

描述需要使用技能的场景，让 AI 判断：

**示例**（康小健 - 健康生活顾问）：

```
用户："我想记录一下今天的体重和运动情况"
AI：→ 调用"健康数据追踪"技能 (health_data_tracking)

用户："给我一些饮食建议"
AI：→ 调用"个性化饮食建议"技能 (personalized_nutrition_advice)

用户："帮我制定一个运动计划"
AI：→ 调用"运动计划制定"技能 (exercise_plan_creation)
```

#### 方法3：提及技能的用途

直接或间接提及技能的用途：

**示例**（学小知 - 学习成长导师）：

```
用户："我想制定一个学习计划"
AI：→ 调用"学习计划制定"技能 (study_plan_creation)

用户："有什么好的记忆方法吗？"
AI：→ 调用"记忆技巧训练"技能 (memory_technique_training)

用户："教我如何做笔记"
AI：→ 调用"笔记方法指导"技能 (note_taking_method_guidance)
```

### 技能关键词参考

每个技能都有相关的关键词，AI 会根据这些关键词判断是否需要调用技能。关键词定义在 `skill_definitions` 表的 `auto_trigger_keywords` 字段中。

**常见关键词示例**：

| 技能类型 | 关键词示例 |
|---------|-----------|
| 时间管理 | 时间、效率、时间管理、任务分解、优先级、拖延 |
| 健康生活 | 健康、饮食、运动、睡眠、体重、压力 |
| 学习成长 | 学习、记忆、笔记、计划、复习、效率 |
| 情绪陪伴 | 情绪、压力、焦虑、陪伴、倾听、支持 |
| 心理健康 | 心理健康、压力源、认知、睡眠健康、人际关系 |
| 情感陪伴 | 聊天、陪伴、鼓励、支持、分享、快乐 |

## 四、自动触发（Auto Trigger）

### 工作原理

1. 用户发送消息
2. 系统检查角色的自动触发技能
3. 如果用户输入包含技能的关键词，触发该技能
4. 技能自动执行（或在 AI 生成回复前执行）

### 配置自动触发

#### 1. 在数据库中设置自动触发

```sql
-- 启用技能的自动触发
UPDATE character_skill_bindings
SET auto_trigger = 1
WHERE character_id = (SELECT id FROM system_characters WHERE name = '时小光')
  AND skill_id = 'habit_tracker';
```

#### 2. 设置自动触发关键词

```sql
-- 设置技能的自动触发关键词
UPDATE skill_definitions
SET auto_trigger_keywords = '["习惯", "追踪", "养成"]'
WHERE skill_id = 'habit_tracker';
```

**关键词格式**：JSON 数组，例如 `["关键词1", "关键词2", "关键词3"]`

#### 3. 验证自动触发配置

```sql
-- 查看已配置自动触发的技能
SELECT 
    sc.name AS '角色',
    sd.name AS '技能名称',
    sd.skill_id AS '技能ID',
    csb.auto_trigger AS '自动触发',
    sd.auto_trigger_keywords AS '触发关键词'
FROM character_skill_bindings csb
JOIN system_characters sc ON csb.character_id = sc.id
JOIN skill_definitions sd ON csb.skill_id = sd.skill_id
WHERE csb.auto_trigger = 1
  AND sc.name = '时小光';
```

### 自动触发技能示例

#### 时小光（时间管理导师）

已配置自动触发的技能：

1. **习惯养成追踪** (habit_tracker)
   - 触发关键词：`["习惯", "追踪"]`

2. **健康习惯养成** (health_habit_formation)
   - 触发关键词：`["健康习惯", "养成"]`

## 五、验证技能触发

### 1. 检查技能是否已装备

```bash
# 使用验证脚本
./scripts/verify_skills_system.sh
```

或直接查询数据库：

```sql
-- 查看角色已装备的技能
SELECT 
    sc.name AS '角色',
    COUNT(csb.skill_id) AS '技能数',
    SUM(CASE WHEN csb.is_enabled = 1 THEN 1 ELSE 0 END) AS '已启用',
    SUM(CASE WHEN csb.auto_trigger = 1 THEN 1 ELSE 0 END) AS '自动触发'
FROM system_characters sc
LEFT JOIN character_skill_bindings csb ON sc.id = csb.character_id
WHERE sc.name IN ('时小光', '康小健', '学小知', '心小暖', '心小安', '暖小阳')
GROUP BY sc.id, sc.name
ORDER BY sc.name;
```

1. 打开前端聊天界面

3. 发送包含技能关键词的消息

## 六、常见问题

### Q1: 技能没有触发，为什么？

**可能原因**：

1. **技能未装备**
   - 检查 `character_skill_bindings` 表中是否有对应记录
   - 确保 `is_enabled = 1`

2. **技能未启用**
   - 检查 `character_skill_bindings` 表的 `is_enabled` 字段

3. **AI 判断不需要调用**
   - Function Calling 是 AI 自主判断的，不是所有情况下都会触发
   - 尝试更明确地表达需要使用技能的需求

4. **关键词不匹配**
   - 检查自动触发关键词是否匹配用户输入
   - 关键词匹配是大小写不敏感的

5. **前端未获取技能**
   - 检查浏览器控制台是否有错误
   - 检查角色 ID 是否正确

### Q2: 如何强制触发某个技能？

目前没有强制触发的机制。技能触发依赖于：

1. **Function Calling**：AI 自主判断
2. **自动触发**：关键词匹配

如果需要确保技能触发，建议：

1. 明确提及技能的功能或用途
2. 使用技能的关键词
3. 配置自动触发关键词

### Q3: 自动触发没有生效，为什么？

**检查清单**：

1. ✅ 技能是否已装备：`SELECT * FROM character_skill_bindings WHERE ...`
2. ✅ 自动触发是否启用：`auto_trigger = 1`
3. ✅ 关键词是否正确配置：`auto_trigger_keywords` 不为空
4. ✅ 关键词格式是否正确：JSON 数组格式 `["关键词1", "关键词2"]`
5. ✅ 用户输入是否包含关键词：关键词匹配是部分匹配的

### Q4: 如何查看技能是否被触发？

**方法1：前端显示**
- 技能触发后，消息底部会显示 `（使用技能：技能名称）`

**方法2：浏览器控制台**
- 打开开发者工具（F12）
- 查看 Console 标签页
- 应该看到 `[generateAIResponse] Function Call:` 日志

**方法3：后端日志**
- 查看后端日志文件
- 应该看到技能执行的日志

### Q5: 如何配置新的自动触发技能？

```sql
-- 1. 启用自动触发
UPDATE character_skill_bindings
SET auto_trigger = 1
WHERE character_id = (SELECT id FROM system_characters WHERE name = '角色名')
  AND skill_id = '技能ID';

-- 2. 设置触发关键词
UPDATE skill_definitions
SET auto_trigger_keywords = '["关键词1", "关键词2", "关键词3"]'
WHERE skill_id = '技能ID';

-- 3. 验证配置
SELECT 
    sc.name AS '角色',
    sd.name AS '技能名称',
    csb.auto_trigger AS '自动触发',
    sd.auto_trigger_keywords AS '触发关键词'
FROM character_skill_bindings csb
JOIN system_characters sc ON csb.character_id = sc.id
JOIN skill_definitions sd ON csb.skill_id = sd.skill_id
WHERE sc.name = '角色名'
  AND sd.skill_id = '技能ID';
```

## 七、技能触发最佳实践

### 1. 明确表达需求

**推荐**：
- "帮我分析一下今天的时间使用情况"
- "把这个任务分解成小步骤"
- "给我一些饮食建议"

**不推荐**：
- "时间"
- "任务"
- "建议"

### 2. 提供上下文信息

**推荐**：
- "我想制定一个学习计划，目标是3个月内掌握Python编程"
- "帮我分析一下这周的工作时间分配，看看哪些地方可以优化"

**不推荐**：
- "学习计划"
- "时间分析"

### 3. 使用自然语言

**推荐**：
- "我感觉最近压力很大，有什么办法缓解吗？"
- "我想养成早睡早起的习惯，有什么建议吗？"

**不推荐**：
- "触发压力管理技能"
- "调用习惯养成技能"

### 4. 组合使用技能

可以在一段对话中组合使用多个技能：

```
用户："我想提高学习效率，能帮我制定一个学习计划，然后教我怎么记笔记吗？"

AI：
1. 调用"学习计划制定"技能
2. 调用"笔记方法指导"技能
3. 基于两个技能的结果生成回复
```
