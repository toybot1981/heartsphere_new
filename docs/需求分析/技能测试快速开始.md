# 技能测试快速开始

## 🚀 快速测试步骤

### 步骤 1：装备技能（前端界面）

1. **打开管理后台**
   - 访问：`http://localhost:3000`
   - 登录管理账号

2. **进入角色管理**
   - 点击"角色管理"
   - 找到任意角色，点击"编辑"

3. **装备测试技能**
   - 切换到"技能管理"标签页
   - 在"可用技能"列表中找到"测试技能"
   - 点击"装备"按钮
   - 在对话框中：
     - 勾选"启用技能"
     - 可选：勾选"自动触发"
     - 优先级：0
   - 点击"确认装备"

4. **验证装备成功**
   - 技能应该出现在"已装备"列表中
   - 技能统计更新：`已装备: 1`

---

### 步骤 2：测试技能执行

#### 方法 A：通过 API 测试（快速）

```bash
# 1. 获取 Token（从浏览器 localStorage 获取）
TOKEN="your-token-here"

# 2. 执行测试脚本
./scripts/test_skill_equip_and_execute.sh 1 $TOKEN
```

#### 方法 B：通过对话测试（真实场景）

1. **打开角色对话页面**
   - 选择已装备"测试技能"的角色

2. **测试对话**
   ```
   用户：请帮我测试一下技能，把 "hello" 转成大写
   AI：→ 应该自动调用 test-skill 技能
       → 返回结果："HELLO"
   ```

3. **更多测试用例**
   ```
   - "请把 Test 反转一下" → 应该返回 "tseT"
   - "请帮我测试 echo 功能" → 应该原样返回输入
   - "把 HELLO 转成小写" → 应该返回 "hello"
   ```

- [ ] AI 可以自动调用技能

## 🔧 故障排查

### 问题：技能未装备

**检查**：
1. 技能是否存在于数据库
2. 角色ID是否正确
3. 后端日志是否有错误

### 问题：技能执行失败

**检查**：
1. 参数格式是否正确
2. 技能是否已装备且启用
3. 后端日志错误信息

### 问题：AI 不调用技能

**检查**：
1. 技能是否已装备
2. 技能是否已启用
3. Function Schema 格式是否正确
4. 用户输入是否明确
