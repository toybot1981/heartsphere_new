## 技术栈

### 前端框架
- React 18+
- TypeScript
- Vite（构建工具）

### UI 库
- Material-UI 或 Ant Design
- Tailwind CSS（可选）

### 状态管理
- React Context 或 Zustand

### 数据获取
- Axios 或 Fetch API
- React Query（可选）

### 可视化
- Chart.js 或 ECharts（图表）
- X6 或 React Flow（流程图）
