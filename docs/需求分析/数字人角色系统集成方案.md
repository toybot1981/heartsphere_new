**文档版本**: V1.0  
**创建日期**: 2025-01-XX  
**项目名称**: 数字生命体交互系统（HeartSphere）

## 一、集成概述

### 1.1 集成目标
将设计的6个日常生活助手角色（时小光、康小健、学小知、心小暖、心小安、暖小阳）及其48个技能集成到心域系统中。

### 1.2 集成范围
- ✅ 角色数据导入（时代表 + 6个角色）
- ✅ 技能系统集成（48个技能定义）
- ✅ 角色技能绑定（角色与技能的关联）
- ✅ 前端展示集成（角色列表、详情页）
- ✅ 技能执行集成（技能调用和执行）

### 1.3 集成步骤概览
1. **数据准备阶段**：验证SQL文件，准备技能数据
2. **数据库集成阶段**：导入角色数据，创建技能定义
3. **技能绑定阶段**：将技能绑定到对应角色
4. **前端集成阶段**：更新前端展示和交互
5. **测试验证阶段**：功能测试和验证

```sql
-- 验证技能数量（按角色分组）
SELECT 
  CASE 
    WHEN skill_id LIKE 'time_%' THEN '时小光'
    WHEN skill_id LIKE 'health_%' THEN '康小健'
    WHEN skill_id LIKE 'learn_%' THEN '学小知'
    WHEN skill_id LIKE 'emotion_%' THEN '心小暖'
    WHEN skill_id LIKE 'mental_%' THEN '心小安'
    WHEN skill_id LIKE 'companion_%' THEN '暖小阳'

  COUNT(*) as skill_count
FROM skill_definitions
WHERE skill_id LIKE 'time_%' OR skill_id LIKE 'health_%' OR skill_id LIKE 'learn_%' 
   OR skill_id LIKE 'emotion_%' OR skill_id LIKE 'mental_%' OR skill_id LIKE 'companion_%'

-- 每个角色应该返回8个技能
```

**验证点**：
- ✅ 48个技能全部创建

### 阶段3：技能绑定

#### 步骤3.1：创建角色技能绑定
**目标**：将48个技能绑定到对应的6个角色

**操作**：创建绑定SQL文件 `bind_skills_to_characters.sql`

```sql
-- 绑定时小光的技能
INSERT INTO character_skill_bindings (character_id, skill_id, is_active, sort_order) VALUES
((SELECT id FROM system_characters WHERE name = '时小光' LIMIT 1), 'time_audit', TRUE, 1),
((SELECT id FROM system_characters WHERE name = '时小光' LIMIT 1), 'task_breakdown', TRUE, 2),
-- ... 其他6个技能
;

-- 绑定其他角色的技能（类似）
```

**或者通过API绑定**：
```bash
# 获取角色ID
CHARACTER_ID=$(mysql -h 127.0.0.1 -u root -p123456 heartsphere -se "SELECT id FROM system_characters WHERE name = '时小光' LIMIT 1")

# 绑定技能
curl -X POST http://localhost:8080/api/skills/characters/{characterId}/bind \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer {token}" \
  -d '{"skillId": "time_audit", "isActive": true, "sortOrder": 1}'
```

**验证SQL**：
```sql
-- 验证每个角色的技能绑定数量
SELECT 
  sc.name as character_name,
  COUNT(csb.id) as bound_skills_count
FROM system_characters sc
LEFT JOIN character_skill_bindings csb ON sc.id = csb.character_id
WHERE sc.system_era_id = (SELECT id FROM system_eras WHERE name = '日常生活助手' LIMIT 1)
GROUP BY sc.name
ORDER BY sc.sort_order;
-- 每个角色应该返回8个技能
```

**验证点**：
- ✅ 每个角色绑定8个技能
- ✅ 技能绑定顺序正确
- ✅ 绑定状态正确（is_active = TRUE）

## 三、技能系统集成详细方案

### 3.1 技能定义结构

每个技能需要包含以下信息：

```json
{
  "skillId": "time_audit",
  "name": "时间审计",
  "description": "帮助用户分析时间使用情况，识别时间浪费和效率低下的环节",
  "category": "life",
  "skillType": "ACTIVE",
  "executionType": "RULE_BASED",
  "functionSchema": {
    "type": "object",
    "properties": {
      "timeRange": {
        "type": "string",
        "enum": ["today", "week", "month"],
        "description": "时间范围"
      },
      "includeSuggestions": {
        "type": "boolean",
        "description": "是否包含建议"
      }
    },
    "required": ["timeRange"]
  },
  "autoTriggerKeywords": ["时间", "效率", "时间管理", "时间去哪了"],
  "maxUsagePerDay": -1,
  "isSystemSkill": true
}
```

### 3.2 技能指令（Level 2）

每个技能需要创建对应的指令：

```sql
INSERT INTO skill_instructions (skill_id, instruction_level, instruction_text, execution_order) VALUES
('time_audit', 2, '你是一个时间管理专家，帮助用户分析时间使用情况...', 1),
('time_audit', 2, '通过对话了解用户的时间分配...', 2),
...
```

### 3.3 技能资源（Level 3）

可选：为技能添加资源（模板、示例等）

```sql
INSERT INTO skill_resources (skill_id, resource_type, resource_name, resource_content) VALUES
('time_audit', 'template', '时间审计报告模板', '...'),
...
```

## 五、常见问题与解决方案

### Q1: SQL执行失败
**原因**：字符编码问题、表不存在、数据重复等

**解决方案**：
1. 确保使用utf8mb4编码
2. 确保表结构已创建
3. 检查是否有重复数据

### Q2: 技能绑定失败
**原因**：角色ID或技能ID不存在

**解决方案**：
1. 验证角色ID是否正确
2. 验证技能ID是否正确
3. 检查外键约束

### Q3: 前端不显示角色
**原因**：API返回数据格式不对、前端组件问题

**解决方案**：
1. 检查API返回数据格式
2. 检查前端组件逻辑
3. 查看浏览器控制台错误

### Q4: 技能调用失败
**原因**：技能执行器配置问题、参数验证失败

**解决方案**：
1. 检查技能执行器配置
2. 验证技能参数格式
3. 查看后端日志
