# 技能创建指南

## 📋 概述

本指南说明如何创建新技能，让数字人角色可以使用这些技能。

---

## 🎯 创建技能的方式

### 方式一：通过 Admin 管理界面（推荐）✨

**位置**：管理后台 → 技能管理

**功能**：
- 可视化创建技能
- 实时预览 Function Schema
- 测试技能执行
- 编辑和删除技能

**步骤**：
1. 登录管理后台
2. 导航到"技能管理"
3. 点击"新建技能"
4. 填写技能信息
5. 保存

---

### 方式二：使用 SQL 迁移脚本

**位置**：`backend/src/main/resources/db/migration/`

**适用场景**：
- 批量迁移现有技能
- 系统初始化
- 版本控制

**示例**：
```sql
-- 创建迁移脚本：V20250104__create_my_skill.sql
INSERT INTO skill_definitions (
    skill_id, name, description, category,
    skill_type, execution_type, function_schema,
    version, author, is_system_skill
) VALUES (
    'my-skill',
    '我的技能',
    '技能描述',
    'UTILITY',
    'ACTIVE',
    'RULE_BASED',
    '{"type":"object","properties":{...}}',
    '1.0.0',
    'Your Name',
    false
);
```

---

### 方式三：通过 API 创建

**API 端点**：`POST /api/skills`

**请求示例**：
```json
{
  "skillId": "my-skill",
  "name": "我的技能",
  "description": "技能描述",
  "category": "UTILITY",
  "skillType": "ACTIVE",
  "executionType": "RULE_BASED",
  "functionSchema": "{\"type\":\"object\",\"properties\":{...}}",
  "version": "1.0.0",
  "author": "Your Name"
}
```

---

## 📝 技能创建必填字段

### 基础信息

| 字段 | 说明 | 示例 |
|------|------|------|
| `skillId` | 技能ID（唯一标识，不可修改） | `crisis-intervention` |
| `name` | 技能名称 | `危机干预` |
| `description` | 技能描述 | `危机干预工具 - 评估风险、制定干预方案` |

### Function Calling 配置

| 字段 | 说明 | 是否必填 |
|------|------|---------|
| `functionSchema` | Function Calling JSON Schema | ✅ **必填**（用于 AI 调用） |
| `executionType` | 执行类型 | 可选（默认：RULE_BASED） |
| `executionConfig` | 执行配置 | 可选 |

### 其他配置

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `category` | 技能分类 | - |
| `skillType` | 技能类型（ACTIVE/PASSIVE/AUTOMATIC） | PASSIVE |
| `autoTriggerKeywords` | 自动触发关键词 | - |
| `maxUsagePerDay` | 每日最大使用次数 | -1（无限制） |
| `version` | 版本号 | 1.0.0 |
| `author` | 作者 | - |
| `isSystemSkill` | 是否为系统技能 | false |

## 🔧 Function Schema 编写指南

### 基本结构

```json
{
  "type": "object",
  "properties": {
    "param1": {
      "type": "string",
      "description": "参数1的描述"
    },
    "param2": {
      "type": "integer",
      "description": "参数2的描述"
    }
  },
  "required": ["param1"]
}
```

### 示例：简单技能

```json
{
  "type": "object",
  "properties": {
    "query": {
      "type": "string",
      "description": "查询内容"
    }
  },
  "required": ["query"]
}
```

### 示例：复杂技能

```json
{
  "type": "object",
  "properties": {
    "action": {
      "type": "string",
      "enum": ["assess", "plan", "guide"],
      "description": "操作类型"
    },
    "patientId": {
      "type": "string",
      "description": "患者ID"
    },
    "symptoms": {
      "type": "array",
      "items": {
        "type": "string"
      },
      "description": "症状列表"
    }
  },
  "required": ["action"]
}
```

## ✅ 创建技能检查清单

### 创建前

- [ ] 确定技能ID（唯一且有意义）
- [ ] 编写技能描述（清晰说明功能）
- [ ] 设计 Function Schema（定义参数）
- [ ] 确定执行类型（SCRIPT/API/GRAPH/RULE_BASED）

### 创建后

- [ ] 验证技能已保存到数据库
- [ ] 测试技能 API 调用
- [ ] 测试 Function Calling（AI 能否调用）
- [ ] 验证技能执行逻辑
- [ ] 检查技能是否出现在可用技能列表

## ⚠️ 注意事项

1. **技能ID唯一性**：确保 `skillId` 在系统中唯一
2. **Function Schema 格式**：必须符合 JSON Schema 规范
3. **系统技能**：系统技能不可删除和修改
4. **版本管理**：使用语义化版本号（如 1.0.0）
5. **权限控制**：设置适当的 `requiredPermissions`

## 🔄 更新技能

### 通过 Admin 界面

1. 进入技能管理
2. 找到要更新的技能
3. 点击"编辑"
4. 修改信息
5. 保存

### 通过 API

```bash
PUT /api/skills/{skillId}
{
  "name": "更新后的名称",
  "description": "更新后的描述",
  ...
}
```

**注意**：系统技能不可修改

---

## 🗑️ 删除技能

### 通过 Admin 界面

1. 进入技能管理
2. 找到要删除的技能
3. 点击"删除"
4. 确认删除

### 通过 API

```bash
DELETE /api/skills/{skillId}
```

**注意**：系统技能不可删除
