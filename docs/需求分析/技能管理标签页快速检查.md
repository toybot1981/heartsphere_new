# 技能管理标签页快速检查

## ✅ 快速检查清单

### 1. 确认进入编辑模式

- [ ] 在角色列表页面
- [ ] 点击了某个角色的 **"编辑"** 按钮
- [ ] 页面显示了编辑表单（不是列表）
- [ ] 标题显示 **"编辑角色"**（不是"新建角色"）

### 2. 查找标签页导航

标签页导航应该在以下位置：

```
┌─────────────────────────────────┐
│  编辑角色                        │  ← 标题
├─────────────────────────────────┤
│  [ 基本信息 ] [ 技能管理 ]       │  ← 标签页导航（这里！）
├─────────────────────────────────┤
│  角色编辑表单...                 │
└─────────────────────────────────┘
```

**如果看不到标签页导航**：
- 检查是否真的进入了编辑模式
- 检查浏览器控制台是否有错误
- 尝试刷新页面

### 3. 点击技能管理标签

- [ ] 能看到 **"技能管理"** 按钮
- [ ] 点击后按钮变为蓝色（激活状态）
- [ ] 页面内容切换为技能管理界面

---

## 🔍 调试步骤

### 步骤 1：打开浏览器控制台

1. 按 `F12` 或右键点击页面 → "检查"
2. 切换到 **Console** 标签页

### 步骤 2：进入编辑模式

1. 点击角色的"编辑"按钮
2. 在控制台查看是否有以下日志：
   ```
   [CharactersManagement] 切换到编辑模式，角色ID: XXX
   ```

### 步骤 3：检查标签页

1. 查看页面，应该能看到标签页导航
2. 点击"技能管理"按钮
3. 在控制台查看是否有以下日志：
   ```
   [CharactersManagement] 切换到技能管理标签页
   ```

### 步骤 4：检查网络请求

1. 切换到 **Network** 标签页
2. 点击"技能管理"标签
3. 查看是否有以下请求：
   - `GET /api/skills/available`
   - `GET /api/characters/{id}/skills`

---

## 🐛 如果仍然看不到

### 可能的原因

1. **没有进入编辑模式**
   - 确认点击了"编辑"按钮
   - 确认页面显示了编辑表单

2. **editingId 为空**
   - 检查控制台日志
   - 确认角色 ID 存在

3. **样式问题**
   - 标签页可能被 CSS 隐藏
   - 尝试调整浏览器窗口大小

4. **代码未更新**
   - 尝试清除浏览器缓存
   - 尝试硬刷新（Ctrl+Shift+R 或 Cmd+Shift+R）
