## 三、设计特点

### 3.1 独立性

✅ **独立的包结构**
- 所有实体类在 `com.heartsphere.skill.entity` 包中
- 不依赖其他业务模块

✅ **不建立 JPA 关系**
- 不使用 `@ManyToOne`、`@OneToMany` 等注解
- 只存储 ID，通过 ID 关联

✅ **通过 ID 关联**
```java
// ✅ 正确：只存储 ID
@Column(name = "character_id")
private Long characterId;

// ❌ 错误：不建立关系
// @ManyToOne
// private Character character;
```

### 3.2 数据完整性

✅ **数据库外键约束**
- 在数据库层面保证数据完整性
- 应用层不直接依赖 JPA 关系

✅ **索引优化**
- 所有外键字段都有索引
- 常用查询字段都有索引

### 3.3 业务方法

✅ **实体类包含业务方法**
- `CharacterSkillBinding.incrementUsageCount()` - 增加使用次数
- `CharacterSkill.addExperience()` - 增加经验值
- `CharacterSkill.checkLevelUp()` - 检查升级
- `SkillConflict.isConflict()` - 检查冲突

## 七、注意事项

### 7.1 模块独立性
