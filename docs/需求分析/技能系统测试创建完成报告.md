## 五、运行测试

### 5.1 运行所有技能系统测试

```bash
cd backend
mvn test -Dtest=com.heartsphere.skill.*
```

### 5.2 运行特定测试类

```bash
# Repository 测试
mvn test -Dtest=SkillDefinitionRepositoryTest
mvn test -Dtest=CharacterSkillBindingRepositoryTest

# Service 测试
mvn test -Dtest=SkillRegistryTest
mvn test -Dtest=CharacterSkillServiceTest
```

### 5.3 运行单个测试方法

```bash
mvn test -Dtest=SkillDefinitionRepositoryTest#testFindBySkillId
```
