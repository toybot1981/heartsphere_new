### 二、服务层

#### 2.1 核心 Service（3个）✅
- **SkillRegistry** - 技能注册表服务
  - 技能缓存管理
  - 角色技能查询
  - Function Definition 转换
  - 自动触发检测

- **SkillExecutor** - 技能执行器服务
  - 多执行器支持（SCRIPT/API/GRAPH/DATABASE/RULE_BASED）
  - 参数验证
  - 权限和使用限制检查
  - 执行历史记录

- **CharacterSkillService** - 角色技能服务
  - 装备/卸载技能
  - 启用/禁用技能
  - 前置条件检查
  - 冲突检查

#### 2.2 执行器实现（4个）✅
- **ScriptSkillExecutor** - 脚本执行器（JavaScript/Python）
- **ApiSkillExecutor** - API 执行器（HTTP 调用）
- **GraphSkillExecutor** - Graph 执行器（流程执行）
- **DatabaseSkillExecutor** - 数据库执行器（SQL 执行）

---

### 三、API 层

#### 3.1 Controller（3个）✅
- **SkillController** - 技能管理 API
  - 获取所有技能
  - 获取可用技能
  - 获取角色可用技能（用于 Function Calling）
  - 检查自动触发技能

- **CharacterSkillController** - 角色技能管理 API
  - 获取已装备技能
  - 装备/卸载技能
  - 启用/禁用技能
  - 设置自动触发和优先级

- **SkillExecutionController** - 技能执行 API
  - 执行技能

#### 3.2 DTO 层（6个）✅
- `SkillDefinitionDTO.java` - 技能定义 DTO
- `CharacterSkillBindingDTO.java` - 角色技能装备 DTO
- `FunctionDefinitionDTO.java` - Function Definition DTO
- `EquipSkillRequest.java` - 装备技能请求
- `SkillExecutionRequest.java` - 技能执行请求
- `SkillExecutionResultDTO.java` - 技能执行结果 DTO

---

### 四、前端层

#### 4.1 技能服务 ✅
- **SkillService** - 前端技能服务
  - 获取角色可用技能
  - 检查自动触发技能
  - 执行技能
  - 获取已装备技能

#### 4.2 Function Calling 集成 ✅
- **类型定义扩展**
  - `FunctionDefinition` - Function Calling 定义
  - `FunctionCall` - AI 返回的函数调用
  - 扩展 `TextGenerationRequest` 支持 Function Calling

- **generateAIResponse 集成**
  - 获取角色技能
  - 转换为 Function Definitions
  - 设置 Function Call 回调
  - 传递给 AI 服务

#### 4.3 适配器支持（4个）✅
- **OpenAIAdapter** - 完整 Function Calling 支持（递归处理）
- **QwenAdapter** - Function Calling 支持（OpenAI 兼容）
- **DoubaoAdapter** - Function Calling 支持（OpenAI 兼容）
- **GeminiAdapter** - Function Calling 支持（Gemini 特定格式）
