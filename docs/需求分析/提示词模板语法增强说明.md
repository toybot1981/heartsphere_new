# 提示词模板语法增强说明

## 一、支持的语法

### 1.1 变量替换

#### 基本变量
```
{{variableName}}
```

#### 带默认值的变量
```
{{variableName|defaultValue}}
```

**示例**：
```
你好，{{name|用户}}！
```

---

### 1.2 条件逻辑

#### 基本条件
```
{{#if condition}}
  条件为真时显示的内容
{{/if}}
```

#### 带else的条件
```
{{#if condition}}
  条件为真时显示的内容
{{else}}
  条件为假时显示的内容
{{/if}}
```

#### 条件表达式支持

1. **简单变量检查**（truthy/falsy）
   ```
   {{#if hasContext}}
   上下文信息：{{context}}
   {{/if}}
   ```

2. **相等比较**
   ```
   {{#if status == "active"}}
   状态：活跃
   {{else}}
   状态：非活跃
   {{/if}}
   ```

3. **不等比较**
   ```
   {{#if role != "admin"}}
   普通用户内容
   {{/if}}
   ```

**Truthy值**：
- 非null对象
- 非空字符串（除了"false"和"0"）
- 非零数字
- true布尔值
- 非空集合/数组

**Falsy值**：
- null
- 空字符串
- 字符串"false"或"0"
- 零值数字
- false布尔值
- 空集合/数组

---

### 1.3 循环处理

#### 基本循环
```
{{#each items}}
  {{this}}
{{/each}}
```

#### 循环中的特殊变量

- `{{this}}`：当前循环项
- `{{@index}}`：当前索引（从0开始）
- `{{@first}}`：是否为第一项（布尔值）
- `{{@last}}`：是否为最后一项（布尔值）

**示例**：
```
角色列表：
{{#each characters}}
  {{@index}}. {{name}} - {{role}}
  {{#if @last}}
    （共{{@index}}个角色）
  {{/if}}
{{/each}}
```

#### 循环对象数组

如果循环项是对象（Map），可以直接访问对象的属性：

```
{{#each users}}
  用户{{@index}}：{{name}}（{{email}}）
{{/each}}
```

## 二、完整示例

### 2.1 情绪分析模板

```
系统提示词：
你是一个情绪分析专家。请分析以下文本的情绪状态。

上下文信息：
{{#if conversationHistory}}
- 对话历史: {{conversationHistory}}
{{/if}}
{{#if timeOfDay}}
- 时间: {{timeOfDay}}点
{{/if}}
{{#if dayOfWeek}}
- 星期: 周{{dayOfWeek}}
{{/if}}
{{/if}}

用户提示词：
文本内容：{{text}}

{{#if includeExamples}}
参考示例：
{{#each examples}}
  - {{text}} → {{emotion}}
{{/each}}
{{/if}}
```

**变量示例**：
```json
{
  "text": "今天心情不错",
  "hasContext": true,
  "conversationHistory": "之前的对话内容",
  "timeOfDay": 14,
  "dayOfWeek": 1,
  "includeExamples": true,
  "examples": [
    {"text": "我很开心", "emotion": "happy"},
    {"text": "有点难过", "emotion": "sad"}
  ]
}
```

## 三、嵌套使用

### 3.1 条件中的循环

```
{{#if hasItems}}
物品列表：
{{#each items}}
  {{#if @first}}
  【开始】
  {{/if}}
  {{name}}：{{description}}
  {{#if @last}}
  【结束】
  {{/if}}
{{/each}}
{{/if}}
```

### 3.2 循环中的条件

```
{{#each characters}}
{{name}}：
  {{#if hasSkills}}
  技能：
  {{#each skills}}
    - {{this}}
  {{/each}}
  {{else}}
  无技能
  {{/if}}
{{/each}}
```

## 四、注意事项

### 4.1 语法规则

1. **标签必须配对**：`{{#if}}` 必须有对应的 `{{/if}}`，`{{#each}}` 必须有对应的 `{{/each}}`
2. **嵌套支持**：支持多层嵌套，但要注意标签的配对
3. **空格处理**：标签内的空格会被忽略，如 `{{#if condition}}` 和 `{{#if  condition  }}` 等价

### 4.2 性能考虑

1. **循环性能**：大量数据的循环可能影响性能，建议限制循环项数量
2. **嵌套深度**：过深的嵌套可能影响可读性和性能

### 4.3 错误处理

1. **未定义的变量**：如果变量未定义且无默认值，会保留原样显示
2. **类型错误**：如果变量类型不匹配（如对非集合使用 `{{#each}}`），会跳过该块并记录警告
3. **标签不匹配**：如果开始和结束标签不匹配，会记录警告并尝试处理

## 五、最佳实践

### 5.1 变量命名

- 使用有意义的变量名
- 避免使用特殊字符
- 使用驼峰命名或下划线命名

### 5.2 条件使用

- 优先使用简单的变量检查
- 复杂逻辑考虑在数据准备阶段处理
- 使用 `{{else}}` 提供默认内容

### 5.3 循环使用

- 在循环中使用 `{{@index}}` 显示序号
- 使用 `{{@first}}` 和 `{{@last}}` 处理首尾项的特殊显示
- 如果循环项是对象，直接使用属性名访问

### 5.4 模板组织

- 保持模板简洁，避免过度嵌套
- 将复杂逻辑拆分为多个模板
- 使用注释说明复杂部分（虽然模板语法不支持注释，但可以在描述中说明）
