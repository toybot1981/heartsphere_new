# 快速创建技能指南

## 🚀 快速开始

目前系统中有两种方式可以创建技能：

### 方式一：迁移现有技能（推荐）✨

系统已经有一个示例技能 `crisis-intervention`，你可以参考它来创建新技能。

**步骤**：

1. **查看示例技能**
   ```bash
   # 查看迁移脚本
   cat backend/src/main/resources/db/migration/V20250104__migrate_crisis_intervention_skill.sql
   
   # 查看原始技能文件
   cat .claude/skills/psychiatry-tools/crisis-intervention.js
   ```

2. **创建新的迁移脚本**
   
   在 `backend/src/main/resources/db/migration/` 目录下创建新的迁移脚本，例如：
   ```sql
   -- V20250104__create_my_skill.sql
   INSERT INTO skill_definitions (
       skill_id, name, description, category,
       skill_type, execution_type, function_schema,
       version, author, is_system_skill
   ) VALUES (
       'my-skill',
       '我的技能',
       '技能描述',
       'UTILITY',
       'ACTIVE',
       'RULE_BASED',
       '{"type":"object","properties":{"query":{"type":"string","description":"查询内容"}},"required":["query"]}',
       '1.0.0',
       'Your Name',
       false
   );
   ```

3. **重启后端服务**
   
   迁移脚本会在应用启动时自动执行。

---

### 方式二：通过 API 创建（临时方案）

在 Admin 技能管理界面创建之前，你可以使用 API 直接创建技能。

**使用 curl**：

```bash
curl -X POST http://localhost:8080/api/skills \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "skillId": "weather-query",
    "name": "天气查询",
    "description": "查询指定城市的天气信息",
    "category": "UTILITY",
    "skillType": "ACTIVE",
    "executionType": "RULE_BASED",
    "functionSchema": "{\"type\":\"object\",\"properties\":{\"city\":{\"type\":\"string\",\"description\":\"城市名称\"}},\"required\":[\"city\"]}",
    "version": "1.0.0",
    "author": "Your Name"
  }'
```

**使用 Postman 或其他 API 工具**：

1. 设置请求方法：`POST`
2. URL：`http://localhost:8080/api/skills`
3. Headers：
   - `Content-Type: application/json`
   - `Authorization: Bearer YOUR_TOKEN`
4. Body（JSON）：
   ```json
   {
     "skillId": "weather-query",
     "name": "天气查询",
     "description": "查询指定城市的天气信息",
     "category": "UTILITY",
     "skillType": "ACTIVE",
     "executionType": "RULE_BASED",
     "functionSchema": "{\"type\":\"object\",\"properties\":{\"city\":{\"type\":\"string\",\"description\":\"城市名称\"}},\"required\":[\"city\"]}",
     "version": "1.0.0",
     "author": "Your Name"
   }
   ```

## 📝 最简单的技能示例

如果你想快速创建一个测试技能，可以使用以下配置：

```json
{
  "skillId": "test-skill",
  "name": "测试技能",
  "description": "这是一个测试技能",
  "category": "UTILITY",
  "skillType": "ACTIVE",
  "executionType": "RULE_BASED",
  "functionSchema": "{\"type\":\"object\",\"properties\":{\"input\":{\"type\":\"string\",\"description\":\"输入内容\"}},\"required\":[\"input\"]}",
  "version": "1.0.0"
}
```

**必填字段**：
- `skillId`：技能ID（唯一）
- `name`：技能名称
- `description`：技能描述
- `functionSchema`：Function Calling 的 JSON Schema（**重要**）

## ✅ 验证技能创建成功

创建技能后，可以通过以下方式验证：

### 1. 查询技能列表

```bash
GET http://localhost:8080/api/skills
```

### 2. 查询单个技能

```bash
GET http://localhost:8080/api/skills/test-skill
```

### 3. 在角色管理页面查看

1. 进入角色管理
2. 编辑某个角色
3. 切换到"技能管理"标签页
4. 应该能看到新创建的技能
