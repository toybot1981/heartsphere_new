# 资源类别更新完成报告

## 更新时间
2025-01-05

## 更新内容
根据剧本物品表（`system_era_items`）和剧本事件表（`system_era_events`）的中文名称，更新资源管理表（`system_resources`）中的类别。

## 匹配逻辑

### 1. 物品资源匹配
- 如果资源名称包含"（物品）"，去掉后缀后匹配 `system_era_items` 表的 `name` 字段
- 如果资源名称不包含后缀，直接匹配 `system_era_items` 表的 `name` 字段
- 匹配成功后，将资源类别更新为 `item`

### 2. 事件资源匹配
- 如果资源名称包含"（事件）"，去掉后缀后匹配 `system_era_events` 表的 `name` 字段
- 如果资源名称不包含后缀，且不匹配 `system_era_items`，则匹配 `system_era_events` 表的 `name` 字段
- 匹配成功后，将资源类别更新为 `event`

### 3. 匹配优先级
- 优先匹配物品（`item`）
- 如果资源名称包含"（物品）"，强制匹配为 `item`
- 如果资源名称包含"（事件）"，强制匹配为 `event`
- 如果资源名称不包含后缀，优先匹配 `item`，如果匹配不到再匹配 `event`

## 更新结果

- `scenario`: 9 个

### 更新后
- `item`: 338 个（修正了 4 个误分类为 event 的资源）

## 验证

执行以下 SQL 可以验证更新结果：

```sql
-- 检查类别分布
SELECT category, COUNT(*) as count
FROM system_resources
WHERE category IN ('item', 'event', 'scenario')
GROUP BY category;

-- 检查物品资源匹配情况
SELECT sr.id, sr.name, sr.category, sie.name as item_name
FROM system_resources sr
INNER JOIN system_era_items sie ON (
    (sr.name LIKE '%（物品）%' AND TRIM(REPLACE(REPLACE(sr.name, '（物品）', ''), ' ', '')) = TRIM(REPLACE(sie.name, ' ', '')))
    OR
    (sr.name NOT LIKE '%（物品）%' AND sr.name NOT LIKE '%（事件）%' AND TRIM(REPLACE(sr.name, ' ', '')) = TRIM(REPLACE(sie.name, ' ', '')))
)
WHERE sr.category = 'item'
LIMIT 10;

-- 检查事件资源匹配情况
SELECT sr.id, sr.name, sr.category, see.name as event_name
FROM system_resources sr
INNER JOIN system_era_events see ON (
    (sr.name LIKE '%（事件）%' AND TRIM(REPLACE(REPLACE(sr.name, '（事件）', ''), ' ', '')) = TRIM(REPLACE(see.name, ' ', '')))
    OR
    (sr.name NOT LIKE '%（物品）%' AND sr.name NOT LIKE '%（事件）%' 
     AND TRIM(REPLACE(sr.name, ' ', '')) = TRIM(REPLACE(see.name, ' ', ''))
     AND NOT EXISTS (
         SELECT 1 FROM system_era_items sie2 
         WHERE TRIM(REPLACE(sr.name, ' ', '')) = TRIM(REPLACE(sie2.name, ' ', ''))
     ))
)
WHERE sr.category = 'event'
LIMIT 10;
```
