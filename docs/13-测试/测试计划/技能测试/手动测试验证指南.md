## 三、关键检查点

### 3.1 浏览器控制台日志

**成功标识**（应该看到以下日志）：

```
[generateAIResponse] 获取到角色技能列表: {
  characterId: X,
  characterName: "时小光",
  skillsCount: 8,
  skills: [...]
}

[generateAIResponse] Function Call: {
  name: "time_audit",
  arguments: "..."
}

[generateAIResponse] 技能激活: {
  skillId: "time_audit",
  skillName: "时间审计"
}
```

**失败标识**（可能的问题）：

- `技能列表为空` → 角色未配置技能
- `Function Calling未触发` → AI未识别需要调用技能
- `技能激活失败` → 技能执行出错

### 3.2 AI回复检查

**成功标识**：

- 回复文本末尾包含："✨ 应用了 时间审计 技能"
- 技能标签使用青色渐变背景，有发光效果

**失败标识**：

- 没有技能名称显示
- 技能名称显示错误
- 回复内容与技能功能不相关

## 五、常见问题

### 5.1 技能未激活

**现象**：发送消息后，没有看到技能激活的日志或显示

**检查步骤**：
1. 检查浏览器控制台是否有错误
2. 检查角色是否配置了技能
3. 检查AI是否正确识别用户意图

**解决方案**：
- 如果角色未配置技能，需要先配置技能
- 如果AI未识别，可以尝试使用更明确的预设话术

### 5.2 Function Calling未触发

**现象**：没有看到 `[generateAIResponse] Function Call` 日志

**可能原因**：
- AI未识别需要调用技能
- 系统指令不够明确
- Function Definitions未正确加载

**解决方案**：
- 检查系统指令是否包含技能提示
- 检查技能列表是否正确加载

### 5.3 技能名称未显示

**现象**：Function Calling触发了，但AI回复中没有显示技能名称

**检查步骤**：
1. 检查 `createStreamHandler.ts` 是否正确传递技能信息
2. 检查 `RichTextRenderer.tsx` 是否正确渲染技能名称
