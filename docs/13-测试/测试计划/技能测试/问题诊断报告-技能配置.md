# 技能配置问题诊断报告

**问题发现时间**: 2026-01-10  
**问题描述**: 管理端显示角色已装备技能，但前端API返回技能列表为空

---

## 一、问题现象

### 1.1 管理端显示
- ✅ 角色"时小光"(ID: 358)已装备8个技能
- ✅ 所有技能状态为"已装备"、"系统"技能
- ✅ 技能包括：时间审计、任务分解、优先级矩阵、时间块规划等

### 1.2 前端API返回
- ❌ `/api/skills/character/358/available` 返回空数组
- ❌ 日志显示：`skillsCount: 0, skills: Array(0)`

---

## 二、问题根本原因

### 2.1 代码流程分析

**API调用链**：
1. 前端调用：`/api/skills/character/{characterId}/available`
2. 后端处理：`SkillController.getCharacterAvailableSkills()`
3. 获取技能：`skillRegistry.getCharacterSkills(characterId)` - 获取已装备技能
4. 转换为Function Definition：`skillRegistry.toFunctionDefinitions(skills)`

**关键过滤逻辑**（`SkillRegistry.toFunctionDefinition()`）：
```java
private FunctionDefinition toFunctionDefinition(SkillDefinition skill) {
    // 检查是否有 function_schema
    if (skill.getFunctionSchema() == null || skill.getFunctionSchema().isEmpty()) {
        log.warn("技能 {} 没有 function_schema，跳过", skill.getSkillId());
        return null;  // ← 这里返回null，会被过滤掉
    }
    // ... 解析function_schema
}
```

### 2.2 问题确认

**已装备的技能缺少 `function_schema`**：
- 管理端只检查技能是否"已装备"
- 但Function Calling需要技能有 `function_schema` 字段
- 如果 `function_schema` 为空，技能会被过滤掉，无法用于Function Calling

---

## 三、验证步骤

### 3.1 检查数据库

需要执行以下SQL查询，检查技能的 `function_schema` 字段：

```sql
-- 1. 查看角色已装备的技能
SELECT 
    csb.character_id,
    csb.skill_id,
    csb.is_enabled,
    sd.name AS skill_name,
    sd.function_schema IS NOT NULL AND sd.function_schema != '' AS has_function_schema,
    LENGTH(sd.function_schema) AS schema_length
FROM character_skill_binding csb
JOIN skill_definition sd ON csb.skill_id = sd.skill_id
WHERE csb.character_id = 358
  AND csb.is_enabled = TRUE
ORDER BY csb.priority DESC;

-- 2. 检查哪些技能缺少 function_schema
SELECT 
    skill_id,
    name,
    function_schema IS NULL OR function_schema = '' AS missing_schema
FROM skill_definition
WHERE skill_id IN (
    SELECT skill_id 
    FROM character_skill_binding 
    WHERE character_id = 358 AND is_enabled = TRUE
);
```

### 3.2 检查后端日志

查看后端日志中是否有以下警告：
```
技能 {skillId} 没有 function_schema，跳过
```

## 四、解决方案

### 4.1 立即修复

**为已装备的技能添加 `function_schema`**：

1. **检查技能定义**：
   - 确认技能表中是否存在这些技能
   - 检查 `function_schema` 字段是否有值

2. **修复技能定义**：
   - 如果技能缺少 `function_schema`，需要添加
   - `function_schema` 应该是符合JSON Schema格式的字符串
   - 格式示例：
     ```json
     {
       "type": "object",
       "properties": {
         "input": {
           "type": "string",
           "description": "用户输入的内容"
         }
       },
       "required": ["input"]
     }
     ```

3. **验证修复**：
   - 重新调用 `/api/skills/character/358/available`
   - 确认返回的技能列表不为空
   - 重新测试技能激活功能

### 4.2 预防措施

1. **技能创建/更新校验**：
   - 在技能创建/更新时，验证 `function_schema` 的有效性
   - 对于需要Function Calling的技能，强制要求 `function_schema`

2. **装备技能时的检查**：
   - 在装备技能时，检查技能是否有 `function_schema`
   - 如果没有，给出警告或提示

3. **管理端显示优化**：
   - 在管理端显示技能时，标识哪些技能有 `function_schema`
   - 区分"已装备"和"可用于Function Calling"的状态
