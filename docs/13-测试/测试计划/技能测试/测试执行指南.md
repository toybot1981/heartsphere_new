## 一、测试前准备

### 1.1 环境准备

1. **确保后端服务运行**：
   ```bash
   # 检查后端服务
   curl http://localhost:8081/api/health
   ```

2. **确保前端应用运行**：
   ```bash
   # 检查前端应用
   curl http://localhost:3000
   ```

3. **获取认证Token**：
   - 登录系统获取Token
   - 或者使用测试账号的Token

### 1.2 获取角色ID

测试需要6个角色的实际ID，可以通过以下方式获取：

#### 方式1：通过数据库查询

```sql
-- 查询6个角色的ID
SELECT id, name FROM characters 
WHERE name IN ('时小光', '康小健', '学小知', '心小暖', '心小安', '暖小阳')
AND user_id = YOUR_USER_ID;
```

#### 方式2：通过API查询

```bash
# 获取角色列表（需要Token）
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:8081/api/characters
```

#### 方式3：通过前端界面

1. 登录系统
2. 进入角色管理页面
3. 找到对应的角色，记录ID

### 1.3 更新测试用例数据

编辑 `scripts/test-skills/data/test-cases.json`，将 `REPLACE_WITH_ACTUAL_ID` 替换为实际的角色ID：

```json
{
  "characters": [
    {
      "name": "时小光",
      "id": "实际的角色ID",
      ...
    }
  ]
}
```

## 二、执行测试

### 2.1 方式1：自动化API测试（推荐）

#### 步骤1：设置环境变量

```bash
export API_BASE_URL=http://localhost:8081
export FRONTEND_URL=http://localhost:3000
export TEST_USER_TOKEN=your_token_here
```

#### 步骤2：运行测试脚本

```bash
cd /Users/admin/Workspace/heartsphere_new
python scripts/test-skills/test-skill-api.py
```

#### 步骤3：查看测试结果

测试结果会保存在 `scripts/test-skills/data/results/results-YYYY-MM-DD.json`

### 2.2 方式2：手动测试（更真实，但较慢）

#### 步骤1：打开前端应用

访问 `http://localhost:3000`

#### 步骤2：选择角色

选择一个要测试的角色（如"时小光"）

#### 步骤3：执行测试用例

按照测试用例文档，逐一测试每个技能：

1. **预设话术测试**：
   - 点击预设话术按钮（如果有）
   - 或手动输入预设话术
   - 观察AI回复
   - 检查是否显示"✨ 应用了 {skillName} 技能"

2. **自然对话测试**：
   - 输入自然语言描述
   - 观察AI回复
   - 检查技能是否被激活

#### 步骤4：记录测试结果

使用测试数据收集表格记录：
- 激活状态（成功/失败）
- Function Calling触发情况
- 响应时间
- 评分（相关性、完整性、用户体验）

## 三、测试数据收集

### 3.1 使用测试记录表

参考 `测试计划文档` 中的测试记录表格式，记录每个测试用例的结果。

### 3.2 关键检查点

每个测试用例需要检查：

1. **技能激活**：
   - ✅ AI回复中是否包含 "✨ 应用了 {skillName} 技能"
   - ✅ 控制台日志中是否有 Function Calling 记录

2. **Function Calling**：
   - ✅ 浏览器控制台是否有 `[generateAIResponse] Function Call` 日志
   - ✅ 是否有 `[generateAIResponse] 技能激活` 日志

3. **响应时间**：
   - ✅ 从发送消息到收到回复的时间
   - ✅ 是否在合理范围内（≤ 5秒为佳，≤ 10秒可接受）

4. **执行质量**：
   - ✅ 技能执行结果是否相关（1-5分）
   - ✅ 技能执行结果是否完整（1-5分）
   - ✅ 用户体验是否流畅（1-5分）

## 四、常见问题

### 4.1 技能未激活

**可能原因**：
- 技能未配置到角色
- Function Calling未触发
- AI未识别用户意图

**检查方法**：
1. 检查浏览器控制台日志
2. 检查后端日志
3. 验证技能是否已绑定到角色

### 4.2 Function Calling未触发

**可能原因**：
- 系统指令不明确
- AI模型不支持Function Calling
- 技能定义有问题

**检查方法**：
1. 检查 `generateAIResponse.ts` 中的系统指令
2. 检查技能列表是否加载
3. 检查Function Definitions是否正确

### 4.3 响应时间过长

**可能原因**：
- AI服务响应慢
- 网络延迟
- 服务器负载高

**解决方法**：
- 检查AI服务状态
- 检查网络连接
- 考虑使用更快的AI模型
