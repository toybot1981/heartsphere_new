## 四、问题排查指南

如果技能未激活，检查以下项：

### 4.1 配置检查

```sql
-- 检查技能绑定
SELECT * FROM character_skill_bindings WHERE character_id = 358;

-- 检查技能定义
SELECT skill_id, name, 
       (function_schema IS NOT NULL AND function_schema != '') AS has_schema
FROM skill_definitions 
WHERE skill_id IN (
    SELECT skill_id FROM character_skill_bindings WHERE character_id = 358
);
```

### 4.2 API检查

```bash
# 检查技能API
curl -H "Authorization: Bearer $TOKEN" \
  http://localhost:8081/api/skills/character/358/all
```

### 4.3 日志检查

```bash
# 检查技能相关日志
tail -f backend/logs/application.log | grep -E "技能|skill|Function Call"
```
