# 插件管理功能测试指南

## 一、测试环境准备

### 1.1 数据库准备

确保数据库迁移脚本已执行：
- `V20250104__create_plugin_system_tables.sql` - 创建插件系统表
- `V20250104__insert_sample_plugins.sql` - 插入示例插件数据

### 1.2 后端服务启动

```bash
cd backend
mvn spring-boot:run
```

或使用IDE启动 `HeartSphereApplication`

### 1.3 前端服务启动

```bash
cd frontend
npm run dev
```

## 二、API测试

### 2.1 获取插件列表

**请求：**
```bash
curl -X GET "http://localhost:8081/api/admin/plugins?page=0&size=20" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```

**预期响应：**
```json
{
  "plugins": [
    {
      "id": 1,
      "pluginId": "photo-album",
      "name": "家庭温馨相册",
      "version": "1.0.0",
      "status": "ACTIVE",
      ...
    }
  ],
  "total": 4,
  "page": 0,
  "size": 20
}
```

### 2.2 获取插件详情

**请求：**
```bash
curl -X GET "http://localhost:8081/api/admin/plugins/photo-album" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```

**预期响应：**
```json
{
  "id": 1,
  "pluginId": "photo-album",
  "name": "家庭温馨相册",
  "version": "1.0.0",
  "description": "记录家庭美好时刻，支持相册管理和照片上传",
  "status": "ACTIVE",
  "permissions": ["FILE_UPLOAD", "DATA_STORAGE"],
  ...
}
```

### 2.3 启用插件

**请求：**
```bash
curl -X POST "http://localhost:8081/api/admin/plugins/journal/enable" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```

**预期响应：** HTTP 200 OK

### 2.4 禁用插件

**请求：**
```bash
curl -X POST "http://localhost:8081/api/admin/plugins/photo-album/disable?force=false" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```

**预期响应：** HTTP 200 OK

### 2.5 更新插件配置

**请求：**
```bash
curl -X PUT "http://localhost:8081/api/admin/plugins/photo-album/config" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "config": {
      "maxAlbums": 200,
      "maxPhotosPerAlbum": 2000
    }
  }'
```

**预期响应：** HTTP 200 OK

## 三、前端界面测试

### 3.1 访问插件管理页面

1. 登录管理后台
2. 在侧边栏点击"插件管理"（🔌图标）
3. 应该能看到插件列表页面

### 3.2 测试搜索功能

1. 在搜索框输入"相册"
2. 应该只显示包含"相册"的插件
3. 清空搜索框，应该显示所有插件

### 3.3 测试筛选功能

1. 选择分类"生活方式"
2. 应该只显示该分类的插件
3. 选择状态"已启用"
4. 应该只显示已启用的插件

### 3.4 测试启用/禁用功能

1. 找到一个已禁用的插件（如"日记插件"）
2. 点击"启用"按钮
3. 插件状态应该变为"已启用"
4. 点击"禁用"按钮
5. 确认对话框应该弹出
6. 确认后，插件状态应该变为"已禁用"

### 3.5 测试详情查看

1. 点击任意插件的"详情"按钮
2. 应该弹出详情弹窗
3. 显示插件的完整信息（ID、版本、描述、权限等）
4. 点击关闭按钮，弹窗应该关闭

### 3.6 测试分页功能

1. 如果插件数量超过20个，应该显示分页控件
2. 点击"下一页"，应该加载下一页数据
3. 点击"上一页"，应该返回上一页

## 五、常见问题排查

### 5.1 插件列表为空

**可能原因：**
- 数据库迁移脚本未执行
- 示例数据未插入

**解决方法：**
```bash
# 检查迁移脚本
ls -la backend/src/main/resources/db/migration/V20250104*.sql

# 手动执行SQL（如果需要）
mysql -u root -p heartsphere < backend/src/main/resources/db/migration/V20250104__insert_sample_plugins.sql
```

### 5.2 API返回401未授权

**可能原因：**
- 管理员token无效或过期
- 未在请求头中携带Authorization

**解决方法：**
- 重新登录管理后台获取新token
- 检查请求头格式：`Authorization: Bearer <token>`

### 5.3 前端页面无法访问

**可能原因：**
- 前端服务未启动
- 路由配置错误

**解决方法：**
```bash
# 检查前端服务
lsof -ti:3000

# 重启前端服务
cd frontend
npm run dev
```

### 5.4 启用/禁用功能不生效

**可能原因：**
- 后端服务未重启
- 数据库事务未提交

**解决方法：**
- 重启后端服务
- 检查后端日志是否有错误
