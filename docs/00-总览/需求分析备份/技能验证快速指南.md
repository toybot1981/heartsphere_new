# 技能验证快速指南

## 🚀 快速验证步骤

### 方法一：通过浏览器验证（最简单）

1. **打开管理后台**
   - 访问：`http://localhost:3000`（或你的前端地址）
   - 登录管理账号

2. **进入角色管理**
   - 点击左侧菜单"角色管理"
   - 找到任意一个角色
   - 点击"编辑"按钮

3. **切换到技能管理标签页**
   - 在编辑页面，点击"技能管理"标签页
   - 应该能看到技能列表

4. **查找测试技能**
   - 在技能列表中查找"测试技能"
   - 或者使用搜索框搜索"测试"

---

### 方法二：通过 API 验证（需要认证）

#### 1. 获取认证 Token

```bash
# 登录获取 token（需要替换为实际的用户名和密码）
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "password"
  }'
```

#### 2. 使用 Token 查询技能

```bash
# 替换 YOUR_TOKEN 为实际的 token
TOKEN="YOUR_TOKEN"

# 获取所有技能
curl -X GET http://localhost:8080/api/skills \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN"

# 获取单个技能
curl -X GET http://localhost:8080/api/skills/test-skill \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN"
```

---

### 方法三：直接查询数据库

```sql
-- 连接到数据库
mysql -u username -p database_name

-- 查询测试技能
SELECT 
    skill_id,
    name,
    description,
    category,
    skill_type,
    execution_type,
    version,
    is_system_skill,
    created_at
FROM skill_definitions 
WHERE skill_id = 'test-skill';

-- 查询所有技能
SELECT skill_id, name, category, skill_type 
FROM skill_definitions 
ORDER BY created_at DESC;
```

**预期结果**：
- 应该能看到 `test-skill` 技能
- 名称：测试技能
- 分类：UTILITY
- 技能类型：ACTIVE

## 🐛 常见问题

### 问题 1：技能未出现在列表中

**可能原因**：
1. 迁移脚本未执行
2. 后端服务未重启
3. 技能未正确创建

**解决方法**：
1. 检查数据库是否有技能记录
2. 重启后端服务（迁移脚本会自动执行）
3. 检查后端日志是否有错误

### 问题 2：API 返回 401 未授权

**解决方法**：
- 确保已登录并获取有效的 token
- 检查 token 是否过期
- 验证 token 格式：`Bearer YOUR_TOKEN`

### 问题 3：前端显示"没有找到技能"

**可能原因**：
- API 请求失败
- 数据格式不匹配
- 前端过滤条件

**解决方法**：
1. 打开浏览器开发者工具（F12）
2. 查看 Console 标签页的错误信息
3. 查看 Network 标签页的 API 请求
4. 检查 API 响应数据
