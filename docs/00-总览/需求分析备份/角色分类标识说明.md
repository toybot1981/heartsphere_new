# 角色分类标识说明

**文档版本**: V1.0  
**创建日期**: 2025-01-XX  
**项目名称**: 数字生命体交互系统（HeartSphere）

---

## 一、分类标识概述

为了更好地区分不同类型的数字人角色，我们为"日常生活助手"时代表下的6个角色添加了**"生活助手"**分类标识。

### 1.1 标识名称
**"生活助手"** (Life Assistant)

### 1.2 标识含义
- **定位**：专注于解决实际生活问题，提供专业指导和情感陪伴的实用型角色
- **特点**：专业、实用、亲和、陪伴
- **区别**：与剧情角色、历史角色、娱乐角色等区分

---

## 二、角色分类体系

### 2.1 现有角色分类

| 分类 | 说明 | 示例角色 | 特点 |
|------|------|---------|------|
| **剧情角色** | 参与故事剧情，有完整故事线 | 林樱、沈凯（大学场景） | 有剧情、有成长、有互动 |
| **历史角色** | 基于历史人物，还原历史背景 | 苏格拉底、拉美西斯二世 | 历史知识、时代背景 |
| **专业角色** | 提供专业服务 | 安然（心理治疗师） | 专业、正式、服务导向 |
| **生活助手** | 解决实际生活问题 | 时小光、康小健等 | 实用、亲和、陪伴 |

### 2.2 "生活助手"角色特点

1. **实用性**：专注于解决真实的生活问题
2. **专业性**：具备相关领域的专业知识和技能
3. **亲和力**：像朋友一样陪伴，而非高高在上的导师
4. **陪伴性**：不仅提供解决方案，还提供情感支持

## 三、标识应用方式

### 3.1 在时代表中标识

**时代表名称**：日常生活助手

**时代表描述**：
```
【生活助手型角色】提供日常生活帮助的专业数字人角色，包括时间管理、健康生活、学习成长、心理健康、情感陪伴等领域。这些角色专注于解决实际生活问题，提供专业指导和情感陪伴。
```

## 五、数据库查询示例

### 5.1 查询所有"生活助手"角色

```sql
-- 方法1：通过时代表查询
SELECT * FROM system_characters 
WHERE system_era_id = (
  SELECT id FROM system_eras WHERE name = '日常生活助手' LIMIT 1
);

-- 方法2：通过标签查询
SELECT * FROM system_characters 
WHERE tags LIKE '%生活助手%';

-- 方法3：通过描述查询
SELECT * FROM system_characters 
WHERE description LIKE '%【生活助手】%';
```

### 5.2 统计各类型角色数量

```sql
SELECT 
  CASE 
    WHEN tags LIKE '%生活助手%' THEN '生活助手'
    WHEN tags LIKE '%历史%' THEN '历史角色'
    WHEN system_era_id IN (
      SELECT id FROM system_eras WHERE name IN ('大学场景', '赛博都市')
    ) THEN '剧情角色'
    ELSE '其他'
  END as character_type,
  COUNT(*) as count
FROM system_characters
GROUP BY character_type;
```
