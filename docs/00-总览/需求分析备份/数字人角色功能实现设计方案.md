# 数字人角色功能实现设计方案

**文档版本**: V1.0  
**编写日期**: 2026-01-06  
**项目名称**: 心域数字人角色系统  
**设计目标**: 实现6个日常生活助手角色的完整功能

---

## 一、功能概述

### 1.1 功能定位

数字人角色系统是心域平台的核心功能之一，通过AI驱动的数字人角色，为用户提供：
- **专业指导**：时间管理、健康生活、学习成长等专业领域的指导
- **情感陪伴**：情绪支持、心理健康维护、日常陪伴
- **个性化服务**：基于用户需求的定制化建议和帮助

### 1.2 角色分类

**生活助手型角色**（本次设计重点）：
1. 时小光 - 时间管理导师
2. 康小健 - 健康生活顾问
3. 学小知 - 学习成长导师
4. 心小暖 - 情绪陪伴师
5. 心小安 - 心理健康守护者
6. 暖小阳 - 情感陪伴伙伴

### 2.3 数据追踪系统

#### 2.3.1 数据模型设计

**时间管理数据**（时小光）：
```sql
CREATE TABLE time_management_data (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    date DATE NOT NULL,
    task_name VARCHAR(255),
    planned_time INT, -- 计划时间（分钟）
    actual_time INT, -- 实际时间（分钟）
    status VARCHAR(50), -- 完成状态
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user_date (user_id, date)
);
```

**健康数据**（康小健）：
```sql
CREATE TABLE health_data (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    date DATE NOT NULL,
    data_type VARCHAR(50), -- 体重、步数、睡眠时长等
    value DECIMAL(10,2),
    unit VARCHAR(20),
    notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user_date_type (user_id, date, data_type)
);
```

**学习数据**（学小知）：
```sql
CREATE TABLE learning_data (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    subject VARCHAR(255), -- 学习科目
    study_time INT, -- 学习时长（分钟）
    progress DECIMAL(5,2), -- 进度百分比
    notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user_date (user_id, created_at)
);
```

## 六、技术难点和解决方案

### 6.1 AI回复质量

**难点**：确保角色回复符合角色设定，保持一致性

**解决方案**：
- 精心设计 system_instruction
- 使用角色记忆系统
- 实现回复质量评估和优化

### 6.2 技能调用准确性

**难点**：准确识别用户意图，调用正确的技能

**解决方案**：
- 使用Function Calling机制
- 实现意图识别算法
- 提供技能列表和说明

### 6.3 数据隐私和安全

**难点**：保护用户数据隐私

**解决方案**：
- 数据加密存储
- 访问权限控制
- 符合隐私法规
