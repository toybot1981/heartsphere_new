## 🎯 集成方式

### 标签页结构

```
编辑角色页面
├── 标签页导航
│   ├── 基本信息 (默认)
│   └── 技能管理
├── 基本信息标签页
│   └── 原有的角色编辑表单
└── 技能管理标签页
    └── CharacterSkillManagement 组件
```

### 使用流程

1. **进入编辑模式**
   - 在角色列表点击"编辑"按钮
   - 进入角色编辑页面

2. **切换到技能管理**
   - 点击"技能管理"标签页
   - 显示技能管理界面

3. **管理技能**
   - 浏览可用技能
   - 装备/卸载技能
   - 配置技能选项

4. **返回基本信息**
   - 点击"基本信息"标签页
   - 继续编辑角色信息
