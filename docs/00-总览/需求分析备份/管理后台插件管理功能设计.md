# 管理后台插件管理功能设计

**目标：为管理后台提供完整的插件管理功能，包括插件列表、启用/禁用、配置管理等**

---

## 一、功能概述

### 1.1 功能定位

插件管理是管理后台的核心功能模块，允许管理员：
- 查看系统中所有可用的插件
- 管理插件的启用/禁用状态
- 配置插件参数
- 查看插件使用统计
- 管理插件版本和更新

### 1.2 功能范围

**核心功能：**
1. 插件列表管理
2. 插件详情查看
3. 插件启用/禁用
4. 插件配置管理
5. 插件使用统计
6. 插件版本管理

**辅助功能：**
1. 插件搜索和筛选
2. 插件分类管理
3. 插件审核（如果支持用户插件）
4. 插件日志查看

### 2.3 插件启用/禁用

#### 2.3.1 功能描述

管理员可以启用或禁用插件。禁用的插件将无法被用户使用。

#### 2.3.2 操作流程

**启用插件：**
```
1. 管理员点击"启用"按钮
   ↓
2. 系统检查插件依赖和兼容性
   ↓
3. 如果检查通过，显示确认对话框
   ↓
4. 管理员确认
   ↓
5. 系统更新插件状态为"已启用"
   ↓
6. 插件变为可用状态
```

**禁用插件：**
```
1. 管理员点击"禁用"按钮
   ↓
2. 显示确认对话框（提示影响）
   ↓
3. 管理员确认
   ↓
4. 系统检查是否有用户正在使用
   ↓
5. 如果无用户使用，直接禁用
   ↓
6. 如果有用户使用，提示是否强制禁用
   ↓
7. 系统更新插件状态为"已禁用"
   ↓
8. 插件变为不可用状态
```

#### 2.3.3 确认对话框

**禁用确认对话框：**

## 三、API接口设计

### 3.1 插件管理API

#### 3.1.1 获取插件列表

**GET /api/admin/plugins**

**请求参数：**
- `keyword` (string, optional): 搜索关键词
- `category` (string, optional): 分类筛选
- `status` (string, optional): 状态筛选（ACTIVE, INACTIVE, ALL）
- `type` (string, optional): 类型筛选（SYSTEM, USER, ALL）
- `page` (int, default: 0): 页码
- `size` (int, default: 20): 每页数量
- `sort` (string, optional): 排序（name, usage_count, rating, created_at）

**响应数据：**
```json
{
  "plugins": [
    {
      "pluginId": "photo-album",
      "name": "家庭温馨相册",
      "version": "1.0.0",
      "description": "记录家庭美好时刻",
      "iconUrl": "...",
      "category": "lifestyle",
      "status": "ACTIVE",
      "usageCount": 1234,
      "rating": 4.8,
      "userCount": 456,
      "createdAt": "2025-01-01T00:00:00"
    }
  ],
  "total": 10,
  "page": 0,
  "size": 20
}
```

#### 3.1.2 获取插件详情

**GET /api/admin/plugins/{pluginId}**

**响应数据：**
```json
{
  "pluginId": "photo-album",
  "name": "家庭温馨相册",
  "version": "1.0.0",
  "description": "记录家庭美好时刻",
  "iconUrl": "...",
  "category": "lifestyle",
  "status": "ACTIVE",
  "author": "系统",
  "permissions": ["FILE_UPLOAD", "DATA_STORAGE"],
  "dependencies": [],
  "minSystemVersion": "1.0.0",
  "configSchema": { /* JSON Schema */ },
  "defaultConfig": { /* 默认配置 */ },
  "usageCount": 1234,
  "userCount": 456,
  "rating": 4.8,
  "createdAt": "2025-01-01T00:00:00",
  "updatedAt": "2025-01-04T00:00:00"
}
```

#### 3.1.3 启用插件

**POST /api/admin/plugins/{pluginId}/enable**

**响应数据：**
```json
{
  "success": true,
  "message": "插件已启用"
}
```

#### 3.1.4 禁用插件

**POST /api/admin/plugins/{pluginId}/disable**

**请求体（可选）：**
```json
{
  "force": false,  // 是否强制禁用（即使有用户在使用）
  "reason": "维护中"  // 禁用原因
}
```

**响应数据：**
```json
{
  "success": true,
  "message": "插件已禁用",
  "affectedUsers": 456  // 受影响的用户数（如果force=false）
}
```

#### 3.1.5 更新插件配置

**PUT /api/admin/plugins/{pluginId}/config**

**请求体：**
```json
{
  "maxAlbums": 100,
  "maxPhotosPerAlbum": 1000,
  "maxPhotoSize": 10,
  "allowedFormats": ["jpg", "png", "webp"],
  "advancedConfig": {
    "thumbnail": {
      "width": 300,
      "height": 300
    }
  }
}
```

**响应数据：**
```json
{
  "success": true,
  "message": "配置已更新"
}
```

#### 3.1.6 获取插件统计

**GET /api/admin/plugins/{pluginId}/statistics**

**请求参数：**
- `startDate` (date, optional): 开始日期
- `endDate` (date, optional): 结束日期
- `granularity` (string, optional): 粒度（day, week, month）

**响应数据：**
```json
{
  "overview": {
    "totalUsage": 1234,
    "activeUsers": 456,
    "totalAlbums": 789,
    "totalPhotos": 12345
  },
  "trend": [
    {
      "date": "2025-01-04",
      "usageCount": 45,
      "newUsers": 12,
      "newAlbums": 23
    }
  ],
  "userDistribution": { /* 用户分布数据 */ }
}
```

#### 3.1.7 获取插件日志

**GET /api/admin/plugins/{pluginId}/logs**

**请求参数：**
- `level` (string, optional): 日志级别（INFO, WARN, ERROR, ALL）
- `startTime` (datetime, optional): 开始时间
- `endTime` (datetime, optional): 结束时间
- `keyword` (string, optional): 搜索关键词
- `page` (int, default: 0): 页码
- `size` (int, default: 100): 每页数量

**响应数据：**
```json
{
  "logs": [
    {
      "timestamp": "2025-01-04T10:30:25",
      "level": "INFO",
      "message": "插件初始化成功",
      "details": {}
    }
  ],
  "total": 1000,
  "page": 0,
  "size": 100
}
```
