## 🔍 测试前准备

### 1. 环境要求

- Flyway 已配置
- 数据库连接正常

### 2. 备份数据库
```bash

mysqldump -u username -p database_name > backup_$(date +%Y%m%d_%H%M%S).sql
```

### 3. 检查现有表结构
```sql
-- 检查 skill_definitions 表是否存在
SHOW TABLES LIKE 'skill_definitions';

-- 查看现有表结构

```

## 🐛 常见问题

### 问题 1：字段已存在错误
**错误信息**：`Duplicate column name 'function_schema'`

**解决方案**：
- 检查字段是否已存在
- 如果已存在，可以跳过该 ALTER TABLE 语句
- 或者先删除字段再添加

### 问题 2：表已存在错误
**错误信息**：`Table 'skill_executions' already exists`

**解决方案**：
- 检查表是否已存在
- 如果已存在，可以删除后重新创建
- 或者使用 `CREATE TABLE IF NOT EXISTS`

### 问题 3：视图创建失败
**错误信息**：`View 'v_character_equipped_skills' already exists`

**解决方案**：
- 先删除视图：`DROP VIEW IF EXISTS v_character_equipped_skills;`
- 然后重新创建

### 问题 4：索引创建失败
**错误信息**：`Duplicate key name 'idx_execution_type'`

**解决方案**：
- 检查索引是否已存在
- 如果已存在，可以跳过
- 或者先删除索引再创建

## 🔄 回滚方案

如果迁移失败，需要回滚：

```sql
-- 删除新创建的表
DROP TABLE IF EXISTS skill_conflicts;
DROP TABLE IF EXISTS skill_prerequisites;
DROP TABLE IF EXISTS skill_executions;
DROP TABLE IF EXISTS character_skill_bindings;

-- 删除视图
DROP VIEW IF EXISTS v_skill_usage_statistics;
DROP VIEW IF EXISTS v_character_equipped_skills;

-- 删除索引
DROP INDEX IF EXISTS idx_execution_type ON skill_definitions;

-- 删除新增字段（谨慎操作）
ALTER TABLE skill_definitions 
DROP COLUMN IF EXISTS is_system_skill,
DROP COLUMN IF EXISTS author,
DROP COLUMN IF EXISTS version,
DROP COLUMN IF EXISTS max_usage_per_day,
DROP COLUMN IF EXISTS required_permissions,
DROP COLUMN IF EXISTS auto_trigger_keywords,
DROP COLUMN IF EXISTS execution_config,
DROP COLUMN IF EXISTS execution_type,
DROP COLUMN IF EXISTS function_schema;
```
