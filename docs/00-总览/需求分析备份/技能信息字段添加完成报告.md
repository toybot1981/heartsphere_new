## 二、字段说明

### 字段定义

| 字段名 | 类型 | 长度 | 说明 | 是否必填 |
|--------|------|------|------|----------|
| skillId | String | 100 | 技能ID，唯一标识一个技能 | 否 |
| skillName | String | 200 | 技能名称，用于前端显示 | 否 |

### 使用场景

1. **技能触发时**: 当角色在对话中触发技能时，系统会设置这两个字段
2. **前端显示**: 前端根据 `skillName` 在消息底部显示 `（使用技能：技能名称）`
3. **数据持久化**: `ConversationMessage` 实体类支持将技能信息保存到数据库

## 四、下一步工作

### 需要在服务层实现的功能

1. **技能执行后设置字段**
   - 在 `MentisAgentServiceImpl.processMessage()` 中，当技能执行后，需要：
     ```java
     if (skillResult != null && skillResult.isSuccess()) {
         SkillDefinition skill = skillDefinitionRepository
             .findBySkillId(skillResult.getSkillId())
             .orElse(null);
         
         if (skill != null) {
             response.setSkillId(skill.getSkillId());
             response.setSkillName(skill.getName());
         }
     }
     ```

2. **对话历史消息映射**
   - 在构建 `MentisMessageDTO` 时，需要从 `ConversationMessage` 实体中映射技能信息：
     ```java
     MentisMessageDTO dto = new MentisMessageDTO();
     // ... 其他字段映射 ...
     dto.setSkillId(message.getSkillId());
     dto.setSkillName(message.getSkillName());
     ```

3. **保存技能信息到数据库**
   - 在 `ConversationService.sendMessage()` 中，当角色消息包含技能信息时：
     ```java
     if (skillId != null && skillName != null) {
         message.setSkillId(skillId);
         message.setSkillName(skillName);
     }
     ```

## 六、注意事项

1. **字段可选性**: 所有技能信息字段都是可选的（nullable），因为不是所有消息都会触发技能
2. **数据一致性**: 确保 `skillId` 和 `skillName` 的一致性，如果设置了 `skillId`，应该同时设置 `skillName`
3. **性能考虑**: 技能信息字段较小，不会对性能造成明显影响
4. **向后兼容**: 由于字段是可选的，不会影响现有功能
