**文件路径**: `frontend/components/screens/CharacterSelectionScreen.tsx`

**修改内容**:
- 添加了角色类型筛选功能
- 筛选选项：全部、生活助手
- 显示筛选后的角色数量
- 使用`filteredCharacters`替代`sceneCharacters`进行渲染

**新增功能**:
```tsx
// 筛选状态
const [characterTypeFilter, setCharacterTypeFilter] = React.useState<string>('all');

// 筛选后的角色列表
const filteredCharacters = React.useMemo(() => {
  if (characterTypeFilter === 'all') {
    return sceneCharacters;
  }
  if (characterTypeFilter === '生活助手') {
    return sceneCharacters.filter(char => char.tags && char.tags.includes('生活助手'));
  }
  return sceneCharacters;
}, [sceneCharacters, characterTypeFilter]);
```

## 三、功能说明

### 3.1 角色卡片徽章

**显示位置**: 角色卡片底部，角色定位标签旁边

**显示条件**: 角色的`tags`数组包含`'生活助手'`

**样式特点**:
- 蓝色主题（#3b82f6）
- 半透明背景
- 圆角设计
- 与角色主题色区分

### 3.2 筛选功能

**位置**: 角色选择页面，场景名称下方

**功能**:
- 全部：显示所有角色
- 生活助手：只显示"生活助手"类型的角色
- 显示筛选后的角色数量

**使用方式**:
1. 点击"全部"按钮显示所有角色
2. 点击"生活助手"按钮只显示生活助手角色
3. 筛选结果实时更新

### 3.3 角色详情页类型显示

**显示位置**: 对话窗口头部，角色名称旁边

**显示条件**: 角色的`tags`数组包含`'生活助手'`

**样式特点**:
- 蓝色主题
- 小尺寸徽章
- 与"已连接"状态标识并列显示

## 五、数据要求

### 5.1 Character类型

角色的`tags`字段必须是数组格式，包含`'生活助手'`：

```typescript
character: {
  tags: ['生活助手', '时间管理', '效率提升', ...]
}
```

### 5.2 QuickConnectCharacter类型

角色的`tags`字段可以是字符串（逗号分隔）或数组：

```typescript
// 字符串格式
character: {
  tags: '生活助手,时间管理,效率提升'
}

// 数组格式
character: {
  tags: ['生活助手', '时间管理', '效率提升']
}
```
