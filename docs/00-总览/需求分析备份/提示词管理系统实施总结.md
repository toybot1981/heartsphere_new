## 二、API接口

### 2.1 模板管理
```
GET    /api/admin/prompts/templates          # 获取模板列表
GET    /api/admin/prompts/templates/{id}     # 获取模板详情
POST   /api/admin/prompts/templates          # 创建模板
PUT    /api/admin/prompts/templates/{id}     # 更新模板
DELETE /api/admin/prompts/templates/{id}      # 删除模板
POST   /api/admin/prompts/templates/{id}/copy # 复制模板
```

### 2.2 模板渲染
```
POST   /api/admin/prompts/templates/{id}/render   # 渲染模板
GET    /api/admin/prompts/templates/{id}/preview  # 预览模板
```

### 2.3 AI生成
```
POST   /api/admin/prompts/templates/{id}/generate # AI生成提示词
```

### 2.4 分类管理
```
GET    /api/admin/prompts/categories         # 获取分类列表
POST   /api/admin/prompts/categories         # 创建分类
PUT    /api/admin/prompts/categories/{id}    # 更新分类
DELETE /api/admin/prompts/categories/{id}    # 删除分类
```

## 三、模板语法

### 3.1 变量占位符
```
{{variableName}}
```

### 3.2 默认值
```
{{variableName|defaultValue}}
```

### 3.3 示例
```
系统提示词：
你是一个{{role}}，请分析用户的消息：{{userMessage}}

用户提示词：
文本内容：{{text}}
{{#if hasContext}}
上下文信息：{{context}}
{{/if}}
```

## 四、使用示例

### 4.1 创建模板
```json
{
  "name": "角色生成模板",
  "categoryCode": "character",
  "description": "用于生成角色的提示词模板",
  "systemPrompt": "你是一个创意写作助手。请为名为\"{{eraName}}\"的世界/时代创建一个完整的角色档案。",
  "userPrompt": "角色概念：\"{{characterConcept}}\"",
  "variables": {
    "eraName": {
      "type": "string",
      "required": true,
      "description": "时代名称"
    },
    "characterConcept": {
      "type": "string",
      "required": true,
      "description": "角色概念"
    }
  },
  "exampleData": {
    "eraName": "现代都市",
    "characterConcept": "一个温柔的程序员"
  }
}
```

### 4.2 渲染模板
```json
{
  "templateId": 1,
  "variables": {
    "eraName": "现代都市",
    "characterConcept": "一个温柔的程序员"
  }
}
```

### 4.3 AI生成提示词
```json
{
  "templateId": 1,
  "variables": {
    "eraName": "现代都市",
    "characterConcept": "一个温柔的程序员"
  },
  "context": "用户希望创建一个温暖的角色"
}
```
