## 🎯 技能功能

### crisis-intervention 技能

**功能**：
1. **评估危机风险**（assess）
   - 根据症状和情况描述评估风险等级
   - 计算风险评分
   - 生成评估报告

2. **制定干预方案**（plan）
   - 根据风险等级生成干预措施
   - 包含立即行动、短期行动、长期行动
   - 提供联系方式和监测计划

3. **获取应急指导**（guide）
   - 根据风险等级提供应对步骤
   - 包含安全措施和就医准备

4. **查看危机资源**（resources）
   - 急救电话
   - 心理热线
   - 医院信息
   - 在线资源
   - 自助工具
