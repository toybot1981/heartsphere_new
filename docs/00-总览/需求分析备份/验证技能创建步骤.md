# 验证技能创建步骤

## 🔍 验证步骤

### 步骤 1：检查后端服务是否运行

```bash
# 检查后端进程
ps aux | grep -i "spring-boot\|java.*heartsphere" | grep -v grep

# 或者检查端口
lsof -i :8080
```

**如果后端未运行**：
```bash
cd backend
mvn spring-boot:run
```

---

### 步骤 2：验证数据库迁移是否执行

#### 方式一：检查 Flyway 迁移记录

```sql
-- 连接到数据库
mysql -u username -p database_name

-- 查看 Flyway 迁移记录
SELECT * FROM flyway_schema_history 
WHERE script LIKE '%test_skill%' 
ORDER BY installed_on DESC;
```

#### 方式二：直接查询技能表

```sql
-- 查询测试技能
SELECT * FROM skill_definitions WHERE skill_id = 'test-skill';

-- 查询所有技能
SELECT skill_id, name, description, category, skill_type 
FROM skill_definitions 
ORDER BY created_at DESC;
```

**预期结果**：
- 应该能看到 `test-skill` 技能
- 技能名称：测试技能
- 分类：UTILITY
- 技能类型：ACTIVE

---

### 步骤 3：验证 API 端点

#### 3.1 获取所有技能

```bash
# 使用 curl
curl -X GET http://localhost:8080/api/skills \
  -H "Content-Type: application/json"

# 或者使用浏览器访问
# http://localhost:8080/api/skills
```

**预期响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1,
      "skillId": "test-skill",
      "name": "测试技能",
      "description": "这是一个简单的测试技能...",
      "category": "UTILITY",
      "skillType": "ACTIVE",
      ...
    }
  ]
}
```

#### 3.2 获取单个技能

```bash
curl -X GET http://localhost:8080/api/skills/test-skill \
  -H "Content-Type: application/json"
```

#### 3.3 获取可用技能（有 function_schema 的技能）

```bash
curl -X GET http://localhost:8080/api/skills/available \
  -H "Content-Type: application/json"
```

---

### 步骤 4：验证前端界面

#### 4.1 打开角色管理页面

1. 登录管理后台
2. 导航到"角色管理"
3. 点击某个角色的"编辑"按钮
4. 切换到"技能管理"标签页

#### 4.2 检查技能列表

**应该能看到**：
- 技能统计：`已装备: X 可用: Y`
- 搜索框：`搜索技能...`
- 技能列表（应该包含"测试技能"）

**如果看不到技能**：

1. **检查浏览器控制台**
   - 按 F12 打开开发者工具
   - 查看 Console 标签页
   - 查看是否有错误信息

2. **检查网络请求**
   - 切换到 Network 标签页
   - 刷新页面
   - 查找 `/api/skills` 请求
   - 检查请求状态和响应

3. **检查 API 响应**
   - 查看 `/api/skills` 请求的响应
   - 确认是否包含 `test-skill`

---

### 步骤 5：测试技能装备

1. 在技能列表中找到"测试技能"
2. 点击"装备"按钮
3. 在装备对话框中配置：
   - 启用：✓
   - 自动触发：可选
   - 优先级：0
4. 点击"确认装备"
5. 验证技能出现在"已装备"列表中

---

## 🐛 故障排查

### 问题 1：技能未出现在数据库中

**可能原因**：
- 迁移脚本未执行
- 迁移脚本执行失败

**解决方法**：
1. 检查 Flyway 迁移记录
2. 手动执行迁移脚本：
   ```sql
   -- 直接执行 SQL
   source backend/src/main/resources/db/migration/V20250104__create_test_skill.sql
   ```
3. 重启后端服务

---

### 问题 2：API 返回空列表

**可能原因**：
- 技能未创建
- API 查询条件错误

**解决方法**：
1. 检查数据库是否有技能记录
2. 检查 API 日志
3. 验证 API 端点是否正确

---

### 问题 3：前端显示"没有找到技能"

**可能原因**：
- API 请求失败
- 数据格式不匹配
- 前端过滤条件

**解决方法**：
1. 检查浏览器控制台错误
2. 检查网络请求状态
3. 验证 API 响应格式
4. 检查前端过滤逻辑

---

### 问题 4：技能装备失败

**可能原因**：
- 角色不存在
- 技能不存在
- 权限问题

**解决方法**：
1. 检查角色ID是否正确
2. 检查技能ID是否存在
3. 检查后端日志
4. 验证 API 权限

---

```bash
curl http://localhost:8080/api/skills | jq '.data[] | select(.skillId == "test-skill")'

# 3. 检查数据库（需要数据库连接信息）
mysql -u username -p -e "SELECT skill_id, name FROM skill_definitions WHERE skill_id = 'test-skill';" database_name
```
