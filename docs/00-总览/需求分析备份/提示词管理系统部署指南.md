## 五、常见问题

### 5.1 迁移失败

**问题**：Flyway迁移失败

**解决方案**：
1. 检查数据库连接配置
2. 检查数据库用户权限
3. 查看Flyway日志了解具体错误
4. 手动执行SQL脚本

### 5.2 表已存在错误

**问题**：表已存在，迁移失败

**解决方案**：
- 迁移脚本使用了 `CREATE TABLE IF NOT EXISTS`，可以安全重复执行
- 如果仍有问题，检查表结构是否匹配

### 5.3 外键约束错误

**问题**：外键约束失败

**解决方案**：
1. 确保先执行 `V20250106__create_prompt_management_tables.sql`（创建分类）
2. 再执行 `V20250106__insert_default_prompt_templates.sql`（插入模板）

### 5.4 模板未生效

**问题**：业务代码未使用模板

**解决方案**：
1. 检查模板是否启用（`is_active = TRUE`）
2. 检查分类代码是否正确
3. 查看后端日志，确认是否找到模板
4. 如果模板不存在，会自动使用默认提示词（这是正常的回退机制）

## 六、回滚方案

如果需要回滚迁移：

### 6.1 删除模板数据

```sql
-- 删除模板数据（保留表结构）
DELETE FROM prompt_templates;
DELETE FROM prompt_categories WHERE code NOT IN ('character', 'emotion', 'memory', 'intent', 'response', 'other');
```

### 6.2 删除表（谨慎操作）

```sql
-- 注意：这会删除所有数据
DROP TABLE IF EXISTS prompt_versions;
DROP TABLE IF EXISTS prompt_variables;
DROP TABLE IF EXISTS prompt_templates;
DROP TABLE IF EXISTS prompt_categories;
```
