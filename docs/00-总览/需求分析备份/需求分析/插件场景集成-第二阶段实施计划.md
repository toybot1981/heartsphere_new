# 插件场景集成 - 第二阶段实施计划

**目标：实现插件在"现实世界"场景中的集成，让插件可以灵活添加到场景中**

---

## 一、实施范围

第二阶段聚焦于场景集成机制，包括：

1. **场景插件管理**：场景中插件的增删改查
2. **插件位置管理**：插件在场景中的位置和布局
3. **插件添加/删除流程**：用户操作流程
4. **插件渲染机制**：插件在场景中的渲染和样式隔离
5. **插件配置**：场景中插件的配置管理

---

#### 任务1.1：场景插件Service层实现

**文件位置：**
- `backend/src/main/java/com/heartsphere/plugin/service/ScenePluginService.java`

**核心功能：**
- 获取场景中的插件列表
- 添加插件到场景
- 从场景删除插件
- 更新插件位置和大小
- 更新插件配置
- 插件显示/隐藏控制

**核心方法：**
```java
public class ScenePluginService {
    // 获取场景插件列表
    List<ScenePluginDTO> getScenePlugins(String sceneId, Long userId);
    
    // 添加插件到场景
    ScenePluginDTO addPluginToScene(String sceneId, Long userId, String pluginId, AddPluginRequest request);
    
    // 从场景删除插件
    void removePluginFromScene(String sceneId, Long userId, Long pluginInstanceId);
    
    // 更新插件位置
    void updatePluginPosition(String sceneId, Long userId, Long pluginInstanceId, PositionUpdateRequest request);
    
    // 更新插件配置
    void updatePluginConfig(String sceneId, Long userId, Long pluginInstanceId, PluginConfig config);
    
    // 切换插件可见性
    void togglePluginVisibility(String sceneId, Long userId, Long pluginInstanceId, boolean visible);
}
```

#### 任务1.2：场景插件Controller实现

**文件位置：**
- `backend/src/main/java/com/heartsphere/plugin/controller/ScenePluginController.java`

**API端点：**

1. **GET /api/scenes/{sceneId}/plugins**
   - 功能：获取场景中的插件列表
   - 请求参数：无
   - 响应：场景插件列表

2. **POST /api/scenes/{sceneId}/plugins/{pluginId}/add**
   - 功能：添加插件到场景
   - 请求体：
     ```json
     {
       "positionX": 100,
       "positionY": 200,
       "width": 400,
       "height": 300,
       "zIndex": 0,
       "config": {}
     }
     ```
   - 响应：插件实例信息

3. **DELETE /api/scenes/{sceneId}/plugins/{pluginInstanceId}**
   - 功能：从场景中删除插件
   - 请求参数：无
   - 响应：删除结果

4. **PUT /api/scenes/{sceneId}/plugins/{pluginInstanceId}/position**
   - 功能：更新插件位置和大小
   - 请求体：
     ```json
     {
       "positionX": 150,
       "positionY": 250,
       "width": 450,
       "height": 350,
       "zIndex": 1
     }
     ```
   - 响应：更新结果

5. **PUT /api/scenes/{sceneId}/plugins/{pluginInstanceId}/config**
   - 功能：更新插件配置
   - 请求体：插件配置对象
   - 响应：更新结果

6. **PUT /api/scenes/{sceneId}/plugins/{pluginInstanceId}/visibility**
   - 功能：切换插件可见性
   - 请求体：
     ```json
     {
       "visible": true
     }
     ```
   - 响应：更新结果

## 三、技术选型

### 3.1 拖拽库

**选项：**
1. **react-draggable**：轻量级拖拽库
2. **react-dnd**：功能强大的拖拽库
3. **自定义实现**：使用原生事件

**推荐：react-draggable**
- 简单易用
- 性能好
- 适合简单的拖拽需求

### 3.2 调整大小库

**选项：**
1. **react-resizable**：专业的调整大小库
2. **react-resizable-panels**：面板调整大小
3. **自定义实现**：使用原生事件

**推荐：react-resizable**
- 功能完整
- 易于集成
- 支持多种约束

### 3.3 布局管理

**选项：**
1. **绝对定位**：使用position: absolute
2. **CSS Grid**：网格布局
3. **Flexbox**：弹性布局

**推荐：绝对定位**
- 适合自由布局
- 易于实现拖拽
- 性能好

## 四、详细设计

### 4.1 插件位置和大小管理

**数据结构：**
```typescript
interface PluginPosition {
  positionX: number;  // X坐标
  positionY: number;  // Y坐标
  width: number;      // 宽度
  height: number;     // 高度
  zIndex: number;     // 层级
}
```

**约束规则：**
- 位置不能超出场景边界
- 最小宽度和高度限制
- 最大宽度和高度限制
- zIndex自动管理（避免重叠）

### 4.2 插件渲染机制

**渲染流程：**
1. 加载场景插件列表
2. 为每个插件创建容器
3. 加载插件代码
4. 初始化插件
5. 渲染插件UI
6. 绑定事件处理

**样式隔离：**
- 使用CSS Modules
- 或使用Shadow DOM（如果支持）
- 插件容器有独立的类名前缀

### 4.3 编辑模式

**编辑模式特性：**
- 显示插件边框
- 显示操作按钮（删除、配置、调整大小）
- 支持拖拽和调整大小
- 支持层级调整

**普通模式特性：**
- 隐藏编辑元素
- 插件正常交互
- 优化性能
