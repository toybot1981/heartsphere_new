## 三、核心服务

### 3.1 PromptTemplateIntegrationService

**位置**：`backend/src/main/java/com/heartsphere/admin/service/PromptTemplateIntegrationService.java`

**主要方法**：
- `getTemplateByCategory(String categoryCode)`：根据分类获取模板
- `renderTemplate(String categoryCode, Map<String, Object> variables)`：渲染模板
- `renderTemplateWithFallback(...)`：渲染模板（带默认值回退）
- `getSystemPrompt(...)`：获取系统提示词
- `getUserPrompt(...)`：获取用户提示词
- `getPrompts(...)`：获取完整的提示词对

**特性**：
- 自动回退：如果模板不存在，使用默认提示词
- 变量支持：支持Map类型的变量传递
- 错误处理：模板不存在时记录警告但不中断流程

## 六、使用示例

### 6.1 在业务代码中使用模板

```java
@Autowired
private PromptTemplateIntegrationService templateService;

public void someBusinessMethod() {
    // 准备变量
    Map<String, Object> variables = new HashMap<>();
    variables.put("userMessage", "用户消息");
    
    // 获取提示词（带默认值回退）
    PromptRenderResponse prompts = templateService.getPrompts(
        "intent",  // 分类代码
        variables,  // 变量
        "默认系统提示词",  // 默认系统提示词
        "默认用户提示词"   // 默认用户提示词
    );
    
    // 使用提示词
    TextGenerationRequest request = new TextGenerationRequest();
    request.setPrompt(prompts.getUserPrompt());
    request.setSystemInstruction(prompts.getSystemPrompt());
    
    // 调用AI服务
    TextGenerationResponse response = aiService.generateText(userId, request);
}
```

### 6.2 模板变量示例

```java
// 简单变量
Map<String, Object> variables = new HashMap<>();
variables.put("text", "今天心情不错");

// 条件变量

// 数组变量（用于循环）
List<String> messages = Arrays.asList("消息1", "消息2");
variables.put("messages", messages);
```

## 九、注意事项

### 9.1 性能考虑

1. **模板查询**：每次调用都会查询数据库，建议实现缓存
2. **模板渲染**：复杂模板可能影响性能，建议限制嵌套深度
3. **变量处理**：大量变量可能影响性能，建议优化变量结构

### 9.2 错误处理

1. **模板不存在**：自动使用默认提示词，记录警告日志
2. **变量缺失**：使用默认值或保留原样，记录警告日志
3. **渲染失败**：使用默认提示词，记录错误日志

### 9.3 安全考虑

1. **变量验证**：对用户输入的变量进行验证和转义
2. **模板权限**：确保只有授权用户可以修改模板
3. **模板审核**：重要模板修改需要审核
