# 提示词管理系统设计文档

## 一、需求概述

### 1.1 核心需求
- **分业务管理**：支持按业务模块分类管理提示词模板
- **模板化生成**：支持AI按照模板自动生成提示词
- **变量支持**：支持在模板中使用变量占位符
- **版本管理**：支持提示词模板的版本控制
- **预览测试**：支持预览和测试生成的提示词

### 1.2 业务场景
- **角色生成**：角色创建的提示词模板
- **情绪分析**：情绪分析的提示词模板
- **记忆提取**：记忆提取的提示词模板
- **意图识别**：意图识别的提示词模板
- **响应生成**：响应生成的提示词模板
- **其他业务**：可扩展的其他业务场景

## 三、数据库设计

### 3.1 提示词模板表 (prompt_templates)

```sql
CREATE TABLE prompt_templates (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(200) NOT NULL COMMENT '模板名称',
    category VARCHAR(100) NOT NULL COMMENT '业务分类',
    description TEXT COMMENT '模板描述',
    system_prompt TEXT COMMENT '系统提示词模板',
    user_prompt TEXT COMMENT '用户提示词模板',
    variables JSON COMMENT '变量定义（JSON格式）',
    example_data JSON COMMENT '示例数据（用于预览）',
    version INT DEFAULT 1 COMMENT '版本号',
    is_active BOOLEAN DEFAULT TRUE COMMENT '是否启用',
    created_by BIGINT COMMENT '创建人ID',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_category (category),
    INDEX idx_name (name),
    INDEX idx_active (is_active)
) COMMENT '提示词模板表';
```

### 3.2 业务分类表 (prompt_categories)

```sql
CREATE TABLE prompt_categories (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    code VARCHAR(100) UNIQUE NOT NULL COMMENT '分类代码',
    name VARCHAR(200) NOT NULL COMMENT '分类名称',
    description TEXT COMMENT '分类描述',
    parent_id BIGINT COMMENT '父分类ID',
    sort_order INT DEFAULT 0 COMMENT '排序',
    is_active BOOLEAN DEFAULT TRUE COMMENT '是否启用',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_parent (parent_id),
    INDEX idx_active (is_active)
) COMMENT '业务分类表';
```

### 3.3 模板变量表 (prompt_variables)

```sql
CREATE TABLE prompt_variables (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    template_id BIGINT NOT NULL COMMENT '模板ID',
    variable_name VARCHAR(100) NOT NULL COMMENT '变量名',
    variable_type VARCHAR(50) NOT NULL COMMENT '变量类型（string/number/boolean/array/object）',
    description TEXT COMMENT '变量描述',
    default_value TEXT COMMENT '默认值',
    is_required BOOLEAN DEFAULT FALSE COMMENT '是否必填',
    validation_rule JSON COMMENT '验证规则（JSON格式）',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (template_id) REFERENCES prompt_templates(id) ON DELETE CASCADE,
    INDEX idx_template (template_id)
) COMMENT '模板变量表';
```

### 3.4 模板版本表 (prompt_versions)

```sql
CREATE TABLE prompt_versions (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    template_id BIGINT NOT NULL COMMENT '模板ID',
    version INT NOT NULL COMMENT '版本号',
    system_prompt TEXT COMMENT '系统提示词',
    user_prompt TEXT COMMENT '用户提示词',
    variables JSON COMMENT '变量定义',
    change_log TEXT COMMENT '变更日志',
    created_by BIGINT COMMENT '创建人ID',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (template_id) REFERENCES prompt_templates(id) ON DELETE CASCADE,
    UNIQUE KEY uk_template_version (template_id, version),
    INDEX idx_template (template_id)
) COMMENT '模板版本表';
```

## 四、模板语法设计

### 4.1 变量占位符

**基本语法**：`{{variableName}}`

**示例**：
```
你是一个{{role}}，请分析用户的消息：{{userMessage}}
```

### 4.2 条件逻辑

**语法**：`{{#if condition}}...{{/if}}`

**示例**：
```
{{#if hasContext}}
上下文信息：{{context}}
{{/if}}
```

### 4.3 循环处理

**语法**：`{{#each items}}...{{/each}}`

**示例**：
```
角色列表：
{{#each characters}}
- {{name}}: {{role}}
{{/each}}
```

### 4.4 默认值

**语法**：`{{variableName|defaultValue}}`

**示例**：
```
温度：{{temperature|0.7}}
```

## 五、API设计

### 5.1 模板管理API

```
GET    /api/admin/prompts/templates          # 获取模板列表
GET    /api/admin/prompts/templates/{id}     # 获取模板详情
POST   /api/admin/prompts/templates           # 创建模板
PUT    /api/admin/prompts/templates/{id}      # 更新模板
DELETE /api/admin/prompts/templates/{id}      # 删除模板
POST   /api/admin/prompts/templates/{id}/copy # 复制模板
```

### 5.2 分类管理API

```
GET    /api/admin/prompts/categories         # 获取分类列表

DELETE /api/admin/prompts/categories/{id}    # 删除分类
```

### 5.3 模板渲染API

```
POST   /api/admin/prompts/templates/{id}/render    # 渲染模板

```

```
POST   /api/admin/prompts/templates/{id}/generate  # AI生成提示词
```

## 九、示例场景

### 9.1 角色生成模板

**模板内容**：
```
系统提示词：
你是一个创意写作助手。请为名为"{{eraName}}"的世界/时代创建一个完整的角色档案。

用户提示词：
角色概念："{{characterConcept}}"
```

**变量定义**：
- `eraName`: 时代名称（必填）
- `characterConcept`: 角色概念（必填）

### 9.2 情绪分析模板

**模板内容**：
```
系统提示词：
你是一个情绪分析专家。请分析以下文本的情绪状态。

用户提示词：
文本内容：{{text}}
{{#if hasContext}}
上下文信息：
- 对话历史: {{conversationHistory}}
- 时间: {{timeOfDay}}点
{{/if}}
```

**变量定义**：
- `text`: 待分析文本（必填）
- `hasContext`: 是否有上下文（布尔值）
- `conversationHistory`: 对话历史（可选）
- `timeOfDay`: 时间（可选）

## 十、注意事项

1. **安全性**：模板渲染时需要对用户输入进行验证和转义
2. **性能**：模板渲染需要缓存机制
3. **可扩展性**：模板语法需要支持扩展
4. **用户体验**：提供清晰的错误提示和帮助文档
5. **版本控制**：重要模板需要保留历史版本
