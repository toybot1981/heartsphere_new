# 模板管理模块 - 用户体验设计

**目标：打造直观、高效、愉悦的模板管理体验**

---

## 一、设计原则

### 1.1 核心原则

1. **零学习成本**
   - 界面自解释，无需阅读文档即可使用
   - 图标和文字双重表达
   - 操作符合用户直觉

2. **渐进式发现**
   - 常用功能放在显眼位置
   - 高级功能隐藏在合适的地方
   - 功能按使用频率组织

3. **即时反馈**
   - 所有操作都有即时反馈
   - 加载状态清晰可见
   - 错误提示友好明确

4. **减少认知负担**
   - 信息层次清晰
   - 避免信息过载
   - 关键信息突出显示

---

## 三、核心功能体验设计

### 3.1 模板浏览体验

#### 3.1.1 视图切换

**三种视图模式：**

1. **卡片视图（默认）**
   - 大卡片，展示预览图、标题、标签、评分
   - 鼠标悬停显示快速操作按钮
   - 适合浏览和发现

2. **列表视图**
   - 紧凑列表，展示更多信息
   - 适合快速查找和对比
   - 支持多选操作

3. **详细视图**
   - 大图 + 详细信息
   - 适合仔细查看模板详情
   - 可以快速预览效果

**切换方式：**
- 顶部工具栏视图切换按钮（图标按钮）
- 快捷键（1/2/3切换视图）
- 记住用户偏好

#### 3.1.2 模板卡片设计

```
┌─────────────────────────┐
│  预览图（可播放动画）      │
│  [播放按钮]              │
├─────────────────────────┤
│  🎓 学习伙伴              │
│  ⭐⭐⭐⭐⭐ (4.8)         │
│  📊 使用 1.2K 次          │
│  🏷️ 教育 · 陪伴           │
│  [快速使用] [查看详情]     │
└─────────────────────────┘
```

**交互细节：**
- 鼠标悬停：卡片轻微放大，显示阴影
- 预览图：可以播放模板的演示动画/GIF
- 点击卡片：进入详情页
- 快速使用按钮：一键使用模板（弹窗配置参数）
- 收藏按钮：右上角小图标，点击收藏/取消收藏

#### 3.1.3 搜索与筛选

**搜索框：**
- 顶部居中，大而明显
- 支持实时搜索（输入即搜索）
- 搜索建议（下拉提示）
- 支持关键词高亮

**筛选器：**
- 侧边栏固定筛选
  - 分类筛选（多选）
  - 标签筛选（标签云或列表）
  - 难度等级筛选
  - 评分筛选（滑块）
  
- 顶部快捷筛选
  - 排序方式（热度、评分、最新、我的）
  - 视图切换
  - 显示数量（每页显示数量）

**筛选状态显示：**
- 显示当前激活的筛选条件（标签形式）
- 可以快速清除单个或全部筛选
- 筛选结果数量提示

#### 3.2.2 实时预览

**预览功能：**
- 右侧固定预览面板
- 用户调整参数时，实时更新预览
- 可以播放模板的演示对话
- 显示Graph流程的可视化预览（简化版）

**预览加载：**
- 初始加载时显示占位图
- 加载完成后平滑过渡到真实预览
- 加载失败时显示友好的错误提示

#### 3.2.3 参数配置体验

**参数配置面板：**
- 分组显示参数（基本信息、性格设置、能力设置等）
- 每组可以展开/折叠
- 参数控件清晰直观：
  - 文本输入：带占位符和提示
  - 滑块：显示当前值和范围
  - 选择器：下拉或单选按钮组
  - 颜色选择：色盘选择器

**参数验证：**
- 实时验证（输入时）
- 友好的错误提示（红色边框 + 提示文字）
- 成功提示（绿色对勾）

**参数预设：**
- 提供几个预设配置（如：严肃型、活泼型、平衡型）
- 用户可以一键应用预设
- 可以保存自己的配置为预设

### 3.3 模板使用流程

#### 3.3.1 快速使用流程

```
用户点击"快速使用"
    ↓
弹出快速配置弹窗（精简参数）
    ↓
用户调整关键参数（可选）
    ↓
点击"创建"
    ↓
显示创建进度（进度条 + 状态文字）
    ↓
创建成功 → 跳转到"我的作品"
    ↓
或 → 直接开始使用（打开对话界面）
```

#### 3.3.2 详细使用流程

```
用户在详情页配置参数
    ↓
实时预览效果
    ↓
点击"立即使用"
    ↓
确认配置（可选，显示配置摘要）
    ↓
创建作品
    ↓
跳转到作品页面或直接使用
```

**创建过程反馈：**
- 显示创建步骤（参数绑定 → Graph生成 → 保存）
- 每个步骤有进度指示
- 步骤完成有动画反馈
- 失败时显示具体错误信息和重试按钮

### 3.4 我的模板管理

#### 3.4.1 "我的模板"页面

**功能区域：**

1. **我的收藏**
   - 收藏的模板列表
   - 可以按分类查看
   - 支持取消收藏

2. **我的作品**
   - 基于模板创建的作品列表
   - 显示使用的模板信息
   - 可以查看、编辑、删除作品

3. **我的模板**（如果用户创建了模板）
   - 用户创建的模板列表
   - 显示使用统计
   - 可以编辑、删除、发布模板

#### 3.4.2 作品管理

**作品卡片：**

**批量操作：**
- 列表视图支持多选
- 批量删除
- 批量分享
- 批量导出（如果支持）

## 四、交互细节设计

### 4.1 加载状态

**加载动画：**
- 骨架屏（Skeleton Screen）代替空白或加载圈
- 卡片加载时显示占位内容
- 平滑的淡入动画

**加载反馈：**
- 加载中的操作按钮显示加载状态
- 网络慢时显示预估时间
- 加载失败时显示重试按钮

### 4.2 空状态设计

**空状态场景：**
- 无搜索结果："没有找到相关模板，试试其他关键词？"
- 无收藏："还没有收藏模板，去发现一些有趣的模板吧！"
- 无作品："还没有创建作品，选择一个模板开始创作吧！"

**空状态设计：**
- 友好的插图或图标
- 清晰的提示文字
- 引导操作按钮（如："去浏览模板"）

### 4.3 错误处理

**错误提示原则：**
- 明确：说明发生了什么问题
- 友好：使用用户能理解的语言
- 可操作：提供解决方案或操作建议

**错误示例：**
- 网络错误："网络连接失败，请检查网络后重试"
- 参数错误："角色名称不能为空"
- 权限错误："您没有权限使用此模板"

### 4.4 成功反馈

**操作成功反馈：**
- 轻微的动画效果（如：按钮的涟漪效果）
- 成功提示（Toast提示，3秒自动消失）
- 状态更新（如：收藏按钮变为已收藏状态）

## 五、视觉设计

### 5.1 色彩系统

**主色调：**
- 使用系统主色调
- 模板卡片使用柔和的背景色
- 重要操作使用强调色

**状态颜色：**
- 成功：绿色
- 警告：黄色
- 错误：红色
- 信息：蓝色

### 5.2 图标系统

**图标使用：**
- 统一的图标风格
- 图标大小一致
- 重要功能使用图标 + 文字

**常用图标：**
- 🔍 搜索
- ⭐ 收藏/评分
- 🏷️ 标签
- 📊 统计
- ⚙️ 设置
- ➕ 添加
- ❌ 删除

### 5.3 动画效果

**微交互动画：**
- 卡片悬停：轻微放大 + 阴影
- 按钮点击：涟漪效果
- 页面切换：平滑过渡
- 列表加载：淡入动画

**动画原则：**
- 快速（不超过300ms）
- 自然（符合物理规律）
- 适度（不过度使用）

## 六、响应式设计

### 6.1 桌面端（>1024px）

- 三栏布局（侧边栏 + 主内容 + 预览面板）
- 卡片网格：每行3-4个卡片
- 完整功能展示

### 6.2 平板端（768px-1024px）

- 两栏布局（侧边栏折叠 + 主内容）
- 卡片网格：每行2-3个卡片
- 部分功能简化

### 6.3 移动端（<768px）

- 单栏布局
- 侧边栏变为底部导航或抽屉
- 卡片网格：每行1-2个卡片
- 核心功能优先

## 七、用户引导

### 7.1 首次使用引导

**引导流程：**
1. 欢迎弹窗：介绍模板中心的功能
2. 高亮提示：指向关键功能（搜索、筛选、快速使用）
3. 完成任务：引导用户完成第一个模板的使用

**引导方式：**
- 遮罩层 + 高亮 + 提示文字
- 可以跳过
- 可以重新查看（在设置中）

### 7.2 功能提示

**上下文提示：**
- 新功能上线：顶部横幅提示
- 功能更新：更新日志弹窗
- 操作提示：悬浮提示（Tooltip）

**提示原则：**
- 不打断用户操作
- 可以关闭
- 不过度提示

## 八、性能优化体验

### 8.1 加载优化

- 懒加载：图片和内容按需加载
- 虚拟滚动：长列表使用虚拟滚动
- 缓存：模板列表和详情缓存
- 预加载：预加载下一页内容

### 8.2 交互优化

- 防抖：搜索输入防抖
- 节流：滚动事件节流
- 乐观更新：操作立即反馈，后台更新
- 离线支持：缓存数据，离线可查看

## 十、关键体验指标

### 10.1 效率指标

- **找到目标模板的时间**：< 30秒
- **使用模板的步骤数**：< 3步（快速使用）
- **参数配置时间**：< 1分钟（简单模板）

### 10.2 满意度指标

- **操作成功率**：> 95%
- **错误率**：< 5%
- **用户满意度评分**：> 4.5/5

### 10.3 参与度指标

- **模板浏览率**：用户访问模板中心的频率
- **模板使用率**：浏览后使用的比例
- **收藏率**：用户收藏模板的比例
