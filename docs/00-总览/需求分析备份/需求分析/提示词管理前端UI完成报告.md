## 四、使用说明

### 4.1 创建模板
1. 点击"创建模板"按钮
2. 填写模板信息：
   - 模板名称（必填）
   - 选择分类（必填）
   - 描述（可选）
   - 系统提示词模板（支持变量：`{{variableName}}`）
   - 用户提示词模板（支持变量）
   - 示例数据（JSON格式，用于预览）
3. 点击"保存"

### 4.2 编辑模板
1. 在模板卡片上点击"编辑"按钮
2. 修改模板信息
3. 点击"保存"

### 4.3 预览模板
1. 在模板卡片上点击"预览"按钮
2. 查看使用示例数据渲染后的提示词
3. 点击"关闭"退出预览

### 4.4 AI生成提示词
1. 在模板卡片上点击"AI生成"按钮
2. 填写变量值（根据模板定义的变量自动生成输入框）
3. 可选：输入上下文信息
4. 点击"生成"按钮
5. 查看AI生成的优化提示词
6. 可以点击"重新生成"再次生成

### 4.5 删除模板
1. 在模板卡片上点击"删除"按钮
2. 确认删除操作
3. 模板将被软删除（标记为禁用）

## 五、变量语法说明

### 5.1 基本变量
```
{{variableName}}
```

### 5.2 带默认值的变量
```
{{variableName|defaultValue}}
```

### 5.3 示例
```
系统提示词：
你是一个{{role|助手}}，请分析用户的消息：{{userMessage}}

用户提示词：
文本内容：{{text}}
```
