# 提示词管理系统快速开始

## 🚀 快速部署（3步完成）

### 步骤1：执行数据库迁移

**方式一：自动迁移（推荐）**

启动后端服务，Flyway会自动执行：

```bash
cd /Users/admin/Workspace/heartsphere_new/backend
mvn spring-boot:run
```

**方式二：手动执行**

```bash
mysql -u root -p heartsphere < backend/src/main/resources/db/migration/V20250106__create_prompt_management_tables.sql
mysql -u root -p heartsphere < backend/src/main/resources/db/migration/V20250106__insert_default_prompt_templates.sql
```

### 步骤2：验证迁移

运行验证脚本：

```bash
./scripts/verify-prompt-management.sh
```

或手动验证：

```sql
-- 检查表
SHOW TABLES LIKE 'prompt_%';

-- 检查分类
SELECT * FROM prompt_categories;

-- 检查模板
SELECT id, name, category_code FROM prompt_templates;
```

### 步骤3：访问管理后台

1. 启动前端服务（如果未启动）：
   ```bash
   cd frontend
   npm run dev
   ```

2. 访问管理后台：
   - URL: http://localhost:3000/admin
   - 登录管理员账号

3. 进入提示词管理：
   - 在侧边栏点击"💬 提示词管理"
   - 应该看到5个默认模板

## 📋 默认模板说明

系统已预置5个默认模板，可直接使用：

1. **意图识别模板**（分类：intent）
   - 用于识别用户消息的意图
   - 变量：`userMessage`

2. **响应生成模板**（分类：response）
   - 用于生成友好的自然语言响应
   - 变量：`executionResult`, `status`

3. **情绪分析模板**（分类：emotion）
   - 用于分析文本的情绪状态
   - 变量：`text`, `hasContext`, `conversationHistory`, `timeOfDay`, `dayOfWeek`
   - 支持条件逻辑

4. **记忆提取模板**（分类：memory）
   - 用于从对话中提取用户记忆
   - 变量：`messages`（数组）
   - 支持循环处理

5. **角色生成模板**（分类：character）
   - 用于生成角色档案
   - 变量：`eraName`, `characterConcept`, `worldStyle`, `existingCharacters`, `requirements`
   - 支持条件逻辑和循环

## 🎯 快速测试

### 测试1：查看模板列表

在管理后台的"提示词管理"页面，应该看到5个模板卡片。

### 测试2：预览模板

1. 点击任意模板的"预览"按钮
2. 应该看到使用示例数据渲染后的提示词

### 测试3：AI生成提示词

1. 点击任意模板的"AI生成"按钮
2. 填写变量值
3. 点击"生成"
4. 应该看到AI生成的优化提示词

### 测试4：创建新模板

1. 点击"创建模板"按钮
2. 填写模板信息
3. 使用模板语法：`{{variableName}}`
4. 保存后应该出现在列表中

## ⚠️ 注意事项

1. **数据库备份**：执行迁移前建议备份数据库
2. **权限检查**：确保数据库用户有创建表和索引的权限
3. **版本兼容**：确保MySQL版本 >= 8.0（支持JSON类型）
4. **回退机制**：如果模板不存在，系统会自动使用默认提示词，不会影响现有功能
