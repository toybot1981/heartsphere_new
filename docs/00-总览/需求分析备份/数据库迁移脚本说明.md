# 技能系统数据库迁移脚本说明

## 一、迁移脚本概述

**文件名**：`V20250104__enhance_skill_system_for_function_calling.sql`  
**版本**：V20250104  
**创建时间**：2025-01-04  
**目的**：增强技能系统以支持 Function Calling 和角色技能装备功能

---

## 二、迁移内容

### 2.1 扩展 skill_definitions 表

添加以下字段以支持 Function Calling：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `function_schema` | TEXT | Function Calling JSON Schema，用于 AI Function Calling |
| `execution_type` | VARCHAR(50) | 执行类型：SCRIPT/API/GRAPH/DATABASE/RULE_BASED |
| `execution_config` | TEXT | 执行配置（JSON格式），包含脚本路径、API配置等 |
| `auto_trigger_keywords` | TEXT | 自动触发关键词（JSON数组格式） |
| `required_permissions` | VARCHAR(255) | 所需权限（逗号分隔） |
| `max_usage_per_day` | INT | 每日最大使用次数（-1表示无限制） |
| `version` | VARCHAR(50) | 技能版本号 |
| `author` | VARCHAR(255) | 技能作者 |
| `is_system_skill` | BOOLEAN | 是否为系统技能（系统技能不可删除） |

**新增索引**：
- `idx_execution_type` - 优化按执行类型查询
- `idx_is_system_skill` - 优化系统技能查询

### 2.2 创建 skill_executions 表

**用途**：记录所有技能的执行历史

**主要字段**：
- `skill_id` - 技能ID
- `character_id` - 角色ID
- `user_id` - 用户ID
- `execution_type` - 执行类型（FUNCTION_CALL/GRAPH_NODE/MANUAL/AUTO_TRIGGER）
- `parameters` - 执行参数（JSON格式）
- `result` - 执行结果（JSON格式）
- `execution_time_ms` - 执行耗时（毫秒）
- `success` - 是否成功
- `error_message` - 错误信息

### 2.3 创建 character_skill_bindings 表

**用途**：管理角色装备的技能及其配置

**主要字段**：
- `character_id` - 角色ID
- `skill_id` - 技能ID
- `is_enabled` - 是否启用
- `auto_trigger` - 是否自动触发
- `priority` - 优先级
- `usage_count` - 使用次数统计
- `last_used_at` - 最后使用时间
- `equipped_at` - 装备时间

**注意**：此表与 `character_skills` 表的区别：
- `character_skills` - 存储技能等级和经验值（游戏化）
- `character_skill_bindings` - 存储技能装备关系（功能化）

### 2.4 创建 skill_prerequisites 表

**用途**：定义技能解锁的前置条件

**主要字段**：
- `skill_id` - 技能ID
- `prerequisite_skill_id` - 前置技能ID
- `prerequisite_level` - 前置技能所需等级
- `required_character_level` - 角色所需等级
- `required_items` - 所需物品（JSON数组）
- `custom_condition` - 自定义条件（JSON格式）

### 2.5 创建 skill_conflicts 表

**用途**：定义不能同时装备的技能

**主要字段**：
- `skill_id_1` - 技能1 ID
- `skill_id_2` - 技能2 ID
- `conflict_type` - 冲突类型（MUTUAL_EXCLUSIVE/WEAK_CONFLICT）
- `conflict_reason` - 冲突原因说明

### 2.6 创建查询视图

#### v_character_equipped_skills

**用途**：查询角色已装备的技能及其详细信息

**包含字段**：
- 角色ID、技能ID
- 技能名称、描述、分类
- 装备配置（启用状态、自动触发、优先级）
- 使用统计（使用次数、最后使用时间）
- 技能等级和经验值

#### v_skill_usage_statistics

**用途**：技能使用统计

**包含字段**：
- 技能ID、技能名称
- 执行统计（总数、成功数、失败数）
- 性能统计（平均耗时、最大耗时、最小耗时）
- 用户统计（使用角色数、使用用户数）
- 最后执行时间
