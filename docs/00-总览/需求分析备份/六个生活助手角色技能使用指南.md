# 六个生活助手角色技能使用指南

**文档版本**: V1.0  
**创建日期**: 2025-01-07  
**项目名称**: 数字生命体交互系统（HeartSphere）

---

## 一、概述

本指南介绍如何使用六个"生活助手"角色的48个技能。这些技能覆盖了时间管理、健康生活、学习成长、情绪陪伴、心理健康和情感陪伴等领域。

### 1.1 技能系统架构

- **执行类型**: 所有技能都使用 `RULE_BASED` 执行类型
- **执行方式**: 通过 `LLMBasedSkillExecutor` 执行，利用大模型的能力
- **指令层级**: 每个技能都有 Level 2 指令（详细使用说明）
- **自动触发**: 部分技能支持自动触发，会在特定条件下自动执行

### 1.2 技能分类

| 分类 | 数量 | 说明 |
|------|------|------|
| healthcare | 23个 | 健康相关技能 |
| life | 16个 | 生活相关技能 |
| social | 9个 | 社交相关技能 |
| PSYCHIATRY | 2个 | 心理治疗相关技能 |

## 二、角色与技能

### 2.1 时小光 - 时间管理导师

**角色定位**: 帮助用户提高时间管理效率，克服拖延症

**8个技能**:

1. **时间审计** (time_audit)
   - 功能: 分析时间使用情况，识别时间浪费
   - 触发: 手动调用
   - 关键词: 时间、效率、时间管理

2. **任务分解** (task_breakdown)
   - 功能: 将复杂任务分解为可执行步骤
   - 触发: 手动调用
   - 关键词: 任务分解、WBS、项目规划

3. **番茄工作法助手** (pomodoro_assistant)
   - 功能: 实施番茄工作法，监控专注时间
   - 触发: 手动调用
   - 关键词: 番茄工作法、专注

4. **优先级矩阵** (priority_matrix)
   - 功能: 使用四象限法进行任务优先级排序
   - 触发: 手动调用
   - 关键词: 优先级、重要紧急

5. **习惯养成追踪** (habit_tracker) ⚡自动触发
   - 功能: 追踪和培养良好习惯
   - 触发: 自动触发
   - 关键词: 习惯、追踪

6. **目标设定与追踪** (goal_setting_tracking)
   - 功能: 设定和追踪目标进度
   - 触发: 手动调用
   - 关键词: 目标、SMART

7. **拖延症诊断** (procrastination_diagnosis)
   - 功能: 诊断拖延症原因，提供解决方案
   - 触发: 手动调用
   - 关键词: 拖延、拖延症

8. **时间块规划** (time_blocking)
   - 功能: 使用时间块方法规划时间
   - 触发: 手动调用
   - 关键词: 时间块、时间规划

**额外技能**:
- CBT认知重构 (cbt-cognitive-restructuring) ⚡自动触发
- CBT行为激活 (cbt-behavioral-activation) ⚡自动触发

## 三、技能调用方式

### 3.1 手动调用

用户可以通过以下方式手动调用技能：

1. **直接提及关键词**: 在对话中提到技能相关的关键词
2. **明确请求**: 直接请求使用某个技能，如"帮我做个时间审计"
3. **功能描述**: 描述想要的功能，系统会自动匹配技能

### 3.2 自动触发

标记为 ⚡自动触发 的技能会在以下情况下自动执行：

1. **习惯追踪类**: 定期自动执行，追踪用户习惯
2. **提醒类**: 在特定时间或条件下自动提醒
3. **陪伴类**: 在对话中自动提供陪伴和支持
4. **危机类**: 在检测到危机信号时自动触发

### 3.3 技能参数

每个技能都有对应的 `function_schema`，定义了技能需要的参数。系统会根据用户输入自动提取参数，或提示用户提供必要参数。

## 四、使用建议

### 4.1 选择合适的角色

- **时间管理问题** → 选择"时小光"
- **健康生活问题** → 选择"康小健"
- **学习成长问题** → 选择"学小知"
- **情绪陪伴需求** → 选择"心小暖"
- **心理健康问题** → 选择"心小安"
- **轻松陪伴需求** → 选择"暖小阳"

### 4.2 技能组合使用

某些技能可以组合使用，获得更好的效果：

- **时间管理**: 时间审计 + 任务分解 + 时间块规划
- **健康管理**: 健康数据追踪 + 个性化饮食建议 + 运动计划制定
- **学习提升**: 学习计划制定 + 记忆技巧训练 + 知识复习提醒
- **情绪管理**: 情绪识别 + 情绪调节技巧 + 正念练习

### 4.3 定期使用

建议定期使用以下技能：

- **时间审计**: 每周一次，了解时间使用情况
- **健康数据追踪**: 每天记录，追踪健康变化
- **学习效果评估**: 每月一次，评估学习进展
- **情绪日记**: 每天记录，追踪情绪变化

## 五、注意事项

### 5.1 专业转介

如果遇到以下情况，系统会建议寻求专业帮助：

- 严重的心理健康问题
- 紧急的情绪危机
- 需要专业治疗的情况

### 5.2 数据隐私

所有技能执行过程中的数据都会：

- 存储在用户账户下
- 仅用于提供个性化服务
- 不会泄露给第三方

### 5.3 技能限制

- 技能不能替代专业医疗建议
- 严重问题应寻求专业帮助
- 技能效果因人而异
