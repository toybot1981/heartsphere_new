## 技术栈

### 后端
- **框架**：Spring Boot
- **数据库**：MySQL
- **AI服务**：Gemini API / Qwen API
- **缓存**：Redis（可选）
- **消息队列**：RabbitMQ（可选，用于异步任务）

### 前端
- **框架**：React + TypeScript
- **UI库**：Tailwind CSS
- **图表**：Chart.js 或 ECharts
- **状态管理**：Context API / Zustand

## 关键决策点

### 1. AI服务选择
- **推荐**：优先使用 Gemini（已集成）
- **备选**：Qwen、Doubao
- **考虑**：成本、响应速度、质量

### 2. 技能实现方式
- **方案A**：Function Calling（推荐）
- **方案B**：规则引擎
- **方案C**：混合方案

### 3. 数据存储策略
- **方案A**：关系型数据库（MySQL）
- **方案B**：时序数据库（InfluxDB，适合时间序列数据）
- **推荐**：MySQL + Redis缓存

## 风险与应对

### 风险1：AI回复质量不稳定
- **应对**：优化system_instruction，实现回复质量评估

### 风险2：技能调用准确率低
- **应对**：使用Function Calling，提供技能说明和示例

### 风险3：性能问题
- **应对**：使用缓存、异步处理、数据库优化
