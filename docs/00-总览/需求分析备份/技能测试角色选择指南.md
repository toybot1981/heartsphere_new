# 技能测试角色选择指南

## 🎯 如何选择测试角色

### 方法一：使用现有角色（推荐）

#### 1. 查看系统中的角色

**通过管理后台**：
1. 登录管理后台
2. 进入"角色管理"
3. 查看角色列表
4. 选择任意一个角色进行测试

**通过 API**：
```bash
# 获取所有角色（需要认证）
curl -X GET http://localhost:8080/api/characters \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

**通过数据库查询**：
```sql
-- 查询所有角色
SELECT id, name, description, system_era_id 
FROM characters 
ORDER BY id 
LIMIT 10;

-- 查询系统角色
SELECT id, name, description, system_era_id 
FROM system_characters 
WHERE is_active = 1 
ORDER BY id 
LIMIT 10;
```

#### 2. 推荐测试角色

根据系统预设，以下角色适合测试：

**现代场景**：
- **大学室友** - 适合测试日常对话技能
- **大学导师** - 适合测试教育类技能

**心理治疗场景**：
- **心理医生** - 适合测试危机干预等心理类技能

**其他场景**：
- 任意一个你熟悉的角色都可以

---

### 方法二：创建测试角色（如果需要）

#### 通过管理后台创建

1. 进入"角色管理"
2. 点击"新建角色"
3. 填写基本信息：
   - 姓名：测试角色
   - 描述：用于测试技能的角色
   - 其他信息按需填写
4. 保存

#### 通过 API 创建

```bash
curl -X POST http://localhost:8080/api/characters \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "name": "测试角色",
    "description": "用于测试技能的角色",
    "bio": "这是一个测试角色",
    "age": 20,
    "gender": "未知"
  }'
```

## 📋 快速查找角色ID

### 方法一：通过管理后台

1. 进入"角色管理"
2. 找到要测试的角色
3. 点击"编辑"按钮
4. 查看浏览器地址栏，URL 中通常包含角色ID
   - 例如：`/admin/characters/edit/123`
   - 角色ID就是 `123`

### 方法二：通过数据库查询

```sql
-- 查询角色ID和名称
SELECT id, name 
FROM characters 
WHERE name LIKE '%测试%' OR name LIKE '%室友%' 
ORDER BY id;

-- 或者查询所有角色
SELECT id, name, description 
FROM characters 
ORDER BY id 
LIMIT 20;
```

### 方法三：通过 API 查询

```bash
# 获取所有角色
curl -X GET http://localhost:8080/api/characters \
  -H "Authorization: Bearer YOUR_TOKEN" | jq '.data[] | {id: .id, name: .name}'
```

## 🎯 推荐测试流程

### 步骤 1：选择一个角色

**最简单的方法**：
1. 打开管理后台 → 角色管理
2. 查看角色列表
3. 选择第一个角色（通常是ID最小的）
4. 记录角色ID（在编辑页面的URL中可以看到）

### 步骤 2：装备技能

1. 编辑选中的角色
2. 切换到"技能管理"标签页
3. 装备"测试技能"

### 步骤 3：测试技能

1. 打开角色对话页面
2. 选择已装备技能的角色
3. 开始对话测试

## 💡 实用技巧

### 技巧 1：使用角色名称查找

如果知道角色名称，可以通过数据库快速查找：

```sql
-- 查找名为"大学室友"的角色
SELECT id, name, description 
FROM characters 
WHERE name = '大学室友';

-- 或者查找系统角色
SELECT id, name, description 
FROM system_characters 
WHERE name = '大学室友';
```

### 技巧 2：使用脚本快速查找

创建一个简单的查找脚本：

```bash
#!/bin/bash
# 查找角色ID
CHARACTER_NAME=${1:-"大学室友"}

# 通过 API 查找（需要 token）
# 或者通过数据库查找
mysql -u username -p database_name -e "
SELECT id, name, description 
FROM characters 
WHERE name LIKE '%${CHARACTER_NAME}%' 
LIMIT 5;
"
```

## ✅ 验证角色选择

选择角色后，可以通过以下方式验证：

### 1. 检查角色是否存在

```bash
# 通过 API
curl -X GET http://localhost:8080/api/characters/{characterId} \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 2. 检查角色是否可以装备技能

```bash
# 尝试获取角色的技能列表
curl -X GET http://localhost:8080/api/characters/{characterId}/skills \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## 📝 测试角色建议

### 推荐测试角色类型

1. **简单角色**：选择描述简单、对话风格明确的角色
2. **常用角色**：选择你经常使用的角色，熟悉其对话风格
3. **新创建角色**：创建一个专门用于测试的角色

### 不推荐

- 过于复杂的角色（可能影响测试结果）
- 系统关键角色（避免影响生产环境）
