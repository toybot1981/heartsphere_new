# X6 编辑器示例 Graph 说明

## 概述

我已经创建了一个完整的示例 Graph，名为 **"角色对话示例 - 冒险者任务"**，展示了所有节点类型的用法。

## 如何查看示例

1. **启动后端服务**（如果尚未启动）
2. **运行数据库迁移**：示例数据会在 Flyway 迁移时自动插入
3. **打开 Admin 管理端**
4. **进入 Graph 流程编辑器**：左侧菜单 → 内容管理 → Graph流程编辑器
5. **勾选 "使用 X6 编辑器（POC）"**
6. **找到 "角色对话示例 - 冒险者任务"** 并点击"编辑流程"

## 示例包含的节点类型

### ✅ 1. Start 节点（开始）
- **节点ID**: `start_1`
- **位置**: (100, 50)
- **功能**: 流程的起始点

### ✅ 2. Dialogue 节点（对话）
- **节点ID**: `dialogue_1`, `dialogue_2`, `dialogue_3`, `dialogue_4`, `dialogue_5`, `dialogue_6`
- **位置**: 分布在流程的各个位置
- **功能**: 显示 NPC 对话和系统消息
- **示例内容**:
  - `dialogue_1`: "你好，冒险者！有一个危险的任务需要你去完成。"
  - `dialogue_2`: "太好了！这个任务需要你进入森林深处，找到神秘的宝藏。"
  - `dialogue_5`: "你成功找到了宝藏的位置！"

### ✅ 3. Choice 节点（选择）
- **节点ID**: `choice_1`
- **位置**: (100, 350)
- **功能**: 让玩家做出选择
- **选项**:
  1. **接受任务** - 增加声望 10
  2. **拒绝任务** - 减少声望 5
  3. **询问更多信息** - 无效果

### ✅ 4. Condition 节点（条件判断）
- **节点ID**: `condition_1`, `condition_2`
- **位置**: (100, 500) 和 (100, 1250)
- **功能**: 根据条件分支流程
- **判断逻辑**:
  - `condition_1`: 判断玩家是否接受任务 (`userChoice == "accept"`)
  - `condition_2`: 判断技能检查是否成功 (`skillCheckResult == true`)

### ✅ 5. Skill Check 节点（技能检查）
- **节点ID**: `skill_check_1`
- **位置**: (100, 800)
- **功能**: 检查角色的探索技能
- **配置**:
  - 技能: `exploration`
  - 难度: 15
  - 成功效果: 经验 +50
  - 失败效果: 生命值 -10

### ✅ 6. State Change 节点（状态变更）
- **节点ID**: `state_change_1`
- **位置**: (100, 950)
- **功能**: 修改角色状态（物品、变量等）
- **变更内容**:
  - 获得物品: 藏宝图 × 1
  - 设置变量: `inForest = true`

### ✅ 7. Wait 节点（等待）
- **节点ID**: `wait_1`
- **位置**: (100, 1100)
- **功能**: 等待玩家操作
- **配置**:
  - 等待类型: `USER_INPUT`
  - 等待条件: `playerReady`
  - 超时时间: 30000ms (30秒)

### ✅ 8. End 节点（结束）
- **节点ID**: `end_1`, `end_2`, `end_3`
- **位置**: 流程的各个终点
- **功能**: 流程结束点
- **结局类型**:
  - `end_1`: 任务完成（成功结局）
  - `end_2`: 任务失败（失败结局）
  - `end_3`: 任务已拒绝（拒绝结局）

## 流程路径

示例包含多条流程路径：

1. **主路径（接受任务）**:
   ```
   Start → Dialogue 1 → Choice 1 → Condition 1 (接受) → Dialogue 2 
   → Skill Check 1 → State Change 1 → Wait 1 → Condition 2 → 
   [成功: Dialogue 5 → End 1] 
   [失败: Dialogue 6 → End 2]
   ```

2. **询问信息路径**:
   ```
   Choice 1 → Dialogue 4 → Condition 1 → ...
   ```

3. **拒绝任务路径**:
   ```
   Choice 1 → Dialogue 3 → End 3
   ```

## 编辑建议

1. **查看节点配置**: 双击节点可以查看和编辑节点属性
2. **测试连线**: 尝试拖动节点，查看连线是否正常
3. **添加新节点**: 从左侧侧边栏拖拽新节点到画布
4. **修改节点内容**: 在右侧属性面板中编辑节点配置
5. **保存更改**: 点击顶部"保存"按钮保存修改

## 注意事项

- 示例数据通过 Flyway 迁移脚本自动插入
- 如果数据库中已存在同名 Graph，迁移可能会失败
- 可以在 Admin 端直接编辑和保存这个示例
- 建议在编辑前先复制一份作为备份
