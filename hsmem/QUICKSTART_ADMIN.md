# HSMem 管理后台 - 快速开始

## 🚀 一键启动

### 方式 1: 使用启动脚本（推荐）

```bash
cd hsmem
./start_admin.sh
```

脚本会自动：
- ✅ 检查依赖
- ✅ 启动 API 服务器
- ✅ 打开管理后台
- ✅ 显示访问地址

### 方式 2: 手动启动

```bash
cd hsmem

# 1. 启动 API 服务器
python3 simple_api_server.py &

# 2. 打开管理后台
# 双击文件: admin_dashboard.html
# 或在浏览器中打开文件
```

## 🎯 快速测试

### 1. 添加对话记忆

在管理后台左侧：
1. 选择"对话"标签
2. 输入用户ID（可选）
3. 输入对话内容：
   ```
   用户: 你好，我叫李明
   助手: 你好李明！
   用户: 我喜欢编程
   ```
4. 点击"保存对话记忆"

### 2. 查看统计

顶部卡片显示：
- 💬 对话资源: 实时更新
- 📝 记忆项: 实时更新
- 📁 记忆分类: 实时更新
- ⚡ 系统状态: 实时更新

### 3. 浏览分类

底部显示所有分类标签：
- preferences（偏好）
- personal_info（个人信息）
- habits（习惯）
- ...

## 💡 使用技巧

### 格式化对话

使用"用户:"和"助手:"前缀：
```
用户: 我叫张三
助手: 你好张三
用户: 我喜欢编程
助手: 编程很棒！
```

### 按主题分类

使用不同的用户ID：
```
user_001  # 工作相关
user_002  # 个人相关
user_003  # 学习笔记
```

### 批量添加

多次添加对话，系统自动：
- 提取关键信息
- 创建记忆项
- 组织到分类

## 🛠️ 常见问题

### Q: 无法连接到服务器？
A: 检查 API 服务器是否运行：
```bash
curl http://localhost:8000/health
```

### Q: 数据不更新？
A: 刷新页面或等待5秒自动刷新

### Q: 保存失败？
A: 查看浏览器控制台错误信息
