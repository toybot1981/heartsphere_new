# HSMem 管理后台使用指南

## 🎨 管理后台介绍

HSMem 提供了一个现代化的 Web 管理界面，让你可以：
- 📊 查看系统统计
- ➕ 添加对话、文本、文档记忆
- 📋 浏览记忆列表
- 🔍 搜索和过滤记忆
- 🗂️ 查看记忆分类

## 🚀 快速启动

### 1. 启动 API 服务器

```bash
cd hsmem
python3 simple_api_server.py
```

服务器将在 `http://localhost:8000` 启动

### 2. 打开管理后台

在浏览器中打开文件:
```
hsmem/admin_dashboard.html
```

或者直接双击文件打开！

## 📱 界面功能

### 🎯 顶部统计卡片

显示四个关键指标：
- 💬 **对话资源**: 存储的对话数量
- 📝 **记忆项**: 提取的记忆数量
- 📁 **记忆分类**: 创建的分类数量
- ⚡ **系统状态**: API 服务健康状态

### ➕ 左侧：添加记忆

#### 对话记忆
1. 输入用户ID（可选）
2. 输入对话内容，格式：
   ```
   用户: 你好，我叫李明
   助手: 你好李明！
   用户: 我喜欢编程
   ```
3. 点击"保存对话记忆"

#### 文本记忆
1. 输入用户ID（可选）
2. 输入文本内容
3. 点击"保存文本记忆"

#### 文档记忆
1. 输入用户ID（可选）
2. 输入文档标题
3. 输入文档内容
4. 点击"保存文档记忆"

### 📋 右侧：记忆列表

- 🔍 **搜索框**: 搜索记忆内容
- 🏷️ **分类过滤**: 按分类筛选
- 📝 **记忆项列表**: 显示所有记忆

### 🗂️ 底部：记忆分类

显示所有记忆分类，每个标签显示：
- 分类名称
- 包含的记忆项数量

## 🔧 高级功能

### 1. 批量添加记忆

可以多次添加对话，系统会自动：
- 提取关键信息
- 创建记忆项
- 组织到分类

### 2. 按用户管理

通过用户ID区分不同用户的记忆：
```javascript
user_id: "user_001"  // 李明的记忆
user_id: "user_002"  // 王芳的记忆
```

### 3. 分类浏览

按分类查看相关记忆：
- preferences（偏好）
- personal_info（个人信息）
- habits（习惯）
- behavior（行为）
- ...

## 🌐 API 集成

管理后台通过 REST API 与服务器通信：

```javascript
// 健康检查
GET /health

// 记忆化对话
POST /api/v1/memory/memorize/conversation

// 获取统计
GET /api/v1/memory/statistics

// 获取分类
GET /api/v1/memory/categories
```

## 🛠️ 故障排查

### 无法连接到服务器

**问题**: 显示"加载失败"

**解决**:
1. 检查 API 服务器是否运行
2. 访问 http://localhost:8000/health
3. 查看浏览器控制台错误

### 数据不更新

**问题**: 统计数据不刷新

**解决**:
1. 刷新页面 (F5)
2. 检查网络连接
3. 查看服务器日志

### 保存失败

**问题**: 点击保存无反应

**解决**:
1. 检查输入格式
2. 查看错误提示
3. 确认服务器正常
