# Agent Simulator

## 概述

Agent Simulator 提供智能体模拟功能，用于本地开发和测试多智能体系统。

## 功能特性

- ✅ Mock Agent 接口
- ✅ 智能体行为模拟
- ✅ 状态管理
- ✅ 与 AgentScope 集成
