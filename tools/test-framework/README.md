# Agent Test Framework

## 概述

Agent Test Framework 提供多智能体系统的测试框架，支持单元测试和集成测试。

## 功能特性

- ✅ 智能体单元测试
- ✅ 集成测试环境
- ✅ 测试数据管理
- ✅ Mock 服务支持

## 状态

当前为框架阶段，完整实现将在后续版本中完成。
