# Mock LLM Service

## 概述

Mock LLM Service 提供本地的大模型 API 模拟服务，用于开发和测试环境，避免调用真实 API。

## 功能特性

- ✅ 模拟 DashScope API 格式
- ✅ 模拟 OpenAI API 格式
- ✅ 响应模板系统
- ✅ 延迟模拟
- ✅ 错误模拟

## 状态
