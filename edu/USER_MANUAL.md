## 学生端使用手册

### 1. 登录和注册

#### 1.1 登录系统

1. 打开浏览器，访问 HeartSphere Edu 系统
2. 输入您的用户名和密码
3. 点击"登录"按钮
4. 登录成功后，系统会自动跳转到学生仪表板

#### 1.2 注册账号

1. 点击登录页面的"注册"按钮
2. 填写注册信息（姓名、邮箱、密码等）
3. 提交注册表单
4. 系统会发送验证邮件到您的邮箱
5. 点击邮件中的验证链接完成注册

### 2. 学生仪表板

学生仪表板是您进入系统后的主页面，显示您的学习概览和推荐内容。

#### 2.1 仪表板功能

- **学习统计**: 显示您的学习时长、完成的任务数等
- **推荐数字人**: 系统根据您的学习情况推荐合适的数字人角色
- **最近互动**: 显示您最近与数字人的互动记录
- **学习进度**: 显示您的整体学习进度

#### 2.2 使用推荐数字人

1. 在仪表板上查看推荐的数字人角色
2. 点击数字人卡片查看详细信息
3. 点击"开始学习"按钮与数字人互动

### 3. 数字人角色

#### 3.1 浏览数字人列表

1. 点击导航栏中的"数字人"菜单
2. 查看所有可用的数字人角色
3. 使用筛选功能（类型、年龄段、学科等）查找感兴趣的角色
4. 使用搜索功能搜索特定角色

#### 3.2 查看数字人详情

1. 点击数字人卡片进入详情页
2. 查看数字人的基本信息：
   - 名称和描述
   - 角色类型（教学助手、学习伙伴等）
   - 适用年龄段
   - 学科标签
   - 难度等级
   - 语言风格
   - 个性特征
   - 特殊功能
3. 查看统计信息：
   - 总互动次数
   - 平均学习时长
   - 学生评分
4. 查看互动历史
5. 查看学习进度图表

#### 3.3 与数字人互动

1. 在数字人详情页点击"开始学习"按钮
2. 选择互动类型（教学对话、作业辅导等）
3. 开始与数字人对话
4. 系统会自动记录您的互动内容
5. 互动结束后，系统会记录学习时长和理解程度

### 4. 学习进度

#### 4.1 查看学习进度

1. 点击导航栏中的"个人资料"菜单
2. 切换到"学习进度"标签
3. 查看您的学习统计：
   - 总学习时长
   - 互动次数
   - 学习主题数
   - 平均理解程度
4. 查看学习进度图表（按时间、按主题等）
5. 查看最近的互动历史记录

#### 4.2 查看互动历史

1. 在学习进度页面查看互动历史列表
2. 使用筛选功能（按日期、按数字人、按类型等）
3. 点击互动记录查看详细信息：
   - 互动内容
   - 学习主题
   - 理解程度
   - 学习时长
   - 您的反馈

### 5. 个人资料

#### 5.1 查看个人资料

1. 点击导航栏中的"个人资料"菜单
2. 查看您的个人信息：
   - 姓名
   - 邮箱
   - 注册时间
   - 学习统计

#### 5.2 编辑个人资料

1. 在个人资料页面点击"编辑"按钮
2. 修改您的个人信息
3. 点击"保存"按钮保存更改

### 6. 常见操作

#### 6.1 搜索功能

- 在数字人列表页面使用搜索框搜索角色
- 支持按名称、描述、学科等搜索

#### 6.2 筛选功能

- 按角色类型筛选（教学助手、学习伙伴等）
- 按年龄段筛选（小学、中学等）
- 按学科筛选（数学、语文、英语等）
- 按难度等级筛选

#### 6.3 排序功能

- 按创建时间排序
- 按互动次数排序
- 按评分排序

## 教师端使用手册

### 1. 登录系统

1. 使用教师账号登录系统
2. 登录成功后，系统会自动跳转到教师仪表板

### 2. 教师仪表板

教师仪表板显示您的教学概览和班级信息。

#### 2.1 仪表板功能

- **班级统计**: 显示您管理的班级数和学生数
- **教学统计**: 显示您的教学时长、课程数等
- **学生活动**: 显示学生的最近活动
- **教学资源**: 显示可用的教学资源

### 3. 学生管理

#### 3.1 查看学生列表

1. 点击导航栏中的"学生管理"菜单
2. 查看所有学生的列表
3. 使用搜索和筛选功能查找特定学生

#### 3.2 查看学生学习情况

1. 点击学生姓名进入学生详情页
2. 查看学生的学习统计：
   - 学习时长
   - 互动次数
   - 学习主题
   - 理解程度
3. 查看学生的学习进度图表
4. 查看学生的互动历史记录

### 4. 数字人管理

#### 4.1 查看数字人列表

1. 点击导航栏中的"数字人管理"菜单
2. 查看所有可用的数字人角色
3. 查看每个数字人的使用统计

#### 4.2 推荐数字人给学生

1. 在数字人列表中选择合适的角色
2. 点击"推荐给学生"按钮
3. 选择要推荐的学生
4. 系统会向学生发送推荐通知

### 5. 教学资源

#### 5.1 查看教学资源

1. 点击导航栏中的"教学资源"菜单
2. 查看所有可用的教学资源
3. 使用筛选功能查找特定资源

#### 5.2 创建教学资源

1. 点击"创建资源"按钮
2. 填写资源信息（标题、描述、内容等）
3. 上传相关文件（可选）
4. 点击"保存"按钮保存资源

## 家长端使用手册

### 1. 登录系统

1. 使用家长账号登录系统
2. 登录成功后，系统会自动跳转到家长仪表板

### 2. 家长仪表板

家长仪表板显示您孩子的学习概览。

#### 2.1 仪表板功能

- **孩子学习统计**: 显示孩子的学习时长、互动次数等
- **学习进度**: 显示孩子的整体学习进度
- **最近活动**: 显示孩子最近的学习活动
- **推荐内容**: 显示系统推荐的学习内容

### 3. 查看孩子学习情况

#### 3.1 查看学习统计

1. 在仪表板上查看孩子的学习统计
2. 查看学习时长、互动次数、学习主题数等
3. 查看学习进度图表

#### 3.2 查看互动历史

1. 点击"互动历史"菜单
2. 查看孩子与数字人的所有互动记录
3. 使用筛选功能（按日期、按数字人等）
4. 点击互动记录查看详细信息

### 4. 查看学习报告

#### 4.1 查看学习报告

1. 点击"学习报告"菜单
2. 选择报告时间段（周报、月报等）
3. 查看详细的学习报告：
   - 学习时长统计
   - 学习主题统计
   - 理解程度分析
   - 学习建议

#### 4.2 导出学习报告

1. 在学习报告页面点击"导出"按钮
2. 选择导出格式（PDF、Excel等）
3. 下载报告文件

### 5. 设置和通知

#### 5.1 设置学习提醒

1. 点击"设置"菜单
2. 设置学习提醒时间
3. 选择提醒方式（邮件、短信等）
4. 保存设置

#### 5.2 查看通知

1. 点击"通知"菜单
2. 查看系统通知和提醒
3. 标记通知为已读

## 常见问题

### Q1: 如何重置密码？

A: 在登录页面点击"忘记密码"链接，输入您的邮箱地址，系统会发送密码重置邮件。

### Q2: 如何联系数字人？

A: 在数字人列表页面选择您感兴趣的角色，点击"开始学习"按钮即可开始互动。

### Q3: 如何查看学习进度？

A: 点击导航栏中的"个人资料"菜单，切换到"学习进度"标签即可查看。

### Q4: 如何筛选数字人？

A: 在数字人列表页面使用筛选功能，可以按类型、年龄段、学科等筛选。

### Q5: 如何查看互动历史？

A: 在个人资料页面的"学习进度"标签中，可以查看所有互动历史记录。

### Q6: 系统推荐数字人的依据是什么？

A: 系统根据您的学习情况、年龄、兴趣等因素推荐合适的数字人角色。

### Q7: 如何反馈问题？

A: 在系统设置页面可以找到"反馈"功能，或者直接联系系统管理员。

### Q8: 如何导出学习报告？

A: 在个人资料页面的"学习进度"标签中，可以导出学习报告（PDF、Excel等格式）。
