# 前端重新部署脚本使用说明

## 快速使用

```bash
cd deploy
sudo ./redeploy-frontend.sh
```

## 脚本功能

这个脚本会完全清理并重新构建前端，解决以下问题：
- React ForwardRef 错误
- 依赖版本冲突
- 构建缓存问题
- 生产环境配置问题

## 执行步骤

脚本会自动执行以下7个步骤：

1. **清理旧文件** - 删除所有旧的构建产物和缓存
2. **检查环境** - 验证 Node.js 版本
3. **重新安装依赖** - 完全重新安装所有依赖
4. **创建配置** - 创建生产环境配置文件
5. **构建项目** - 重新构建前端项目
6. **部署文件** - 复制到生产目录
7. **验证部署** - 检查部署是否成功

## 注意事项

- 需要 root 权限运行
- 会完全清理 node_modules，需要重新下载依赖（可能需要几分钟）
- 构建过程可能需要几分钟时间
- 脚本会自动保存构建日志到 `build.log`

## 故障排查

如果脚本执行失败：

1. 查看构建日志：
   ```bash
   cat frontend/build.log
   ```

2. 检查 Node.js 版本：
   ```bash
   node -v  # 需要 18+
   ```

3. 手动执行步骤：
   参考 `docs/14-部署运维/前端重新部署指南.md`
