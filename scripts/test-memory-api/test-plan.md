## 📊 测试用例

### 测试用例1: 对话记忆化
**前置条件**: HSMem服务运行
**步骤**:
1. 发送对话记忆化请求
2. 验证响应包含resource_id和items_count
3. 验证记忆项已创建

**预期结果**: 成功创建记忆项

### 测试用例2: 记忆检索
**前置条件**: 已有记忆数据
**步骤**:
1. 发送检索请求
2. 验证返回相关记忆项
3. 验证过滤条件生效

**预期结果**: 返回相关记忆项

### 测试用例3: 用户数据隔离
**前置条件**: 两个用户都有记忆数据
**步骤**:
1. 用户A登录
2. 用户A检索记忆
3. 验证只能看到用户A的记忆

**预期结果**: 用户只能访问自己的记忆
