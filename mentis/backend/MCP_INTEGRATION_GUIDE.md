# MCP 工具集成使用指南

## 概述

MCP (Model Context Protocol) 工具已成功集成到 Mentis 对话系统中。当用户发送消息时，系统会自动检测是否需要调用 MCP 工具，并在需要时自动调用。

## 集成架构

```
用户消息
  ↓
MentisAgentService
  ↓
McpIntegrationService (检测是否需要工具)
  ↓
McpToolAdapter (转换工具格式)
  ↓
McpClientService (调用 MCP 服务器)
  ↓
工具执行结果
  ↓
AI 服务 (生成最终响应)
```

## 功能特性

### 1. 自动工具检测

系统会自动检测用户消息中的搜索意图，关键词包括：
- 搜索、查询、查找、找、搜
- search、find、lookup
- 最新、最近、现在、当前、实时、最新消息、新闻

### 2. 工具调用流程

1. **工具发现**: 从所有启用的 MCP 配置中加载可用工具
2. **意图识别**: 分析用户消息，判断是否需要调用工具
3. **工具执行**: 调用相应的 MCP 工具
4. **结果处理**: 将工具执行结果反馈给 AI，生成最终回答

### 3. 工具命名规则

MCP 工具在系统中的命名格式：`mcp_{configId}_{toolName}`

例如：
- `mcp_1_tavily_search` - 配置 ID 为 1 的 Tavily 搜索工具

## 使用示例

### 示例 1: 自动搜索

**用户消息**: "搜索一下最新的 AI 技术发展"

**系统处理**:
1. 检测到"搜索"关键词
2. 自动调用 Tavily 搜索工具
3. 将搜索结果反馈给 AI
4. 生成包含搜索结果的回答

### 示例 2: 普通对话

**用户消息**: "你好，介绍一下自己"

**系统处理**:
1. 未检测到工具调用需求
2. 直接使用 AI 生成回答
3. 不调用任何工具

## API 使用

### 发送消息（自动使用 MCP 工具）

```bash
POST /api/mentis/chat/send
Content-Type: application/json

{
  "sessionId": "your-session-id",
  "message": "搜索最新的 AI 技术发展"
}
```

响应将包含基于 MCP 工具执行结果的回答。

## 配置要求

1. **MCP 配置必须启用**: 在 MCP 配置管理界面中，确保相关配置的"启用"开关已打开
2. **连接状态**: 建议先测试连接，确保 MCP 服务器可访问
3. **工具可用**: 确保 MCP 服务器提供了可用的工具

## 当前支持的 MCP 服务器

### Tavily 搜索

- **配置名称**: Tavily 搜索
- **工具名称**: `tavily_search` (实际名称可能因 MCP 服务器而异)
- **功能**: 实时网络搜索
- **使用场景**: 当用户需要搜索最新信息时自动调用

## 调试和日志

### 查看工具调用日志

```bash
tail -f mentis-backend.log | grep -i "mcp\|tool"
```

### 关键日志信息

- `自动检测到搜索意图，将调用工具` - 工具自动检测成功
- `执行 MCP 工具失败` - 工具执行失败
- `获取 MCP 工具失败` - 无法从 MCP 服务器获取工具列表

## 故障排除

### 问题 1: 工具未被调用

**可能原因**:
- MCP 配置未启用
- 用户消息中未包含搜索关键词
- MCP 服务器连接失败

**解决方法**:
1. 检查 MCP 配置是否启用
2. 测试 MCP 连接
3. 查看日志了解详细错误

### 问题 2: 工具调用失败

**可能原因**:
- MCP 服务器不可访问
- API Key 无效
- 工具参数不正确

**解决方法**:
1. 在配置界面测试连接
2. 检查 API Key 是否正确
3. 查看工具的参数要求

### 问题 3: 工具结果未正确使用

**可能原因**:
- 工具返回格式不符合预期
- AI 服务调用失败

**解决方法**:
1. 检查工具返回的数据格式
2. 查看 AI 服务日志
3. 验证 AI 服务配置

## 扩展开发

### 添加新的工具检测逻辑

在 `McpIntegrationService.detectToolCallsFromUserMessage()` 方法中添加新的检测逻辑：

```java
// 检测其他类型的工具需求
if (needsOtherTool(userMessage)) {
    // 查找相应的工具并创建 ToolCall
}
```

### 自定义工具调用

可以通过 API 直接调用工具：

```bash
POST /api/mentis/mcp/configs/{id}/tools/{toolName}/call
Content-Type: application/json

{
  "arguments": {
    "query": "搜索关键词"
  }
}
```

## 性能优化

1. **工具缓存**: 考虑缓存工具列表，避免每次请求都查询
2. **异步调用**: 对于耗时的工具调用，考虑使用异步处理
3. **结果缓存**: 对于相同查询，可以缓存搜索结果

## 安全注意事项

1. **API Key 保护**: API Key 存储在数据库中，建议加密存储
2. **输入验证**: 验证工具参数，防止注入攻击
3. **访问控制**: 确保只有授权用户可以访问 MCP 配置
