## 系统概述

HeartSphere Edu 管理员系统是教育版的后台管理系统，用于管理学生、教师、教学内容、审核流程和数据分析。

### 主要功能模块

- **学生管理**: 管理学生账号、查看学生学习情况
- **教师管理**: 管理教师账号、查看教师教学情况
- **内容管理**: 管理教学内容、课程、资源
- **内容审核**: 审核用户提交的内容
- **数据分析**: 查看系统使用统计和分析报告
- **系统设置**: 配置系统参数和权限

## 登录系统

### 1. 访问管理员系统

1. 打开浏览器，访问 Admin 管理系统
2. 输入管理员用户名和密码
3. 点击"登录"按钮
4. 登录成功后，系统会自动跳转到管理员仪表板

### 2. 安全提示

- 使用强密码
- 定期更换密码
- 不要在公共设备上登录
- 退出时记得登出系统

## 仪表板

管理员仪表板是您进入系统后的主页面，显示系统的整体概览和关键指标。

### 1. 仪表板功能

#### 1.1 系统统计

- **学生总数**: 显示注册学生总数
- **教师总数**: 显示注册教师总数
- **活跃用户**: 显示最近7天活跃用户数
- **内容总数**: 显示系统内容总数

#### 1.2 最近活动

- **最近注册**: 显示最近注册的学生和教师
- **最近活动**: 显示用户最近的活动记录
- **系统通知**: 显示系统通知和提醒

#### 1.3 数据图表

- **用户增长趋势**: 显示用户注册增长趋势
- **活跃度统计**: 显示用户活跃度统计
- **内容统计**: 显示内容创建和审核统计

### 2. 使用仪表板

1. 查看系统整体情况
2. 点击统计卡片查看详细信息
3. 使用图表分析数据趋势
4. 查看最近活动了解系统动态

## 学生管理

### 1. 查看学生列表

1. 点击左侧菜单中的"学生管理"
2. 查看所有学生的列表
3. 使用搜索功能查找特定学生
4. 使用筛选功能（按年级、按状态等）

### 2. 学生信息

#### 2.1 查看学生详情

1. 点击学生姓名进入学生详情页
2. 查看学生基本信息：
   - 姓名、邮箱、注册时间
   - 年级、班级
   - 账号状态
3. 查看学生学习情况：
   - 学习时长
   - 互动次数
   - 学习主题
   - 理解程度
4. 查看学习进度图表
5. 查看互动历史记录

#### 2.2 编辑学生信息

1. 在学生详情页点击"编辑"按钮
2. 修改学生信息
3. 点击"保存"按钮保存更改

### 3. 学生操作

#### 3.1 创建学生账号

1. 在学生列表页面点击"创建学生"按钮
2. 填写学生信息（姓名、邮箱、密码等）
3. 选择年级和班级
4. 点击"保存"按钮创建账号

#### 3.2 禁用/启用学生账号

1. 在学生列表中选择学生
2. 点击"禁用"或"启用"按钮
3. 确认操作

#### 3.3 重置学生密码

1. 在学生详情页点击"重置密码"按钮
2. 系统会发送密码重置邮件给学生
3. 学生可以通过邮件重置密码

#### 3.4 删除学生账号

1. 在学生详情页点击"删除"按钮
2. 确认删除操作
3. **注意**: 删除操作不可恢复，请谨慎操作

### 4. 批量操作

#### 4.1 批量导入学生

1. 在学生列表页面点击"批量导入"按钮
2. 下载导入模板
3. 填写学生信息（Excel 格式）
4. 上传文件
5. 系统会自动导入学生信息

#### 4.2 批量导出学生

1. 在学生列表页面点击"导出"按钮
2. 选择导出格式（Excel、CSV等）
3. 下载导出文件

## 内容审核

### 1. 审核队列

1. 点击左侧菜单中的"内容审核"
2. 查看待审核的内容列表
3. 按优先级排序（紧急、普通等）
4. 使用筛选功能（按类型、按提交时间等）

### 2. 审核内容

#### 2.1 查看待审核内容

1. 在审核队列中点击内容标题
2. 查看内容详细信息
3. 查看提交者信息
4. 查看审核历史（如果有）

#### 2.2 审核操作

1. **通过审核**:
   - 点击"通过"按钮
   - 填写审核意见（可选）
   - 确认操作
   - 内容将自动发布

2. **拒绝审核**:
   - 点击"拒绝"按钮
   - 填写拒绝原因（必填）
   - 确认操作
   - 内容将被标记为拒绝状态

3. **退回修改**:
   - 点击"退回"按钮
   - 填写修改意见（必填）
   - 确认操作
   - 内容将退回给提交者修改

### 3. 批量审核

#### 3.1 批量通过

1. 在审核队列中选择多个内容
2. 点击"批量通过"按钮
3. 确认操作

#### 3.2 批量拒绝

1. 在审核队列中选择多个内容
2. 点击"批量拒绝"按钮
3. 填写拒绝原因
4. 确认操作

## 常见问题

### Q1: 如何重置学生密码？

A: 在学生管理页面，点击学生详情，然后点击"重置密码"按钮，系统会发送密码重置邮件给学生。

### Q2: 如何批量导入学生？

A: 在学生管理页面，点击"批量导入"按钮，下载导入模板，填写学生信息后上传即可。

### Q3: 如何审核内容？

A: 在内容审核页面，查看待审核内容，点击"通过"、"拒绝"或"退回"按钮进行审核。

### Q4: 如何查看数据分析？

A: 在数据分析页面，可以查看用户分析、内容分析等各类数据统计和图表。

### Q5: 如何配置系统权限？

A: 在系统设置中，点击"角色管理"，创建或编辑角色，然后配置相应的权限。

### Q6: 如何导出数据报告？

A: 在数据分析页面，选择报告类型和时间段，点击"导出"按钮，选择格式后下载。

### Q7: 如何备份数据？

A: 在系统设置中，点击"数据备份"，选择备份类型后开始备份，完成后下载备份文件。

### Q8: 如何联系技术支持？

A: 在系统设置中可以找到技术支持联系方式，或直接发送邮件到 admin-support@heartsphere.com。
