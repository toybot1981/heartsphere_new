## 📝 使用示例

### NodePropertyPanel 使用

```tsx
<NodePropertyPanel
  node={selectedNode}
  onUpdate={(nodeId, config) => {
    // 更新节点配置
    setNodes((nds) =>
      nds.map((n) =>
        n.id === nodeId
          ? { ...n, data: { ...n.data, config } }
          : n
      )
    );
  }}
/>
```
