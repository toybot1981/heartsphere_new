# Change: 更新项目上下文文档

## Why

当前的 `openspec/project.md` 是模板文件，缺少实际的项目信息。为了帮助 AI 助手更好地理解项目上下文，需要基于现有的开发规范文档（心域开发指南、插件开发规范等）来丰富项目上下文文档，包括：

- 项目目的和技术栈
- 代码风格和命名规范
- 架构模式和设计原则
- 测试策略
- Git 工作流
- 领域上下文
- 重要约束
- 外部依赖

这将使 AI 助手在创建新的 change proposal 时能够：
- 更好地理解项目背景
- 遵循项目既定的规范和约定
- 做出符合项目架构的决策
- 减少需要澄清的问题

## What Changes

- **更新 `openspec/project.md`**：
  - 填充项目目的和技术栈信息
  - 添加代码风格和命名规范（基于心域开发指南）
  - 添加架构模式和设计原则
  - 添加测试策略
  - 添加 Git 工作流规范
  - 添加领域上下文（心域系统的核心概念）
  - 添加重要约束
  - 添加外部依赖信息

## Impact

- **影响的文件**：
  - `openspec/project.md` - 主要更新文件
  
- **影响的规范**：
  - 无（project.md 是项目上下文文档，不是规范文档）
  
- **影响的工作流**：
  - 后续所有使用 OpenSpec 创建的 change proposal 都会参考更新后的 project.md
  - AI 助手在创建 proposal 时会更好地理解项目上下文

## Notes

- 此变更仅更新项目上下文文档，不涉及代码或规范变更
- 不需要创建 spec deltas，因为 project.md 不是规范文档
- 内容基于现有的开发规范文档，确保一致性
