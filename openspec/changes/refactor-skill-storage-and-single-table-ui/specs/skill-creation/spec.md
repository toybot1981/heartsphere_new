## ADDED Requirements

### Requirement: AI 生成后单表展示
系统 SHALL 在 AI 生成技能完成后，在**同一张表/同一视图**中直接展示生成结果，不再分多步向导展示。

#### Scenario: 生成完成后进入单表视图
- **WHEN** 用户选择 AI 自动生成并完成生成
- **THEN** 系统在单表/单视图页面中展示生成的技能完整信息（元数据 + skill_content + 资源列表）
- **AND** 用户可在该同一视图中直接编辑并保存，无需再经过多步向导
- **AND** 展示内容包含技能主信息与 Bundled Resources（若有），与「技能编辑」使用同一套布局与交互

#### Scenario: 单表视图内容
- **WHEN** 用户查看生成结果或编辑技能
- **THEN** 单表视图展示技能元数据（name、description 等）及完整 SKILL.md 指令内容（skill_content）
- **AND** 单表视图展示该技能关联的 Bundled Resources 列表（按 scripts、references、assets 区分或分组）
- **AND** 用户可在同一视图中修改元数据、指令内容与资源列表并保存

### Requirement: 编辑页与生成页统一
系统 SHALL 使技能编辑页与「AI 生成结果展示」使用相同的单表/单视图布局与交互。

#### Scenario: 编辑入口使用单表视图
- **WHEN** 用户从技能列表或其它入口进入「编辑」某技能
- **THEN** 系统加载该技能数据并在与「生成结果展示」相同的单表视图中展示
- **AND** 用户可在该视图中编辑技能主信息与资源并保存
- **AND** 布局、字段组织与生成结果页一致，仅数据来源为已有技能

#### Scenario: 生成后可直接转入编辑
- **WHEN** 用户在生成结果单表视图中点击保存
- **THEN** 系统将当前视图中的数据持久化为新技能或更新已有技能
- **AND** 保存后仍停留在单表视图或跳转至该技能的编辑单表视图，行为与从列表进入编辑一致
