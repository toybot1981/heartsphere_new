# Change: 迁移所有技能到新格式并删除旧技能

## Why

当前系统中存在新旧两种技能格式并存的问题：

1. **旧格式技能仍在使用** - 数据库中仍有大量使用 `function_schema` 的旧格式技能，这些技能不符合新的 Claude Skills 规范
2. **格式不统一** - 新旧格式并存导致系统需要维护两套兼容逻辑，增加了复杂性和维护成本
3. **技能质量不一致** - 旧技能缺少新规范要求的字段（`skill_content`, `mcp_tool_config`, `license`, `compatibility`, `metadata`），描述和指令可能不够完整
4. **迁移不彻底** - 之前的迁移方案保留了向后兼容，旧技能仍然存在，没有完全迁移到新格式
5. **AI理解能力受限** - 旧格式的技能描述和指令不够清晰，影响 AI 对技能的理解和使用

为了彻底解决这些问题，需要：
- 使用 AI 根据旧技能描述生成符合新规范的新技能
- 删除所有旧格式技能
- 确保新技能包含完整的元数据、指令和配置

## What Changes

- **AI生成新技能** - 读取所有旧技能，使用 AI 服务根据旧技能的描述、功能等信息生成符合新规范的新技能
- **批量迁移流程** - 创建批量迁移工具，自动处理所有旧技能的迁移
- **删除旧技能** - 迁移完成后，删除所有旧格式技能（或标记为已废弃）
- **数据备份** - 在删除前备份旧技能数据，以防需要恢复
- **迁移验证** - 验证生成的新技能是否符合新规范，确保质量
- **角色技能绑定迁移** - 将角色装备的旧技能绑定迁移到对应的新技能

## Impact

- **Affected specs**: 
  - 修改 `skill-migration` 能力规范（如果存在）
  - 新增 `skill-batch-migration` 能力规范
  
- **Affected code**: 
  - `admin/backend`: 新增批量迁移服务，集成 AI 生成功能
  - `admin/frontend`: 新增批量迁移管理界面（可选）
  - `main/backend`: 更新技能查询逻辑，移除对旧格式的支持
  - 数据库：删除或标记旧技能数据
  
- **Affected data**: 
  - `skill_definitions` 表中的所有旧技能将被删除
  - `character_skill_bindings` 表中的绑定需要迁移到新技能
  - 可能需要备份旧数据
