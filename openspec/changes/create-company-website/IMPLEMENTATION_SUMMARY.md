## 技术实现

### 前端技术栈
- **框架**: React 18 + TypeScript
- **样式**: Tailwind CSS
- **动画**: Framer Motion
- **SEO**: React Helmet Async
- **路由**: 基于路径检测的自定义路由

### 后端技术栈
- **框架**: Spring Boot 3.2.0
- **语言**: Java 17
- **验证**: Jakarta Validation
- **邮件**: Spring Mail
