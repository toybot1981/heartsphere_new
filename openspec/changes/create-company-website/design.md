# Design: 公司官网设计与架构

## Context

泰安正心智能科技有限公司需要一个官方官方网站，要求：
- 保持科技感，又要有一定温度
- 解释正心的理念（来自《大学》八条目，承上启下的作用）
- 重点介绍核心产品"心域"（HeartSphere）
- 提供一些图文展示
- 展示AI相关服务能力

## Goals

1. **品牌传达**：通过视觉设计和内容组织，传达"正心"理念和公司价值观
2. **产品展示**：清晰、直观地展示心域产品的核心功能和价值
3. **用户体验**：提供流畅的浏览体验，响应式设计支持多设备访问
4. **技术实现**：基于现有前端技术栈（React + TypeScript + Tailwind CSS），保持代码一致性
5. **可维护性**：模块化设计，便于后续内容更新和功能扩展

## Non-Goals

- 不创建独立的CMS系统（内容通过代码管理，或后续考虑）
- 不实现复杂的用户交互功能（如在线试用、实时聊天等，这些属于产品应用本身）
- 不实现多语言支持（初期仅支持中文）

## Decisions

### 决策1：网站架构
**决定**：作为现有React应用的一部分，使用独立路由前缀（如 `/company`）进行组织。

**理由**：
- 复用现有技术栈和基础设施
- 保持代码库统一，便于维护
- 可以共享组件和工具函数
- 部署简单，无需额外配置

**替代方案**：
- 独立子域名和独立应用：增加部署复杂度，但可以完全独立
- 静态网站生成器（如Next.js）：功能过度，当前需求不需要SSR

### 决策2：视觉设计风格
**决定**：采用现代简约风格，结合以下元素：
- **科技感**：使用渐变、光效、微动画、几何图形
- **温度感**：使用柔和的色彩过渡、圆角设计、人文元素、正心理念的可视化
- **色彩方案**：
  - 主色：深蓝/紫色系（科技感）+ 金色/暖色点缀（温度感）
  - 背景：深色主题为主，配合浅色内容区域
  - 强调色：金色/橙色（代表"正心"的光明与温度）

**理由**：
- 平衡科技感与温度感，符合公司理念
- 深色主题更符合科技公司形象，同时通过暖色点缀增加温度
- 金色可以象征"正心"理念中的光明与智慧

### 决策3：内容组织
**决定**：采用单页应用（SPA）结构，主要页面包括：
1. **首页**：Hero区域 + 核心理念预览 + 产品亮点 + 快速导航
2. **关于我们**：正心理念详解（《大学》八条目图解、正心的承上启下作用）
3. **核心产品**：心域详细介绍（功能模块、使用场景、图文展示、产品截图）
4. **AI服务**：其他AI服务介绍（服务类型、案例展示）
5. **联系我们**：公司信息、联系方式、业务咨询表单

**理由**：
- 清晰的导航结构，便于用户快速找到信息
- 每个页面聚焦一个主题，避免信息过载
- 支持SEO优化（每个页面独立路由和meta信息）

### 决策4：图片资源管理
**决定**：
- 静态资源存放在 `frontend/public/company/` 目录
- 按类型组织：`images/philosophy/`（理念相关）、`images/product/`（产品截图）、`images/company/`（公司相关）
- 支持响应式图片（不同分辨率）

**理由**：
- 便于管理和维护
- 符合现有项目结构
- 支持CDN部署（如果需要）

### 决策5：动画和交互
**决定**：
- 使用轻量级动画库（如 framer-motion）实现页面过渡和元素动画
- 动画原则：微妙、流畅，不干扰内容阅读
- 关键交互：滚动触发动画、悬停效果、页面过渡

**理由**：
- 增强科技感和现代感
- 提升用户体验
- 不过度使用，保持专业形象

### 决策6：后端API需求
**决定**：
- 联系表单提交需要后端API支持
- 其他内容均为静态，无需API
- 联系表单数据存储到数据库，并发送通知邮件（可选）

**理由**：
- 最小化后端复杂度
- 联系表单是唯一需要动态交互的功能
- 便于后续扩展（如内容管理、访问统计等）

## Risks / Trade-offs

### 风险1：内容更新需要代码部署
**风险**：每次内容更新需要重新部署代码，不够灵活。

**缓解措施**：
- 初期内容相对稳定，更新频率不高
- 后续可以考虑引入简单的CMS或配置文件管理内容
- 将内容与代码分离（如使用JSON配置文件）

### 风险2：SEO优化
**风险**：SPA应用对SEO不够友好。

**缓解措施**：
- 使用React Helmet管理meta标签
- 添加结构化数据（JSON-LD）
- 考虑后续引入SSR（如Next.js）如果需要更好的SEO

### 风险3：视觉设计实现复杂度
**风险**：科技感与温度感的平衡需要精细的设计和实现。

**缓解措施**：
- 参考优秀科技公司官网设计
- 使用设计系统（Tailwind CSS + 自定义组件）
- 迭代优化，先实现基础版本，再逐步完善视觉效果
