# Change: 日常生活助手角色技能测试计划

## Why

当前系统为6个日常生活助手角色（时小光、康小健、学小知、心小暖、心小安、暖小阳）共配置了48个技能，这些技能是系统的核心功能之一。为了确保技能系统正常工作，需要制定系统化的测试计划，验证：

1. 技能是否能被正确激活（通过预设话术或自然对话）
2. 技能执行结果是否符合预期
3. Function Calling 机制是否正常工作
4. 技能在AI回复中的显示是否正确
5. 用户体验是否流畅

## What Changes

- **新增**: 创建完整的技能测试计划，覆盖6个角色、48个技能
- **新增**: 实现自动化测试脚本，支持批量测试
- **新增**: 实现测试数据收集和报告生成机制
- **新增**: 创建详细的测试报告模板，包含测试结果、问题分析、改进建议

## Impact

- **Affected specs**: 新增 `skill-testing` 能力规范
- **Affected code**: 
  - `docs/13-测试/` - 新增测试计划和报告文档
  - `scripts/test-skills/` - 新增测试脚本
  - 可能需要修改前端日志输出以支持测试数据收集
