# Spec Delta: 完成剩余组件的主题迁移

## ADDED Requirements

### Requirement: 所有 PC 端组件必须支持主题切换

所有 PC 端组件（包括页面、模态框、辅助组件）SHALL 使用 CSS 变量而非硬编码颜色，确保在主题切换时能够正确更新样式。

#### Scenario: 用户切换主题时，所有 PC 端组件正确更新
- **Given**: 用户已登录，当前使用"科技风格"主题
- **When**: 用户在设置中切换到"海天宁静"主题
- **Then**: 
  - 所有 PC 端组件（包括模态框、页面、辅助组件）的背景色、文字颜色、边框颜色等都应更新为"海天宁静"主题的样式
  - 主题切换应即时生效，无需刷新页面
  - 所有组件应保持功能正常，无视觉错误

#### Scenario: 新添加的组件自动支持主题切换
- **Given**: 开发人员添加了一个新的 PC 端组件
- **When**: 组件使用 CSS 变量而非硬编码颜色
- **Then**: 
  - 组件在不同主题下正确显示
  - 主题切换时组件样式正确更新

### Requirement: 所有移动端组件必须支持主题切换

所有移动端组件（包括页面、模态框、基础组件）SHALL 使用 CSS 变量而非硬编码颜色，确保在主题切换时能够正确更新样式。移动端组件 SHALL 优先使用移动端专用变量。

#### Scenario: 用户切换主题时，所有移动端组件正确更新
- **Given**: 移动端用户已登录，当前使用"科技风格"主题
- **When**: 用户在移动端设置中切换到"海天宁静"主题
- **Then**: 
  - 所有移动端组件（包括页面、模态框、基础组件）的背景色、文字颜色、边框颜色等都应更新为"海天宁静"主题的样式
  - 移动端特殊效果（云纹背景、星空背景等）应正确应用
  - 主题切换应即时生效，无需刷新页面
  - 所有组件应保持功能正常，无视觉错误

### Requirement: 组件迁移必须遵循统一的迁移模式

组件迁移时 SHALL 遵循统一的迁移模式，使用标准的 CSS 变量命名和替换规则，确保代码一致性和可维护性。

#### Scenario: 开发人员迁移组件时使用标准模式
- **Given**: 开发人员需要迁移一个使用硬编码颜色的组件
- **When**: 开发人员按照迁移模式进行迁移
- **Then**: 
  - 背景色使用 `var(--bg-primary)`, `var(--bg-card)` 等变量
  - 文字颜色使用 `var(--text-primary)`, `var(--text-secondary)` 等变量
  - 边框颜色使用 `var(--bg-overlay)` 等变量
  - 悬停效果使用 `onMouseEnter/onMouseLeave` 实现
  - 移动端组件使用移动端专用变量

### Requirement: 迁移后的组件必须保持向后兼容

迁移后的组件 SHALL 在默认的"科技风格"主题下正常显示，确保现有用户不受影响，所有功能正常工作。

#### Scenario: 迁移后的组件在默认主题下正常显示
- **Given**: 组件已迁移到主题系统
- **When**: 用户使用默认的"科技风格"主题
- **Then**: 
  - 组件显示效果与迁移前一致
  - 所有功能正常工作
  - 无视觉错误或样式问题

### Requirement: 迁移后的组件必须符合可访问性标准

迁移后的组件 SHALL 确保文字与背景的对比度符合 WCAG AA 标准，在所有主题下都保持良好的可读性。

#### Scenario: 检查颜色对比度
- **Given**: 组件已迁移到主题系统
- **When**: 检查文字与背景的对比度
- **Then**: 
  - 所有文字与背景的对比度至少达到 WCAG AA 标准（4.5:1）
  - 大文本（18px 以上）的对比度至少达到 3:1
  - 在"科技风格"和"海天宁静"两个主题下都符合标准

## MODIFIED Requirements

### Requirement: 主题系统覆盖范围扩展（从部分组件扩展到所有组件）

主题系统的覆盖范围 SHALL 从部分组件扩展到所有组件，确保整个应用都支持主题切换，提供一致的用户体验。

#### Scenario: 主题系统覆盖所有组件
- **Given**: 主题系统基础设施已建立，部分组件已迁移
- **When**: 完成所有剩余组件的迁移
- **Then**: 
  - 所有 PC 端组件都支持主题切换
  - 所有移动端组件都支持主题切换
  - 主题切换时，整个应用的所有组件都正确更新
  - 无遗漏的硬编码颜色（除语义色和动态颜色外）

## Notes

- 本变更是对 `add-theme-skin-management-system` 的延续和完成
- 迁移工作应分阶段进行，优先核心功能组件
- 每个阶段完成后应进行测试验证
- 迁移过程中应保持代码质量和向后兼容性
