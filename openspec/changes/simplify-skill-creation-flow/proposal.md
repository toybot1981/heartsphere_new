# Change: 简化技能创建流程

## Why

当前的专业 Skill Creator 工具虽然功能完善，但存在以下问题：

1. **流程过于复杂** - 需要经过8个步骤（模板选择、基础信息、元数据配置、指令编写、MCP工具配置、执行配置、资源管理、预览验证），对于简单技能来说过于繁琐
2. **学习成本高** - 用户需要了解每个字段的含义和填写要求，对于新手不够友好
3. **缺乏AI辅助** - 虽然提供了模板，但无法根据用户描述自动生成技能内容，类似 Claude 的 skill-creator 体验
4. **文件导入缺失** - 无法直接导入已有的 skill.md 文件，需要手动重新输入

参考 Claude 官方的 skill-creator 工具，我们需要提供三种创建方式，按优先级排序：
1. **AI自动生成**（首选）- 用户输入描述，AI自动生成完整的技能定义
2. **文件导入**（次选）- 上传 skill.md 文件或直接粘贴 md 内容，自动解析并填充表单
3. **手动编辑**（最后）- 保留现有的分步骤编辑能力，但提供更好的 placeholder 和提示

## What Changes

- **新增AI生成模式** - 用户输入自然语言描述，调用AI服务生成完整的技能定义（包括基础信息、指令、MCP配置等）
- **新增文件导入功能** - 支持上传 skill.md 文件或直接粘贴 md 内容，自动解析 YAML 元数据和 Markdown 指令内容
- **优化手动编辑模式** - 改进现有分步骤表单，为每个字段提供更详细的 placeholder 和示例
- **统一入口界面** - 创建统一的入口界面，让用户选择创建方式（AI生成/文件导入/手动编辑）
- **智能填充** - AI生成和文件导入后，允许用户进一步编辑和完善

## Impact

- **Affected specs**: 
  - `skill-creation` (已存在，需要扩展)
  
- **Affected code**: 
  - `admin/backend`: 新增 AI 生成服务、文件解析服务，扩展 SkillCreatorService
  - `admin/frontend`: 重构 SkillCreator 组件，新增创建方式选择界面、AI生成界面、文件上传界面
  - `main/backend`: 可能需要调用 AI 服务接口（如果 admin 模块无法直接访问）
