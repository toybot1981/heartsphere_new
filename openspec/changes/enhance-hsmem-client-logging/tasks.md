# Tasks: 增强 HSMemClientService 日志记录

## 阶段 1: 日志工具类实现

- [ ] 1.1 创建日志工具类 `HSMemLogHelper`
  - 提供 `logRequest()` 方法：记录请求开始日志
  - 提供 `logResponse()` 方法：记录响应日志
  - 提供 `logError()` 方法：记录错误日志
  - 提供 `logPerformance()` 方法：记录性能日志
  - 提供 `generateRequestId()` 方法：生成请求ID

- [ ] 1.2 创建敏感信息脱敏工具类 `LogSanitizer`
  - 实现 `sanitizeApiKey()` - API密钥脱敏
  - 实现 `sanitizeToken()` - Token脱敏
  - 实现 `sanitizeText()` - 长文本截断和摘要
  - 实现 `sanitizeRequest()` - 请求参数脱敏
  - 实现 `sanitizeResponse()` - 响应体脱敏

- [ ] 1.3 创建性能监控工具类 `PerformanceLogger`
  - 提供 `startTimer()` 方法：开始计时
  - 提供 `endTimer()` 方法：结束计时并记录耗时
  - 提供 `isSlowRequest()` 方法：判断是否为慢请求
  - 支持统计信息记录（请求总数、成功数、失败数、平均耗时等）

- [ ] 1.4 编写工具类单元测试

  - 测试敏感信息脱敏
  - 测试请求ID生成
