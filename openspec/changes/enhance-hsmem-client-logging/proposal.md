# Change: 增强 HSMemClientService 日志记录

## Why

`HSMemClientService` 是 backend 调用 hsmem Python 服务的核心组件，负责所有记忆服务的底层操作。当前可能存在以下问题：

1. **日志不够详细**：缺少请求/响应的详细信息，难以追踪问题
2. **错误信息不完整**：错误发生时缺少足够的上下文信息，难以定位问题根源
3. **性能监控缺失**：没有记录请求耗时，难以识别性能瓶颈
4. **调试困难**：缺少关键操作的日志记录，排查问题需要额外的调试工具

为了便于运维和问题排查，需要：

1. **详细记录请求信息**：包括请求URL、方法、参数、用户ID等
2. **详细记录响应信息**：包括响应状态、响应体摘要、处理结果等
3. **完整记录错误信息**：包括异常堆栈、错误详情、请求上下文等
4. **记录性能指标**：包括请求耗时、重试次数等
5. **结构化日志**：使用统一的日志格式，便于日志分析和查询

## What Changes

### 日志记录增强

- **ADDED**: 请求日志记录
  - 记录请求URL、HTTP方法、请求头（脱敏后）
  - 记录请求参数摘要（包含用户ID、消息数量、文本长度等，避免记录完整内容）
  - 记录请求开始时间

- **ADDED**: 响应日志记录
  - 记录响应状态码、响应时间
  - 记录响应体摘要（resource_id、items_count、categories等）
  - 记录处理结果（成功/失败）

- **ADDED**: 错误日志记录
  - 记录异常类型和消息
  - 记录异常堆栈（仅DEBUG级别，生产环境可配置）
  - 记录请求上下文（URL、方法、参数摘要）
  - 记录重试信息（如果实现重试机制）

- **ADDED**: 性能日志记录
  - 记录每个请求的处理耗时
  - 记录慢请求（超过阈值的请求）
  - 记录统计信息（请求总数、成功数、失败数、平均耗时等）

- **ADDED**: 日志级别配置
  - INFO级别：记录关键操作和错误
  - DEBUG级别：记录详细的请求/响应内容
  - TRACE级别：记录最详细的信息（包括完整请求体和响应体）

### 日志格式优化

- **MODIFIED**: 统一日志格式
  - 使用统一的日志前缀（如 `[HSMemClient]`）
  - 包含请求ID（用于追踪单个请求的完整流程）
  - 使用结构化日志格式（便于日志分析工具解析）

- **ADDED**: 敏感信息脱敏
  - 对API密钥、Token等敏感信息进行脱敏
  - 对长文本内容进行截断（仅记录摘要）

## Impact

### 受影响的后端代码

- `main/backend/src/main/java/com/heartsphere/memory/service/HSMemClientService.java` - 新增详细的日志记录
  - 在方法入口记录请求日志
  - 在方法返回前记录响应日志
  - 在异常捕获中记录错误日志
  - 在方法执行前后记录性能日志

- `main/backend/src/main/resources/application.yml` - 新增日志级别配置
  - 添加 `com.heartsphere.memory.service.HSMemClientService` 的日志级别配置
  - 支持通过环境变量或配置文件调整日志级别

### 日志输出

- **控制台日志**：开发环境显示详细日志
- **文件日志**：生产环境记录到日志文件（根据现有日志配置）
- **日志聚合**：支持通过日志分析工具查询和分析

### 需要创建的规范

- HSMemClientService 日志记录规范
- 日志格式和级别规范
- 敏感信息脱敏规范

## Benefits

1. **问题排查**：详细的日志帮助快速定位问题
2. **性能监控**：通过耗时日志识别性能瓶颈
3. **运维支持**：清晰的日志便于运维人员监控系统状态
4. **审计追踪**：完整的操作日志便于审计和追溯
5. **调试效率**：详细的日志减少调试时间

## Risks

1. **日志量增加**：详细的日志可能产生大量日志文件，需要合理配置日志轮转和清理策略
2. **性能影响**：日志记录可能带来少量性能开销（可通过异步日志缓解）
3. **敏感信息泄露**：需要确保敏感信息脱敏策略正确实施

## Dependencies

- 需要确保日志框架（SLF4J + Logback）正常配置
- 需要确保日志配置文件支持新的日志级别
- 如果使用日志聚合工具，需要确保日志格式兼容
