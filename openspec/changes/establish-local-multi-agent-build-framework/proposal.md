# Change: Establish Local Multi-Agent Build Framework

## Why

当前项目完全基于大模型构建，存在以下问题：

1. **构建依赖外部服务**：构建过程依赖在线大模型服务，无法在离线或网络不稳定环境下可靠构建
2. **缺乏本地开发工具链**：没有统一的本地开发、构建、测试工具链，各模块构建方式分散
3. **多智能体支持不足**：虽然已有 AgentScope 集成，但缺乏统一的本地多智能体开发、测试、调试框架
4. **构建可靠性差**：依赖外部 API 导致构建不稳定，难以进行持续集成和自动化测试
5. **开发效率低**：缺乏本地模拟和测试环境，每次测试都需要调用真实的大模型 API，成本高且速度慢

**目标**：
- 建立完全本地化的构建和开发环境，减少对外部服务的依赖
- 提供统一的多智能体项目支持框架，支持本地开发、测试、调试
- 实现可靠的构建流程，支持离线构建和持续集成
- 提供本地模拟和测试工具，降低开发成本和提升开发效率

## What Changes

### 核心变更

- **ADDED**: 本地构建系统 (`local-build-system`)
  - 统一的构建脚本和工具链
  - 本地依赖管理（Maven 本地仓库、npm 本地缓存）
  - 离线构建支持
  - 多模块并行构建优化
  - 构建缓存和增量构建

- **ADDED**: 多智能体开发框架 (`multi-agent-framework`)
  - 本地智能体模拟器（Mock Agent）
  - 智能体编排和协作框架
  - 本地测试和调试工具
  - 智能体状态管理和持久化
  - 智能体间通信机制

- **ADDED**: 开发工具链 (`development-tooling`)
  - 本地开发环境一键启动脚本
  - 依赖检查和环境验证工具
  - 代码生成和脚手架工具
  - 本地文档生成和查看工具
  - 开发调试工具集

- **MODIFIED**: 现有构建脚本优化
  - 统一各模块的构建方式
  - 添加构建缓存机制
  - 优化构建性能
  - 增强错误处理和日志输出

- **ADDED**: 本地测试框架
  - 智能体单元测试框架
  - 集成测试环境（不依赖外部 API）
  - Mock 大模型服务
  - 测试数据管理

### 架构调整

**现有架构**（依赖外部服务）：
```
开发环境
  ├── 构建脚本（分散在各模块）
  ├── 依赖外部 API（大模型服务）
  ├── 测试需要真实 API 调用
  └── 构建不稳定（网络依赖）
```

**新架构**（本地化构建）：
```
本地开发环境
  ├── 统一构建系统
  │   ├── 本地依赖管理
  │   ├── 离线构建支持
  │   └── 构建缓存
  ├── 多智能体框架
  │   ├── 本地智能体模拟器
  │   ├── 智能体编排工具
  │   └── 本地测试框架
  ├── 开发工具链
  │   ├── 环境检查工具
  │   ├── 代码生成工具
  │   └── 调试工具
  └── Mock 服务
      ├── Mock 大模型服务
      └── Mock 外部 API
```

## Non-Breaking Changes

### 兼容性考虑

1. **向后兼容**：
   - 现有构建脚本和流程保持不变
   - 新工具为可选使用，不影响现有工作流
   - 可以逐步迁移到新的构建系统

2. **渐进式迁移**：
   - 新工具与现有工具并行存在
   - 团队可以逐步采用新工具
   - 支持混合使用（部分模块使用新工具，部分保持原样）

3. **配置兼容**：
   - 现有配置文件保持不变
   - 新配置为可选添加
   - 支持环境变量覆盖

## Risks and Mitigations

### 技术风险

1. **工具复杂度**：
   - **风险**：新工具链可能增加学习成本
   - **缓解**：提供详细文档和示例，逐步引入

2. **维护成本**：
   - **风险**：需要维护额外的工具和脚本
   - **缓解**：工具设计简单易用，自动化程度高

3. **Mock 准确性**：
   - **风险**：Mock 服务可能与真实服务有差异
   - **缓解**：定期更新 Mock 服务，保持与真实服务一致

### 业务风险

1. **开发习惯改变**：
   - **风险**：团队需要适应新的开发流程
   - **缓解**：提供培训和迁移指南，支持渐进式迁移

2. **工具稳定性**：
   - **风险**：新工具可能存在未知问题
   - **缓解**：充分测试，保留现有工具作为备选
