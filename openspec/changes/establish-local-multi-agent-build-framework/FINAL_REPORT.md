## 使用指南

### 快速开始

```bash
# 1. 设置本地环境
./scripts/dev/setup-local-env.sh

# 2. 检查环境
./scripts/dev/check-env.sh

# 3. 构建所有模块
./scripts/build/build-all.sh

# 4. 构建单个模块
./scripts/build/build-module.sh main

# 5. 清理缓存
./scripts/build/cache-clean.sh --expired
```
