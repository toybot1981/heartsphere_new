   - 添加了新的标签页和UI组件
   - 添加了详情对话框

### 功能特性

1. **三层架构展示**
   - Resource Layer: 展示原始资源数据
   - Memory Item Layer: 展示提取的记忆项
   - Memory Category Layer: 展示记忆分类

2. **完整追溯链**
   - 资源 → 记忆项：通过 `resource_id` 关联
   - 记忆项 → 分类：通过 `categories` 字段关联
   - 分类 → 记忆项：通过分类详情查看包含的记忆项

3. **数据过滤和关联**
   - 按用户ID查询记忆项（通过API参数）
   - 通过记忆项的 `resource_id` 过滤关联的资源
   - 通过记忆项的 `categories` 过滤关联的分类
