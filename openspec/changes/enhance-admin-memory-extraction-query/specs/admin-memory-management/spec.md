## MODIFIED Requirements

### Requirement: Admin用户记忆管理
Admin用户记忆管理功能SHALL支持通过hsmem API进行记忆查询和删除操作，并SHALL提供记忆提取追溯功能，允许管理员查看用户记忆的三层架构（Resource Layer → Memory Item Layer → Memory Category Layer）的完整信息。

#### Scenario: 通过HSMem查询记忆
- **WHEN** admin用户在用户记忆管理页面
- **THEN** 可以输入查询条件
- **AND** 调用hsmem检索API查询记忆
- **AND** 显示查询结果列表

#### Scenario: 通过HSMem删除记忆
- **WHEN** admin用户在用户记忆管理页面选择记忆项
- **THEN** 可以删除选中的记忆项
- **AND** 调用hsmem删除接口（如果存在）或标记删除
- **AND** 更新列表显示

#### Scenario: 查看用户记忆提取追溯
- **WHEN** admin用户在用户记忆管理页面选择"记忆提取追溯"标签页
- **AND** 输入或选择用户ID
- **THEN** 系统显示该用户的所有原始资源（Resource Layer）
- **AND** 显示从这些资源中提取的记忆项（Memory Item Layer）
- **AND** 显示记忆项所属的分类（Memory Category Layer）
- **AND** 提供资源→记忆项→分类的完整追溯链展示

#### Scenario: 查看资源详情
- **WHEN** admin用户在记忆提取追溯页面点击某个资源
- **THEN** 系统显示资源详情对话框
- **AND** 显示资源的完整原始数据（对话消息、文本内容、文档内容等）
- **AND** 显示资源的模态类型、创建时间、元数据等信息
- **AND** 显示从该资源提取出的所有记忆项列表（可点击跳转）

#### Scenario: 查看记忆项详情
- **WHEN** admin用户在记忆提取追溯页面点击某个记忆项
- **THEN** 系统显示记忆项详情对话框
- **AND** 显示记忆项的完整内容、摘要、类型、分类、重要性等信息
- **AND** 显示记忆项关联的原始资源（可点击跳转）
- **AND** 显示记忆项所属的所有分类（可点击跳转）

#### Scenario: 查看分类详情
- **WHEN** admin用户在记忆提取追溯页面点击某个分类
- **THEN** 系统显示分类详情对话框
- **AND** 显示分类的名称、摘要、描述等信息
- **AND** 显示该分类下的所有记忆项列表（可点击查看详情）
- **AND** 显示分类的创建时间、更新时间、版本等信息

#### Scenario: 查看记忆提取统计
- **WHEN** admin用户在记忆提取追溯页面选择用户ID
- **THEN** 系统显示该用户的记忆提取统计信息
- **AND** 包括资源总数、记忆项总数、分类总数
- **AND** 显示记忆提取的时间分布
- **AND** 显示记忆类型分布（偏好、习惯、个人信息等）
- **AND** 显示分类分布统计

#### Scenario: 追溯链导航
- **WHEN** admin用户在资源详情中点击关联的记忆项
- **THEN** 系统跳转到该记忆项的详情页面
- **AND** 在记忆项详情中可以继续点击查看关联的分类
- **AND** 在分类详情中可以查看包含的所有记忆项
- **AND** 提供返回上一级的导航功能

## ADDED Requirements

### Requirement: 用户记忆提取追溯功能
Admin记忆管理模块SHALL提供用户记忆提取追溯功能，允许管理员查看用户记忆的三层架构（Resource Layer → Memory Item Layer → Memory Category Layer）的完整信息和追溯关系。

#### Scenario: 访问记忆提取追溯页面
- **WHEN** admin用户访问用户记忆管理页面
- **THEN** 可以看到"记忆提取追溯"标签页
- **AND** 点击该标签页可以进入记忆提取追溯视图

#### Scenario: 按用户ID查询记忆提取
- **WHEN** admin用户在记忆提取追溯页面输入用户ID
- **AND** 点击"查询"按钮
- **THEN** 系统调用hsmem API查询该用户的所有资源
- **AND** 系统调用hsmem API查询该用户的所有记忆项
- **AND** 系统调用hsmem API查询相关的分类信息
- **AND** 显示查询结果，包括资源列表、记忆项列表、分类列表

#### Scenario: 资源列表展示
- **WHEN** admin用户在记忆提取追溯页面查询用户记忆
- **THEN** 系统显示资源列表
- **AND** 每个资源项显示：资源ID、模态类型（对话/文本/文档）、创建时间
- **AND** 每个资源项可以点击查看详情
- **AND** 显示从该资源提取出的记忆项数量

#### Scenario: 记忆项列表展示
- **WHEN** admin用户在记忆提取追溯页面查询用户记忆
- **THEN** 系统显示记忆项列表
- **AND** 每个记忆项显示：记忆项ID、摘要、类型、分类、重要性、创建时间
- **AND** 每个记忆项可以点击查看详情
- **AND** 显示该记忆项关联的资源ID（可点击跳转）

#### Scenario: 分类列表展示
- **WHEN** admin用户在记忆提取追溯页面查询用户记忆
- **THEN** 系统显示分类列表
- **AND** 每个分类显示：分类名称、摘要、包含的记忆项数量、创建时间
- **AND** 每个分类可以点击查看详情
- **AND** 显示该分类包含的所有记忆项ID（可点击跳转）

#### Scenario: 记忆提取统计展示
- **WHEN** admin用户在记忆提取追溯页面查询用户记忆
- **THEN** 系统显示记忆提取统计卡片
- **AND** 显示资源总数、记忆项总数、分类总数
- **AND** 显示记忆提取的时间分布（可选，如果数据支持）
- **AND** 显示记忆类型分布（偏好、习惯、个人信息等）
- **AND** 显示分类分布统计

#### Scenario: 空状态处理
- **WHEN** admin用户在记忆提取追溯页面查询用户ID
- **AND** 该用户没有任何记忆数据
- **THEN** 系统显示友好的空状态提示
- **AND** 提示该用户暂无记忆提取记录

#### Scenario: 加载状态处理
- **WHEN** admin用户在记忆提取追溯页面点击查询
- **THEN** 系统显示加载状态指示器
- **AND** 在数据加载完成后隐藏加载状态
- **AND** 如果加载失败，显示错误提示信息
