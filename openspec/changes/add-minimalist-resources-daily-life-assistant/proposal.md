# Change: Add Minimalist Resources for Daily Life Assistant Scenario

## Why

日常生活助手场景和其6个角色目前使用的是占位符资源（placeholder://），需要为这些角色添加实际的图片资源。根据用户需求，这些资源应采用极简主义风格，以体现现代、干净、功能性的设计理念。

## What Changes

- **ADDED**: 为"日常生活助手"时代表添加极简主义风格的场景资源
- **ADDED**: 为6个日常生活助手角色添加极简主义风格的头像和背景资源：
  1. 时小光 - 时间管理导师（头像 + 效率工作室背景）
  2. 康小健 - 健康生活顾问（头像 + 健康生活馆背景）
  3. 学小知 - 学习成长导师（头像 + 智慧书房背景）
  4. 心小暖 - 情绪陪伴师（头像 + 温暖小屋背景）
  5. 心小安 - 心理健康守护者（头像 + 心理健康中心背景）
  6. 暖小阳 - 情感陪伴伙伴（头像 + 阳光客厅背景）

## Impact

- **Affected specs**: 资源管理能力（新增资源）
- **Affected code**: 
  - `main/backend/src/main/resources/db/migration/` - 新增资源迁移脚本
  - `system_resources` 表 - 新增资源记录
- **Database**: 
  - 新增 1 个时代表资源（era 类别）
  - 新增 6 个角色头像资源（character/avatar 类别）
  - 新增 6 个角色背景资源（character 类别）

## Design Principles

1. **极简主义风格**:
   - 简洁的线条和形状
   - 干净的配色方案（浅色、柔和色调）
   - 最少的装饰元素
   - 功能性优先
   - 现代感和专业感

2. **资源要求**:
   - 头像：简洁、友好、符合角色特征
   - 背景：与角色场景描述一致，极简风格
   - 时代表：体现生活助手场景的特色
