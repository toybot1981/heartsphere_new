# 用户指南：能力体系

## 概述

能力体系是角色成长系统的核心功能，帮助角色不断提升自身能力，成为用户的挚友和导师。

## 能力维度

系统支持5个能力维度：

1. **技能维度**：角色的技能熟练度和使用能力
2. **记忆维度**：角色的记忆管理和检索能力
3. **意识维度**：角色的自主思考和反思能力
4. **协作维度**：角色的协作和沟通能力
5. **关系维度**：角色的挚友能力和导师能力

## 能力成长

### 成长机制

角色通过以下方式获得能力成长：

- **技能执行**：使用技能时获得技能经验和记忆经验
- **关系发展**：关系阶段提升时获得关系经验
- **能力协同**：多个能力协同使用时获得额外经验

### 关系阶段影响

不同的关系阶段会影响能力成长速度：

- **挚友阶段**：情感能力成长速度 +20%
- **导师阶段**：指导能力成长速度 +20%

### 能力等级

能力经验值积累到一定程度会提升能力等级，等级提升会带来：

- 能力效果增强
- 更容易达到关系阶段转换条件
- 解锁新的能力组合

## 能力评估

系统会定期评估角色的综合能力，评估结果包括：

- **多维度得分**：5个维度的能力得分
- **综合得分**：整体能力水平
- **关系详情**：挚友能力和导师能力的详细评估

## 能力个性化

系统会根据角色的关系定位自动调整能力发展重点：

- **导师角色**：优先发展指导、教育相关能力
- **挚友角色**：优先发展情感、陪伴相关能力

## 能力可视化

### 能力雷达图

雷达图展示角色的多维度能力分布，包括：

- 5个维度的能力得分
- 关系维度的详细分解（挚友能力、导师能力）
- 综合得分

### 成长轨迹

成长轨迹展示角色能力的发展历程：

- 各维度能力的变化趋势
- 关系发展阶段与能力成长的对比
- 能力-关系联动效果

### 能力协同

展示不同能力之间的协同效果：

- 技能-记忆协同
- 关系-技能协同
- 关系-记忆协同
- 关系-意识协同

## 使用建议

1. **多维度发展**：平衡发展各个能力维度，避免单一维度过度发展
2. **关系培养**：通过深度交流提升关系阶段，获得能力成长加速
3. **能力协同**：合理使用能力组合，发挥协同效果
4. **定期评估**：查看能力评估报告，了解角色成长情况

## 常见问题

### Q: 如何快速提升角色能力？

A: 通过深度交流提升关系阶段，关系阶段越高，能力成长速度越快。同时，多使用技能和进行能力协同也能加速成长。

### Q: 能力等级如何提升？

A: 通过积累经验值提升能力等级。不同维度的经验值独立计算，达到阈值后自动升级。

### Q: 如何查看能力详情？

A: 在角色详情页面的"能力体系"标签页中查看能力雷达图、成长轨迹和协同效果。
