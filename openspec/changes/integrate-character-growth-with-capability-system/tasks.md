## 整合说明

### 整合方式

1. **保留现有功能**：不破坏已实现的系统，在其基础上扩展
2. **整合到能力体系**：将导师/挚友能力纳入统一的能力体系
3. **统一实现机制**：统一能力成长、评估、协同机制
4. **能力-关系联动**：实现能力成长与关系发展相互促进

### 数据同步

- 定期同步现有关系数据到能力体系（如每天同步一次）
- 提供数据一致性检查工具
- 支持手动触发数据同步

### 向后兼容

- 保持现有API兼容性
- 现有功能继续工作
- 新功能作为扩展，不影响现有功能
