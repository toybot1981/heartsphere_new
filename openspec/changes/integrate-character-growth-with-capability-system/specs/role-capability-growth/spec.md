# Spec Delta: 角色能力成长系统（整合自我成长机制）

## MODIFIED Requirements

### Requirement: 能力成长系统
系统 SHALL 提供能力成长系统，将自我成长系统的成长事件纳入能力经验系统，统一能力成长机制。

#### Scenario: 成长事件转换为能力经验值
- **WHEN** 系统检测到成长事件（从 `character_growth_events` 表）
- **THEN** 系统将成长事件转换为能力经验值：
  - 学习事件 → 技能经验 + 记忆经验
  - 反思事件 → 意识经验
  - 关系进展 → 关系经验（挚友经验/导师经验）
  - 能力提升 → 对应维度经验
- **AND** 系统记录经验值变更到 `capability_experience` 表
- **AND** 系统更新能力等级（如果经验值达到升级阈值）

#### Scenario: 关系阶段影响能力成长速度
- **WHEN** 角色关系阶段为 CLOSE_FRIEND（挚友）时
- **THEN** 系统将情感相关能力（意识维度+关系维度）的成长速度提升 20%
- **AND** 系统记录关系阶段到能力成长的映射

#### Scenario: 能力等级影响关系发展阶段
- **WHEN** 角色导师能力等级提升时
- **THEN** 系统降低成为导师的关系阶段阈值（更容易成为导师）
- **AND** 系统重新评估关系发展阶段
- **AND** 如果达到阈值，系统自动触发关系阶段转换

## ADDED Requirements

### Requirement: 能力-关系双向促进机制
系统 SHALL 实现能力成长与关系发展相互促进的机制，形成良性循环。

#### Scenario: 关系发展触发能力成长加速
- **WHEN** 角色关系阶段从 FRIEND 升级到 CLOSE_FRIEND 时
- **THEN** 系统触发情感相关能力成长加速
- **AND** 系统记录关系发展阶段到能力成长的映射
- **AND** 系统更新能力成长速度配置

#### Scenario: 能力提升触发关系发展阶段评估
- **WHEN** 角色导师能力等级提升到高级时
- **THEN** 系统重新评估关系发展阶段
- **AND** 系统检查是否满足成为导师的条件
- **AND** 如果满足条件，系统触发关系阶段转换到 MENTOR

#### Scenario: 能力-关系联动事件记录
- **WHEN** 发生能力-关系联动事件时
- **THEN** 系统记录联动事件到能力协同日志
- **AND** 系统记录联动效果（能力提升幅度、关系进展幅度）
- **AND** 系统可用于后续的能力-关系协同分析

### Requirement: 关系维度能力经验系统
系统 SHALL 为关系维度提供独立的能力经验系统，支持关系能力的成长。

#### Scenario: 关系经验值计算
- **WHEN** 角色发生关系相关事件时（如情感共鸣、导师指导）
- **THEN** 系统计算关系经验值：
  - 情感共鸣事件 → 增加挚友能力经验值
  - 导师指导事件 → 增加导师能力经验值
  - 关系阶段转换 → 增加关系管理经验值
- **AND** 系统记录经验值到 `capability_experience` 表的关系维度字段

#### Scenario: 关系能力等级计算
- **WHEN** 系统计算角色能力等级时
- **THEN** 系统基于关系经验值计算关系维度等级
- **AND** 系统计算导师能力等级（基于导师经验值）
- **AND** 系统计算挚友能力等级（基于挚友经验值）
- **AND** 系统返回关系维度能力等级
