# Design: Enhance Company Website Tech Style

## Context

公司官网已完成扁平化设计和UX优化，现在需要：
- 增强科技感，体现AI技术公司的形象
- 修复核心产品页面底部被遮挡的问题
- 添加心域网站链接，方便用户访问产品

## Goals

1. **增强科技感**：通过视觉元素、动效、配色提升科技感
2. **修复布局问题**：确保所有页面内容完整可见
3. **添加产品链接**：在关键位置添加心域网站链接

## Non-Goals

- 不改变整体扁平化设计风格
- 不进行大规模重构
- 不改变现有功能逻辑

## Decisions

### 决策1：科技感增强方案

**决定**：通过以下方式增强科技感：
- **渐变背景**：在Hero区域和关键区块添加微妙的科技感渐变
- **装饰元素**：添加几何图形、网格背景等科技感装饰
- **微动效**：添加悬停时的微妙动效和光效
- **配色增强**：使用更鲜明的科技蓝和紫色渐变
- **图标和视觉元素**：使用更现代的图标和视觉元素

**理由**：
- 保持扁平化设计的同时增强科技感
- 不过度设计，保持专业和现代感
- 提升品牌形象和用户信任度

### 决策2：布局修复方案

**决定**：修复核心产品页面底部被遮挡问题：
- **增加底部间距**：在ProductPage底部添加足够的padding-bottom
- **检查Footer位置**：确保Footer不会遮挡内容
- **优化滚动体验**：确保用户可以滚动到页面最底部

**理由**：
- 确保所有内容可见
- 提升用户体验
- 符合Web设计最佳实践

### 决策3：产品链接添加方案

**决定**：在以下位置添加心域网站链接：
- **Footer**：在"快速链接"或"联系我们"区域添加"访问心域"链接
- **产品页面**：在ProductShowcase和ProductHighlights组件中添加"立即体验"按钮，链接到 http://heartsphere.cn
- **Hero区域**：在HeroSection的CTA按钮区域添加"体验产品"链接

**理由**：
- 方便用户快速访问产品
- 提升产品转化率
- 增强用户体验

## Design System

### 科技感增强元素

#### 渐变背景
```css
/* Hero区域渐变 */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
/* 或更柔和的版本 */
background: linear-gradient(135deg, #f5f7fa 0%, #c3cfe2 100%);
```

#### 装饰元素
- 几何图形：使用SVG或CSS创建几何装饰
- 网格背景：subtle grid pattern
- 光效：subtle glow effects on hover

#### 微动效
- 悬停时的轻微缩放和阴影变化
- 渐变色的微妙变化
- 图标和按钮的微动效

### 布局修复

#### 页面底部间距
```css
/* ProductPage 底部间距 */
padding-bottom: 4rem; /* 64px */
/* 或使用 min-height 确保内容可见 */
min-height: calc(100vh - footer-height);
```

### 链接样式

#### 产品链接按钮
- 主按钮样式：primary-500背景，白色文字
- 悬停效果：颜色加深，轻微提升
- 图标：添加外部链接图标

- 更新HeroSection，添加科技感渐变和装饰
- 更新关键组件，添加微动效
- 优化配色和视觉层次

### 阶段2：布局修复 (Week 1)
- 修复ProductPage底部间距
- 检查并修复其他页面的布局问题
- 测试滚动体验

### 阶段3：添加产品链接 (Week 1)
- 在Footer添加心域网站链接
- 在产品页面添加"立即体验"按钮
- 在Hero区域添加产品链接

## Risks / Trade-offs

### 风险1：过度设计

**风险**：增强科技感可能导致设计过于复杂。

**缓解措施**：
- 保持简洁，只添加必要的科技感元素
- 使用微妙的渐变和动效
- 保持扁平化设计的核心原则

### 风险2：性能影响

**风险**：添加动效和装饰元素可能影响性能。

**缓解措施**：
- 使用CSS动画而非JavaScript
- 使用transform和opacity进行动画
- 优化图片和资源大小

## Open Questions

3. **外部链接样式**：是否需要特殊的样式来标识外部链接？
