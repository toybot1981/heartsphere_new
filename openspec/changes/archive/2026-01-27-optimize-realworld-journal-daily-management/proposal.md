# Change: 优化现实世界日志功能，便于日常管理

## Why

心域中的「现实世界」将作为用户本地办公的主要载体，承载日志、备忘、邮件管理等能力。当前阶段先不实现备忘与邮件，优先**优化日志（日记）功能**，便于用户在日常工作中快速记录、检索与管理日记条目，提升现实世界作为个人管理中心的可用性。

当前日志具备基础 CRUD、标签、搜索、模板与镜面洞察，但**缺少以日期为核心的快捷筛选**（如今日、本周）、**列表展示与排序**对日常回顾不够友好，**快捷写今日**等高频操作不够顺畅。本变更针对上述痛点做针对性增强，聚焦「日常管理」场景。

## What Changes

- **日期快捷筛选**：
  - 在现实世界日志列表增加「今日」「本周」「本月」等快捷筛选，以及可选日期范围筛选。
  - 与现有关键词搜索、标签筛选并存，可组合使用。

- **列表展示与排序优化**：
  - 支持按日期分组展示（如按日 / 按周），便于按时间回顾。
  - 增加排序选项：按日记日期、按更新时间等，默认按日期倒序。
  - 在条目较多时考虑列表性能（如虚拟滚动或分页），避免卡顿。

- **快捷写今日**：
  - 提供「写今日」等一键入口，快速创建日期为当天的日记。
  - 可选关联模板（如晨间意图、晚间回顾）， prefilled 标题/内容骨架，减少重复操作。

- **模板与创建体验**：
  - 优化模板选择入口与展示，便于在创建/编辑时快速选用。
  - 新建日记时默认 `entryDate` 为当天，与「写今日」体验一致。

- **PC 与 Mobile 一致**：
  - 上述优化在 PC（RealWorldScreen）与 Mobile（MobileRealWorldScreen）上同步落地，交互可依端态适配，能力对齐。

## Impact

- **影响的代码**：
  - `main/frontend/components/RealWorldScreen.tsx`：日期筛选、分组、排序、快捷写今日、模板入口。
  - `main/frontend/mobile/screens/MobileRealWorldScreen.tsx`：同上，移动端适配。
  - `main/frontend/hooks/useJournalHandlers.ts`：若涉及创建默认值、模板逻辑可在此或调用方调整。
  - `main/frontend/utils/journalTemplates.ts`：若新增或调整模板，在此维护。
  - 可能新增 `main/frontend/components/realworld/` 下子组件（如日期筛选条、分组列表），便于复用与维护。

- **影响的文档**：
  - 现实世界 / 日志功能的使用说明（若有），补充日期筛选、快捷写今日、排序等用法。

- **不改变的内容**：
  - 日志后端 API 语义不变；若前端需按日期范围请求，仅在现有 API 上做客户端筛选或与后端约定轻量扩展，不做大规模 API 改造。
  - 备忘、邮件管理等**不在本次范围内**，仅优化日志。

## Notes

- 现实世界作为「本地办公载体」的长期方向（日志 + 备忘 + 邮件）已明确，本变更只做日志优化，为后续扩展打基础。
- 所有新增交互须遵循项目 UX 规范与主题系统，与现有现实世界风格一致。
- 实现时优先采用最小可用方案（如先做前端筛选与排序），再视需要演进服务端支持。
