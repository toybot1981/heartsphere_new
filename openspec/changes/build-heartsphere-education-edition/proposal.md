# Change: Build HeartSphere Education Edition

## Why

当前心域（HeartSphere）系统主要面向成人用户，提供数字生命体交互、场景管理、角色扮演等功能。然而，教育市场对AI学习工具的需求日益增长，特别是针对小学生和中学生的AI教育产品。

**市场需求**：
1. **AI素养教育**：随着AI技术的普及，学生需要从小培养AI素养，了解AI的基本概念和应用
2. **寓教于乐**：传统的教育方式难以吸引学生，需要通过游戏化、场景化的方式激发学习兴趣
3. **个性化学习**：不同年龄段的学生有不同的学习需求，需要分阶段、分层次的教学内容
4. **教学辅助**：教师需要工具来辅助教学、辅导作业、进行心理辅导
5. **家长监管**：家长需要了解孩子的学习进度和AI使用情况

**技术优势**：
- 心域系统已经具备场景管理、角色扮演、AI对话等核心能力
- 可以复用现有的AI服务、用户系统、插件系统等基础设施
- 通过独立部署，可以针对教育场景进行优化和定制

**业务价值**：
- 拓展新的市场领域（K12教育市场）
- 建立教育品牌形象
- 为未来教育产品线奠定基础

## What Changes

### 核心架构变更

- **ADDED**: 独立的教育版前端应用 (`frontend-edu/`)
  - 基于React + TypeScript + Vite构建
  - 独立的UI设计系统，符合儿童友好的视觉风格
  - 支持Web端和移动端（Capacitor）
  - 与主系统前端代码库分离，但可共享公共组件库

- **ADDED**: 独立的教育版后端服务 (`backend-edu/`)
  - 基于Spring Boot 3.2.0 + Java 17
  - 独立的数据模型和业务逻辑
  - 与主系统后端代码库分离，但可共享公共模块（如AI服务、安全模块）
  - 独立的数据库schema或表前缀（如 `edu_*`）

- **ADDED**: 独立的教育版管理后台 (`admin-edu/`)
  - 教师管理界面
  - 学生管理界面
  - 课程内容管理
  - 学习数据分析
  - 家长监管功能

### 功能模块

- **ADDED**: 年龄分级内容系统
  - 小学生版（6-12岁）：简化界面、基础AI概念、趣味场景
  - 中学生版（13-18岁）：进阶AI应用、复杂场景构建、编程思维培养
  - 内容过滤和审核机制，确保适合不同年龄段

- **ADDED**: AI学习工具集
  - AI概念学习：通过对话和互动学习AI基础知识
  - 场景构建工具：可视化场景编辑器，适合学生使用
  - 角色创建工具：简化的角色创建流程，引导式设计
  - AI实验工坊：安全的环境让学生实验AI功能

- **ADDED**: 作业辅导系统
  - 智能作业助手：帮助学生理解题目、提供解题思路
  - 作业检查：语法、数学计算、逻辑检查
  - 学习建议：基于作业情况提供个性化学习建议
  - 防作弊机制：鼓励思考而非直接给答案

- **ADDED**: 心理辅导系统
  - 情感识别：识别学生的情绪状态
  - 心理对话：与AI角色进行心理疏导对话
  - 压力管理：提供压力释放和情绪管理建议
  - 成长记录：记录学生的心理成长轨迹

- **ADDED**: 教师工具集
  - 课程管理：创建和管理教学场景、角色
  - 学生监控：查看学生的学习进度和AI使用情况
  - 作业布置：通过系统布置作业，查看完成情况
  - 教学资源：共享教学场景和角色模板

- **ADDED**: 家长监管系统
  - 学习报告：查看孩子的学习进度和AI使用统计
  - 时间管理：设置使用时长限制
  - 内容过滤：设置允许访问的内容类型
  - 安全监控：监控异常行为和不当内容

### 公共模块复用

- **MODIFIED**: 共享模块设计
  - AI服务模块：复用现有的AI对话、文本生成等服务
  - 用户认证模块：复用JWT认证，但增加教育版特定的角色（学生、教师、家长）
  - 文件存储模块：复用文件上传和存储服务
  - 插件系统：教育版特定的插件（如数学计算插件、英语学习插件）

### 数据隔离

- **ADDED**: 数据隔离机制
  - 教育版数据与主系统数据完全隔离
  - 独立的数据库或表前缀
  - 独立的用户体系（可支持单点登录SSO）
  - 数据备份和恢复策略

## Non-Breaking Changes

这是一个全新的独立系统，与主系统完全分离：

1. **代码隔离**：教育版代码在独立的代码库或目录中，不影响主系统
2. **数据隔离**：使用独立的数据库或schema，数据完全隔离
3. **部署隔离**：独立部署，不影响主系统的运行
4. **API隔离**：独立的API端点（如 `/api/edu/*`），不冲突

**可能的集成点**：
- 单点登录（SSO）：可选，允许用户在主系统和教育版之间切换
- 数据同步：可选，如果需要将教育版数据同步到主系统（如学生长大后迁移到主系统）
