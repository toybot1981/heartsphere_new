# Change: Add One-Click Deployment Pipeline

## Why

当前 DevOps 工作台已经提供了单个脚本的执行能力，包括：
- 代码扫描（ESLint、SonarQube、安全扫描）
- 测试（单元测试、集成测试、E2E测试）
- 构建（全量构建、单模块构建、前端/后端构建）
- 部署（开发环境、生产环境的前端/后端部署）

但是这些脚本目前只能单独执行，存在以下问题：

1. **操作繁琐**：部署一个项目到测试/生产环境需要手动执行多个步骤（扫描 → 测试 → 构建 → 部署），容易遗漏步骤或执行顺序错误
2. **缺乏流程管理**：无法将多个脚本组织成一个完整的部署流程
3. **缺乏可视化**：无法直观看到整个部署流程的执行进度和当前阶段
4. **错误处理不完善**：某个步骤失败后，无法自动回滚或提供清晰的错误信息
5. **缺乏流程模板**：每次部署都需要手动选择和执行各个步骤，无法保存常用流程

**目标**：
- 提供一键部署能力，将安全扫描、代码扫描、测试、构建、部署整合成一个完整的流程
- 支持测试系统和生产系统的完整部署流程
- 实现执行过程的可视化，清晰显示当前执行阶段和进度
- 支持流程模板的保存和复用
- 提供流程执行历史记录和回放功能

## What Changes

### 核心变更

- **ADDED**: 部署流程定义系统
  - 流程模板配置（YAML格式）
  - 流程步骤定义（扫描、测试、构建、部署）
  - 步骤依赖关系管理
  - 条件执行逻辑（如：测试失败则停止部署）

- **ADDED**: 部署流程执行引擎
  - 流程编排和执行
  - 步骤状态管理（待执行、执行中、成功、失败、跳过）
  - 并行/串行执行控制
  - 错误处理和回滚机制

- **ADDED**: 部署流程可视化组件
  - 流程进度可视化（Pipeline视图）
  - 当前阶段高亮显示
  - 步骤状态指示器
  - 实时日志流显示
  - 流程执行时间线

- **ADDED**: 部署流程管理API
  - 流程模板CRUD接口
  - 流程执行接口
  - 流程状态查询接口
  - 流程历史记录接口

- **ADDED**: 预定义流程模板
  - 测试环境完整部署流程（安全扫描 → 代码扫描 → 测试 → 构建 → 部署）
  - 生产环境完整部署流程（安全扫描 → 代码扫描 → 测试 → 构建 → 部署）
  - 快速部署流程（跳过扫描，直接构建 → 部署）
  - 仅扫描流程（安全扫描 → 代码扫描）

### 功能模块

1. **流程模板管理**
   - 创建、编辑、删除流程模板
   - 流程步骤配置（脚本选择、参数设置）
   - 步骤依赖关系配置
   - 条件执行规则配置

2. **流程执行**
   - 一键启动完整部署流程
   - 实时显示执行进度
   - 步骤执行状态更新
   - 错误处理和中断机制

3. **流程可视化**
   - Pipeline视图（类似CI/CD Pipeline）
   - 步骤状态可视化（待执行、执行中、成功、失败）
   - 当前执行阶段高亮
   - 步骤执行时间显示

4. **流程历史**
   - 流程执行历史记录
   - 执行结果查看
   - 失败原因分析
   - 流程回放功能

## Impact

### 影响的现有功能

- **MODIFIED**: DevOps 工作台
  - 新增"部署流程"标签页
  - 在脚本执行界面增加"添加到流程"功能
  - 执行历史中显示流程执行记录

- **ADDED**: 新的数据库表
  - `deployment_pipelines`: 流程模板表
  - `pipeline_executions`: 流程执行记录表
  - `pipeline_steps`: 流程步骤表
  - `pipeline_step_executions`: 步骤执行记录表

### 不兼容变更

无

## Migration Strategy

1. **数据迁移**：无需迁移，新功能独立于现有功能
2. **配置迁移**：预定义流程模板通过YAML配置文件加载
3. **用户培训**：提供流程模板使用文档和示例

## Acceptance Criteria

1. ✅ 可以创建和保存部署流程模板
2. ✅ 可以一键执行完整的部署流程（测试/生产环境）
3. ✅ 流程执行过程可视化，清晰显示当前阶段
4. ✅ 支持流程步骤的并行/串行执行
5. ✅ 支持条件执行（如：测试失败则停止部署）
6. ✅ 支持流程执行历史查看和回放
7. ✅ 支持流程执行的中断和回滚
8. ✅ 预定义流程模板可以正常使用
