# Change: 准备软件著作权申请材料

## Why

为HeartSphere项目的四个核心产品（主客户端、管理平台、Mentis、教育版）准备符合国家软件著作权登记要求的申请材料。这些材料是软件著作权法律保护的基础，也是项目知识产权保护的重要环节。

当前项目已具备完整的技术实现，但缺少符合官方要求的软件著作权申请文档。需要为每个产品分别编写：
- 软件说明书（前30页+后30页，共60页）
- 源代码文档（前30页+后30页，共60页，每页不少于50行）
- 软件基本信息描述

所有材料需围绕"数字生命"主题，体现各产品的核心功能和技术特点。

## What Changes

- **新增文档**：为四个产品分别创建软件著作权申请材料
  - 主客户端（数字生命主客户端系统）
  - 管理平台（数字生命管理平台系统）
  - Mentis（数字生命Mentis智能体系统）
  - 教育版（数字生命教育版系统）

- **文档内容**：每个产品包含
  - 软件说明书：详细描述软件功能、架构、运行环境、技术特点
  - 源代码文档：精选代表性源代码，前30页+后30页
  - 软件基本信息：名称、版本、开发语言、运行环境等

- **文档位置**：在项目根目录下创建 `copyright-materials/` 目录，按产品分类组织
  ```
  copyright-materials/
  ├── main-client/          # 主客户端材料
  ├── admin-platform/       # 管理平台材料
  ├── mentis/              # Mentis材料
  └── education-edition/   # 教育版材料
  ```

- **文档格式**：符合软件著作权登记要求
  - Word文档格式（.docx）
  - 标准页眉页脚，页码规范
  - 清晰的技术描述和代码注释

## Impact

- **法律保护**：为四个产品获得软件著作权法律保护
- **知识产权**：明确项目各产品的知识产权归属
- **文档维护**：新增文档目录，不影响现有代码结构
- **影响范围**：仅新增文档，不修改任何代码
