## 🎯 强制要求

### 所有新代码必须：

1. ✅ **使用 `LazyImage` 组件**
   - ❌ 禁止：直接使用 `<img>` 标签
   - ✅ 必须：使用 `LazyImage` 组件

2. ✅ **指定 `purpose` 参数**
   - 必须使用标准场景类型
   - 禁止自定义场景类型

3. ✅ **提供 `variants` 参数（如果后端支持）**
   - 如果后端返回了多分辨率版本URL，必须传递给组件

4. ✅ **遵循标准场景类型**
   - `thumbnail`, `list`, `detail`, `background`, `chatBackground`, `original`

## 📊 统一规则

### 场景类型映射

| 场景类型 | PC端分辨率 | 移动端分辨率 | 回退策略 |
|---------|-----------|-------------|---------|
| `thumbnail` / `list` | 200×200 | 200×200 | 原图 |
| `detail` | 800×600 | 800×600 | 小缩略图 → 原图 |
| `background` | 800×600 | 800×600 | 小缩略图 → 原图 |
| `chatBackground` | 1920×1080 | 800×600 | 中等质量图 → 小缩略图 → 原图 |
| `original` | 原图 | 原图 | 无 |

## 🎓 开发者指南

### 新代码开发

1. **导入 LazyImage 组件**
   ```tsx
   import { LazyImage } from '../components/LazyImage';
   ```

2. **使用组件并指定场景类型**
   ```tsx
   <LazyImage
     src={imageUrl}
     alt="图片描述"
     purpose="thumbnail"  // 必须指定
     className="w-full h-full object-cover"
   />
   ```
