# Design: 扁平简洁风格设计

## Context

当前公司官网使用了深色主题配合复杂渐变、模糊效果和阴影的设计，用户反馈"太丑陋"。需要改进为扁平、简洁、清新的科技风格，同时保持科技感和专业感。

## Goals

1. **简洁清新**：采用扁平化设计，减少视觉噪音，提升内容可读性
2. **科技感**：通过简洁的线条、清晰的层次和现代配色体现科技感
3. **专业感**：保持专业形象，但更加友好和易读
4. **一致性**：所有页面和组件采用统一的设计语言

## Non-Goals

- 不改变功能逻辑和组件结构
- 不改变内容组织方式
- 不改变路由和导航结构
- 不改变后端API和数据处理

## Decisions

### 决策1：色彩方案
**决定**：采用浅色主题，使用清新明亮的配色
- **主背景**：白色（#FFFFFF）或极浅灰色（#F8F9FA）
- **次要背景**：浅灰色（#F1F3F5）用于卡片和区块
- **主色**：科技蓝（#3B82F6）或紫色（#6366F1），体现科技感
- **强调色**：清新的蓝色系（#0EA5E9）或绿色系（#10B981）
- **文字**：深灰色（#1F2937）主文字，中灰色（#6B7280）次要文字
- **边框**：浅灰色（#E5E7EB）用于分割和边框

**理由**：
- 浅色背景提升可读性，符合现代设计趋势
- 蓝色系体现科技感，同时保持清新
- 减少视觉疲劳，提升用户体验

**替代方案**：
- 深色主题：不符合"简洁清新"的要求
- 多彩配色：可能显得不够专业

### 决策2：扁平化设计原则
**决定**：采用扁平化设计，遵循以下原则：
- **无渐变**：使用纯色或极简的线性渐变
- **无阴影**：移除复杂的阴影效果，或使用极简的阴影
- **无模糊**：移除背景模糊和毛玻璃效果
- **简洁边框**：使用细线边框（1px）或背景色区分
- **清晰层次**：通过颜色、间距和大小建立层次

**理由**：
- 扁平化设计更现代、更简洁
- 减少视觉干扰，突出内容
- 符合当前设计趋势

### 决策3：卡片设计
**决定**：扁平化卡片设计
- **背景**：白色或浅灰色背景
- **边框**：1px 浅灰色边框，或使用背景色区分
- **圆角**：小圆角（4-8px），保持简洁
- **间距**：充足的内部间距（16-24px）
- **悬停效果**：简洁的颜色变化或轻微提升，不使用复杂阴影

**理由**：
- 扁平化卡片更现代
- 清晰的边界但不突兀
- 提升内容可读性

### 决策4：按钮设计
**决定**：扁平化按钮设计
- **主按钮**：纯色背景（主色），无渐变，无阴影
- **次按钮**：边框按钮，使用主色边框和透明背景
- **圆角**：中等圆角（6-8px）
- **悬停效果**：颜色加深或变浅，不使用缩放和阴影

**理由**：
- 扁平化按钮更现代
- 清晰的视觉反馈
- 符合扁平设计原则

### 决策5：导航栏设计
**决定**：扁平化导航栏
- **背景**：白色或极浅灰色，无模糊效果
- **边框**：底部1px浅灰色边框
- **链接**：深色文字，悬停时使用主色
- **Logo**：使用主色，无渐变

**理由**：
- 简洁清晰
- 提升可读性
- 符合扁平设计

### 决策6：Hero区域设计
**决定**：简化Hero区域
- **背景**：纯色或极简渐变，无模糊效果
- **文字**：深色文字，使用主色强调
- **按钮**：扁平化按钮设计
- **装饰**：移除复杂的背景装饰

**理由**：
- 突出核心信息
- 减少视觉干扰
- 提升可读性

## Design System

### 色彩规范

```css
/* 主色 */
--primary: #3B82F6;        /* 科技蓝 */
--primary-light: #60A5FA;  /* 浅蓝 */
--primary-dark: #2563EB;   /* 深蓝 */

/* 辅助色 */
--accent: #0EA5E9;         /* 清新蓝 */
--success: #10B981;        /* 绿色 */
--warning: #F59E0B;        /* 橙色 */

/* 中性色 */
--bg-primary: #FFFFFF;     /* 主背景 */
--bg-secondary: #F8F9FA;   /* 次要背景 */
--bg-tertiary: #F1F3F5;    /* 第三背景 */

/* 文字 */
--text-primary: #1F2937;   /* 主文字 */
--text-secondary: #6B7280; /* 次要文字 */
--text-tertiary: #9CA3AF;  /* 第三文字 */

/* 边框 */
--border: #E5E7EB;         /* 边框 */
--border-light: #F3F4F6;   /* 浅边框 */
```

### 间距规范

- **页面边距**：16px（移动端），24px（桌面端）
- **组件间距**：24px（小间距），48px（中间距），80px（大间距）
- **卡片内边距**：16px（小卡片），24px（大卡片）

### 字体规范

- **标题**：粗体，深色
- **正文**：常规，深灰色
- **次要文字**：中灰色，较小字号

### 圆角规范

- **小圆角**：4px（按钮、小卡片）
- **中圆角**：8px（卡片、容器）
- **大圆角**：12px（特殊容器）

- 更新所有卡片组件（FeatureCard、ServiceCard等）

### 阶段4：细节优化
- 优化动画效果，使其更简洁
- 调整间距和留白
- 优化响应式设计

## Risks / Trade-offs

### 风险1：失去科技感
**风险**：扁平化设计可能显得过于简单，失去科技感。

**缓解措施**：
- 使用科技感的蓝色系配色
- 保持简洁但现代的视觉元素
- 通过清晰的层次和布局体现专业性

### 风险2：视觉层次不够
**风险**：扁平化设计可能导致视觉层次不够清晰。

**缓解措施**：
- 通过颜色对比建立层次
- 使用间距和大小区分重要性
- 保持清晰的视觉引导

## Open Questions

1. **主色选择**：使用蓝色还是紫色作为主色？
2. **背景选择**：纯白色还是极浅灰色？
3. **动画效果**：是否保留动画，但简化效果？
