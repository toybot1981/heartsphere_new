# 提案总结：增强技能应用与调试体系

## 📋 提案概览

**变更ID**: `enhance-skill-application-and-debugging`  
**类型**: 架构增强 + 功能新增  
**影响范围**: 后端 AI 处理核心 + 前端聊天窗口  
**工期估计**: 5-6 周（2-3 人并行）

---

## 🎯 核心问题

当前心域系统虽然有完整的技能定义框架，但在实际应用中存在：

1. ❌ **技能应用逻辑不清晰** - 没有明确的技能选择和优先级管理机制
2. ❌ **调试可见性缺失** - 开发者无法看到技能激活的原因和过程
3. ❌ **用户体验不透明** - 用户不知道 AI 为什么使用某个技能
4. ❌ **系统间耦合度低** - 技能应用与记忆系统没有很好的协同

---

## ✨ 解决方案

### 后端系统设计

#### 1. **技能应用引擎** (Skill Application Engine)
使用多维度评分模型智能评估技能适用性：

```
综合得分 = 关键词权重(0.3) × 关键词得分 
         + 语义权重(0.3) × 语义相似度
         + 上下文权重(0.2) × 上下文匹配
         + 内存权重(0.2) × 内存触发
```

- 每个技能获得 0-100 分数
- 仅得分 > 60 的技能被考虑应用
- 按得分排序，第一个满足条件的技能被选中执行

#### 2. **执行记录追踪** (Execution Record Tracking)
创建 `skill_execution_records` 表持久化保存完整的执行生命周期：

```
- 评估阶段数据：各维度得分、匹配原因、拒绝理由
- 应用阶段数据：使用的参数、执行时长
- 结果阶段数据：执行结果、错误消息、资源使用
- 关联数据：相关的内存、对话轮次
```

#### 3. **技能-记忆关联** (Skill-Memory Correlation)
在执行记录中存储影响决策的记忆 ID，支持双向追踪：

```
技能执行 → 查询相关的内存事实
内存事实 → 查询受其影响的技能应用
```

### 前端用户界面设计

#### 1. **技能调试面板** (Skill Debug Panel)
在聊天窗口中增加与记忆调试框并列的技能调试面板：

```
┌─────────────────────────────────────┐
│  聊天窗口                            │
├──────────────┬──────────────────────┤
│ 对话内容     │  调试面板            │
│              ├──────────────────────┤
│              │  📌 技能激活 (新)    │
│              │  ├─ 技能1 [激活中]  │
│              │  │  ├─ 原因: 关键词匹配
│              │  │  ├─ 得分: 85分    │
│              │  │  └─ [详情]       │
│              │  ├─ 技能2 [已完成]  │
│              │  │  ├─ 原因: 语义匹配
│              │  │  ├─ 得分: 72分    │
│              │  │  └─ [详情]       │
│              ├──────────────────────┤
│              │  🧠 记忆调试         │
│              │  ├─ 记忆1           │
│              │  ├─ 记忆2           │
└────────────────────────────────────┘
```

#### 2. **响应中的技能标记** (Skill Usage Indication)
在 AI 响应中显示使用的技能及原因：

```
AI: "根据你的兴趣，我为你推荐..."  [技能: 推荐系统 85分]
                                      [内存触发: 你的购物历史]
```

#### 3. **内存-技能关联可视化** (Memory-Skill Correlation)
展示内存如何影响技能选择：

```
用户消息 → 关键词/语义匹配 → 查询内存 → 技能评分 → 技能应用

例如：
"我想买本书" 
  ↓
关键词匹配: "购物相关"
  ↓
查询内存: 用户偏好、购买历史
  ↓
评估技能: 推荐系统(82分), 搜索(65分)
  ↓
执行: 推荐系统技能
```

## 🔧 配置示例

```yaml
# application.yml
skill:
  application:
    enabled: true
    scoring:
      keyword-weight: 0.3          # 关键词匹配权重
      semantic-weight: 0.3         # 语义相似度权重
      context-weight: 0.2          # 上下文权重
      memory-weight: 0.2           # 内存触发权重
    threshold: 60                  # 最小应用得分
    max-concurrent-skills: 1       # 最多并发技能数
  execution:
    async-record: true             # 异步记录
    record-retention-days: 90      # 记录保留天数
    archive-batch-size: 1000       # 归档批处理大小
  debug:
    enabled: true                  # 调试模式
    detailed-logging: true         # 详细日志
```
