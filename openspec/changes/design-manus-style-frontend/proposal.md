# Change: 设计 Manus 风格的前端交互界面

## Why

参考 Manus AI 的成功界面设计（详见截图），当前 Mentis 前端界面需要重新设计，采用 Manus 的布局和风格，提供更好的用户体验。

当前前端存在的问题：
1. **界面布局不统一**：缺少类似 Manus 的清晰左右分栏布局
2. **会话管理分散**：没有统一的会话列表和操作区
3. **任务显示不直观**：任务列表和进度显示不够清晰
4. **虚拟机界面缺失**：缺少实时虚拟机操作和显示界面
5. **交互体验不一致**：不同功能模块的交互方式不统一

通过采用 Manus 的布局风格，可以：
- 提供统一的会话管理体验（左侧会话列表，右侧操作区）
- 动态显示任务列表（当任务分解时自动显示）
- 动态显示虚拟机界面（当需要虚拟机执行时自动创建和显示）
- 统一会话操作（不区分标准会话、任务会话、VM 会话）
- 根据工具执行环境自动切换界面（智能显示相关界面）

## What Changes

### 核心界面设计

1. **统一会话界面** (`unified-session-ui`)
   - 左侧边栏：会话列表、项目列表、任务列表
   - 右侧主内容区：对话界面、任务详情、虚拟机终端
   - 底部输入框：统一的消息输入（支持文本、语音、附件）
   - 顶部工具栏：操作按钮（协作、分享、设置等）

2. **任务列表显示** (`task-list-display`)
   - 当任务分解时，自动在左侧显示任务列表
   - 任务列表显示任务步骤、状态、进度
   - 点击任务可查看详情和执行日志
   - 任务完成后自动更新状态

3. **虚拟机操作界面** (`virtual-computer-view`)
   - 当需要虚拟机执行时，自动创建虚拟机并在右侧显示
   - 虚拟机终端实时显示命令执行
   - 虚拟机屏幕预览（VNC 或截图）
   - 虚拟机控制按钮（重置、暂停、恢复等）

4. **动态布局系统** (`dynamic-layout`)
   - 根据会话状态动态调整布局
   - 根据工具执行环境自动显示相关界面
   - 支持多面板同时显示（对话 + 任务 + 虚拟机）
   - 响应式设计，适配不同屏幕尺寸

### 设计原则

- **统一会话模型**：所有会话使用相同的界面和操作方式
- **智能界面切换**：根据任务需求自动显示相关界面
- **实时反馈**：实时显示 AI 思考过程、任务进度、虚拟机状态
- **Manus 风格**：采用 Manus 的视觉设计和交互模式

## Impact

- **Affected specs**: 
  - 新增 `unified-session-ui` capability
  - 新增 `task-list-display` capability
  - 新增 `virtual-computer-view` capability
  - 新增 `dynamic-layout` capability
  - 可能修改现有的前端相关能力（如果存在）

- **Affected code**:
  - `mentis/frontend/src/components/` - 重新设计主要组件
  - `mentis/frontend/src/pages/` - 重新设计页面布局
  - `mentis/frontend/src/services/` - 可能需要新增服务
  - `mentis/frontend/src/styles/` - 新增 Manus 风格样式

- **Breaking changes**: 
  - **BREAKING**: 现有前端界面将完全重构
  - 现有组件可能需要重写或大幅修改
  - 路由和导航结构可能改变

- **Dependencies**:
  - 可能需要新增 UI 组件库（如果现有库不支持所需组件）
  - 可能需要新增 VNC 客户端库（noVNC 或类似）
  - 可能需要新增图表库（用于任务流程图）
