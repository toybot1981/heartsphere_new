# 快速开始指南

## 前置要求

1. **hsmem服务运行**
   ```bash
   cd hsmem
   python3 rest_api_server.py
   ```
   服务将在 `http://localhost:8000` 启动

2. **Admin前端环境**
   - Node.js 和 npm/yarn 已安装
   - 项目依赖已安装

## 配置步骤

### 1. 配置hsmem服务地址（可选）

如果hsmem服务不在默认地址运行，需要配置环境变量：

创建或编辑 `.env.local` 文件：
```bash
VITE_HSMEM_BASE_URL=http://localhost:8000
```

### 2. 启动Admin前端

```bash
cd admin/frontend
npm run dev
# 或
yarn dev
```

## 使用指南

### 访问记忆管理模块

1. 登录Admin后台
2. 导航到"记忆管理"模块
3. 可以看到以下标签页：
   - **系统概览** - 查看hsmem服务状态和统计信息
   - **记忆测试** - 测试记忆化功能
   - **用户记忆** - 管理用户记忆（包含HSMem查询）
   - 其他原有标签页...

### 记忆测试功能

#### 测试对话记忆
1. 点击"记忆测试"标签页
2. 选择"对话记忆"子标签
3. 输入用户和助手的对话消息
4. 可选：输入用户ID和代理ID
5. 点击"测试对话记忆"按钮
6. 查看测试结果（资源ID、记忆项数量、分类信息）

#### 测试文本记忆
1. 在"记忆测试"标签页选择"文本记忆"子标签
2. 输入文本内容
3. 可选：输入上下文信息（JSON格式）
4. 可选：输入用户ID
5. 点击"测试文本记忆"按钮
6. 查看测试结果

#### 测试文档记忆
1. 在"记忆测试"标签页选择"文档记忆"子标签
2. 输入文档标题和内容
3. 可选：输入作者和用户ID
4. 点击"测试文档记忆"按钮
5. 查看测试结果

### 记忆查询功能

1. 点击"用户记忆"标签页
2. 切换到"HSMem查询"子标签
3. 输入查询文本（例如："用户喜欢什么？"）
4. 可选：输入用户ID进行过滤
5. 可选：设置返回数量限制
6. 点击"查询记忆"按钮
7. 查看查询结果列表
8. 点击"查看详情"查看记忆项详细信息

### 查看统计信息

1. 点击"系统概览"标签页
2. 查看HSMem服务状态卡片：
   - 服务健康状态
   - 资源总数
   - 记忆项总数
   - 分类总数
3. 点击"刷新HSMem数据"按钮更新统计信息

## 常见问题

### Q: 服务连接失败
**A:** 检查：
- hsmem服务是否运行在配置的地址
- 服务地址是否正确（默认：http://localhost:8000）
- 网络连接是否正常
- CORS配置是否正确（hsmem已默认配置）

### Q: 测试功能无响应
**A:** 检查：
- hsmem服务是否正常运行
- 浏览器控制台是否有错误信息
- 网络请求是否成功（打开开发者工具查看Network标签）

### Q: 查询结果为空
**A:** 可能原因：
- 数据库中确实没有匹配的记忆
- 查询条件过于严格
- 先使用记忆测试功能创建一些记忆，然后再查询

### Q: 删除功能不可用
**A:** 这是正常的。hsmem API当前未提供删除接口，删除功能需要等待API支持。

## 测试建议

### 完整测试流程

1. **服务连接测试**
   ```
   1. 启动hsmem服务
   2. 访问Admin记忆管理模块
   3. 查看"系统概览"，确认服务状态为"healthy"
   ```

2. **记忆测试流程**
   ```
   1. 测试对话记忆：创建一段对话并记忆化
   2. 测试文本记忆：创建一段文本并记忆化
   3. 测试文档记忆：创建一篇文档并记忆化
   4. 验证所有测试都返回成功结果
   ```

3. **查询测试流程**
   ```
   1. 使用记忆测试功能创建一些记忆
   2. 使用查询功能搜索刚创建的记忆
   3. 验证查询结果包含预期的记忆项
   4. 测试用户ID过滤功能
   5. 测试数量限制功能
   ```

4. **错误处理测试**
   ```
   1. 停止hsmem服务
   2. 尝试进行测试或查询
   3. 验证错误提示是否友好
   4. 重新启动服务
   5. 验证功能恢复正常
   ```
