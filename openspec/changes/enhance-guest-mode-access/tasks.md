## Phase 2: User Creation & Authentication

- [x] 2.1 创建独立的游客登录接口 `POST /api/auth/guest-login`
  - 在 `AuthController` 中创建 `guestLogin()` 方法
  - 自动创建临时用户（生成唯一用户名）
  - 为临时用户分配体验会员
  - **不初始化个人场景和角色**（游客使用系统预置内容）
  - 生成JWT Token并返回
  - 返回预置场景和角色ID（硬编码）

- [x] 2.2 创建独立的游客注册接口 `POST /api/auth/guest-register`
  - 在 `AuthController` 中创建 `guestRegister()` 方法
  - 检测当前用户是否为游客（体验会员）
  - 更新用户信息（用户名、密码、邮箱）
  - 升级会员类型为正式会员
  - **初始化个人场景和角色**（首次创建）
  - 生成新的JWT Token并返回

- [x] 2.3 实现临时用户名生成策略
  - 格式：`guest_<timestamp>_<random>`
  - 确保用户名唯一性

- [x] 2.4 修改前端登录流程
  - 更新游客登录逻辑，调用 `POST /api/auth/guest-login`
  - 更新游客注册逻辑，调用 `POST /api/auth/guest-register`
  - 处理游客登录响应（Token、用户信息、isGuest标志）
  - 保存游客状态到本地存储
  - 加载预置场景和角色数据

- [ ] 2.5 测试游客登录和注册流程
  - 验证用户创建成功
  - 验证会员分配正确
  - 验证登录状态正常
  - 验证注册升级流程正常
