## Phase 2: 用户创建和认证测试

### 2.1 游客登录测试
- [ ] **测试步骤**:
  1. 打开前端应用
  2. 点击"游客登录"或"以游客身份进入"
  3. 输入昵称（可选）
  4. 提交登录请求

- [ ] **预期结果**:
  - 后端自动创建临时用户（用户名格式: `guest_<timestamp>_<random>`）
  - 自动分配体验会员
  - 返回JWT Token
  - 返回用户信息，`isGuest: true`
  - 返回预置场景ID（50）和角色ID列表（315-320）
  - 前端成功登录并显示预置场景和角色

- [ ] **验证点**:
  - 检查数据库中是否创建了新用户
  - 检查用户是否分配了体验会员
  - 检查Token是否有效
  - 检查前端是否正确显示预置内容

### 2.2 游客注册测试
- [ ] **测试步骤**:
  1. 以游客身份登录
  2. 点击"注册"按钮
  3. 填写注册信息（用户名、邮箱、密码、昵称）
  4. 提交注册请求

- [ ] **预期结果**:
  - 后端检测到当前用户为游客
  - 更新用户信息（用户名、密码、邮箱）
  - 升级会员类型为正式会员
  - 初始化个人场景和角色
  - 返回新的JWT Token
  - 前端成功升级并显示初始化向导

- [ ] **验证点**:
  - 检查用户信息是否正确更新
  - 检查会员类型是否升级
  - 检查是否创建了默认场景
  - 检查用户ID是否保持不变（数据迁移）
