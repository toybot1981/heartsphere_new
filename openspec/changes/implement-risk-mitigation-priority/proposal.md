# Change: 实施风险缓解优先级任务

## Why

在系统大重构（refactor-split-into-subprojects）开始前，需要实施风险缓解优先级任务，以降低重构过程中的风险。根据风险分析，识别了 21 个风险，其中 7 个高风险项需要重点关注。

为了确保重构顺利进行，需要在迁移前完成以下优先级任务：
1. 建立代码分析工具和流程
2. 创建技术培训计划
3. 建立 API 兼容层
4. 创建统一构建脚本

这些任务将帮助团队：
- 提前识别和预防代码重复问题
- 降低依赖管理的学习成本
- 减少 API 路径变更带来的影响
- 简化构建和部署流程

## What Changes

### 1. 代码分析工具和流程

- **安装和配置代码分析工具**（SonarQube 或 CodeClimate）
- **建立代码重复度基线**，设定目标值（< 3%）
- **集成到 CI/CD**，自动检测代码重复度和依赖关系
- **建立代码分析报告机制**，定期生成分析报告

### 2. 技术培训计划

- **准备 Maven 多模块项目培训材料**，包含实际操作示例
- **准备 npm/yarn workspace 培训材料**，包含实际操作示例
- **安排技术培训**（2-3 次，每次 2 小时）
- **创建操作手册和 FAQ**，覆盖常见问题

### 3. API 兼容层

- **设计 API 路径兼容机制**，支持旧路径重定向到新路径
- **实现 API 兼容层**，在迁移过渡期保留旧 API 路径
- **建立 API 路径映射表**，记录旧路径到新路径的映射
- **创建 API 迁移工具**，自动更新前端 API 调用

### 4. 统一构建脚本

- **创建统一构建脚本**（build-all.sh），支持单独构建和联合构建
- **创建各子项目构建脚本**（build-client.sh、build-admin.sh 等）
- **优化构建流程**，支持并行构建和缓存
- **集成到 CI/CD**，支持多项目构建

## Impact

### 影响的文件

- **新增文件**:
  - `scripts/setup-dev.sh` - 开发环境设置脚本
  - `scripts/build-all.sh` - 统一构建脚本
  - `scripts/build-client.sh` - 客户端构建脚本
  - `scripts/build-admin.sh` - 管理端构建脚本
  - `scripts/build-mentis.sh` - Mentis 构建脚本
  - `scripts/migrate-api-paths.sh` - API 路径迁移脚本
  - `docs/development-guide.md` - 开发指南
  - `docs/faq.md` - 常见问题解答
  - `docs/code-analysis-baseline.md` - 代码分析基线报告

- **修改文件**:
  - `.github/workflows/ci.yml` 或 CI/CD 配置文件 - 集成代码分析检查
  - `backend/pom.xml` - 添加代码分析插件配置
  - `frontend/package.json` - 添加代码分析脚本

### 影响的规范

- **代码质量规范**: 建立代码重复度要求（< 3%）
- **构建规范**: 建立统一构建流程
- **API 规范**: 建立 API 兼容层使用规范
- **开发规范**: 更新开发指南，包含新的工具和流程

### 影响的工作流

- **开发工作流**: 开发环境设置流程更新
- **构建工作流**: 构建流程统一和优化
- **CI/CD 工作流**: 集成代码分析检查
- **培训工作流**: 新增技术培训流程

## Notes

- 这些任务需要在系统大重构开始前完成（阶段 0：风险缓解准备）
- 预计完成时间：2 周
- 这些任务将为后续的重构工作奠定基础，降低重构风险
- 所有工具和脚本应该易于使用和维护
