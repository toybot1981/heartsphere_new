# Change: Add Database Migration Scripts

## Why

需要建立本地开发环境数据库和生产环境数据库之间的迁移机制。本地开发环境不断更新，需要能够安全地将本地数据库的变更（包括表结构变更和系统数据更新）同步到生产环境，同时保护生产环境中的用户数据。

## What Changes

- **ADDED**: 数据库迁移脚本系统，支持：
  1. 对比本地和远程数据库的表结构差异
  2. 自动创建远程数据库中不存在的表
  3. 自动更新远程数据库中表结构变更（字段添加、修改、索引变更等）
  4. 系统数据的完全同步（系统配置表、系统预设数据等）
  5. 用户数据的部分更新（仅更新图片相关数据）
- **ADDED**: 迁移脚本位于 `deploy/` 目录，包含：
  - 主迁移脚本（Shell 脚本）
  - 表结构对比工具
  - 数据同步脚本
  - 配置文件和文档

## Impact

- **Affected specs**: 数据库迁移能力（新能力）
- **Affected code**: 
  - `deploy/` 目录下新增迁移脚本
  - 可能需要在 `main/backend/` 中提供数据库结构导出工具
- **Database**: 
  - 本地数据库（MySQL，localhost:3306，root/123456）
  - 生产数据库（MySQL RDS，rm-bp1bg7xxnka508amyvo.mysql.rds.aliyuncs.com:3306，heartsphere/Tyx@19811009）

## Principles

1. **不删除远程数据库**: 迁移过程中绝不删除生产环境的数据库或表
2. **表结构增量更新**: 只添加缺失的表和字段，不删除现有字段
3. **系统数据完全同步**: 系统相关数据（system_* 表）完全按照本地数据更新
4. **用户数据部分更新**: 普通用户相关数据仅更新图片相关字段（avatar_url, image_url 等）
5. **安全第一**: 所有操作前进行备份检查，支持回滚机制
