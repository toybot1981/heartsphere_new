# Change: 优化Mobile端UX体验

## Why

根据用户反馈和截图分析，当前Mobile版本存在以下严重的UX问题：

1. **TabBar遮挡问题**: 底部导航栏（TabBar）遮挡页面内容，导致用户无法看到或操作被遮挡的元素
2. **导航功能失效**: TabBar和返回键无法正常返回，影响用户导航体验
3. **登录页面问题**: 登录页面按钮过大，比例不协调，不符合移动端设计规范
4. **布局问题**: 页面内容区域未考虑TabBar高度，导致内容被遮挡
5. **安全区域适配**: 部分页面未正确处理iOS安全区域（Safe Area），导致内容被状态栏或底部指示器遮挡
6. **视觉风格不统一**: 缺乏统一的扁平化、简洁、科技感的设计风格

这些问题严重影响用户体验，需要进行整体规划和优化。

## What Changes

- **修复TabBar遮挡问题**:
  - 为所有页面内容区域添加底部内边距，避免被TabBar遮挡
  - 统一使用安全区域适配（Safe Area Insets）
  - 确保滚动区域正确计算可用高度

- **修复导航功能**:
  - 修复TabBar导航功能，确保点击能正确跳转
  - 修复返回键功能，确保能正确返回上一页
  - 统一导航状态管理

- **优化登录页面**:
  - 调整按钮尺寸，符合移动端触摸目标规范（最小44x44px）
  - 优化页面布局和比例
  - 改进表单元素大小和间距

- **建立Mobile UX规范**:
  - 定义统一的移动端设计风格（扁平化、简洁、科技感）
  - 制定布局规范（安全区域、TabBar高度、内容区域）
  - 制定组件规范（按钮、表单、卡片等）
  - 制定交互规范（触摸反馈、动画、手势）

- **统一视觉风格**:
  - 统一色彩系统（符合科技感、扁平化、温馨风格）
  - 统一字体系统
  - 统一间距系统
  - 统一圆角和阴影

## Impact

- **影响的文件**:
  - `frontend/mobile/components/MobileBottomNav.tsx` - TabBar组件优化
  - `frontend/mobile/MobileApp.tsx` - 主应用布局优化
  - `frontend/mobile/screens/*.tsx` - 所有移动端页面组件
  - `frontend/components/LoginModal.tsx` - 登录页面优化
  - `docs/12-开发指南/开发规范/心域开发指南.md` - 添加Mobile UX规范章节
  
- **影响的规范**:
  - 新增Mobile UX设计规范章节
  
- **影响的工作流**:
  - 所有Mobile页面开发必须遵循新的UX规范
  - 代码审查需要检查UX规范符合性

## Notes

- 此变更将建立完整的Mobile UX规范，作为后续开发的指导标准
- 优先修复严重的遮挡和导航问题
- 逐步优化现有页面以符合新规范
- 新页面必须严格遵循规范
- **特殊说明**: `MobileConnectionSpaceScreen`（心域连接星空页面）的视觉设计和交互体验已经比较满意，**尽量不改动**。如果存在TabBar遮挡等技术问题，可以修复，但保持现有的星空动画、布局和视觉风格不变
