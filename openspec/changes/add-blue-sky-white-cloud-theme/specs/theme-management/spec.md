## ADDED Requirements

### Requirement: 蓝白主题（蓝天白云风格）
系统 SHALL 提供一个新的主题选项 "蓝天白云"（`blue-sky-white-cloud`），具有以下特征：

#### Scenario: 用户选择蓝白主题
- **WHEN** 用户在设置中选择 "蓝天白云" 主题
- **THEN** 系统应用蓝白主题的CSS变量
- **AND** 背景显示为天空蓝渐变（从浅天蓝到深天蓝）
- **AND** 卡片背景显示为白色云朵效果（半透明白色，带柔和云朵纹理）
- **AND** 文字颜色为深蓝色系（确保在浅色背景上清晰可读）
- **AND** 按钮和强调元素使用蓝色渐变

#### Scenario: 主题颜色对比度
- **WHEN** 蓝白主题被应用
- **THEN** 所有文字颜色与背景颜色的对比度符合WCAG AA标准（≥4.5:1）
- **AND** 主要文字与背景对比度≥7:1（确保清晰可读）

#### Scenario: 心域连接页面星辰效果
- **WHEN** 用户在蓝白主题下访问心域连接页面（ConnectionSpace）
- **THEN** 背景显示为蓝天渐变（从浅天蓝到深天蓝）
- **AND** 背景包含云朵效果（使用CSS径向渐变创建）
- **AND** 画布上布满闪烁的星辰（数量根据画布大小动态调整）
- **AND** 星辰具有明显的脉冲闪烁动画效果
- **AND** 心域星辰（代表角色的星辰）具有特殊光晕效果（蓝色和粉色光晕）
- **AND** 星辰颜色包括白色、淡蓝色、淡粉色（心域色）

#### Scenario: 移动端适配
- **WHEN** 用户在移动设备上使用蓝白主题
- **THEN** 心域连接页面的星辰效果正常显示
- **AND** 动画流畅（≥30fps）
- **AND** 性能优化（根据设备性能调整星辰数量）

#### Scenario: 主题切换
- **WHEN** 用户从其他主题切换到蓝白主题
- **THEN** 主题立即切换，无闪烁或延迟
- **AND** 所有组件正确应用新主题的颜色变量
- **AND** ConnectionSpace组件正确应用增强的星辰效果
