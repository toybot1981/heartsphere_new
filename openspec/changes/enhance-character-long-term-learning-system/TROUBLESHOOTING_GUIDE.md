如果您遇到问题，请按以下步骤快速定位：


## A. 页面崩溃/加载失败

### 症状
- 页面显示空白或 "无法连接"
- 浏览器控制台出现红色错误
- 部分组件不显示

### 快速诊断

```bash
# 1. 检查网络连接
ping api.heartsphere.com

# 2. 打开浏览器开发者工具 (F12)
# 3. 检查 Console 标签页的错误信息
# 4. 查看 Network 标签页的请求状态
```

### 常见原因和解决方案

#### 原因 1: API 服务不可用

**错误信息**: `Failed to fetch` 或 `Connection refused`

**检查**:
```bash
# 检查后端服务是否运行
curl http://localhost:8080/actuator/health

# 应该返回类似:
# {"status":"UP","components":{"db":{"status":"UP"}}}
```

**解决**:
```bash
# 启动后端服务
cd /path/to/backend
./gradlew bootRun

# 或使用 Docker
docker start heartsphere-backend
```

#### 原因 2: 认证过期

**错误信息**: `401 Unauthorized` 或 `Invalid token`

**检查**:
```javascript
// 在浏览器控制台运行:
console.log(localStorage.getItem('token'));
```

**解决**:
```javascript
// 清除本地数据并重新登录
localStorage.clear();
sessionStorage.clear();
// 然后刷新页面重新登录
location.reload();
```

#### 原因 3: CORS 错误

**错误信息**: `Access to XMLHttpRequest blocked by CORS policy`

**检查**: 查看浏览器开发者工具 Network 标签页，找到 OPTIONS 请求

**解决**:
```yaml
# 后端配置 (application.yml)
spring:
  web:
    cors:
      allowed-origins: 
        - http://localhost:3000
        - https://heartsphere.com
      allowed-methods: GET,POST,PUT,DELETE,OPTIONS
      allowed-headers: "*"
```

## B. 功能不工作

### 症状
- 按钮点了没反应
- 数据没有保存
- 搜索功能无法使用
- 反馈提交失败

### 快速诊断

```bash
# 1. 打开浏览器开发者工具 Network 标签
# 2. 执行操作
# 3. 观察是否有 API 请求
# 4. 检查请求状态 (200? 400? 500?)
# 5. 查看响应内容
```

### 常见原因和解决方案

#### 原因 1: 权限不足

**错误信息**: `403 Forbidden`

**检查**:
```javascript
// 检查当前用户权限
console.log(localStorage.getItem('user'));
```

**解决**:
- 确认您有访问该角色的权限
- 联系管理员升级权限
- 尝试退出登录并重新登录

#### 原因 2: 参数验证失败

**错误信息**: `400 Bad Request` 和具体错误信息

**检查**: 查看错误信息中的详细说明

**常见情况**:
```
错误: "Content contains sensitive information"
→ 内容包含敏感信息，无法保存
→ 解决: 移除电话、邮箱等个人信息

错误: "Similar asset already exists"
→ 已存在相似的资产
→ 解决: 检查现有资产是否已包含该知识，或修改内容使其更独特

错误: "Title cannot be empty"
→ 标题为空
→ 解决: 填写有意义的标题
```

#### 原因 3: 服务器错误

**错误信息**: `500 Internal Server Error`

**检查**:
```bash
# 查看服务器日志
tail -f /var/log/heartsphere/application.log | grep ERROR

# 查看最后 100 行日志
tail -100 /var/log/heartsphere/application.log
```

**解决**:
1. 尝试刷新页面
2. 检查是否有服务器维护通知
3. 联系技术支持并提供错误代码

## C. 数据不正确

### 症状
- 角色等级不对
- 知识资产消失了
- 反馈没有更新信任度
- 学习进度停止

### 快速诊断

```bash
# 1. 重新加载页面 (Ctrl+F5)
# 2. 清除浏览器缓存
# 3. 等待数据刷新 (最多 60 秒)
# 4. 查看是否有错误通知
```

### 常见原因和解决方案

#### 原因 1: 缓存过期

**现象**: 看到旧数据

**解决**:
```javascript
// 清除浏览器缓存
// 方法 1: 按 Ctrl+Shift+Delete (Windows) 或 Cmd+Shift+Delete (Mac)
// 方法 2: 右键页面 → 检查 → Storage → Clear Site Data
// 方法 3: 强制刷新 (Ctrl+F5)
```

#### 原因 2: 定时任务未执行

**现象**: 等级长期不变

**检查**: 这是正常的，定时任务每天凌晨 2 点自动运行

**解决**:
- 等待下一个运行周期（最多 24 小时）
- 或联系管理员手动运行衰减任务

#### 原因 3: 数据库同步延迟

**现象**: 提交了数据但还看不到

**检查**: 等待 30 秒后刷新

**解决**:
```javascript
// 手动重新加载数据
// 方法: 点击组件上的 "🔄 刷新" 按钮
```

#### 原因 4: 信任度计算错误

**现象**: 提交反馈后信任度没有变化

**检查**:
```sql
-- 查看最近的反馈记录
SELECT * FROM character_knowledge_assets 
WHERE id = {资产ID}
ORDER BY updated_at DESC LIMIT 1;

-- 查看学习历史
SELECT * FROM character_learning_history 
WHERE asset_id = {资产ID}
ORDER BY created_at DESC LIMIT 5;
```

**解决**:
- 通常延迟 5-10 秒，等待后刷新
- 如果 1 分钟后还没有更新，重新提交反馈

## D. 性能变慢

### 症状
- 页面加载缓慢
- 操作响应慢
- 搜索结果延迟大

### 快速诊断

```bash
# 1. 打开浏览器开发者工具 → Performance 标签
# 2. 记录一个操作
# 3. 检查哪个步骤最慢
```

### 常见原因和解决方案

#### 原因 1: 网络连接慢

**检查**: 打开 Network 标签，查看请求时间

**解决**:
- 检查网络连接速度
- 切换到 WiFi（如果正在使用移动网络）
- 稍后重试

#### 原因 2: 知识库过大

**现象**: 搜索结果很多时很慢

**检查**:
```sql
-- 查看角色有多少资产
SELECT COUNT(*) FROM character_knowledge_assets 
WHERE character_id = {角色ID};

-- 如果数字很大（> 1000），这是原因
```

**解决**:
- 使用更具体的搜索关键词
- 使用筛选减少结果数量
- 管理员可以清理低质量资产

#### 原因 3: 服务器繁忙

**现象**: 所有操作都很慢

**检查**: 在不同时段重试

**解决**:
- 服务器可能在处理大量请求
- 避免在高峰时段执行大量操作
- 稍后重试

#### 原因 4: 浏览器问题

**现象**: 只在某个浏览器上慢

**解决**:
```bash
# 尝试以下操作:
# 1. 清除浏览器缓存
# 2. 禁用浏览器扩展
# 3. 尝试隐私模式
# 4. 更新浏览器
# 5. 尝试其他浏览器
```

## E. 错误消息

### 常见错误信息速查表

| 错误信息 | 含义 | 解决方案 |
|---------|------|--------|
| **Network error** | 网络连接问题 | 检查网络，重试 |
| **Failed to fetch** | 无法连接到服务器 | 检查 API 是否运行 |
| **401 Unauthorized** | 认证失败 | 重新登录 |
| **403 Forbidden** | 权限不足 | 检查权限或联系管理员 |
| **404 Not Found** | 资源不存在 | 检查 ID 是否正确 |
| **500 Internal Server Error** | 服务器错误 | 查看日志或联系支持 |
| **Timeout** | 请求超时 | 检查网络或重试 |
| **Sensitive info detected** | 包含敏感信息 | 移除个人信息 |
| **Similar asset exists** | 资产重复 | 检查现有资产 |
| **Database connection error** | 数据库连接失败 | 检查数据库状态或重启 |
