## 系统概述

### 什么是长期学习系统？

角色长期学习系统是一套让您的数字角色随着时间推移而变得越来越聪明的机制。系统会：

- 📚 **自动记录** 对话中的有价值信息
- 🧠 **智能提取** 可以重复使用的知识
- 📊 **追踪进度** 角色的成长和经验积累
- ⭐ **评估质量** 根据用户反馈调整知识价值
- 🔄 **持续优化** 不断完善和更新知识

### 为什么这很重要？

**传统系统**: 每次对话都从零开始，角色无法从过往经历中学习。

**长期学习系统**: 角色就像真实的人一样，通过不断学习和实践变得更加专业。

## 核心概念

### 1. 角色等级 (Experience Level)

角色会根据累积的知识和经验获得不同的等级：

#### 等级结构

```
🆕 L1 新手   ──→  🌱 L2 初级   ──→  📚 L3 中级   ──→  ⭐ L4 高级   ──→  👑 L5 专家
  (0-5)            (6-20)           (21-50)           (51-100)          (>100)
```

#### 等级特性

| 等级 | 名称 | 能力 | 特征 |
|------|------|------|------|
| L1 | 新手 | 基础回答 | 刚开始学习，回答可能不够准确 |
| L2 | 初级 | 正确回答简单问题 | 掌握基本概念，可靠性提高 |
| L3 | 中级 | 处理大多数常见问题 | 知识丰富，可以给出详细答案 |
| L4 | 高级 | 处理复杂和边界情况 | 经验丰富，能理解微妙之处 |
| L5 | 专家 | 提供专业级别的建议 | 知识渊博，可信度最高 |

### 2. 知识资产 (Knowledge Assets)

系统会自动提取和存储四种类型的知识：

#### 资产类型

```
┌─────────────────────────────────────────────────────────────┐
│                        知识资产分类                          │
├──────────────┬──────────────┬──────────────┬──────────────┤
│ 领域知识      │ 交互技巧      │ 决策规则      │ 经验模式      │
│              │              │              │              │
│ 通用的专业   │ 如何更好地   │ 特定情况下   │ 重复出现的    │
│ 知识和理论   │ 与用户交互   │ 的决策标准   │ 行为模式      │
│              │              │              │              │
│ 例: 投资原理  │ 例: 简化复  │ 例: 何时推  │ 例: 用户    │
│    、财务知识 │    杂概念    │    荐某产品  │    常见问题  │
└──────────────┴──────────────┴──────────────┴──────────────┘
```

### 3. 信任度 (Trust Score)

每个知识资产都有一个 0-100% 的信任度评分，代表该知识的质量和可靠性：

- 📈 **创建时**: 50% (初始评分)
- 👍 **收到正面反馈**: +5%
- 👎 **收到负面反馈**: -10%
- 😴 **长期未使用**: -2% (每天)
- ✅ **被使用**: 保持或提高

## 提交反馈

### 为什么反馈很重要？

您的反馈帮助系统：
- ✅ 识别高质量的知识
- ❌ 找出有问题的资产
- 📈 自动调整信任度
- 🎓 让角色不断改进

### 如何提交反馈

#### 方式 1: 在对话后反馈

对话完成后，您可能会看到反馈提示：

```
这个回答对您有帮助吗？
👍 有帮助   👎 没帮助   💬 提供反馈
```

点击相应的按钮来提交反馈。

#### 方式 2: 在知识库中反馈

在知识库查看器中，您可以对每个资产进行评分：

```
┌────────────────────────────────────────┐
│ 投资风险管理基础                        │
│ [领域知识] [已批准] ✅                  │
│                                        │
│ 完整内容...                            │
│                                        │
│ 这个知识对您有帮助吗?                  │
│ 👍 有帮助 (5个已有此评价)              │
│ 👎 没帮助 (1个已有此评价)              │
│ 💬 添加详细反馈                        │
└────────────────────────────────────────┘
```

### 反馈示例

**好的反馈:**
- ✅ "这个解释很清楚，帮我理解了股票基础"
- ✅ "这个建议对我的投资决策很有帮助"
- ✅ "完全同意这个看法，很实用"

**不好的反馈:**
- ❌ "不好"
- ❌ "觉得不对"

**改进的反馈:**
- ✅ "这个观点过于保守，不适合所有投资者"
- ✅ "应该加入更多关于风险管理的内容"
- ✅ "这个例子可能对初学者来说太复杂了"

## 常见问题

### Q1: 为什么我看到一些资产还在 "待审核" 状态？

**A:** 新创建的资产需要管理员审核以确保质量。待审核的资产仍然可以使用，但信任度相对较低。审核通常在 24 小时内完成。

### Q2: 等级不变的原因是什么？

**A:** 可能的原因：
1. 新资产还没有收集到足够的反馈
2. 最近的反馈是负面的，降低了平均信任度
3. 资产长期未使用，信任度自动衰减
4. 已达到最高等级 (L5)

### Q3: 我能手动创建知识资产吗？

**A:** 是的！如果您想在没有对话的情况下添加知识，可以联系管理员或使用管理面板手动创建。

### Q4: 旧资产会被删除吗？

**A:** 系统会自动清理质量很差的资产（信任度 < 20% 且 60 天未使用），但优质资产会被永久保留。

### Q5: 多个用户的反馈如何计算？

**A:** 系统使用加权平均：
- 最近的反馈权重更高
- 历史反馈权重较低
- 这确保系统对最新趋势敏感

### Q6: 为什么某些内容被标记为 "不能保存"？

**A:** 出于隐私保护，系统自动检测并阻止包含以下内容的资产：
- 电话号码、邮箱、身份证等个人信息
- 家庭成员名字、亲属关系等隐私信息
- 高度个人化的经历

这是为了保护用户隐私。

## 最佳实践

### 1. 充分利用多个角色

不同的角色可能会学到不同的知识。同时使用多个角色可以获得更多元的视角。

### 2. 定期查看等级进度

定期检查角色的等级可以帮助您了解系统的工作进度。

### 3. 提供详细的反馈

相比简单的 "好" 或 "坏"，详细的反馈更有帮助：
- ✅ "这个建议对初学者来说太复杂了"
- ❌ "不好"

### 4. 参与持续改进

如果您发现资产有问题，立即提交反馈。系统会根据您的反馈调整其行为。

### 5. 关注角色特性

不同类型的角色可能在不同领域表现更好。选择最合适的角色来完成特定任务。

### 6. 理解信任度的含义

信任度高的资产并不一定是绝对真理，而是反映了基于用户反馈的相对可靠性。

### 7. 利用搜索功能

当您记不清具体知识时，使用知识库搜索可以快速找到相关资产。

## 隐私和安全

### 您的数据安全吗？

是的！系统采用了多层安全措施：
- 🔒 所有通信都是加密的
- 🔐 敏感信息自动检测并阻止
- 👤 您的个人信息与知识资产分离
- 📋 所有操作都有审计日志

### 我能删除我的数据吗？

可以。您可以：
1. 请求删除特定对话
2. 请求删除您的账户
3. 导出您的所有数据

请联系隐私团队了解详细流程。
