## 🎯 快速参考

### 常用命令

```bash
# 编译后端
cd backend && ./gradlew clean build

# 运行测试
./gradlew test

# 启动应用
java -jar app.jar

# 检查健康状态
curl http://localhost:8080/actuator/health

# 查看日志
tail -f /var/log/heartsphere/application.log
```

### 常用 API

```bash
# 获取角色统计
GET /api/memory/v1/character/{id}/stats

# 创建知识资产
POST /api/memory/v1/character/{id}/assets

# 提交反馈
POST /api/memory/v1/assets/{id}/feedback

# 查询相关资产
GET /api/memory/v1/character/{id}/related-assets
```

### 常用配置

```yaml
# 定时任务配置
heartsphere.memory.scheduled.decay-job.cron: "0 0 2 * * *"

# 隐私检测配置
heartsphere.memory.sensitive-info.enabled: true

# 相似度检测配置
heartsphere.memory.similarity.threshold: 0.75
```
