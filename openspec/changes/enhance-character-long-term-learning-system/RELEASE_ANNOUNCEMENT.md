## 🚀 快速开始

### 1. 环境要求

```
- Java 17+
- Spring Boot 3.2.0+
- MySQL 8.0+
- Redis 6.0+
- Node.js 18+ (前端)
```

### 2. 快速部署

```bash
# 1. 克隆代码
git clone https://github.com/heartsphere/heartsphere.git
cd heartsphere

# 2. 配置数据库
mysql -u root -p < main/backend/src/main/resources/db/migration/V20260122__add_character_learning_system.sql

# 3. 启动后端
cd main/backend
./gradlew bootRun

# 4. 启动前端
cd ../frontend
npm install
npm run dev
```

### 3. 验证安装

```bash
# 运行验证脚本
./scripts/verify_character_learning_system.sh

# 或查看快速启动清单
cat openspec/changes/enhance-character-long-term-learning-system/QUICK_START_CHECKLIST.md
```
