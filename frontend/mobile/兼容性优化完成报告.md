### 1. 平台检测工具 ✅

#### 文件
- `frontend/utils/platform.ts`

#### 功能
- 平台类型检测（`browser`、`wechat-miniprogram`、`unknown`）
- 安全访问 `window`、`document`、`localStorage`、`navigator`

#### 使用示例
```typescript
import { isBrowser, isWeChatMiniProgram, safeWindow, getSystemInfo } from '../utils/platform';

if (isBrowser) {
  // 浏览器环境
}

if (isWeChatMiniProgram) {
  // 微信小程序环境
}

const window = safeWindow();
const systemInfo = getSystemInfo();
```

### 2. 存储兼容层 ✅

#### 文件
- `frontend/services/storage/platformStorage.ts`

#### 功能
- 统一的存储接口（`StorageAdapter`）
- 浏览器适配器（使用 `localStorage`）
- 微信小程序适配器（使用 `wx.storage`）
- 异步API（兼容微信小程序）

#### 使用示例
```typescript
import { platformStorage } from '../services/storage/platformStorage';

await platformStorage.setItem('key', 'value');
const value = await platformStorage.getItem('key');
await platformStorage.removeItem('key');
await platformStorage.clear();
const keys = await platformStorage.getAllKeys();
```

### 3. Token存储兼容 ✅

#### 文件
- `frontend/services/api/base/tokenStorage.ts`

#### 修改内容
- 更新为使用 `platformStorage`
- 保留同步API（向后兼容）
- 新增异步API（推荐使用）

#### 使用示例
```typescript
import { getToken, saveToken, removeToken } from '../services/api/base/tokenStorage';

// 同步版本（向后兼容）
const token = getToken();
saveToken('token');

// 异步版本（推荐，支持微信小程序）
import { getTokenAsync, saveTokenAsync } from '../services/api/base/tokenStorage';
const token = await getTokenAsync();
await saveTokenAsync('token');
```

### 4. 网络请求兼容层 ✅

#### 文件
- `frontend/services/api/base/platformRequest.ts`

#### 功能
- 统一的请求接口（`platformRequest`）
- 浏览器适配器（使用 `fetch`）
- 微信小程序适配器（使用 `wx.request`）
- 兼容的响应格式

#### 使用示例
```typescript
import { platformRequest } from '../services/api/base/platformRequest';

const response = await platformRequest('/api/endpoint', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(data),
});

const data = await response.json();
```

## 📝 需要修改的代码

### 1. 替换 localStorage 使用 ⚠️

#### 需要修改的文件
- `frontend/mobile/MobileApp.tsx` - 11处 `localStorage.getItem('auth_token')`

#### 修改方法
```typescript
// 修改前
const token = localStorage.getItem('auth_token');

// 修改后（同步版本，向后兼容）
import { getToken } from '../services/api/base/tokenStorage';
const token = getToken();

// 或使用异步版本（推荐）
import { getTokenAsync } from '../services/api/base/tokenStorage';
const token = await getTokenAsync();
```

### 2. 替换 window 对象访问 ⚠️

#### 需要修改的文件
- `frontend/mobile/MobileApp.tsx` - `window.confirm` 使用

#### 修改方法
```typescript
// 修改前
if (window.confirm('确认？')) { ... }

// 修改后
import { safeWindow } from '../utils/platform';
const window = safeWindow();
if (window && window.confirm('确认？')) { ... }
```

### 3. 替换 fetch 使用 ⚠️

#### 需要修改的文件
- `frontend/services/api/mailbox/mailbox.ts` - 多处 `fetch` 使用
- 其他直接使用 `fetch` 的文件

#### 修改方法
```typescript
// 修改前
const response = await fetch('/api/endpoint', options);

// 修改后
import { platformRequest } from '../services/api/base/platformRequest';
const response = await platformRequest('/api/endpoint', options);
```
